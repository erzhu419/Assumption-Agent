# 0.131—0.154方向复核

[逐批原始结果汇总](paired_version_history.json)核对25次正式比较：0.135—0.137的同批结构发现明显改善，0.148—0.154七批中六批平均误差上升。各批装置、任务族和部分预算不同，不能连乘百分比；0.131的完成状态也不能和后来的严格预测达标直接比较。0.132/0.132.1曾明确保留0.131默认入口，后期多个失败候选却继续成为下一批比较的源码基线。

本轮固定原0.131任务重新比较其冻结源码与冻结0.154：两臂同12装置、六阶段、每题240观测/240000计算、Gaussian噪声0.01，全部24条学习链及自然回访结束后才执行144项共同终测。无API调用、无源码修改。旧0.131的72题误差、学习费用与完成状态精确复现历史结果。

相同旧任务的平均响应误差上升40.69%、总计算上升175.32%、CPU上升45.83%；12条链中10条退步、1条改善，另1条只相差5.25e−18，视为数值相同；六个阶段的均值全部变差。[完整比较](old_capability_anchor/comparison.json)保留各题及费用。原reader严格比较得到的13胜16平43负仅作为原始计数留档；用明确的浮点同值比较（`math.isclose`，相对容差1e−9、绝对容差0）后为9胜25平38负。该处理只合并约1e−17及更小的舍入差，未更改学习、终测、均值或成功标准。实际最终报告中，旧版72次含噪响应提案、51次选择及确认在新版均为0；新版增加73次条件配对实验研究、280次配对干预评估。该动作变化提示研究入口与资源分配问题，尚非单项功能的因果消融。

## Limitations

这是已见旧任务的能力保留诊断，不是新任务泛化或编码模型切换的因果试验。采用原文档引用且仍存在的共同实验工厂；未找到另存的历史runner字节副本，但旧版全部题结果与费用本次精确复现。含噪任务没有设成功阈值，完成状态不代表已通过精度验收。对照双方均为完整黑格尔机，当前普通Code／同一LLM比较仍待完成。
