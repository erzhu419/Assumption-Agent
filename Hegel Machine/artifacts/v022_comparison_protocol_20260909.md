# 0.22 预先固定的完整比较与小实验协议

## 完整任务序列

固定种子为 **5501、4507、6781**。6781 在本轮实现与结果之前预选；它的独立质量结果不用于设计生产代码。5501、4507 使用已完成的 0.21 最终结果，不重复旧基线。

| 种子 | 0.21 基线 | 0.22 比较 |
| --- | --- | --- |
| 5501 | `hegel_machine_v021_final_seed5501_paired_20260909.json` | 冻结后完整新跑 |
| 4507 | `hegel_machine_v021_final_seed4507_paired_20260909.json` | 冻结后完整新跑 |
| 6781 | 从 `v022_baseline_source_20260909` 的 0.21 快照新跑，标签 `v022_baseline` | 冻结后完整新跑 |

每个种子和每个臂都从空知识库开始。按 development、confirmation、forward、continual、stateful 的原顺序运行全部 **65 题**。每访上限保持 **96 观测、24000 计算、5 研究轮**，每题最多2访；每臂共享上限 **12480 观测、3120000 计算**。停止规则、访问选择和实际总费用均保留。

两个臂保持原定义：methods 正常选择方法；ordinary 仅令 `ResearchMethods.choose` 与 `opportunity` 返回 None。其它研究、知识、决策实验及反馈继续启用。因此臂间比较回答方法选择的作用，跨版本比较回答整套0.22改动的作用，不能混为同一个因果结论。

每个种子的两个完整研究臂都停止后，才调用原 `evaluate_session` 生成独立结果。报告全部任务、全部费用、预测损失、决策损失及方法/决策实验实际行为，保留负收益和无改进结果。若发现可复现执行错误，保留该轮产物并单独标记，不覆盖为修复后的结果。

执行脚本：`artifacts/run_v022_complete_sessions_20260909.py`。默认运行三个固定种子，也可用 `--seed 5501` 等单独运行，便于安排独立进程；`--label` 只区分保存产物，不改变研究策略。现阶段只准备，等生产冻结后运行。

## 针对实验投入的小对照

固定开发种子 **1237**，覆盖开发套件中所有公开 `decision_costs` 非空的任务，不根据独立误差或收益挑题。每题先完成一次真实研究，保存同一时刻的工作区、知识库、已付轨迹、部署方案和实际未决问题。各实验臂从该 JSON 状态的独立副本开始。新seed6781不参与这些开发案例。

| 臂 | 实际行为 | 要回答的问题 |
| --- | --- | --- |
| 固定代表两轨迹 | 对已经冻结的完整方案，购买原0.21的两条代表轨迹并比较 | 原便宜实验获得什么证据、花了多少费用？ |
| 针对性探查 | 从当前公开候选、已付证据和可控变量构造能区分当前决策的实验，实际执行并记录结果 | 有目标的实验是否比固定代表轨迹更能区分当前方案？ |
| 证据冲突后追加 | 先执行相同针对性探查；仅在实际证据留下尚未解决的冲突且有可执行后续实验时追加投入 | 追加实验是否产生足以改变方案的证据，其净收益是否值得费用？ |

另保留“立即停止”的部署方案作为零追加费用的参照。它不购买研究观测；最终只承担单列的评价费用。

第五臂为同预算的完整 `CognitiveAgent` 修订访问。这样“冲突后追加”就是实际生产短运行，与完整访问直接比较，不重复运行一个名称不同的相同短流程。

小对照每臂的追加总上限保持 **96 观测、24000 计算**。允许不同臂实际少花费用，不把耗尽预算当完成目标。针对性探查与冲突追加必须走生产实际执行链；入口冻结后再接 runner，不在脚本中仿制另一套选择算法。可在实验侧关闭一个具体新机制形成对照，但不新增生产开关。

具体候选在观察比较结果前冻结。原两代表轨迹臂继续执行原已付工作区上可用的方案比较，不能用旧的最终评分代替当前执行。任何臂若没有真实未决问题，应记录 `no_executable_question` 并保持零追加费用；预算不足保留问题。追加分支不能根据隐藏任务标签、评价结果或预设“必须采纳”来触发。

所有任务和所有臂都研究停止后，再用每题相同的16条独立轨迹评分。报告预测 pinball、固定成本下的 decision loss、每轨迹差值、真正发生的方案/规则变化，以及全部追加观测、仪器费用、实验设计计算、比较计算和后续研究费用。区分“缩小了不确定性”“改变了实际决策”“降低了独立损失”；过程完成不能替代后两者。

小对照脚本为 `artifacts/run_v022_decision_experiments_20260909.py`。三个短臂都调用生产 `run_decision_research`：固定代表两轨迹仅在实验进程中让 `decision_research.plan_decision_probes` 返回 `{}`、`_additional_decision_pair` 返回 `[]`；针对性探查仅关闭后者；冲突后追加不修改任何生产调用。采纳、比较和反馈逻辑保持完全相同。没有可执行定向包时，按生产流程退回代表轨迹并如实记录。

初次实际访问的随机种子为 `1237 + task_index * 10007`，各追加臂共用 `initial_seed + 1000003`。独立评价使用 `visit_seed + 2000003`。所有任务和臂都停止后才购买独立评价轨迹，评价费用单列。过程出错保留失败产物，不覆盖成成功。

三种子新旧费用、按损失类型的独立质量、实际短运行与未决问题由 `artifacts/summarize_v022_complete_sessions_20260909.py` 汇总，并逐种子单列预先指定的 `n11` 任务实际两访行为与决策损失。

全部脚本在生产冻结后才运行；固定种子、任务选择、费用上限、对照含义和评价顺序不随实现结果更改。
