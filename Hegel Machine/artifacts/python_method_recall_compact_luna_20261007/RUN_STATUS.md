## Limitations and next step

These are repeated attempts on one development failure state, with four calls per attempt, not independent task confirmation or evidence that recall never works. The interface and readout work; reliable model adoption remains unresolved. Next, connect the historical supported-parent rule to candidate replacement: retain the supported program as an executable incumbent, test missing cases, and compare a proposed rewrite against that incumbent before replacing it. Preserve the failed batches rather than extending them until success.
