# 真实Luna会话对照：知识可用，尚无额外收益

固定4组旧装置×保留／清空知识，共8次订阅`gpt-6-luna`尝试。
两臂共享工具、72行消费者前缀及限制，由LLM自行选择研究和提交；全部停止后统一做128行终评。

| 结果 | 保留知识 | 逐题研究 |
|---|---:|---:|
| 确认且终评正确 | 3 | 3 |
| 调用耗尽、未提交 | 1 | 0 |
| 服务容量中断 | 0 | 1 |
| 自主回访／来源收益确认 | 0 | 0 |

排除服务中断所在配对后，三组结果为2/3对3/3。消费者观测均288行，测量72／0，调用23／20，token597,151／524,046。计入共同来源生产后，观测均864行、测量720／648。6个提交均通过终评，最大MSE为`2.14e-17`，无错误确认。

保留组实际调用仪器、响应、历史长度算子各一次，但无人选择原生研究、回访或显式来源确认。失败案`1120077`第三次调用已得到打印为零的轨迹留出误差，随后改用不完整特征、重复分析，最终未提交。

共55次调用，54次报告usage，已知token至少1,382,508；输入缓存命中706,816／1,367,434（51.69%）。容量失败不是超时，未补跑。协议、冻结源码和原始轨迹保存在本目录；数字见[summary.json](summary.json)、[analysis.json](analysis.json)。

## Limitations / 下一步

来源由已有离线研究器生产，四组装置此前已测，逐题组也有全部研究工具。本批检验知识可用性，不代表完整框架的普遍比较。普通Python拟合以执行时间记录，host计算账不是全部运算量。两次`manifest:null`提交错误在后续调用中自行纠正；接口修复发生于本批之后，原费用和结果保留。

下一步复用已有“机制变化→修订→旧条件返回”任务，并把已有候选比较接入研究选择，让有效解释及时保留和确认。当前可直接拟合的任务不再扩大刷分；缺口是研究决策及知识采用，而不是继续增加工具数量。
