# 已声明子题接回持续研究（2026-10-08）

复用历史 online recurse、DiscoveryWorld 数值 binding、既有 `inquire`、`contrast` 与 `evaluate`；补齐未测、无数值绑定的子题路由。宿主只安排模型已经声明的子题，子层与父层共用账户；同一父调用内不重复自动委派，并保留父层决策机会。

同时修复两个实际接口问题：嵌套实验及镜像视图反复内联导致请求超限；改用新实验文件后，分析仍错误绑定旧实验自身的 `answer`。独立修复的分析文件继续保留。145项相关用例通过，其中33项新增。

子题来源是上一轮 `discoveryworld_local_focus_20261008` 中模型的原始决策，原样重放；其调用与用量作为继承成本，不计入本轮新增量。这是操作者选择起点的条件开发续跑。四次新增超限失败均保留并计入账户。各阶段原始 `result.json`、`brief.json`、实际模型文件与宿主源码均在本目录对应子目录。

条件续跑合计29次新增请求（25次有效决策、4次输入超限）、1,232个新世界动作、18次有限实验执行、51次程序执行及18次子答案回传；累计31/32调用时模型主动finish，最终13/29。18次实验包含同一问题的反复修订，不是18个独立发现。新增reported tokens为8,764,418，其中input 8,724,094、output 40,324、cached input 212,480（已包含在input内）；普通入口单独计费见[汇总](summary.json)。

已观察到“子答案返回→提出有限实验→实测否定→改写实验”，并有自主纠错：误用1000-Hz按钮时先判目标未达，下一轮改正并实测2301 Hz。自动子研究只有1次，其最初答案使用旧付费证据；宿主没有提供新的科学变量、公式、频率或实验程序。新路径绑定修复由回归测试确认，不能将后续同路径改稿的正确分析归因给该分支。

## Limitations

本次没有新机制规律、父研究程序的有效改稿或任务收益。未采样的整数和非整数设置仍未被排除；模型最终只否定实际采样点并承认任务未解。每次设计只有一个扫频实验与“这批会成功／不会成功”两个命题；这不等于有解释力的候选竞争。旧多实验选择及表示修订入口已经存在，本段未采用不同研究方向。

下一步核验既有父研究复议：新的否定子答案目前连续触发同一子比较的下一轮。父委派、原程序入口及动作权限都完整，是否由这种焦点安排促成反复扫频仍需同现场对照，不能直接认定是模型无权限或旧选择器失效。
