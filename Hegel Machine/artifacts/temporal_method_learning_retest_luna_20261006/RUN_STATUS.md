# Method-learning retest: executable artifact, incomplete method

The repaired learner receives the complete downstream API and must actually
invoke its authored procedure on an empty new task before publication. It
then freezes the method for four independent transfers at new seed 99206007.
Both conditions retain identical predictive files, old plan and verbal lessons.

| Condition | Independently correct | Transfer rows | Transfer calls | New-method calls |
|---|---:|---:|---:|---:|
| Retain method | 1/2 | 204 | 20 | 1 |
| Delete method | 1/2 | 288 | 21 | 0 |

Both finite tasks confirm and pass 256-row evaluation. Both recurrent tasks
stop at the token boundary without a confirmed predictor; there are no false
confirmations. Including the shared original learning gives 396/480 rows.
The 43 new calls report 2083969 tokens; 49.52% of input tokens are cache hits.
Six method-learning tests and twelve base inquiry/runner tests pass.

The [Luna-authored program](consolidation/shared/consolidated_method.py) only
returns four short meter trajectories. It has no post-acquisition operators
and does not use current evidence to change its plan. Its one executed reuse
repeats the old acquisition plan on the finite task. No method is rewritten.
In both recurrent tasks the agents keep extending history or fitting response
coefficients against the old instrument, rather than successfully assessing
and rebuilding the changed instrument. Lower acquisition counts therefore do
not establish an effective research-method gain.

Limitations: two small development cohorts use different paired apparatuses;
API and publication changes are not isolated interventions. The donor is a
selected successful paid development experience, not a population sample.
One-shot retrospective consolidation has not learned a complete adaptive repair
procedure, and these traces do not establish online recursive decomposition.

training task, return its actual failure evidence to the method learner, revise
it, then freeze it before a new transfer/deletion comparison. Retain both this
