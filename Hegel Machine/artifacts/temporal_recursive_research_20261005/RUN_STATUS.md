# Prospective temporal research

The offline controller confirms and independently solves 24/24 targets across
12 new paired apparatuses. Each final program is frozen before 48 fresh
confirmation rows and a separate 256-row terminal sample (MSE threshold 1e-10).

| Procedure | Finite memory | Recurrent state |
|---|---:|---:|
| Frozen short-source model | 0/12 | 0/12 |
| Expanded quadratic history | 12/12 | 0/12 |
| Three-lag quadratic refit on the same paid response rows | 12/12 | 0/12 |
| Adaptive history / instrument-child research | 12/12 | 12/12 |

All finite cases stop after a supported history revision, with no meter cost.
All recurrent cases open the instrument question before measuring. Fifteen
short measured rows retain finite and recurrent explanations; their predicted
disagreement selects a four-step probe. Its evidence chooses the recurrent
program, which becomes a coordinate of the parent's fitted quadratic response.
Worst recurrent terminal MSE is 7.36e-17, versus 0.00762–0.316 for the same-data
history control. Source cost is 48 rows; target cost is 144 rows for finite
cases and 163 rows plus 57 measurement units for recurrent cases.

Eight focused tests pass, including an intervention that replaces the returned
child answer and breaks the parent prediction. This run makes zero model calls.
`plan.json`, per-case programs, paid records, event traces and `summary.json`
contain the procedure and results; previous LLM outcomes remain unchanged.

Limitations: this is a developer-authored bounded algorithm in two known task
families. The controls isolate representation repair, not superiority over a
flat researcher with the same instrument-model candidates. Recursive procedure
invention, current-task LLM advantage and cross-domain transfer remain untested.

Next: give a flat adaptive control the same candidate operations and instruments,
then use the common LLM interface to test selection and reuse of these operations.
