12链均实际删除了1个已确认采用源：root04/10为concept_0003，其余为concept_0001。保留知识相对删源：噪声均值−6.42%、条件均值−27.97%、条件达标63对51、compute−3.84%；但噪声链为2胜1平9负，条件链为6胜3平3负。平均收益受少数大变化影响，不能称稳定贡献。

候选实际记录26次目标绑定撤回；禁新增撤回后，156题误差与记账费用逐项相同。撤回接口生效，但本批没有展示额外优化收益。候选190次普通独立确认、5259行确认数据；首次compute14,878,356、回访6,070,874、筛查11,837,586。

**限制。** 仅两类既有生成机制的13阶段新实例；删源是首次确认采用前的条件干预，保留之前已付证据与经验，并给定完整臂的回访机会。已有接触与替代知识均可能存在。root07删源曾漏撤一个未执行问题，失败原始记录保留且仅该根从原fork重跑；[额外运行开销](deletion_runner_failure.json)单列。baseline4与候选至多8 workers，CPU不用于声称速度改善。旧157开发不混入正式结果。相关测试54通过、2个历史tail失败保留。
