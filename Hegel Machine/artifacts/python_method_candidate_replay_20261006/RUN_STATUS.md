# 冻结的学得研究程序已跑通

最后一次 Luna 写出的[原样程序](candidate.py)通过三类源实践，再在另外两份假设档案的六个目标上全部通过新确认及独立终评。两次旧条件直接复用原假设；两次参数变化完成重拟合；两次仪器变化完成“旧假设反例 → 重拟合不足 → 仪器测量与验证 → 响应修订 → 新确认”。六例最大终评 MSE 为 6.34e-19。

| 六个迁移目标 | 学得程序 | 固定程序 |
|---|---:|---:|
| 新确认且终评通过 | 6/6 | 6/6 |

学得程序观测多 14.29%、计算多 11.53%，主要因为先购买新数据反驳旧假设，再修订。重放全程零模型调用；另三次源实践耗费 384 行、144 测量、5,803 计算。此前所有作者阶段共 49 次调用、2,015,212 已知 tokens，另一次用量未知，已报告输入缓存命中 40.11%。旧失败及各轮固定参考费用全部保留在 [summary.json](summary.json)。

## 限制与下一步

这是对未发布的最后候选进行外部冻结评估，作者自主完成发布仍未实现。新产物是条件化研究步骤，拟合器和状态模型族复用既有工具；探测序列来自已付费记录，记录编号依赖当前共同前缀。两份迁移档案属于已有仪器家族。重拟合验证通过、随后新确认失败的分支仍可能重复提交，未由本批覆盖。

本轮已给论文补上窄机制证据，尚无整体性能或成本优势。后续重点是让方法修订及时进入实际检验和发布，并处理新确认反驳替代模型的情形；不再以反复措辞调整代替机制改进。本轮相关测试 20 项通过。
