## Limitations

这是开发环境的接入实验，候选由作者提交；不是模型自主发明新仪器。成功依赖操作性候选预测及实测，末次 `nonlocal_progress=0`，未建立全族联合预测收敛。此环境提供新仪器，不能把此前无新测量的三例pilot改报为3/3；没有新增正式DiscoveryWorld或同预算Agent优势结果。
