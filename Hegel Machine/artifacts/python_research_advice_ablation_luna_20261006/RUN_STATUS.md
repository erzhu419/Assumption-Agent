配对结果为1胜、0负、3平。两个参数任务调用分别4／7、4／5；两个结构任务均各用12次。展示建议少14.15% token、24.02%计价计算，多50%测量。观测少240行全部来自第二结构配对，两臂在该题均未完成。

成功结构轨迹中，旧解释失败后，Agent购买仪器读数、拟合候选、调用区分实验，再实测并评估仪器；支持唯一候选后改写父响应，完成新确认，终评MSE `1.09e-18`。该配对两臂各付144测量单位，对照继续拟合控制历史且新确认失败。[成功轨迹](trial_003/training.json)、[对照轨迹](trial_002/training.json)。

建议由已付结果生成，不额外拟合或购买数据。展示组15个有后续动作的建议中，6个与下一动作及所要求参数精确匹配；改名、延后执行不计为立即匹配。隐藏组7个对应机会没有精确匹配，该计数只表示反事实一致性。一次参数修订实际调用了原源码 `refit`；成功结构题实际执行了仪器子研究并消费其结果。68项相关测试通过，覆盖建议隐藏、旧候选保留、新反例及完整反馈链。

本批实际68次调用、2,096,640 tokens，无服务中断，usage全部有记录。输入缓存1,033,728／2,077,456，命中49.76%。原有两次来源学习的11次调用、281,866 tokens单列在summary中，本轮未重新消费。

## Limitations / 下一步

这是两个已研究装置上的四个开发任务，测的是建议展示；尚不足以证明稳定收益或完整黑格尔机相对普通Agent的优势。第二结构题收到区分建议后仍转回高阶历史拟合，已付数据MSE近零而新确认MSE `4.18e-4`，12次调用耗尽。现存 `instrument_action` 能从持久记录恢复该子问题，但普通Python操作后未继续呈现它。下一步补这处衔接，并在新装置上检验是否减少研究中断；本批结果保留，不以再次重放替代失败。
