# Independent random source retention/delete receipt

Generated by `scripts/run_source_feedback_random_retention.py` under the
0.181.0 continuation line. It runs two arms over the same ten-task sequence:
eight independently drawn transition mechanisms and two compatible anchor
tasks. Offers are screened once from the common warm library, then both arms
use the same per-task minimum resource cap (`24` observations and `438`
compute units). The feedback arm retains source returns; the matched arm
deletes them after each visit. External model calls are zero.

Both arms spend `330` observations and `1,290` compute units, with `24`
observations and `120` actual compute units on every executed task. Feedback
selects the repaired source on the two compatible anchors; the matched arm
selects the stale source. The eight independently drawn mechanisms select the
same source and have identical held-out losses in both arms. This supports a
local source-feedback effect while providing no evidence of a stable random
long-horizon gain or general source contribution.
