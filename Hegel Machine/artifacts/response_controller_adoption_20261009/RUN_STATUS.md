## Limitations 与下一步

直接控制已被模型自主采用，第一例失败仍来自科学研究而非长动作列表失控。两个新提案均相容，因此本轮没有“收到可靠排除后成功改稿”的新在线证据；五项旧提案前置排除证据继续见上一轮报告。历史两例都失败，本轮一例成功，但非随机配对归因，不能把差异全部归因于接口。下一科学缺口是将实验选择与新结构修订从扫描、近似点拟合中分离；三臂结果同时要求保留实际求解和预测确认两个目标。
