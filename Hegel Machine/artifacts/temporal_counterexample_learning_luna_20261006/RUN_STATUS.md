# Parent counterexample becomes a reusable research-method revision

Luna receives one actual paid response-only failure, the original first donor and
old method. It makes one source edit, practices three opaque cases and publishes
in five calls: 166,174 tokens, 408 observations, 648 measurement units and 25,233
computation units.
Second-donor and transfer outcomes are unavailable during authoring. New/existing
practice and study tests pass 12 cases. No provider or operator failure occurs
during authoring.

Every revised response case executes: 72 measured rows support the old instrument;
48 fresh rows refute its old parent prediction; the program uses those 120 paid rows
to refit only the response; another 48 rows confirm it. Terminal MSE is 5.79e-18–8.59e-16.
No extra measurement or instrument refit occurs. All 18 run the published source,
without LLM calls. The other 10 cases preserve old fresh/terminal outcomes exactly.

Transfer observations: 2928→2544; measurement: 3888 unchanged; computation: 183048→200712.
Authoring is additional. Cached input: 36608/164478 (22.3%); total new model calls: 5.
Original numerical priors remain unchanged inputs; training-fitted models do not transfer.

## Limitations and next step

This is explicitly prompted repair within supplied operator families. Related
calibration cases are not independent population samples. The learned branch uses
any failed confirmation as its trigger; all tested activations concern a supported
instrument and refuted response. Next test whether method revisions distinguish
other failure sources. This old/new frozen contrast does not complete the earlier
capacity-interrupted live comparison or establish overall resource superiority.
