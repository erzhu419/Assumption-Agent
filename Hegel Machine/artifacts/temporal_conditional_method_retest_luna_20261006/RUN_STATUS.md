## Limitations and next step

The interface works, but evidence-conditioned method learning remains unestablished.
The seed immediately refits the apparatus, removing the initial contrast between
valid and invalid prior knowledge. Next use paired unchanged/changed mechanisms
with the same frozen earlier calibration; test whether one final program uses
actual support to retain or repair it. No further single-situation retake is planned.
