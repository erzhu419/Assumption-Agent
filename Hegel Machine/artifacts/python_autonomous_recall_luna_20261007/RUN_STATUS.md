# 自主取回与论文收束

复用0.77/0.92的父方法保留机制及现有实践历史，把各稿最新实测支持直接呈现给作者。20次固定Luna尝试从同一失败状态开始；两组均关闭主机自动选回，共用八次调用及原六案例发布门槛。

保留组7次原样发布、1次取回后编辑发布；2次已取回但调用耗尽未提交。移除组全部尝试改写，5次token耗尽、3次调用耗尽。两组各一次可恢复JSON格式错误，已计费；无终止性服务失败或未知用量。共107次新增实践、123次模型调用，输入缓存命中23.94%。保留／移除组观测7392／14704、测量4104／19920、计算310562／1235959。

起点旧稿只通过case_5，选回后仍须补齐自己的其他案例。7个原样发布共享此前12/12目标证据一次，本轮新增目标执行为0；三份编辑后发布的程序只有本轮源案例证据。

14项相关测试通过。英文论文已按框架与研究问题重组，完整开发轨迹保留在附录F。

## Limitations与下一步

这是单一历史失败状态的重复决策；两组同预算，因既有实践数5／4而不使用相同确认随机流。相较此前四调用实验，本轮同时改变摘要、指令和调用上限，不能单独归因于摘要。跨任务稳定性与长期收益仍待验证；下一实验应换失败状态并检验研究收尾。当前先完成论文，不再扩展数值求解器。
