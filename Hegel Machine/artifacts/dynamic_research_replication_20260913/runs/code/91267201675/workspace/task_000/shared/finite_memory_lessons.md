Task 000: deterministic two-lag polynomial response. Instrument observations identified meter[t] = a*u[t] + b*u[t-1] + c*u[t-1]^2 and target[t] = d + e*u[t] + f*meter[t]^2 + g*meter[t-1]. Expanding these equations eliminates the paid meter. The resulting 11-term control-only basis had full rank on 96 instrumented observations and predicted an independent 32-row control-only trajectory with maximum error below 3e-15. Missing pre-trajectory controls are zero.

shared/lagged_polynomial.py provides ordinary least-squares fitting for explicit finite-memory monomial bases. Refit coefficients on each task. Its zero-padding and finite-memory assumptions need evidence before reuse; persistent state, noise, or different nonlinearities may require a different basis or model. Repeated plateaus identify memory length; varied transitions identify interactions.
