# 0.23 固定比较协议

本轮先保存当前 **0.22.0** 的54个认知源码文件及包入口到 `artifacts/v023_baseline_source_20260909/hegel_machine`。随后实现可以继续；新增种子的旧基线只导入此快照中的全部 cognition 模块。正式依赖沿用未变的现有包路径。

## 四种子完整序列

固定种子为 **5501、4507、6781、7919**。7919 在本轮结果产生之前预选，其独立质量不用于设计新机制。

| 种子 | 0.22 比较基线 | 0.23 |
| --- | --- | --- |
| 5501 | 已完成 `v022_release`，不重跑 | 冻结后实际完整配对 |
| 4507 | 已完成 `v022_release`，不重跑 | 冻结后实际完整配对 |
| 6781 | 已完成 `v022_release`，不重跑 | 冻结后实际完整配对 |
| 7919 | 从0.22源码快照实际运行，标记 `v023_baseline` | 冻结后实际完整配对 |

每种子按 development、confirmation、forward、continual、stateful 顺序运行全部 **65题**。每臂从空知识库开始；每访最多 **96观测、24000计算、5轮**，每题最多 **2访**，每臂共享上限 **12480观测、3120000计算**。最低改善量仍为0.002，不改变停止规则或判定阈值。

methods 使用正常方法选择；ordinary 仅关闭 `ResearchMethods.choose` 与 `opportunity`，保留所有其它研究机制。两个完整臂均停止后才生成独立评分，报告每种子、每臂的全部预测损失、决策损失、首访/续访/全局总费用、实际研究行为及未决问题。

原三种子基线文件为 `hegel_machine_v022_release_seed{seed}_paired_20260909.json`；7919文件为 `hegel_machine_v023_baseline_seed7919_paired_20260909.json`。保留旧结果与失败运行，新版本使用 `v023_release`。进程可以并发，不能把已提交任务当作完成。

执行脚本：`artifacts/run_v023_baseline_seed7919_20260909.py` 与 `artifacts/run_v023_complete_sessions_20260909.py`。四种子汇总脚本保留全部两个臂跨版本结果，并将详细决策/n11诊断放入独立文件。

## 同一付费状态的小对照

固定种子 **1237**，按 development、confirmation、forward、continual、stateful 五个分区的同一顺序，包含公开 `decision_costs` 非空的全部 **7道风险任务**，不用独立损失选题。每题从空知识库完成一次真实初访，保存同一时刻的工作区、知识库、解释程序、已付数据及实际候选校准。这项扩展在任何0.23小对照执行前固定，覆盖n11且保留所有其它公开风险题。

对同一个实际解释程序，比较 nominal 决策与实际研究拟合出的校准决策；不在实验脚本中构造更优模型，不仿制采纳算法。随后从同一份已付 JSON 状态的独立副本执行停止、实际短决策问题、完整修订，后两者继续使用相同96/24000上限。没有实际短问题记为无可执行问题，预算不足保留待办。

初访种子为 `1237 + global_task_index * 10007`，global_task_index是上述65题顺序中的位置；追加访问共用 `initial_seed + 1000003`；所有任务和全部臂停止后，用 `visit_seed + 2000003` 的同一16条独立轨迹评分。先前拟合、比较、观测费用不抹去；新增请求与计算按实际记入本臂，评价费用单列。采纳与否、预测改善、校准后的真实决策改善分别报告。

小对照脚本为 `artifacts/run_v023_calibration_continuation_20260909.py`，五臂为 nominal、实际 proposed_calibration、停止、短问题、完整修订。初始两个模型直接读取生产 `compare_initial_calibration` 动作保存的 previous/candidate 完整方案，不额外拟合或修改生产调用。只有与初访最终predictor相同的真实已付候选参与初始校准比较；没有候选明确记为 unavailable，单列可配对任务，不能填入一个假校准方案。

所有入口在生产冻结后才执行，不根据结果改变种子、任务、预算或采纳阈值。脚本保留未决与失败；可读摘要只含费用、标量质量、实际行动和逐轨迹损失，完整模型仍在原始结果中。

跨普通、测量、结构与延迟实验的 ResearchAgenda 小演示单列为功能和费用证据，不并入65题风险研究的因果比较。

## 已知失败后的费用分配修复

原 `v023_release` 全部结果保留。4507 f02 与7919 c08 暴露启动检索挤占已报价拟合费用；分别从原0.23源码重现36访、42访前缀，截取真实下一访入口。新旧Controller使用相同工作区、知识库、方法、观测/计算预算和16条新评价轨迹执行。这是已知失败条件的修复诊断。

随后 `v023_corrected` 使用相同四种子、任务、预算和阈值完整复跑，同时对比原release与0.22基线。这些种子的结果已经看过，复跑不作为新的独立确认。
