# Which revision is needed?

The [protocol](protocol.json) specifies 30 new apparatus instances. Each naturally
learns A, B and C once, then clones its library into three conditions: unchanged,
total-response gain 1.35, and event radius 0.45. Each condition is followed by a
return to the original response. The gain changes the contribution of A; the
radius changes B while the total remains conserved. Public task descriptions and
measurement interfaces are identical, and control seeds are matched.

The agent algorithm is unchanged. Every successor has its own task allowance and
carries only its branch's library. There is no inserted challenge or cross-task
budget borrowing. All learning precedes terminal evaluation. The shared prefix
is evaluated once, giving 270 research outcomes; 180 additional frozen-C
predictions are a separately charged prediction reference.

`run_cohort.py` imports the adjacent frozen `runtime/`. [summary.json](summary.json)
contains all cases, phase results, exact source calls, charged resources and
paired cost differences between conditions. Case files retain full successor
actions and transfer attempts. The separate development instance is excluded
from the 30-case analysis. Three targeted tests passed in
`tests/test_revision_choice_study.py`. All runs are offline.

All 270 research outcomes passed terminal evaluation and fresh confirmation.
The frozen C reference passed 30/30 unchanged first successors and 0/30 in each
changed condition; all 90 original returns passed. Unchanged tasks reused C;
gain changes refitted A/B without relation experiments; all radius-change cases
purchased relation-discriminating evidence. First-successor mean observations
were 24.00 / 40.00 / 113.07, and computation was 427.00 / 529.33 / 107,719.20.
All successors retained the exact original component definitions. All 90 returns
called C and added no new response concept. See manuscript Section 5.5.

This is a boundary test for the first paper's retention-and-revision claim.
The gain and radius changes have different complexity; their cost difference is
not an algorithm comparison. Missing stop reasons remain unknown. General
applicability discovery, new structural families and long-horizon amortization
remain follow-up research.
