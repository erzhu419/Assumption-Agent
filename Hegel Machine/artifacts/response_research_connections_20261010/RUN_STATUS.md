# 研究知识与父子交接的三处接线修复

复用[修前分析](../response_refuted_author_return_20261010/child_return_audit/ANALYSIS.md)定位的历史实现，未增加求解器或替研究者指定新假设。

- 普通族比较继承仍适用的已付完整排除，计算不足不再抹去旧结论。真实 after3 恢复全族排除研究义务；after1 的平方族、after2 的三次族仍有相容见证。计算表示和条件子族分别保留原适用范围。
- 实测提案因子题暂缓时保留交还关系；子题返回后，用当前父绑定、族结论和已复核证据重审。新证据尚未比较或父方法改变时继续由作者研究。
- 响应作者可以执行其稿件的关联试验，取得实测后的预览回传；点反驳保留独立子题，旧父答案和正式采用路径保留。

最终整合后的16项针对性检查通过，覆盖父子交还、已付排除、作者试验和父层采用的交互。各部分此前的原行为及新增用例也已通过。

`replay_child_return.py` 使用原来的12条记录决策，不插入强制交还或新模型答案。`handoff_only` 仅更换父子交接；`integrated` 同时启用三处修复。生产模块保存在 `runtime_before/` 和 `runtime_after/`。两份重放均已结束，结果见 [comparison.json](comparison.json)。

## Limitations

本轮没有新API调用。完整集成后的后续选择仍来自旧轨迹，不能将决策数变化解释为新的自主收益。排除知识和执行交接修复不能单独证明模型会稳定提出新结构；原来平方族仍相容而连续局部选点的研究选择问题仍待新决策验证。
