# 0.130 空库响应与时间尺度联合发现

正式协议固定12套新装置9914201–12，每套窗口3→5→7→2→9→恢复3；平方响应、内部权重0.35、观测噪声σ=0.01。比较0.129逐题独立、0.130逐题独立与0.130累计，共216题。全部从空库开始，首题没有静态来源；宽度、响应结构和噪声参数不提供给Agent。

每题首次上限240观测/24万计算，累计组每链总1440观测/144万计算，剩余池允许回访；逐题独立组保留题内学习，每题重置跨题知识且不回访。旧、新独立比较代码能力变化；新累计与新独立同时涉及知识积累与回访资源配置。全部学习完毕后统一4×64终评，保留全部任务、负例、费用和真实CPU。全离线search，外部模型调用0。

开发为已知9914002/05/10的18题空库旧失败，旧结果复用自0.129正式独立臂；已直接比较源码内容确认baseline一致。开发与正式结果分别保存，正式结果不用于修改本轮算法。

## Limitations 与下一步

开发后修复在固定平方响应、加性有限窗口家族取得冷启动进展，不能视为一般开放结构发现。累计仍有5题未决，恢复3步阶段MSE较独立增加52.41%；最差pair为root03窗口9，1.74114e−5→4.00647e−5。累计组同时包含知识和资源池/回访，非单记忆组件消融。

下一重点是知识复用的研究选路与成本：避免已有解释、程序回放、重新发现和反向筛选同时重复投入。现存CPU只精确到研究调用；窗口2/9合占54.8%，最慢root11窗口2为106.32秒，最终仅39节点，尚不能把耗时精确归因于某函数或知识调用展开。
