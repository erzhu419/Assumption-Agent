## Limitations与下一步

6次混叠运行都实际触发冻结程序缺少`reference_research_question`的NameError；其中5次最终耗尽24调用，Code第2次最终模型请求300秒超时。Hegel确实进入子研究修稿，部分恢复执行后继续实测；这些运行仍受共同起始导出缺陷影响，不能据0/3判科学能力不足或停研正确。

低参数Hegel第2次在第164次程序执行、119个动作后遇单次Python超时；此前两份重复程序历史合计约24.3MB，实际单调用分段耗时未保存。之后16次子研究调用仅检查、无源码修订或追加观测，最终第18次模型调用失败。该失败保留在5/9中，不从结果里剔除。

本批支持同一可用程序能被两种Agent自主采用并完成任务，尚未显示额外Hegel组织收益。Code也获得完整研究算法，故本比较不能检验整套算法相对从零vanilla的增益；三种条件的模型重复也不是9个独立任务。

批次结束后，已在现有导出器与本实验入口接回历史研究问题函数，保留原16声明；11项本地入口／指标／实际缺失分支测试通过。后续批次单次Python时限改为30秒、累计仍600秒；本批协议仍为5秒，原运行器已存档，结果未改，尚未运行修后的新LLM批次。
