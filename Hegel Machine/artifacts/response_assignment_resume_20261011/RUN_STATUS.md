## Limitations

首次重放因静态函数绑定旧模块而无效，已修正导入顺序；原输出及原因保留于`initial_replay_import_issue.json`，只采用connected两次输出。完整成功重放的物理轨迹相同，但窄题不再提前退出，改变了父比较与7879试验时点；旧第14条决策提前引用尚未出现的266号观测，被正确拒绝。故严格完整轨迹标志仍为false，计算减少不能当作新模型策略收益。原委派错位也不是已证实的唯一失败原因，上一批成功作者同样曾收到窄题。完成的六次比较仍是一个已打开开发任务上的重复续研，跨任务及递归独有收益待证。
