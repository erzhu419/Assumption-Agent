# GPT6 建议：完成度与方向复核

2026-09-12，当前认知主线 **0.59.0**。对照 [GPT6_advice.md](../markdown/GPT6_advice.md) 与[具体方案](../markdown/Hegel_Machine_Vision_Progress_and_Research_Critique.md)，原构想尚未全部完成。本轮把统一修订、跨任务知识投入与共同对照接到同一未知任务接口，[实现和结果](hegel_machine_unified_research_20260912.md)已能检验知识带来的后继成本变化。

## 三处缺口的实际进展

| 缺口 | 本轮已经实现并运行 | 仍需完成 |
|---|---|---|
| 统一自主选择修订 | 同一公共接口下比较参数、历史、非线性表示及测量联合解释；不知道正确机制类别；新轨迹决定采用或重开。48题全部解出，包含延迟和仪器角色变化 | 将一般风险模型、连续隐状态、对象关系和更多结构族接入同一竞争；旧六族专用演示仍含按family分流 |
| 更一般的研究与知识积累 | 真实残差子问题组成可执行父程序候选并参与比较；完整概念跨命名调用；知识决定短试验买哪些仪器、使用多少观测，失效后恢复常规研究；共享知识也已被既有元先验研究与会话消费 | 22项元先验没有全部通用化；一般问题分解、新研究程序、任意仪器与高层框架的自主生成尚未实现 |
| 长期价值与普通Agent对照 | 三种子16题流中，知识版本相对无记忆减少50.67%观测、50.90%仪器费用和57.04%搜索计算；第二轮24题三项费用均低于固定库。固定库、固定实验、记忆消融与真实Python/LLM Agent使用同一任务接口和资源上限 | 开放任务分布、噪声、风险及持续机制变化下的稳定净收益；整个16题发现成本仍高于固定库。普通代码原始交付10/16，加入既有模型事后执行为16/16；没有显示预测精度优势 |

“十类有界闭环”表示各类能力分别存在，不是整体完成百分比。四个原始环节——发现、主动检验、选择修订、跨任务积累——已有真实执行；当前主线已进一步让这些环节作用于同一个未知任务流。六处构想修正继续成立：以收益立论，保留证据而允许撤销信念，接受可展开概念，允许先验竞争，允许新实验拆开旧观测等价，允许联合修订。

## 当前效果应该怎样理解

0.59的前期发现有成本。完整16题序列中，相对固定库少用22.92%观测和69.31%仪器费用，但搜索计算较高；第二轮才在三项费用上同时占优。这支持有限任务族中的实际积累收益，不能概括为所有研究环境上的优势。普通代码Agent也能发现联合规律、改写模型和复用Python库；16个已写模型均通过独立终评。默认系统相对它少用10.84%观测、62.92%学习仪器费用，结果按预测、观测、仪器、运行时间与模型用量分别解释。

本批定向探针没有新增解题收益，因此默认使用随机轨迹；仪器、表示、短试验和恢复研究仍由证据选择。另设观测设计完全固定的对照，区别于仅关闭定向探针。默认入口为 `cognition unified`，支持检查点及知识库导入导出。[配置](../config/cognition_unified.json)、[架构](architecture.md)、[能力地图](hegel_machine_capability_map_20260909.md)。

## Limitations 与下一步

当前任务仍是有限本地仿真，历史上限四步，主要候选来自既有多项式与残差组合；8+8+8短试验方法由开发者提供，运行中选择是否采用及购买的仪器。SC-KG点式程序接口尚不支持历史程序的直接部署。方法本身更一般的发明、风险与噪声的自主修订，以及其他结构族的共同发现，是接下来应进入统一接口的功能。

下一批应把新噪声、参数变化和机制持续漂移放入同一任务流，使旧知识可能长期失效；由实测决定作用域撤回、研究预算和方法修订。继续以未来任务损失及累计真实投入为主终点，按同一任务流维护五类对照。

此前0.58已修复部署修订赶不上后继初始研究的顺序问题；0.57改进了单任务约束知识。它们作为现有部件保留。[上一轮方向复核](../artifacts/unified_research_20260912/advice_goal_status_before.md)、[0.57结果](hegel_machine_constraint_knowledge_20260912.md)。
