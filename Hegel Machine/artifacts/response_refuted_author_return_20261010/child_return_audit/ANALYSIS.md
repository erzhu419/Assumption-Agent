# 下一轮修复前的因果分析

本轮只分析与离线干预，不修改生产研究器、不调用新模型。最新六次结果仍为同一失败现场的 Hegel 修前 0/3、修后 1/3；不能把三个不同问题统称为“不会修订假设”。

## 三次修后运行暴露了不同断点

**重复2：有效新结构已形成，实验交接遗漏。** 第11调用提出三次函数基并实际试验。7880 Hz 阴性只否定该点；整个三次族仍未被排除。现成研究器已选出7906实验，32个有限响应假设对此有8个阳性、24个阴性预测。未答子题当时阻止交还合理。第12调用只是分析已有观测223，没有新增观测、改父程序或改变响应绑定；它返回的是点级反驳，且没有其他待决依赖。父循环却直接请求下一次模型决策，遗漏对原来待交还实验的重审。最后到24调用耗尽才执行7906并完成。这处修复针对已经找到有效结构后的研究效率。

**重复3：已排除的旧族因计算不足变回未知。** `signal_gap_interaction_5` 在96条独立响应下已完整排除；最终135条响应包含原96条，函数基、所需特征和共享连通响应带前提不变，却被新的 `UNKNOWN / branch_limit` 覆盖。其余声明族均已排除，这一个未知阻断了已有“全部旧族被排除→研究新结构或测量”的分支。用同一求解器、原50000计算上限、不加额外分支截断重查当前135条响应，83/83分支仍被排除，仅用12473计算、零新世界动作。求解器在预算不足时返回未知没有错；没有继承仍然适用的旧排除结论才是断点。证据和复现入口见 [family_exclusion_audit.json](family_exclusion_audit.json) 与 [recheck_family_exclusion.py](recheck_family_exclusion.py)。

**重复1：还有相容旧族，研究选择没有转向。** 这里同样发生交互族排除回退，但平方族仍有可执行相容成员，不能套用“全部族排除”。模型已经收到共享前提研究义务，却继续2672–2689附近的点试验；最终22个无进展周期、零非局部进展、无新函数基。它收到并引用了反例。缺的是让行动回答当前上层问题，而不只是区分同一旧族的几个成员。不能全面禁止备用实验：重复2的成功也需要执行一个仍相容的成员区分实验。

## 历史能力已经存在，下一步接回两条主线

1. **先让排除结论持续生效。** `world_reference_hypothesis._reuse_paid_family_exclusions` 已有同表示、旧响应保留时的排除复用，但只接进了新提案的点候选过滤。将同一适用条件接进普通全族后果比较，让本次计算不足不覆盖已成立排除。继承的是实际证据下的全族结论；表示、数值读数或前提改变时仍需重新比较。用重复3验证既有新结构研究入口是否恢复，以重复1仍相容的平方族及重复2的三次族防止过度排除。
2. **再接回被子题暂缓的父实验。** 在原提案已取得实测、已产生合法父实验但被待答子题阻挡时，保留这个待交还关系。子答案返回后，使用当前证据、绑定、族状态与依赖重新判断。仅有一个任意旧备用点，或子题只是结束，不构成交还依据。复用既有 `inquiry_finished` 和父程序入口，不重新建控制器。

这两处修复改变的是研究知识和控制权的实际接续。稳定提出新结构仍要由随后真实模型选择验证；首先区分“状态判断错误”与“在正确状态下选择无效”。

## 次要接口修复的边界

响应表示作者曾原样调用反馈提供的试验动作，重复1被延迟4次、重复3被延迟1次：说明允许执行，而提案沙盒只放行条件作者的关联试验。历史条件作者和响应稿预览回传都已实现。

不能只在许可条件里加一个例外。当前带 `response_comparison` 的实测会进入 `_execute_bound_response`，正式记录作者大问题的结论，可能把已有父答案改成窄族的反驳。作者内试验应复用已有预览比较与同作者回传；父程序显式采用仍走原正式路径。这项修复解决真实的接口冲突，但不解释其后十余次旧族点搜索。

## 离线交还干预

`../audit_child_return.py` 固定原来的前三决策和成功续研的前九条新决策，总计12条。两份运行共用原代码、程序包、预算和观测；干预版仅在第12调用子答案返回处给现有父程序控制权，不指定函数、设置或后续模型答案。未提供的下一次模型决策作为停止边界。结果保存在 `unchanged/` 和 `yield_parent/`；它检验这一次交还的实际后果，不等于已实现通用修复。

两份重放都精确复现原237条观测，子题返回后均无待决依赖。原路径请求第13次决策而停止于诊断边界；交还版仅再执行2个世界动作，观测238在指定7906 Hz确认激活并完成。原完整现场需要24条决策、301观测、1525388计算；交还重放使用12条原决策、239观测、1126563计算。节省62个动作、398825计算，零新API。未提供下一决策的对照不算任务失败，计数器中的第13次只是未发送请求。完整比较见 [handoff_comparison.json](handoff_comparison.json)。

## Limitations

三种失败来源分别成立，不能用一例成功证明另两例已解决。全族排除继承能恢复正确研究义务，尚未证明模型因此会提出有效新结构；交还干预是对已打开成功现场的事后诊断。生产代码本轮保持不变，新的真实LLM对照应在上述语义接线完成后再进行。
