## Limitations

这是反复使用过的开发案例及人工实现的研究政策修复，不是未见任务成功、新结构自主发现或递归独有优势。实际分派诊断为已耗尽模型预算的现场增加2个不可调用的哨兵槽，均未使用；返回动作由实验驱动执行，LLM自主采用尚未验证。一次修订也可能增加失败成本，小型投影回归保留了这种负例。

物理重放与前置数值比较分别计费，不能仅用573931的物理阶段计算宣称净收益；实际分派路径646678包含本次全部求解。历史窄声明缩小了研究作用域并重置其停滞阶段，基线不单独识别这两项贡献。3个控制相对早期报告90／77／109动作有变化；本次消融只排除新增修订策略的影响，没有隔离共用数值辅助函数与其他runtime修改。首次分派夹具漏恢复notes的0观测错误亦保存，随后仅补原字段重试。
