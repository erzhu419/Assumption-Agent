# 同候选三臂：族级预测确认与目标激活的取舍

复用原三个`ResponseLab`条件、两个声明族、3条初始响应及旧成员／族级选择器。A为有限代表，B为平铺族级，C与B计算相同，但参考实验在购入前通过真实`query → evaluate → child return`执行。三臂均最多8条新增响应，确认包含在内；逐0..8花费点比较，并在B的全部实测日志上重放三个更新器。0新增模型调用，6项研究驱动测试通过。

| 端点／代价（3个固定开发条件） | A 代表 | B 平铺族级 | C 父子族级 |
|---|---:|---:|---:|
| 固定面板事前确定预测、随后两点确认 | 0/3 | 2/3 | 2/3 |
| 固定面板两点实测阳性，不要求事前确定 | 1/3 | 2/3 | 2/3 |
| 任意设置使两个目标均出现阳性 | 3/3 | 2/3 | 2/3 |
| 新增响应动作总计 | 24 | 13 | 13 |
| 研究计算单位 | 7,902 | 155,080 | 155,080 |
| 实际子答案返回 | 0 | 0 | 7 |

任意设置两目标激活的首次花费为A的2/5/2，B、C的3/7/未达。B、C在错误共享前提条件中实测排除声明族后停研；A继续找到了阳性点。因此代表法更快解决激活，族级法更好完成原pilot定义的跨对象事前预测确认；不能把第一行称为整体任务胜率。三臂都没有错误确认。

B/C动作、共同花费点、末测预测及同日志更新完全一致，未测得显式递归额外收益。同日志下A的最终面板集合也变为`TT`、`TT`、空集；中间可能集合与选点不同，不能说A拿到同数据仍无法形成结论。末测覆盖整张公开目标网格，排除已购点：A共73个未购点中的2个确定负预测错误；B/C共84点中只确定4个阳性且均正确，其余未决。覆盖与分母不同，不能合并为同覆盖准确率优势。

复现：`PYTHONPATH=src python3 scripts/run_response_family_controls.py --output <new-directory>`。全部端点、真实问题返回和共同花费记录见`results.json`，固定日志更新见`same_log_replay.json`。

## Limitations

这是三种已有确定性诊断条件，不是随机重复或LLM对照。C的子任务划分固定；计算比A多，未证明总成本更低、递归独有优势或自主方法学习。纯研究方法迁移仍须保持候选一致另做。
