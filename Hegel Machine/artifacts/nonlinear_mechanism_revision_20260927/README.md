# 非线性内部机制修订实验（2026-09-27）

冻结 0.122 基线；来源由同一离线 Agent 连续实测学习 `a*x²+b*z²` 及其平方读出，未向知识库注入真程序。每个有源链都计入两次来源研究的实际成本；空库组从零积累。所有组使用每任务 240 观测、240000 计算、4 轮、8 候选，实验不调用外部模型。

固定目标顺序：删除内部 z² → 恢复 → 内部 z² 系数变为原来的 0.55 → 再恢复。开发根为 9912701–9912702；正式根为 9912801–9912812，均在来源研究前写入协议。所有研究完成后统一进行每任务 4×64 新轨迹终评，阈值 MSE ≤ 1e-7。

开发 32 个目标结果：有源新旧达标 8/8 与 4/8；两空库组均 0/8；无误报。新增删除知识也被后继系数变化任务重新组合调用。完整结果及成本在 `development/summary.json`。正式 12 根结果：旧有源 30/48，新有源 46/48；两空库组均 0/48；四组误报均 0。删项 3/12→12/12，后继系数变更 3/12→10/12，两次恢复均 12/12。新有源完成 13 次实际机制实验（65 行），10 个成功系数任务均调用删项后学得概念。正式结果与归因见 `fresh_replication/summary.json`、`insights.json`。

计入来源、目标研究、终评后，有源总计算 3726059→1321533（−64.53%），总观测 18648→17177（−7.89%）。来源成本两臂同为 1440 观测、169428 计算。新空库总计算 4789873、总观测 20504。旧有源发生 2 次自然回访，其成本已纳入；其他组无回访。

复现脚本：`scripts/run_nonlinear_mechanism_revision.py`，依次执行 `--phase source`、`learn`、`evaluate`、`summarize`，`--output` 指向含冻结 protocol.json 和 runtime/src 的开发或正式目录。每个 arm 在独立进程加载对应 runtime，源研究统一使用 baseline/src。

Limitations：这是确定性二维多项式装置的有限实验；空库仍不能自主发现四次响应。当前局部编辑保留内部系数，后继系数变化的解来自学得程序的组合，不能写成一般非线性参数优化已完成。正式 root05、root08 的系数任务仍 unresolved（终评 MSE 0.003230、0.001246）；两者仍可召回原模型与删除后知识，需要改进组合搜索或开展内部系数研究。冻结正式样本未据结果重调。
