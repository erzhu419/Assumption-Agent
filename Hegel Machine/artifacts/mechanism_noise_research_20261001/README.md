## Limitations

本轮是已见任务的固定能力诊断，尚未建立新任务泛化、普通Code/LLM优势或稳定长期净收益。CPU原值显著增加，两候选轮均两族各4worker并行；行为完全相同的条件组也增加，未定位运行环境与执行开销贡献，不能宣称速度改善。含噪任务未新增成功阈值，部分回访之后最终程序变化，机制重复不能直接算作最终完整确认。

后续优先级保持：①研究投入与完整确认，减少首次研究和筛选浪费；②知识贡献归因、错误迁移撤回及长期净收益，检验增加筛选与回访是否带来后继收益。
