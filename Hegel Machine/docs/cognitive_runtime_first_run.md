# 认知主线骨架与首轮运行

2026-09-07；开发分支 `codex/hegel-cognitive-mainline`，基于 `20fd4011`；包版本 `0.3.0`。

主 README、架构与研究路线已切换到假设发现、主动实验、认知修订和跨任务知识。旧 README 与架构全文保存在 `docs/history/`。新入口可以直接运行完整认知循环。

## 当前交付

`cognition/` 包含统一研究对象、可执行程序语言、六类候选生成、竞争诊断与有限递归问题树、主动探测、工作假设修订与回滚、实验内知识库、交互环境、评测及 CLI。程序支持数值、逻辑组合和原始历史；候选参数、阈值和风险校正由观测拟合。模型描述及原始任务接口不携带正确修复标签。

知识是实际可调用的程序。迁移失败排除该任务；已支持的任务被新反例推翻时撤销知识。不同任务本来可能需要不同规律，因此不能因两个不相关任务失败就全局删除一个概念。

默认序列有 12 个任务：5 个获取知识、5 个迁移、2 个反例任务，覆盖参数、历史依赖、迟滞、尾部风险与冗余变量。每个系统使用同一任务接口、固定损失、每任务 96 单位观测预算与 24000 单位计算预算。最终评测在 Agent 输出之后读取独立轨迹，共 2304 行。

## 运行

在 `Hegel Machine` 目录下：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition run \
  --config config/cognition_research.json \
  --output artifacts/cognition_run.json

PYTHONPATH=src python3 -m hegel_machine cognition compare \
  --config config/cognition_research.json \
  --output artifacts/cognition_comparison.json
```

`run --memory artifacts/cognition_memory.json` 可读取并保存跨运行程序库。比较命令为各系统重新初始化任务与知识，另外实施获取阶段后删除知识库的干预。

## 首轮观察

固定 seed 7，当前骨架结果如下。平方误差与 pinball 分别对应不同任务目标，分开汇总；数值越低越好。计算单位是候选与观测的评估工作量。

| 系统 | 平方误差任务均值 | Pinball 任务均值 | 观测成本 | 计算单位 | 最终输出直接复用已有程序的任务数 |
|---|---:|---:|---:|---:|---:|
| 固定当前观测模型 | 0.284319 | 0.180900 | 492 | 13738 | 0 |
| 同语言普通程序搜索 | 0.071344 | 0.251751 | 492 | 124333 | 0 |
| 关闭主动实验 | 0.064809 | 0.251751 | 476 | 67298 | 2 |
| 每任务从空知识开始 | 0.038202 | 0.145754 | 444 | 98947 | 0 |
| 完整认知骨架 | 0.038438 | 0.145754 | 428 | 89933 | 3 |
| 获取阶段后删除知识 | 0.038202 | 0.145754 | 444 | 100579 | 0 |

完整运行保存了 8 个程序、32 次任务范围限制。实际发生了以下行为：

- 从观测拟合出线性关系 `0.3 + 1.4*x`。
- 从原始历史构造 `0.6*x + 1.2*lag(x,1)`，并在后续任务调用。
- 尝试并比较关系组合、条件残差分位数和删除变量后重拟合。
- 新观测使工作假设回滚，再继续搜索。
- 后续反例任务需要重新引入此前无用的变量，原程序在该任务受到限制。

本轮知识复用降低了部分观测与搜索成本，但平方误差略高于无知识版本。3 次复用表示实际调用行为，不表示三个迁移都充分正确。例如迟滞任务仍有预测误差，当前控制器可能过早接受在已见数据上有效的简单阈值。这个结果确定了后续应改进的认知机制：更有针对性的观测、条件化知识范围，以及组合搜索与停止策略。

完整轨迹见 [单系统结果](../artifacts/cognition_run.json) 和 [六系统结果](../artifacts/cognition_comparison.json)，日常查看可先用 [3.4 KB 比较摘要](../artifacts/cognition_comparison_summary.json)。

## 验证与 Known Issues

18 项针对性测试通过，覆盖真实数据拟合、历史程序、组合关系、风险校正、简化、探测区分力、实际知识调用、按范围限制与撤销、预算以及最终评测与学习分离。未运行旧 formal 资格链。

这是可运行研究骨架与公开 synthetic development 结果，尚未形成独立确认的泛化结论。有限算子语言、最多三步历史、有限 probe 目录、问题树遍历及具体程序库已经实现；通用 LLM proposer、学得的宏参数化、连续条件作用域、任意新测量、多步价值规划、完整鲁棒控制和开放世界元算子发明属于后续扩展。完整方向见 [研究路线](cognitive_research_roadmap.md)。
