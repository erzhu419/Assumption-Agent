## Limitations

新例仅一例实际触发并改善。收益来自选点后更新原 GP，本批没有新增目标模型采用，两个新表示的独立收益尚未证实；最终优化结果没有提高，稳定长期收益仍未达成。本批未重跑 vanilla 或普通 Code Agent。

最差目标回归为 0.004063 → 0.021220：实验再次选择已知失效边界，改变了原 GP 的后续学习。见[三例诊断](../artifacts/sc_kg_objective_reentry_v052_20260911/regression_diagnosis.json)。下一步比较区分实验与普通优化动作的实际价值，减少重复确认已知错误，保留能暴露尚未解释区域的实验。
