## Limitations

正式范围仍为两个可直接控制的条件、AND/OR/XOR、有限窗口及二次响应，噪声0；付费不可控条件仅为另列开发用例。该用例局部确认通过而独立MSE仍为0.01308，不能计入正式1e−6达标；门槛区间仍宽，完成判断需要更好的区分证据。正式逐题独立root07的五步窗口OR仍未决，MSE0.001492，实际两条曲线及边界已研究，312观测后计算耗尽，未误报完成。稳定长期净收益、更多条件与更广泛表示、含噪联合发现尚未完成；逐题独立臂仍是完整黑格尔机，普通Code/外部LLM及完整模块消融未在本轮补齐。早期数据重复采购、测量方向计算耗尽和曲线未充分采购的真实负例保留于[负例目录](../artifacts/condition_response_actions_20260930/test_counterexamples)。
