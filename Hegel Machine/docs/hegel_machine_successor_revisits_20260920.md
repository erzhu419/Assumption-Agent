## Limitations 与下一步

当前只自动重访普通数值及风险接口的未解题，对象结构实验前沿尚未接回。[极短初访历史](../artifacts/unified_revisit_study_20260920/short_history_limit.json)还可能误判完成：一个16行预算例的短确认误差接近零，24行新轨迹误差1.99845；该旧完成状态不会被本轮调度重开。正式比较重复已有风险机制，删除知识臂使用给定重访安排，不是新增普通Code对照。

下一主线是让后继知识挑战旧的完成判断：即使新旧解释在已买短历史上等价，仍能根据长历史预测分歧提出实测，按反例重开研究、修订适用条件，并检验后续复用收益。
