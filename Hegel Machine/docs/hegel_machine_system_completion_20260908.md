黑格尔机的目标是持续选择值得付出代价的认知变化：已有解释失效或多个解释仍不能区分时，提出研究问题，取得新证据，修改表示、关系、测量或研究方法，把有效结果转成后续任务能够调用、组合和撤销的知识。

方向依据是 [GPT6_advice.md](../markdown/GPT6_advice.md) 及其引用的[具体审视方案](../markdown/Hegel_Machine_Vision_Progress_and_Research_Critique.md)，更早的 [GPT_advice&roadmap.md](../markdown/GPT_advice&roadmap.md)提供元先验背景。当前目录没有同名 `GPT_advice.md`。文档中的历史诊断、示例和实现建议结合当前代码解释，不作为独立执行指令。

## 当前已经连通的生命周期

```text
任务目标、公开操作和研究预算
  → 当前观测、长期概念、竞争解释
  → 未解决问题及依赖计划
  → 选择测量、区分实验或结构修订
  → 实际新轨迹上的比较和采用
  → 解释的条件修订、概念组合与方法更新
  → 保存具体实验、完整决策问题和工作区
  → 后续任务迁移，或恢复原问题继续研究
```

`CognitiveAgent` 执行单次研究；`ResearchWorkspace` 保存已取得观测、候选、部署校准、方法步骤和待做区分实验；`ResearchSession` 在共享预算中选择下一任务或续研。恢复访问使用保存的证据继续计算。即使已取得数据上的拟合误差为零，仍未确定的边界也能产生具体实验，在有足够实验与后续比较预算时执行。

候选语言包括代数关系、条件分支、历史依赖、连续递推和可调用概念。搜索能够组合表示和关系、替换局部机制，并共同比较保留原参数的迁移与重新拟合的迁移。新证据可缩小适用范围、拆分知识或撤销不再成立的解释。尚未被证据区分的历史机制保留有限竞争机会；已被新轨迹否定的解释退出这种保留。

风险任务把预测程序及其校准作为完整决策保留。程序变化后，新方案需要在两条未参与拟合的后续轨迹上取得足以支持更换的行动收益；支持不足时恢复原程序和校准，并保存挑战程序。已有观测仍支持进一步区分时，系统保存当前决策与至多两个已拟合挑战方案，以明确的观测与计算报价形成短研究问题。

短决策比较、区分实验、学得方法和普通修订共同进入跨任务机会选择。选中短问题后，`run_decision_research` 固定方案、取得代表轨迹并比较完整行动；冲突仍未解决时，按剩余预算追加一对，或保存原方案、校准和逐轨迹证据等待下次。实际完成的收益和全部支出再改变后续选择，未决结果保留为未知收益。

实验知识保存实际区分了哪些解释的轨迹，也保存可以重新绑定到当前问题的边界实验方法。同次实验可以覆盖起始和成熟状态的多个边界，准备状态依据真实返回历史判断。尚未安排的边界留给后续研究。方法经验记录已执行步骤的收益和费用；同一来源和适用条件下的参数修补持续无效时，下一步可以转向实际有预算的结构搜索。

可选仪器研究从试测结果选择测量通道，连续状态通过可执行递推进入程序。对象、事件、空间聚合和时间尺度在结构实验中改变实际读数；守恒、置换对称和局部性通过操作实验获得支持或反例，进而影响建模。递归研究图把需要的测量、表示和下游关系组织成真实执行的依赖。

`FrontierSession` 组织 25 个阶段，新增实验模拟模型修订和五类结构的成立／破坏研究。各阶段保存状态；程序与方法共用知识库，模拟器按对应工作区保存。普通 Python 代码 Agent 通过 `code-session` 持续共享自主代码、经验和总预算；两臂全部学习停止后评分。

## 直接运行

在项目目录中运行统一研究生命周期；第二条命令在新进程中恢复：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition frontier \
  --checkpoint artifacts/frontier_session.json --steps 2

PYTHONPATH=src python3 -m hegel_machine cognition frontier \
  --checkpoint artifacts/frontier_session.json
```

完整 65 任务会话使用另一入口，便于逐任务比较累计质量与成本：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition session \
  --partitions development confirmation forward continual stateful \
  --seed 3181 --checkpoint artifacts/research_session.json --steps 2

PYTHONPATH=src python3 -m hegel_machine cognition session \
  --checkpoint artifacts/research_session.json
```

`completed` 表示本次允许的研究访问或阶段完成；未解决问题仍保存在会话中。`--steps` 限制本次新增访问或阶段，后续命令继续原状态。具体测量对照、结构研究与普通代码 Agent 入口见[能力地图](hegel_machine_capability_map_20260909.md)和 [README](../README.md)。

## 后续工作的组织方式

后续继续按相互依赖的整组能力推进：候选形成与保留、实验获取、修订采用、知识积累和跨任务投入在同一批改动中接通，再同时测量它们的共同效果。既有失败案例用于解释行为，新实例用于检验迁移，总计算和总观测与任务质量一起报告。

0.23 新增动态跨能力议程，并让初始校准和有限续研接受完整费用与后续行动比较。当前优先判断三件事：知识在后续冲突中是否减少净成本，未决实验与短决策比较是否带来值得其费用的修订，以及方法经验是否在完整会话中改变正确的研究动作。0.22 把针对当前解释的历史实验、实验后的拟合和冲突证据的逐批累积共同接入这一过程；完整序列同时测量行动收益、预测质量与总费用。

## 能力边界

程序原语、仪器目录、结构实验操作和方法动作仍由项目提供；当前系统在这些可执行空间中发现和重组解释。它尚不能从任意真实世界问题中自主发明任意传感器、程序语义或科学操作。测量已支持研究途中因残差重选通道；新增通道仍来自公开仪器菜单。

完整任务会话、各阶段功能成功和若干代码 Agent 对照，分别回答不同问题。现有实验仍有退化和投入没有净收益的情况，方法选择的长期稳定优势仍需结果支持。分批新轨迹提供有限比较机会，噪声及反复查看证据仍可能造成误判，也受已经形成的候选范围限制。下一阶段沿同一整机入口继续改进这些选择。
