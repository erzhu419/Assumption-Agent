# 认知主线 0.6.0：联合修订、持续观测与风险学习

日期：2026-09-08。0.5.0 的[结果](cognitive_runtime_v3_results.md)和实际认知包保留；本轮在其失败基础上继续开发。

这轮把已发现的组合规律和历史证据真正用到了修订中。旧 forward 三种子的平均平方误差由 **0.284248 降至 0.007666**，平均计算支出下降 **41.2%**，观测支出增加 **15.2%**。新的 continual 序列中，27 个非滞回确定性任务都学到可持续预测的程序，64 步评测的平方误差均低于 `1e-12`；剩余确定性误差集中在状态滞回。风险学习改善了总体成本损失，知识对计算有节省，但还没有形成稳定的观测节省。

## 1. 这次解决了哪些实际障碍

上一轮剩余误差主要来自强联合组合 f09。此外，f03 已经取得变量独立变化的证据却没有完成修订，f07 的输入历史与输出递归在八步重置轨迹上等效，风险任务的选择也不稳定。

`sparse_search.py` 现在同时比较历史深度与坐标支持。它先联合拟合当前变量、平方、交互与历史扩展，再缩减支持，保留少量候选并允许删换早期选错的项。不同历史深度使用各自可用的全部观测；同一支持共享列计算，并按实际所需历史重新拟合。旧版只按残差相关性向前添加、统一截到最长历史的搜索保留为消融。

`controller.py` 为后续研究轮次保留计算空间，并在获取代表轨迹前确保候选比较有预算。候选先在少量观测上筛选，入围后再用完整证据和新轨迹比较。新提议和已有候选交错进入筛选，避免队列前面的记忆占完新结构的机会。

集成时进一步定位到 f08：正确四阶成熟程序已经生成，浅层候选却先耗完了启动拟合预算。`selection.py` 现在先跨历史深度轮流拟合每个成熟模型的当前坐标，剩余预算才用于更广泛的启动搜索。启动分支可独立拟合线性、平方与交互系数。该改变让“生成正确成熟程序”真正走到“比较完整可执行程序”。

代表轨迹的长度随候选使用的历史增加，在公开观测长度上限内覆盖多个历史周期。这样，较长观测可以区分短段上等效的输入延迟与输出递归。固定八步代表轨迹保留为消融；所有臂仍共享环境原有的长目录查询。

`risk_search.py` 直接拟合任务给定的 pinball 损失，使用当前变量和绝对值坐标，输出普通可执行 AST。风险行动按固定欠估／过估成本对应的分位数选择；残差结构在整段轨迹上比较。最终预测程序选定后，控制器再取得一段预留的新观测用于收缩校准，此后不再修改该预测程序。

保存的 0.5.0 包为 `artifacts/cognition_v3_reference/`，完整新版本为 0.6.0。所有配置每个 episode 上限相同：**96 个观测点、24,000 个候选计算单位、5 轮研究**。风险学习的校准观测和计算包含在这些上限之内。

新 `continual` 分区在算法确定后首次运行：12 个 episode，种子 **401、503、607**，含新的参数和变量角色、不同延迟的联合组合、偏斜异方差风险，以及同一任务的延迟变化。训练接口允许最长 32 步，最终独立评测为 **8 段各 64 步的轨迹**。按历史长度 0–7、8–31、32+ 分开报告，观察启动、可训练时域和更长时域的预测。

最终对照矩阵共 72 条配置—种子序列、954 个配置—任务 episode。各臂共享同种子环境、初始观测、可查询目录、最终评测行和预算上限，自适应查询可以不同。模型代码在首次读取 continual 前确定，本次首读后保持不变。

## 4. 联合修订与动态规律

旧 forward 中，f09 的三种子误差原为 1.300738、3.508856、3.209075，新版均小于 `1e-12`。以 seed 101 为例，运行得到的成熟规律为 `0.35*x + 0.6*x*x - 0.93207281*x*z - 0.7*lag(x,2)`，不足两步时使用独立拟合的当前项。f03/101 从把 x、z 的作用混淆的模型修订为 `x - 1.087137*x*x`；f08 三种子的完整启动与四阶历史预测也均小于 `1e-12`。

continual 的新组合覆盖两、三、四阶输入历史及角色迁移。完整新版在 27 个非滞回确定性 episode 中恢复了可用于长轨迹的规律，包括同一任务后来改变延迟后的修订。其 32+ 历史分段最大平方误差低于 `9e-15`。

最清楚的短段混淆出现在 continual 的 n01/607：固定短代表轨迹选中 `lag(target,4)`，0–7 历史段几乎没有误差，8–31 段误差升至 **0.987812**，32+ 段为 **0.856021**。完整新版使用 `lag(input,4)`，三个分段均近于零。短轨迹臂把同一错误带入 n06，32+ 段误差 **0.961740**，完整新版也将其消除。

联合束搜索与旧贪心搜索在定型实验中的最终精度实质相同，不能把总体精度提升全部归给束搜索。它在旧 forward 节省约 **9.3% 观测、12.5% 计算**，在 continual 节省约 **5.2% 观测、5.0% 计算**；development 中反而多用约 3.8% 计算。完整流程的收益也包含预算分配、启动拟合和比较证据的改变。

continual 剩余确定性误差全部来自 n10：三种子的平方误差为 **0.071891、0.101666、0.085285**。它仍把带开关记忆的状态转换近似为线性历史或阈值化线性历史。下一步应让运行中的候选搜索比较有状态的转换规则，并由实验找出进入和退出状态的不同阈值。

## 5. 知识价值和风险选择

关闭新增风险学习时，continual 的 pinball 损失为 **0.543415**，完整新版为 **0.353981**；实际行动成本损失由 **0.366723 降至 0.338921**。预测分位数的改善大于行动层面的改善，后者仍受残差结构和校准影响。固定短代表轨迹的 pinball 更低（0.344411），但行动成本更高（0.347287），两项指标需要分别解释。

n04/401 仍保留常量预测，pinball 为 0.469807；其他尾部任务也未恢复稳定的条件分位数规律。后续重点是尾部观测的取得和校准量分配，检验它们能否改善最终行动损失。

相对关闭知识，continual 完整新版每条序列平均少用 **5,531 计算单位**，多用 **30.67 个观测点**；平方误差从 0.010262 改善到 0.008628，行动损失却从 0.334696 上升到 0.338921。旧 forward 的知识也节省计算但增加观测。这支持“知识帮助压缩部分搜索”的有限结论；知识的整体收益还不稳定。

continual 共测了 130 次复用候选，其中 118 次未通过当时的新证据比较。这些是候选层面的失败，不是 118 次最终错误迁移。最终反事实评分中，保存的旧版错误采纳为 **19/51**，完整新版为 **1/76**，错误回退为 **1/1**；只有一次回退，不能据此推断一般回退能力。development 的错误采纳由旧版 6/77 增到 11/93，因此修订选择仍有需要改善的情形。

下一阶段把知识检索提前用于提出更有辨识力的实验，并降低反复无收益模板的竞争开销；同时继续保留“去掉知识后反而更好”的任务作为直接开发对象。

## Limitations

- 旧三个分区都是开发依据。continual 是本轮算法确定后的首次结果，生成器仍公开，也共享基础机制；将来据其结果改动系统时，它转为新的开发依据。
- 新联合搜索仍使用有限的坐标字典和有上限的支持大小。编写搜索器与调度规则是研发修改；运行内学到的是具体结构、系数、历史长度、实验和知识。
- 代表观测覆盖公开控制范围，主动实验价值来自有限竞争程序的近似。最终 64 步超过训练单次查询的 32 步上限，历史区间结果应分别解释。
- 每组只有三个 suite 种子，区间按种子重采样；所有已尝试任务仍计入覆盖分母。计算单位和墙钟时间分列，预算上限相同不表示实际支出相同。
- 最终错误采纳和错误回退只比较实际记录的程序对，不是所有未采用候选的最优操作标签；没有回退事件时，回退准确率没有分母。
- 风险结构的交叉比较以当前固定预测程序为条件，独立新轨迹只在最终程序选定后用于校准。有限尾部样本与收缩校准不提供普遍风险覆盖保证。
- 新风险模型的 `kind` 表示残差结构，行动含义还需看 `action_rule` 和 `calibration_offset`；新模式中的 nominal 可带经验区间和后校准。`worst_case_loss` 仍是所学区间端点的损失指标，不能解释成实际测试最坏风险。
