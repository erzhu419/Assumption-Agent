# 最窄研究闭环修复（2026-10-04）

**最窄离线闭环通过：空库学习→后继实际调用→实测反例→限制旧假设→学习替代→回到原条件继续复用。** 本轮保留当前主线，修复审计发现的六处行为错误，并补齐两个仪器研究入口；没有修改原 session 回归的质量和实际调用断言。

修复包括：当前付费反例优先于旧条件覆盖；取消外层重复扣留的确认预算；近零收益不再确认或撤回；非相邻重复候选合并回原位置；单源回报按具体程序匹配；组合首访保留收益密度顺序。仪器校准失败后先比较按实际费用计价的普通当前／历史响应，再考虑昂贵的条件研究；冻结旧 call 的实测失败留下反例，拟合后消失的 call 不再获得来源信用。

固定协议为 `1→1→2→1`，每任务上限为 96 观测、384 测量、24,000 计算，1 轮研究。full 从空库正常运行；所有臂学习结束后，才进行每任务 64×4 行独立终测，达标为 MSE<1e-6，full 另须完成研究期的新轨迹确认。来源删除臂共享真实学得的首题前缀，只删除该来源及派生知识，研究配置、方法经验和预算相同，允许正常重新学习。

首批冻结确认 **10/12**：两个实例在机制变化后没有学到替代模型。修复第二个仪器入口的研究顺序及实际 call 归因后，两个失败例作为开发回归通过；另冻结源码及 12 个新 seed，再运行独立确认，结果 **12/12 闭环、48/48 任务达标**。前后两批分开保留，不把旧失败替换或并入新批次。
