# 目标与约束共享取证

2026-09-10，0.39.0。

约束实验在采样前同时为目标候选作预测，同一份实测推进两个模型；目标反例可提出旧控制的约束适用性复测，两次新读数支持变化才重划约束范围，否决则恢复原计划。约束重建保留已验证的目标预测器、证据范围和噪声状态。每臂继续使用 32 次初始观测加 32 次在线调用。

[220 组完整配对结果](../artifacts/sc_kg_joint_evidence_v039_20260910/result_brief.json)相对冻结的 0.38，目标越小越好：

| 范围 | 改善 / 持平 / 退步 | 可行：旧 → 新 |
|---|---:|---:|
| 193 个开发案例 | 10 / 180 / 3 | 192 → 193 |
| 最后加入的 27 个新种子案例 | 2 / 25 / 0 | 26 → 27 |
| 合计 | **12 / 205 / 3** | **218 → 220** |

新种子的三个目标独变案例平均目标 **2.76990 → 2.73233**，目标 GP MSE **0.000902 → 0.000697**；三例均实际采用目标模型，约束保持原解释。全组 290 次共享未来观测支持了 44 次目标模型采用；29 次约束适用性研究中，12 次经第二次新实测确认变化，17 次否决变化。匹配的目标与约束搜索计算 **2,570,501 → 2,579,737（增加 0.36%）**。

首轮 193 组保留于 `attempt_1_coupled_goal_head/`。随后发现约束重建会重新校准目标模型，修复后仅重跑受影响的 10 条轨迹并加入上述 27 组；前 193 组均计为开发数据。10 条重跑均实际保留目标模型。典型联合变化案例的最终目标 GP MSE **0.09911 → 0.02186**，其目标证据起点保留 44，约束起点为 47；最终目标保持 0.5 且可行。[两次实现的比较](../artifacts/sc_kg_joint_evidence_v039_20260910/independent_goal_head_comparison.json)保留原误差。

本轮累计实际新增 **9,088 次在线、768 次初始和 3,840 次独立评价，共 13,696 次模拟器调用**，包含首轮与修复重跑；已复用结果不重复计费。新增 17 项功能测试通过，目标、约束、SC 接入和会话相关回归通过；最终 SC 集成测试为 21 项。

## Limitations 与下一步

仍有 3 个开发案例的最终目标退步，部分模型预测误差也变大。上述联合变化案例的纯目标程序 MSE 为 0.000491，最终 GP 仍明显较差，需由后续实测选择局部残差修订。末段排名冲突目前直接安排两次复测，绕过新位置探索，第二次也不按首测结果重选；下一步让新点与旧点通过同一次 SC-KG 候选评分竞争，每买一次观测后重新决定。

新种子来自相同生成器；本批收益尚不代表开放世界能力或稳定长期净收益。目标解释仍限于现有仿射与加性二次语言，跨任务目标知识复用尚未接通。[十项目标状态](hegel_machine_advice_goal_status_20260909.md)继续保留整体构想的未完成项。
