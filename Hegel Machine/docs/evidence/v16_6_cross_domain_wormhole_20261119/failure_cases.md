# Failure Cases, Negative-Transfer Traps & Honest Non-Gain Cases (`failure_cases.md`)

依据《06_给Gemini的实施合同.md》与 V16.7 红队复核要求，如实报告本轮无收益簇、表示同分项、摊销边界与负迁移拦截（全部数值由实测动态导出）：

## 1. 簇 A（有序离散边界）：Hegel 在目标成本上未击败 `O_strong`（诚实记录）
- **实测现象**：在 4 个独立冻结评测簇（20 道簇 A 目标 + 短早期异常口反例校验）上，`Hegel_V16_6` 与 `O_strong` 严格通过率均为 `20/20`（零非法降标、零短早期异常漏检），簇 A 目标复合成本差 `Hegel - O_strong = +0.7500`。
- **结论边界**：簇 A 验证的是**证据门控形成、近失例分裂（`some_adjacent_flip` vs `earliest_global_threshold`）与前缀完备证书安全性**，不宣称在已知基础二分原语上产生探针优势。

## 2. 1-Hop 小规模（$K \le 6$）下 `Forest` 与 `Flat_equal_content` 的诚实同分说明
- **实测现象**：在单跳跨域基准上，赋予完全相同合同、`ALIGN` 排除谓词、`ScaleMap` 保真证书与四级权限门控的扁平表对照 `Flat_equal_content` 与 `Hegel_V16_6` 目标测量成本完全一致（复合成本差 `Hegel - Flat_equal_content = +0.2000`）。
- **保留森林+虫洞图的战略依据**：在 1-hop 小规模下，净收益主要来自**有界合同、近失例排除、多资源 CEGAR 探针程序与多尺度门控**而非检索数据结构；但森林+`HorizontalWormholeEdge` 在**多跳非传递误差累积拦截（$\sum \prod L_m \varepsilon_j > \text{tol}$）**与局部树垂直回退上提供扁平等价类无法替代的结构保障，并为 M3 大规模候选库（$K \ge 32$）预留图索引接口。

## 3. 双源对比形成与开发门控校准的真实摊销地平线 $\Delta C(N)$
- **双源 vs 单源**：双源对比成功消除了单源表面混杂属性 `has_serial_mutex`，在未见跨域目标上实现净节省 `Hegel_2src - Hegel_1src = -38.6750`/簇；但因多投入第 2 个源回合，在 `N=14` 目标窗口内含源总账为 `+29.3000`/簇，扩展到 `N=28` 未见目标时含源总账转为 **`-9.3750`/簇**（跨过盈亏平衡点）。
- **开发校准成本单列与分摊**：2 个开发簇的同快照配对校准总计耗费 `1278.25` 复合成本（折合每个评测簇分摊 `319.56`）。给定已冻结门控时，`N=14` 评测簇端到端 `Hegel - O_strong = -23.2500`；若把一次性开发校准费硬分摊进仅 4 个评测簇，则在 `N=14` 时为 `+296.3125`，随目标流或服务簇规模扩大持续摊薄。

## 4. 诚实的弱根节点降级退出（`T_B5`）与跨尺度误用拦截（`T_C2`）
- **弱父节点无收益退出**：在 `T_B5_unbounded_sqrt_concave` 上，`ALIGN` 排除谓词在购买确认点前即阻断有理饱和试验（若移除该学得排除谓词则会多花 `6.0` 测量成本试探失败确认点），弱根节点 `sys_root_concave_limit` 经实测效用账本计费后标记 `archived_low_utility = True` 并零浪费回退开放语法。
- **实测包队列跨尺度拦截**：在真实离散包事件队列模拟器生成的 `T_C2_service_burst_tail_latency` 上，实测校准探针发现 `window_average` 对平均吞吐误差为 `0.0000 <= 0.025`，但对 `p99` 尾延迟破坏闭合，从而在 0 附加探针时拒绝有理饱和迁移（测量成本 `42.0`）。
- **源阶段对账**：每簇源+近失例（含尺度校准探针）复合成本均值：`Hegel_V16_6 = 446.93`，`O_strong = 450.07`，`O_HExA_inspired = 453.18`。
