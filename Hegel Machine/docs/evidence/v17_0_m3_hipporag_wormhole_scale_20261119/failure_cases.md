# V17.0 M3 Attribution Boundaries, Tradeoffs & Failure Cases (`failure_cases.md`)

## 1. `Recall@1` vs `Recall@2`（单跳词面精度 vs 多跳关联覆盖）的真实权衡
- 在全部 `92` 次 pilot 后检索中，`Flat_BM25_EqualMetadata` 的授权 `Recall@1` 为 `0.7826`，略高于 `Hegel_M3_HippoPPR` 的 `0.6957`（导致在 `T_Assoc` 子类上由于 `T03`/`T05` 多消耗一次 Top-2 内候选排错，PPR 子类复合成本比 `Flat_BM25` 高 `+6.3270`）。
- 这是图扩散（$\alpha = 0.80$）的经典真实代价：概率质量向多跳邻居传播时，部分一跳精确词面匹配节点的第 1 名锐度被相邻高连通分支分流；但与此同时，图扩散将授权 **`Recall@2` 推升至 `1.0000`（`92/92` 全覆盖，对比 `Flat_BM25` 的 `0.9130`）**，彻底消除了多跳桥接目标（`T_MultiHopGuard` 净省 `-17.6705`/簇）跌出试用窗口后触发的昂贵全量探索（每次漏召回多耗费 `+20.0` 物理测量费与 `+48.0` 全库合成计算），使总物理测量费与总复合成本均在 `4/4` 簇严格胜出。

## 2. 索引构建开销、源期开销与开发期校准成本边界
- `HippoRAGWormholeIndex` 每簇建图开销为 `51.15` 逻辑计算（折合 `2.5575` 复合成本），高于扁平倒排表的 `7.20`（`0.36` 复合成本）；因此若目标流极短（`N < 13` 对比 `Flat_BM25`，或 `N < 7` 对比 `O_strong`），建索引与源期反例检验的固定投入尚未摊平。
- 此外，一次性冻结开发集（`2` 个 Dev 簇共 `76` 源记录 + `48` 次成对分叉校准）总计投入 `6931.84` 复合成本，在 `paired_results.json` 中独立单列，不隐瞒基础设施校准成本。

## 3. 23 类机理库外函数（`OOS01`, `OOS02`）的诚实未知边界
- 在纯正弦波 `5 + sin(u)`（确认 `RMSE ≈ 1.83 > 0.01`）与二维调频振荡 `sin(a*b) + 0.5*cos(2a)`（确认 `RMSE ≈ 1.06 > 0.02`）共 `8/8` 个域外工作区上，系统均如实返回 `status = "scoped_unknown"`、`model_path = None`，`false_confirmation = 0`。
