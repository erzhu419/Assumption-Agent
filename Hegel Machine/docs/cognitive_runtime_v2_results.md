# 认知主线 0.4.0：落实内容与实际结果

日期：2026-09-07。本轮在本地 `codex/hegel-cognitive-mainline` 的工作区继续实现；认知版本为 0.4.0。

**本轮已把 GPT6 建议中的认知操作、长期知识接口和研究比较接通。实际结果支持部分知识收益，同时显示新实验生成和联合策略仍有明显泛化短板。**

建议与代码逐项对应见 [GPT6 建议落实记录](../markdown/GPT6_advice_Implementation_20260907.md)，运行与设计入口见 [README](../README.md) 和 [架构](architecture.md)。

## 1. 本轮交付

新增依赖计划、参数化与子表达式抽象、变量角色映射、连续 probe 构造、随观测更新的行为分组、条件作用域及反例撤销、固定风险代价下的不确定集决策、真实 Codex 程序生成，以及多种子和知识删除实验。

几个贯通行为已经实际执行：中间表示作为后一步程序的输入；暂时更差的谓词被组合为正确关系；新的 probe 将原先同组的解释分开；复用失败改变研究问题；成功复用后仍可简化；反例区分新情境不适用与原支持情境失效。

本轮也修正了会直接妨碍认知的实现问题：复用后过早停止、联合计划未优先消费中间表示、回退后使用旧损失、反复用新实验区分已经被证据否定的程序、重拟合抽象被错记成原具体规律成立，以及搜索耗尽风险决策预算。

运行命令已经覆盖 `cognition run`、`compare`、`research`；知识库可以跨进程保存与恢复，模型生成使用本机配置的 Codex 默认模型。

## 2. 验证与实验设计

`PYTHONPATH=src python3 -m pytest -o addopts='' tests/test_cognition*.py -q`：**52 passed**。这些测试检验可执行行为与测量语义。

主要实验每个任务最多 96 个观测点、24,000 候选计算单位、5 轮研究。开发序列 17 个 episode，种子 7、11、19；留出组合序列 12 个 episode，种子 23、47、83。11 个本地配置对应 **561 个开发 episode、396 个留出 episode，共 957 个配置—任务运行**；全部完成，预测覆盖 100%，运行失败与显式拒绝均为 0。

两组比较运行时使用相同学习代码与配置，未根据留出结果调参。之后增加的最终反事实计分仅扩充测量；再次运行后，各配置的损失、观测支出与候选计算支出均与先前一致。早期文件保留，本文采用含独立误接受/误回退测量的 `cognition_v2_final_*` 报告。

评价行在控制器返回后使用。反复参与候选选择的 validation 属于自适应开发数据；误接受/误回退另在最终评价行上测量。区间以整套任务的种子为 bootstrap 单位；质量与资源不合成为总分。

## 5. 知识积累与实际修订

种子 7 的完整开发序列保存了 **16 个具体程序和 24 个抽象模板**，最终选择中有 **1 次直接程序复用、5 次抽象重拟合**。本条序列出现从源概念到重拟合子概念的实际继承，最大 generation 为 1。

部分最终程序包括：

```text
参数重拟合：add(0.3, mul(1.4, x))
两步历史：add(mul(0.6, x), mul(1.2, lag(x, 2)))
变量角色迁移：add(0.3, mul(1.4, u))
交互关系：add(-0.2, mul(1.1, mul(x, z)))
原支持任务发生变化后的替代程序：add(0.6, mul(-1.3, x))
```

该序列记录 81 次候选级作用域限制、1 次撤销。多个候选可在同一个任务中分别被限制，因此这些计数不能解释为 81 个任务。此前被反驳的复用程序没有以同一表达式保留到对应 episode 终点。

程序片段来自 [最终序列报告](../artifacts/cognition_v2_final_sequence.json)，知识对象保存在 [可恢复知识库](../artifacts/cognition_v2_library.json)。历史任务仍有误差：部分短轨迹的历史起始行使用公共 fallback，迟滞任务也未稳定学到完整机制。

## 6. 独立误接受、误回退与风险决策

运行时 fresh 检查回答“这次决定是否符合当时看到的证据”。最终反事实计分另将修订前后 AST、回退与恢复 AST 放到终局评价行上，回答新数据是否支持该次决定。它只计已实际比较的程序对，不修改学习动作或知识。

| 分区 | 最终误接受 / 已评分修订 | 最终误回退 / 已评分回退 | 缺失 AST | 行动损失 | 区间覆盖 |
|---|---:|---:|---:|---:|---:|
| 开发 | 22 / 62 | 3 / 17 | 0 | 0.166918 | 0.275 |
| 留出组合 | 38 / 75 | 5 / 25 | 0 | 0.493390 | 0.238 |

误接受定义为后程序的最终预测损失比前程序高出 0.002；误回退定义为被拒程序的最终预测损失比恢复程序低至少 0.002。表中分母是修订事件，包含后续可能再次修正的中间状态。全部计数、种子级区间及额外评测成本在 `final_counterfactual` 中。

留出上的 38/75 次误接受与 5/25 次误回退表明，当前选择策略仍有认知能力缺口。风险任务已实际比较名义、全局和条件不确定集并据此选择行动；较低区间覆盖也说明当前区间不能提供稳定风险保障。

## 8. 复现入口与研究取向

在 `Hegel Machine/` 中运行：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition run \
  --memory artifacts/my_knowledge.json --output artifacts/my_sequence.json

PYTHONPATH=src python3 -m hegel_machine cognition research \
  --seeds 7 11 19 --output artifacts/my_development.json

PYTHONPATH=src python3 -m hegel_machine cognition research \
  --partition confirmation --seeds 23 47 83 --output artifacts/my_confirmation.json
```

已有知识路径会被读入；做空库对照时使用新路径或省略 `--memory`。每条命令同时产生小型 `_summary.json`。本轮主要结果先读 [开发汇总](../artifacts/cognition_v2_final_development_research_summary.json) 和 [留出汇总](../artifacts/cognition_v2_final_confirmation_research_summary.json)。

本轮结束后，研究优先级已经具体到实验价值、修订选择和抽象搜索成本。新 probe 会区分候选，但它选择的区域可能无助于最终任务，甚至放大过拟合；复杂计划能消费中间表示，但未必值得额外计算。下一阶段需要用这些认知结果改进策略。

## Limitations

- 所有任务来自公开小型仿真器；留出集合保留组合、参数范围与历史长度，尚不是外部独立设计的隐藏基准。现在已读过的留出结果若用于调策略，就属于新的开发依据。
- 每组只有三个种子。bootstrap 区间按种子计算，不能按评价行数把样本量放大。表中的零失败说明运行完成，不代表预测正确。
- 最终误接受和误回退只衡量预测损失相对已记录程序对的变化，不包含复杂度与风险行动的所有取舍，也不是全局最佳操作标签。
- 候选计算单位计量程序—观测工作，真实时间另存；主机调度与其他工作会影响墙钟时间。本报告不据毫秒差异作速度结论。
- 不确定集是经验残差区间，区间端点最坏损失不是所有环境上的最坏风险。覆盖和迁移效益仍弱。
- LLM 对照是三任务运行 pilot，采用受限 AST 生成接口，期间有指令协议精简；不能推出通用代码 Agent 或某个模型的整体能力结论。
- 抽象、观测生成与动作调度受当前语言和启发式限制；通用理论发明、更长代际积累和跨领域鲁棒收益仍需实证。
