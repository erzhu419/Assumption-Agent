本批落实 [GPT6 advice 的认知动作选择](../markdown/GPT6_advice.md#L388)：匿名对象测量先供响应学习使用，输入修复或部署确有需要时再做仪器映射；短复用试验按实际剩余预算放行，并复用已付对象观测。当前任务实测有效的区分实验优先于旧来源及默认步骤，失效时仍可转向其他方法，正负证据均保留。

## Limitations 与下一步

有来源组共享一个实际学得的来源，空库组每题独立学习；这些不是12条长期积累链。本批改进研究投入顺序，不构成一般最优政策。空库的组合表达仍有缺口：现有搜索分别改变关系、事件和窗口，错误的响应形式也会误导关系范围修订。[已付数据诊断](../artifacts/object_response_investment_20260920/cold_diagnosis.json)显示，直接组合现有结构候选仍未解决。下一重点是共同生成响应组合并修订关系范围，保留新轨迹比较及失败后续研预算。外部 API 对照继续暂缓，本批全部离线。
