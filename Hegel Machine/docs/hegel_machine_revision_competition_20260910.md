# 候选竞争、区分实验与剩余预算

2026-09-10，0.33.0。

后续 [0.34 主动确认](hegel_machine_active_confirmation_20260910.md)已修复本批启动过晚的病例；下文保留 0.33 当时的结果与判断。

本批继续解决带噪时候选过简与研究启动偏晚。[候选比较](../src/hegel_machine/cognition/revision_candidates.py)加入逐坐标二次假设，遍历全部公开坐标；每次留出一条已付观测，重新编译候选并预测这条观测，按预测证据保留最多三个解释。再从公开随机点与边界点中选取预测分歧较大、位置分散的四个控制点，用同四次新实测比较全部冻结候选。未来误差难以区分时，使用此前交叉验证证据选择，长度仅作平局判据。

[研究控制器](../src/hegel_machine/cognition/joint_model_revision.py)使用滑动四条证据窗口，保留原九倍误差阈值和至少两条共同异常要求；补充测量数量随剩余预算缩减，始终为后续验证留出四次调用。已付反例进入拟合，低维候选可以在较少数据上接受检验。新解释继续通过真实 SC-KG 的目标／约束模型重建与共享知识库消费。

[固定协议及结果](../artifacts/sc_kg_joint_revision_competition_v033_20260910/summary.json)包含旧 28 个开发病例、新 18 个确认病例；两臂共 92 份记录，基线为保存的真实 0.32 代码与结果。所有病例均保持每臂 64 次模拟，其中初始 32 条完整向量观测双方相同。

开发六个带噪病例选出五个单坐标二次与一个加性二次，程序误差均值从 0.09326 降到 0.000380。新带噪确认的两个成功病例，程序误差分别约 1.39e-4 与 3.58e-4；其中一例在最后一次调用才采用，另一例采用后还有五条真实预测。30 个稳定控制无误重开，真实采样与基线一致。

区分实验改变了采样位置：新带噪确认在变化后全部 20 次调用上的预测 MSE 从 0.1559 增至 0.1770。每次成功研究的编译、交叉验证和实验规划计算为约 3693–4575 单位，高于旧版；总模拟预算保持不变。本批实际新增初始实测 384、在线调用 2048，独立评分另用 1536；历史初始、旧基线及评分记录复用，详见结果中的成本分项。

[完整认知回归](../artifacts/cognition_v033_release_20260910.log) **683 项通过**，覆盖非固定坐标的非线性发现、多候选事前预测、区分实验、八次剩余预算、真实 SC 优化、知识回传和暂停／恢复。[研究脚本](../scripts/run_sc_kg_joint_revision_competition_study.py)保存了数据复用与分组执行入口。

## Limitations 与下一步

新带噪确认仍有一例到第 61 次调用才发现共同失配，剩余三次无法完成四次验证；它主导了残余泛化误差。下一步应研究首次强反例出现后的主动确认实验，避免等待普通优化采样再次暴露问题，并继续保留稳定任务对照。当前仍限于这些机制、三维控制和噪声设置，尚未证明长期总体收益；一条上游墙钟耗时记录为负，因此本批不使用该字段比较速度。
