### 已知问题与下一步门槛

已知问题集中在证据解释和采用：历史断言的`satisfied/violated`描述原断言，当前`residual`描述本候选预测偏差；二者曾被混读，后续又发生分臂偏移错误。两种探测的输出相同只支持所测协议下的输出收敛，不能证明隐状态完全消失；反序结果也不能排除一般加性动态。固定五折已被多次用于开发选择，改善须继续经过新确认；当前结果未建立一般自主发现、递归组织独有收益或优于强Code的结论。早期随机／方差臂没有改变Python内直接选探针的决策，不能据其56次结果宣称选择策略的独立贡献。

后续沿已有入口逐步判断：

1. **证据门槛**：先使用已存同源OOF、行索引和正确分臂误差，撤回错误的第二臂解释；已有数据不重复购测，已恢复OOF不重复补算。
2. **候选门槛**：由Luna选择一项实测约束，改写其现有完整研究程序并实际保存、执行新`fit/predict`候选；若声明子结果影响模型，要有实际绑定及模型消费记录。无需先识别唯一全局机制。
3. **比较门槛**：沿保存的原分折规则、相同已付数据范围比较新旧候选。若纳入新增176行训练，应同时重评对应基线并标明范围；保留负结果，避免跨数据范围比较总分。
4. **确认与发布门槛**：满足既有付费拟合／提交条件后才请求新的96行独立确认及512行源终测；源成功后再走原方法实践／发布流程，新的迁移须另按既定登记执行。
5. **停止条件**：只有文字解释、诊断或旧算法重拟合而没有新候选交付时，记录未决，不原样追加同类调用。保护原26/26、窗口8/8、14/14稿、001成功预测器、039参照和全部付费记录。
