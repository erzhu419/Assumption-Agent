# 竞争风险解释驱动追加实验

0.97接通最新[GPT6 advice](../markdown/GPT6_advice.md)第378–435行要求的“竞争解释、辨别实验与追加投入选择”：已有残差修正有正收益、但当前样本不足以区分时，根据已付证据估算所需新观测；冻结原程序和竞争程序，购买完整字段的新响应，再决定修订或继续保留未决。后续拟合及代表性确认的预算先行预留；实验无法解决时不记作修订成功。

[实现](../src/hegel_machine/cognition/risk_experiments.py)、[四阶段配置](../config/cognition_risk_experiment_session.json)与[运行脚本](../scripts/run_risk_experiment_study.py)。相关26项测试通过；真实弱证据片段追加35行观测、140测量和280计算后，发现有支持的残差解释。该片段只说明实验路径有效，完整任务收益另测。

完整比较采用预先固定的8组新随机序列，每组噪声源→独立输入→响应变化→返回源任务；旧0.95、上版0.96.1与新0.97共96项。各题仍限384观测、1536测量、240000计算，固定0.9分位数目标及原控制采样策略。所有学习结束后，每题终测16×96行，计入失败研究与完整序列成本。[协议](../artifacts/risk_experiment_study_20260920/protocol.json)固定于运行前；两个已见开发序列单列。

新序列96项已全部完成，[完整结果](../artifacts/risk_experiment_study_20260920/main/final_digest.json)如下：

## Limitations 与下一步

相对0.95，学习测量增加24.03%、终测测量增加75.93%；独立输入阶段仍较差，尚不能称稳定净收益。样本数预测仍可能低估投入。此批重复已有机制，未增加真实普通Code对照。终测曾因并行读取未写完的检查点失败一次；原子替换修复及1项交错读写回归通过，仅补齐未评分的4题，见[恢复记录](../artifacts/risk_experiment_study_20260920/main/execution_recovery.json)。

下一主线：后继知识触发旧未解任务续研，恢复旧观测及竞争解释，按实际改善决定重访，并比较完整累计损失与成本。
