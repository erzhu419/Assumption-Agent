## Limitations 与下一步

当前状态与读出仍属于有限候选族，四套装置不能证明稳定长期净收益；新增观察表达能力不等于最新advice总体完成。本批旧版对照为0.89.1，并未新增普通LLM Code运行。无控制输入的纯初态衰减模型，若未加历史可用性保护而直接请求重置前的读数，仍缺少历史不足检查；本批响应均有重置保护。

下一主线是让多个观察解释参与竞争，并根据它们的分歧选择测量与研究步骤；不再把几个百分点的搜索成本优化作为优先任务。
