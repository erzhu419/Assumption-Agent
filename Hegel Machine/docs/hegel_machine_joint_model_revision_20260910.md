# 共同失配后的假设重研

2026-09-10，0.32.0。后续候选选择与预算改进见 [0.33 研究结果](hegel_machine_revision_competition_20260910.md)。

原失败案例已修复：即使学得模型相对更好，两个模型共同失配也会重开研究。系统实际执行覆盖测量、编译新解释、未来测量验证和模型替换，并把新解释存成可调用知识。`cognition prior --optimize` 已默认接入这一流程。

[JointModelRevision](../src/hegel_machine/cognition/joint_model_revision.py)冻结最初四次事前预测形成的误差／噪声参考，每四次实测比较两模型整体误差；两者均超过参考九倍，且至少两条共同异常时，保留反例并重开研究。偶尔准确的控制点不会清空邻近反例。八次公开覆盖用于拟合，之后四次实测验证冻结候选；已有拟合证据与未来证据必须同时达标。

[SC-KG 接线](../src/hegel_machine/cognition/sc_kg_environment.py)在原预算内购买这些测量。替换时，目标 GP、两种约束 GP 和噪声模型一起按新证据段重建，完整已付观测保留。[会话](../src/hegel_machine/cognition/meta_prior_session.py)保存旧先验的条件与反例、新解释的范围，并按实际使用阶段分别回传部署证据和成本。

[第一轮 38 次运行](../artifacts/sc_kg_joint_revision_v032_20260910/summary.json)修复四个无噪变化案例，却暴露连续异常规则的带噪漏检。改为批次累计后，[最终对照](../artifacts/sc_kg_joint_revision_batch_v032_20260910/summary.json)覆盖 19 个开发病例和 9 个新确认病例，共 56 份配对记录；旧结果与源码保留，三个确认种子在运行前固定。

## Limitations 与下一步

带噪候选仍容易按宽误差容差选出过简线性解释；下一步应让线性与非线性候选依靠区分实验竞争，并为剩余研究预算安排更早的验证。新确认三例分别是候选不支持、最后一次调用才采用、启动过晚预算不足；因此尚未证明带噪结构恢复或稳定长期优化收益。当前机制族、三维问题与噪声设置有限；单次 SC 优化中途的完整恢复仍未接通。
