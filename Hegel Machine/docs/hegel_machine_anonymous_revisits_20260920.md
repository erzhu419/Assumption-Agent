## Limitations与下一步

旧版一套续研因传感银行字段混用崩溃，终测使用最后交付模型；该次崩溃费用未保存，旧版总成本只能给下界。删除知识组获给定续研安排，不是自主普通Code；本批仍未证明稳定长期净收益。

下一主线是研究程序按当前任务修订：识别从焦点任务迁到事件任务后已失去区分力的实验，转向能区别当前关系的时序干预，同时给响应修订留下预算。
