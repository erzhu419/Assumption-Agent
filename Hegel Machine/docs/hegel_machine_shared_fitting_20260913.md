## Limitations 与下一步

主比较为有限条件先验与仿射控制，直接复用已完成的0.73正式60题；对象基线是实际执行过的0.72，0.73未跑该组。计算指标沿用项目行计算单位，没有墙钟加速或新增真实vanilla对照结论。原构想的一般结构生成与开放研究能力仍未完成。

下一步补动态仪器：现有标定丢弃控制历史，不能解释同一当前控制下由不同过去造成的读数差。接通带历史的仪器拟合、时间正确的程序替换与实验规划，让实测区分仪器变化和机制变化，再验证后继任务能否免去测量。
