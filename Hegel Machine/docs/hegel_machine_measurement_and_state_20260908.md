# 黑格尔机 0.11.0：测量、连续状态与剩余功能

后续进展见[0.12.0 整合研究系统](hegel_machine_integrated_research_20260908.md)，本文保留本版本的实现与运行记录。

日期：2026-09-08。对应当前本地工作树。

本轮沿 [GPT6 建议](../markdown/GPT6_advice.md)及其[详细方案](../markdown/Hegel_Machine_Vision_Progress_and_Research_Critique.md)，把“改变观察方式与表示”接成实际运行链：购买仪器读数，用观测比较测量组合，发现连续状态，再进入普通认知控制器的实验、修订和知识积累。此前 [0.9.0](hegel_machine_functional_implementation_20260908.md)与 [0.10.0](hegel_machine_callable_concepts_20260908.md)已实现证据续研、条件知识、行动经验和可调用概念。

## 本轮新增的实际行为

### 测量与控制分开

`measurement_lab.py` 提供三个连续过程任务，公开一个可控制输入和两个可购买的仪器通道。每次实验返回所选通道的实际读数，分别累计观测与测量费用。`process` 后端把装置状态与参数放在另一个本地 Python 进程，通过 JSON 行请求执行控制、采集读数和返回结果。

`MeasurementResearchAgent` 先购买两条试验轨迹，在第一条上拟合每个可承担的测量组合，用第二条比较预测收益，再选出在已测最佳损失容差内费率最低的组合。试验轨迹继续作为已获得证据进入普通 `CognitiveAgent`，后续实验按选定通道实际扣费。三个策略 `learned`、`controls_only`、`all` 分别选择仪器、仅观察控制和响应、使用所有可承担仪器。

实际下发的 probe 只包含可控输入。为比较尚未执行的实验，两种探测策略使用已获得的仪器路径构造可能的传感器读数情景，预测费用按情景数计算。

### 连续状态成为可执行的解释

新增 `accumulate(decay, drive, initial)`：从一次实验的起点沿已见输入递推连续状态。状态搜索从观测估计衰减、输入驱动、初始值与读出，支持两个模式的线性读出，以及同一衰减下的平方和交叉读出。某些二次读出可约化为一个有效驱动方向。

程序可以在没有历史目标值的新轨迹上执行。状态结构能够作为子概念抽取、嵌套调用、重绑定变量和保存恢复；衰减系数参与拟合形状，避免把不同时间尺度误当成同一个拟合问题。

### 累计解释与概念选择

`ResearchWorkspace` 保留累计证据支持的最佳候选。候选筛选必须让它参加完整比较；新轨迹打平时，如果原始证据和参考证据都明确支持它、收益覆盖新增复杂度，控制器可以恢复较大的解释。新轨迹明确反对旧解释时仍保留新证据的决定作用。

可调用概念先由已获得证据筛选。普通坐标和历史拟合仍有残差时，才比较哪些调用及其组合能提供额外解释能力；筛选复用已有拟合程序，并给实际组合拟合留下计算额度。不同来源的有用概念由残差收益参与选择。

续研及明确选择表示修订时，控制器集中分配完成基础坐标与历史拟合、必要项裁剪和候选比较所需的资源。其他搜索使用扣除这项承诺后的余量，使已经获得的证据能形成完整解释。

## 运行入口

在项目目录运行：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition lab \
  --checkpoint artifacts/lab_learned.json --backend process \
  --tasks 0 1 2 --steps 1

PYTHONPATH=src python3 -m hegel_machine cognition lab \
  --checkpoint artifacts/lab_learned.json --resume
```

默认每任务上限为 128 条观测、100000 个计算单位、512 个测量单位和 3 轮研究。每完成一题保存程序、已获得证据、知识、费用及独立长轨迹评估。恢复发生在任务边界，跳过已完成任务。`--strategy controls_only` 或 `--strategy all` 使用各自 checkpoint 运行对照；评估计算独立列出。

## 实际结果

[249 项认知回归](../artifacts/cognition_v011_integrated_tests_20260908.log)及 [1 项表示续研专测](../artifacts/cognition_v011_representation_runtime_20260908.log)通过，共 250 项。新增行为覆盖连续递推、变量重绑定、无历史目标值预测、真实测量费用、两种实验策略、普通控制器选择状态研究、累计解释恢复、概念证据选择和 CLI 任务边界恢复。

[三策略实际进程运行](../artifacts/measurement_v011_integrated_comparison_20260908.json)使用相同任务和资源上限，每题完成研究后另测 4 条 64 步轨迹。每个策略内部跨三题共享其自己的知识库。

学习选择在三题均保留 `sensor_a`。相对所有仪器，节省 456 个测量单位，同时多用 79360 个研究计算单位：选择本身有计算成本。本次结果支持在此装置中辨认有效测量并减少仪器支出，未显示所有资源都更少。

测量会话先完成一题暂停，再由新命令恢复并完成剩余两题，第一题结果原样保留。每条评估轨迹发生在本题研究结束后，768 行评估费用单列。

第一次完整运行暴露了一项真实失败：[原运行](../artifacts/lab_v011_learned_20260908.json)在平方读出任务选中了无关仪器，最终 MSE 为 0.25847。连续状态优化器曾把状态数超限、不能保留为最终程序的中间二次拟合当作完成，返回了较差的旧候选。修复后先构造实际可执行的一至二维状态方向，再用该程序的预测误差判断停止；原始负结果保留。

另一轮 [65 任务整合运行](../artifacts/hegel_machine_v011_first_integration_summary_20260908.json)暴露了普通表示预算的连接问题。三步延迟任务的新状态搜索没有改善预测，续研时已有 86 行观测，但每轮只给了零碎的历史拟合工作。相同证据用 2040 个计算单位的一次普通搜索即可恢复正确解释；实际轮额度在比较等费用扣除后只剩约 1423。这个失败用于修正完整拟合与后续比较的资源分配。

修正后的[完整会话](../artifacts/hegel_machine_v011_integrated_summary_20260908.json)完成 65 个任务、75 次访问，暂停前十次的程序原样保留。56 个任务达到学习侧阈值，9 个继续列为未解决。三步延迟任务的独立 MSE 恢复至 6.07e-20。[终局评估](../artifacts/hegel_machine_v011_integrated_evaluation_20260908_summary.json)记录 10 次续研中 6 次有明确改善、0 次明确恶化；这项比较只衡量同一会话的首次与末次访问。

| 可调用概念与语言生长 | 定义、嵌套组合、共享执行、证据选择与状态子概念 | 根据多任务使用合并或拆分概念，学习更丰富的对象语义 |

| 观察、潜在状态与尺度 | 实际仪器选择、连续状态、状态读出、长轨迹执行 | 主动改变聚合尺度、形成对象与事件、在研究过程中重新配置仪器 |

## 下一步的建设顺序

先把有效实验变为可迁移知识：保存被区分的解释、实验条件和后续收益，在下一任务检索并改造这项实验。它直接推进实验价值判断、错误迁移与方法学习。

随后让研究方法的步骤可修订：将成功与失败的行动序列提炼为带适用条件的方法，实际比较继续拟合、改测量、换表示及停止的收益。结构先验沿具体装置扩展，优先贯通局部机制或守恒关系的发现、区分与使用；普通代码 Agent 对照同步接入。

## Limitations

- 三个新任务仍是本地模拟装置；独立进程执行增加了实际交互能力，尚未接入现实仪器或第三方服务。
- 连续状态搜索在给定的递推族和有限读出内工作，不能据此宣称一般隐藏机制恢复。使用最多两条状态模式，尚无对象、事件或自选尺度的通用构造。
- 测量策略在任务开始比较通道，此后固定；先买所有可承担仪器的试验费用计入总支出。未来传感器情景由经验路径近似，尚未学习可干预的传感器生成模型。
- 原有 65 题中，任务索引 7、21、61 的终局损失比 0.10.0 增加，分别为 0→0.005208、0.001319→0.002426、0.021484→0.029297；索引 3、8、20、21、32、44、51、57、61 未达到当前学习侧阈值。功能扩展尚未形成全面的质量或成本优势。
- 测试和本地装置结果验证本轮功能与有限任务效果；完整开放世界构想、方法自我修订及优于完整普通 Agent 的主张继续保留为研究目标。
