## Limitations

本轮限普通控制观测、平方损失和不读取历史目标的响应。稳定长期净收益仍未成立；CPU覆盖完整研究调用，未做函数级归因，不能将增长全部归于追加实验；本轮普通新轨迹直接比较两套冻结模型，并修复了回访噪声游标，未分别消融这两项。独立组也是完整搜索Agent重置知识，并非普通Code/LLM对照；一般条件分支与更广泛结构组合、完整同LLM对照仍未完成。
