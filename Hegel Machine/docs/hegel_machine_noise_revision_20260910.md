# 从重复观测修订噪声模型

2026-09-10，0.45 研究实验；未采用为默认策略，当前版本仍为 0.43，默认认知行为沿用 0.42。

上一批四个不可行推荐中，有的已被重复观测三至四次。原 pooled HVD 混合拟合残差与同点样本方差，每条记录等权；多次复测揭示的噪声可能被大量较小的拟合残差稀释。

本批新增一个可竞争的噪声估计：在同一有效范围内，每个点只保留一份样本方差，按其 `n−1` 自由度合并；被撤销的约束观测排除。后续同点实测与测前已有 `n` 次观测的均值作差，用 `(1+1/n)σ²` 比较预测损失，避免让 GP 均值误差决定噪声模型的选择。证据支持时采用，反证支持旧模型时撤回。当前实测先评价测前预测，再进入下一轮参数更新。目标与约束分别研究；已知机制研究未决时暂停对应噪声研究。

采用后的噪声进入下一次 GP 更新、可行性判定和实验模拟；原 HVD 持续更新，保留撤回依据。模拟观测也可触发采用或撤回，并按同一重复统计规则重拟合。实际观测预算保持 N64。

## 实际结果

第一版 16 例全部持平，结果保留在[开发记录](../artifacts/sc_kg_noise_revision_v045_20260910/development_attempt_v1/)。第二版[完整 382 例](../artifacts/sc_kg_noise_revision_v045_20260910/result_brief.json)为 **0 改善、382 持平、0 退步**；两臂均有 378 个可行解。旧 355 例的四个失败未修复，新 27 例均可行。真实观测轨迹、推荐点及两 GP 误差也全部相同。

538 个噪声候选中，476 个（88.5%）不足本方法所需的四次未来复测；50 个已有四次但仍未分离，4 个获证据支持保留旧模型，8 个支持新模型。[八次采用](../artifacts/sc_kg_noise_revision_v045_20260910/adoption_outcomes.json)均为最后一次观测后的目标噪声修订，已没有后续优化动作。约束噪声未获采用。

新 27 例完整 KG 评分耗时 46.09 → 47.39 秒，未产生优化收益，因此已恢复默认策略；[冻结实现](../artifacts/sc_kg_noise_revision_v045_20260910/method_source_v045/)、运行脚本与实验测试保留。83 项相关测试通过。含第一版开发，本轮实际研究模拟调用共 11,008 次；未触发新方法的旧轨迹和既有观测已复用。

下一步把噪声区分实验提前纳入研究预算，使检验完成后还来得及改变决策；同时处理少量重复样本下噪声估计的不确定性，以及约束均值的局部偏差。[失败分解](../artifacts/sc_kg_noise_revision_v045_20260910/failed_noise_diagnosis.json)显示已有足够复测的候选也未获支持，单纯降低采用门槛不能据此解决问题。

## Limitations

本批研究 pooled 噪声。采用新噪声后，过去 GP 更新使用的权重尚未重算；新预测损失的配对标准误是经验判据。未知机制变化仍可能污染同点差异，暂停条件依赖现有机制研究的发现能力。重复观测的噪声拟合和更好的后续预测，均不能直接保证最终推荐可行。
