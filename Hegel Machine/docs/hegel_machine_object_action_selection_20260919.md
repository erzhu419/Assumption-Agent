## Limitations 与下一步

本轮实验证据覆盖公开对象角色及既有测量视图下的失败恢复；内层区分实验继续执行已有研究程序。未产生候选的诊断开销已计全会话费用，但尚不更新跨任务动作价值；本批4次有经验的输入诊断花费32观测、336测量而保留原经验。匿名对象归纳中的同类选择尚未检验，风险任务的共同选择及稳定长期净收益仍未完成；本批未新增普通Code对照。下一主线为固定风险目标下的共同投入选择：让不确定性修订、机制修订和输入重测按同批新响应的实际风险损失竞争，先用已有噪声、遗漏输入与返回旧任务的序列验证。
