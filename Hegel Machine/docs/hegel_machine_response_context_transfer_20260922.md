# 0.113：实验方法的响应背景迁移

方法现在保存实测有效的响应分支，按后继程序及仪器重绑布尔激活条件，再执行已有边界求解。实测成功才积累子方法，失败只限制对应条件并保留父方法；预算入口按最短必要历史预筛，再支付实际实验长度。新增5项真实实验回归、相关既有32项通过。

12个新来源实际从空库学习；两类后继、三档预算、三臂共216次学习及216次终测完成。各后继独立从同源重启；删除臂只删除来源实验方法，仍可学习新方法。达标阈值为4条独立64行轨迹的MSE≤1e-7；[完整结果及来源费用](../artifacts/boundary_method_transfer_20260922/fresh_replication/summary.json)。

新版在6个独立来源的8次后继运行中实测完成背景改写。相对旧版，实验规划计算减少4.99%，但全部后继计算仅少179／约1287万，观测多4行、测量多48，含来源学习CPU增加0.33%。删来源方法少解的1题未使用新增改写，因此本次新机制的终测收益尚未体现。

## Limitations

新版仍有3次误判完成；当前改写限于分支激活条件，长期净收益与外部LLM对照未完成。本批均为本地离线实验。
