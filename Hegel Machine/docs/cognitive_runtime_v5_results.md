# 认知主线 0.7.0：状态转换、迁移实验与尾部学习

日期：2026-09-08。[0.6.0 结果](cognitive_runtime_v4_results.md)保留本轮开发依据。

0.7.0 在旧 continual 上把平均平方误差从 **0.008628 降至 0.000716**，观测减少 **14.2%**、计算减少 **14.9%**。新 stateful 的状态分类错误率从 **10.20% 降至 3.05%**，整体平方误差下降 **68.1%**。本轮两个分区中的知识都实现了观测和计算净节省。

改进主要来自单输入状态规律、证伪后的及时拟合和可用参数的保留。双输入组合状态仍有明显退化，真实切换行的总错误由150增到164；新任务中的尾部拟合也没有稳定优势。这些病例构成下一步开发重点。

## 实际改变

`state_search.py` 从实际观测的两个输出值出发，比较无状态规则与依赖前一输出的条件规则。进入、保持和启动条件分别拟合；变量、阈值方向、历史长度以及启动是否共用某个状态分支都参与竞争。相邻观测之间的阈值变体保留下来供实验区分。所有输出仍是原有 `Program` 表达式。

`transition_probe` 在候选的阈值附近找未观测区间，给同一输入安排不同的准备历史，轮换高／低值起始，并单独探测启动条件。控制器先比较冻结的候选，再安排下一次定向实验；取得的反例可以阻止提前结束，并为后续比较保留观测额度。已有观测支持的同等复杂度修正，可以在新代表轨迹没有退化时采用，避免窄边界恰好没被新随机轨迹覆盖就拒绝修正。

迁移现在保留旧模板参数，同时提出重新拟合的参数。初始轨迹不足以估计长延迟时，已有系数仍能接受新实验比较。既有观测和新轨迹都支持的迁移可以提前结束；在两种证据上均明显较差的旧候选退出本次竞争。若新代表轨迹已经证伪了初始看似可用的记忆，系统先用这些数据完成下一轮拟合，再决定是否需要购买更多观测。

风险候选增加稳健位置与尺度的联合估计，通过全部残差共享标准化尾部信息，并与直接条件分位数拟合竞争。采用和回退参考累计代表轨迹，降低单条短轨迹的影响。最终预测程序确定后，预留的 16 个观测实际用于两条新的八步轨迹；校准将中心化训练残差先验与这些新残差合并后取分位数。

## 对照设计

保存的完整 0.6.0 包位于 `artifacts/cognition_v4_reference/`。各配置上限一致：每个 episode 96 个观测点、24,000 个计算单位、5 轮研究；实际支出分别报告。

| 配置 | 区别 |
|---|---|
| reference_v4 | 完整 0.6.0 |
| cognitive_v5 | 完整 0.7.0 |
| without_state_search | 不生成新的状态条件候选 |
| without_transition_probes | 不使用新的状态／启动阈值实验 |
| without_transfer_scheduling | 不保留原参数竞争，不使用迁移提前结束和候选淘汰 |
| without_tail_fit | 保留 0.6 分位数候选、校准和单条新轨迹决策权重 |
| without_knowledge | 关闭跨任务知识 |

旧 continual 使用种子 401、503、607，是本轮开发依据。新 stateful 使用预先确定的种子 809、907、1009，包含状态方向、变量角色、两个控制量组合、同一上下文状态条件改变及其他确定性和风险任务。训练单次轨迹最多 32 步，最终为八条独立 64 步轨迹。

除原有预测、行动损失、资源和错误修订外，新增二值状态分类与实际状态改变位置的错误数，并分历史长度报告。评测记录在学习结束后生成。新 stateful 的首次运行在最后一次旧任务修正和135项测试通过后开始；首读后生产代码未再调整。

最终实验包含 **42 条完整序列、504 个配置—任务 episode**，全部完成。旧 continual 每条序列含10个平方损失任务和2个风险任务；新 stateful 含11个平方损失任务（其中8个二值状态任务）和1个风险任务。损失按同一类型任务平均，再对种子平均；资源为每条12任务序列的平均实际支出。

## 病例与后续工作

**单输入状态规律已经改善。**旧 n10 三种子的平方误差从0.071891、0.101666、0.085285降至0.011719、0.005859、0.003906。新 stateful 的基础、变量换名和阈值改变病例共9,216行，错误从旧版1,019降到63（11.06%→0.68%），切换行错误从114降到28。最后同名 s01 改变条件后，新版三种子仅16行错误，能够依据新观测修订旧规律。

**剩余状态错误集中在组合表示。**s08、s09贡献了新版375个错误中的312个（83.2%）。实际机制分别由 `x + 0.45*z` 和 `0.35*x - z` 驱动；专门状态搜索仍主要对单个原始变量拟阈值，809和907的最终程序均遗漏另一个输入。组合病例错误率为10.16%，高于旧版7.62%；组合切换行错误从36增至136。现有转换实验把另一个输入固定在中点，只能继续细化这个切面。

下一步应贯通“联合坐标搜索—状态条件规则—实验设计”：由观测学习控制量的组合，在该组合上比较进入／退出条件，再同时变化多个输入去区分竞争解释。1009/s08的通用关系搜索已经产生双输入与历史状态组合，说明可执行语言具备表达能力，缺口在专门搜索和实验的衔接。

**知识资源收益开始同时体现在观测和计算。**相对无知识，旧 continual 每条序列平均净省98.67个观测、20,087计算单位；新 stateful 净省17.33个观测、8,369.33计算单位。新 stateful 的总体状态错误也减少，但切换行错误高于无知识、无迁移调度臂，主要仍来自组合病例。单看新状态迁移任务，完整系统与无调度的总观测为561与562，节省主要来自更广泛的任务序列，不能归给这一小组。

**尾部风险收益仍不均衡。**旧 continual 完整行动损失为0.319486，关闭新增尾部机制时为0.345584。新 stateful 两者仅为0.353477与0.354249，而直接pinball反从0.355519升到0.369302。后续应研究组合或情境变化下的位置／尺度表示与尾部观测分配，依据实际行动结果判断是否有收益。

## Limitations

- 两个分区都是公开合成环境；continual 已用于开发。stateful 的首次结果在模型确定后读取；后续若据此改动模型，它也成为开发依据。
- 状态规则来自有限的表达式和候选搜索。当前状态搜索主要学习二值观测输出与控制变量的阈值关系；不能据此推断一般隐状态发现。
- 每组只有三个 suite 种子；共享预算上限不等于相同支出。分类错误率按二值输出阈值计算，与平方误差分别报告。
- 预测使用实际已观测历史；长轨迹结果不等同于缺少后续反馈时的自由递推预测。
- 风险采用／回退使用自适应研究资料。独立新轨迹在程序选定后用于校准，有限尾部样本仍不提供一般覆盖保证。
- `fresh_gain` 仍表示新轨迹损失差，`evidence_gain` 表示用于决定的证据损失差；`calibration_weight` 在新模式中是校准残差的质量占比，具体语义由 `calibration_method` 区分。
