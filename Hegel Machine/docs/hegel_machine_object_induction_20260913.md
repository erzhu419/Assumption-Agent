# 匿名对象发现与组合研究

2026-09-13，0.65.0。研究者现在从匿名控制、传感字段和付费转移观测中学习对象划分。前后变化和单独干预提出数量、驱动及位置假设；未决归属决定下一次混合干预和选择实验。完整对象模型进入仪器学习与概念组合，后继先取得新证据再复用；同名改线后撤回失配模型并重建。总量响应无法区分选择归属时保留多个候选。

已学概念还可与当前对象角色共同作时间变换，通过联合拟合消除状态项，保留原调用中的局部作用，再形成事件、总量组合和窗口程序。实际采用的依赖与步骤进入研究图。噪声解释则接受一次独立重复实验：完整实测输入历史相同、响应稳定而模型仍有明显误差时，继续寻找未解释的关系。

## 运行结果

开发序列包含焦点、总量、事件、组合、窗口、同名改线及改名后继9题；两臂从空知识开始，均只收到匿名接口。每题预算512观测、6144测量、480000搜索计算；独立终测每题4条64步新轨迹。对照只关闭对象归纳。

第一版对象恢复9/9，但预测仅5/9，对照1/9。[失败结果](../artifacts/object_induction_20260913/development_v1/summary.json)保留：事件重新估计已有关系边界，在最后确认失败；下游缺失事件知识，近似残差又被当成噪声传播。[修复后开发](../artifacts/object_induction_20260913/development_v2/summary.json)默认9/9通过，最大MSE为2.88e-18；全部最终预测免测量，学习1326观测、8478测量、352938搜索计算。对照仍1/9，8道失败题均保留未解决状态；其中5题的独立重复观测实际否决了噪声解释。

正式三种子包含新的装置、匿名名字及接线，其中一组为4对象；每种子两臂各9题，另有一个空知识总量阴性。合计57题已完成，[正式结果](../artifacts/object_induction_20260913/comparison_v1/summary.json)：

完整序列的观测、测量与搜索计算分别减少35.88%、33.39%和86.13%。默认最大终测MSE为5.94e-17，三次同名改线均触发旧对象模型撤回与重建，事件和窗口后继继续调用已有概念。三个独立总量阴性均准确预测，同时保留3、4、3个选择归属未决；这些阴性不计入27题覆盖率。

## Limitations 与下一步

首次对象识别的观测1017对648、测量7320对4320，分别增加56.94%和69.44%；该三题默认3/3、对照0/3，完整序列的节省来自后继复用。数量、驱动、位置、选择这组角色假设及一对一分组仍预设。主循环仅把完整对象图用于结构研究，部分已识别关系尚未直接使用；两个对象的位置可能对称，位置直接作用于动态时仍可能与驱动混淆。重复响应检验只针对取得的匹配历史，不能证明一般环境没有噪声。搜索计算采用现有逐行计费。

本轮未新增真实LLM调用；关闭对象归纳是算法消融，既有提供对象角色的Code结果不构成当前匿名任务的配对比较。22项元先验通用化、任意新角色与研究操作、开放分布长期净收益仍未完成。

下一步让部分对象图按任务需要直接参与预测与研究，并让角色与依赖分解本身成为竞争元先验，用不同干预背景区分位置直接作用和驱动，继续推进角色定义的修订。对应[原目标进展](hegel_machine_advice_goal_status_20260909.md)。
