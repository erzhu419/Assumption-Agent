# 对象结构旧题续研

0.100把[最新advice](../markdown/GPT6_advice.md)第471–499行的竞争解释、主动实验和知识后续价值接入对象旧题。后继概念先在旧题同批已付响应上比较；续研恢复对象候选、关系条件、研究图、细粒度测量及状态转移，进入原结构干预、关系区分和独立确认流程。细测量可按公开接口投影为粗测量，旧批次不重新采购。[会话配置](../config/cognition_object_revisit_session.json)与[比较脚本](../scripts/run_object_revisit_study.py)。

开发场景：A已执行结构干预但64观测/12000计算耗尽，B在测量字段改名后自主学得关系，随后尝试返回A。三臂固定为0.99、对象续研和按同一续研安排删除后继知识；总池是两次初访配额之和。正式比较使用8套预定新装置，覆盖2/3对象与焦点/事件响应，全部初访与续研结束后再独立终测。

19项相关测试通过。[正式结果](../artifacts/object_revisit_study_20260920/main/final_digest.json)全部正常完成，三臂48项初访、16次实际续研全部计入。各题须随机轨迹与公开边界误差均≤1e-6才算达标：

|---|---:|---:|---:|---:|---:|
| 0.99 | 8/16 | 0/8 | 2,809 | 13,758 | 1,541,171 |
| 0.100 | 16/16 | 8/8 | 2,965 | 14,757 | 1,621,907 |
| 删除后继知识 | 12/16 | 4/8 | 3,500 | 18,789 | 2,003,800 |

新版相对旧版8胜0平，相对删除知识4胜4平；后者观测、测量和记账计算分别减少15.29%、21.46%、19.06%。相对未解决旧题的0.99，这三项增加5.55%、7.26%、5.24%。学习CPU分别104.56/116.86/114.41秒，计算计数的减少未转为CPU节省。8次续研均实际采用后继概念，恢复比较62个候选；继承并按旧实测检查关系区间后，新增8次独立确认、156行和999测量，另计筛选76,024计算。本批无需新购区分实验；删除知识臂重新购测区分实验后仍有4题未决。

新版最终16题均可免仪器预测，同一终测规模的部署测量费用为0（旧版18,540，删除知识19,440）。为了同时评价初始和最终模型，实际终测仍购入5,664行及旧版/新版各18,540、删除知识19,440测量，未计作部署节省。[预定协议](../artifacts/object_revisit_study_20260920/protocol.json)保留装置、预算及独立终测设置。

## Limitations与下一步

本轮聚焦公开对象角色接口的未解题。匿名对象归属尚未学全时的继续归纳、对象完成判断受新知识挑战、跨结构分解和更一般的研究程序改写仍需推进。删除知识臂接受给定续研安排，不能替代自主普通Agent；稳定长期净收益仍需完整序列证据。
