# 含噪响应修订（0.127，2026-09-27）

落实最新 [GPT6 advice](../markdown/GPT6_advice.md) 的主动区分、有效修订和后继复用：重复实测既用于区分噪声，也用于重拟合已有响应基底及窗口内部公式。新候选与旧程序在新轨迹上竞争，保留实际更好的解释；噪声尺度和定向反例也可由实测修订。

同预算比较0.126与0.127，均从空库开始、跨两阶段积累知识；每题最多240行观测、240000计算。所有研究完成后统一进行4×64行独立终测，全离线。两组关键回归分别21项、35项通过，覆盖重拟合、旧模型保留、重复实验及续研。

首次方案在另一批新装置上出现一次严重退化，完整负结果保留。修复实测重复未进入拟合、训练残差低估噪声尺度及大幅系统误差误判后，该已知窗口反例MSE由3.977恢复至7.579e−5；其源任务的新拟合在新观测上输给旧程序，系统正确保留旧程序。旧反例纳入开发，最终复现另用新种子。详细记录及运行入口见[实验记录](../artifacts/noisy_response_revision_20260927/README.md)。

## Limitations 与下一步

开发仍有1题未决；正式4题误差变差，其中新增完成的窗口题精度反而降低。部分噪声尺度修订让研究过早停止，并把较差来源传给后继，静态响应尚无平均收益。当前证据限于两阶段、固定基底与独立响应噪声，经验3SE判断不提供通用统计保证，也不等同于普通LLM/Code对照。下一主线转向更长的机制变化序列，结合后继收益判断停研、追加研究和知识撤回；一般条件分支、高维对象冷启动和外部模型对照仍未完成。
