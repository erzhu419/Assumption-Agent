## Limitations 与下一步

噪声实验限于 pooled 模型；方差后验 95% 分位数不构成新的频率覆盖保证，模拟仍用匹配矩的 Gaussian 分布。主动提名的独立收益与目标续验修复仅做了上述开发回放。下一步让收益明显但差异较大的候选保留未决状态，按剩余预算和区分价值决定是否追加验证；同时继续解决混合变化前后数据的均值失配。整机开放世界能力与稳定长期净收益尚未实现。
