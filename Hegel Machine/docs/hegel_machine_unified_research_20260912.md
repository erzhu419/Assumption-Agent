# 0.59：统一未知任务研究与知识投入

本轮把测量、历史、表示、递归残差和跨任务知识接入同一研究循环，新增可恢复的 `cognition unified` 入口。研究者只取得公开控制、可购买仪器和实测，不接收正确机制类别。原建议的三处缺口已有共同执行与比较；22项元先验通用化及开放世界研究仍未完成。

## 实际实现

- 旧表示失配后，共同比较参数、历史、非线性表示，以及购买仪器后的联合解释；`ResearchGraph` 中的残差子问题实际求解并参与父程序候选比较。选中的程序用新的完整轨迹确认。
- 完整学得程序决定短试验的仪器需求，执行8行拟合、8行新验证、8行冻结确认。失败时保留普通研究预算，重开假设；延迟变化与相关仪器换位均已执行。
- 概念沿用现有DSL和共享知识库，跨命名绑定后实际调用；新知识可以导出并被既有元先验研究与会话消费。实验方法来源与最终程序调用分别记录。
- 普通代码对照沿用真实LLM/Python工具循环，自主选择测量、编写和修改代码；共享Python源码与二进制学习产物进入后继任务。

统一任务流包含当前响应、控制历史、仪器历史联合依赖、重命名、延迟变化、非线性仪器、相关仪器换位、低秩组合八类机制，随后再次交错访问。三种子各16题；每题上限192观测、768仪器费用和120000研究计算。外部评价使用学习结束后的4条64行新轨迹。

所有方法预测误差均接近零。相对无记忆，默认版本少用50.67%观测、50.90%仪器费用和57.04%搜索计算。30题通过短研究完成，其中27题的最终程序保留实际概念调用；其余短研究利用了知识指导的实验方法。错误旧延迟经过短试验被拒绝，仍有预算学出正确新延迟。

第二轮合计24题，默认版本只用576观测、1152仪器费用、17040计算；固定库为2304、9216、21744，三项均较少。整个16题序列中，首次发现的计算费用仍使系统高于固定库。定向探针本批只增加计算，因此默认使用随机轨迹，测量与修订选择继续由证据驱动。

首版统一循环虽48题全部解出，但记忆没有减少观测和仪器支出；该负结果促成上述知识指导投入。首版192任务记录完整保留；第二版新增96任务，复用未受改动影响的固定库与无记忆记录。[首版](../artifacts/unified_research_20260912/summary.json)、[第二版](../artifacts/unified_research_20260912/revision2/summary.json)、[协议](../artifacts/unified_research_20260912/protocol.json)、[默认选择](../artifacts/unified_research_20260912/default_selection.json)。42项相关测试通过。固定实验对照另外执行48题，四条24行轨迹、全部仪器及采样量均在看到响应前确定。相对此对照，默认版本少用22.92%观测、69.31%仪器费用和31.67%搜索计算。

## 普通代码Agent共同对照

第一种子相同16题流已全部运行。默认系统、固定候选库、完全固定实验、无记忆及普通代码Agent五类对照共用公共任务接口与每题观测/仪器上限；另保留定向探针消融。

| 同一16题序列 | 可执行模型解出数 | 学习观测 | 学习仪器费用 |
|---|---:|---:|---:|
| 0.59默认 | 16/16 | 1184 | 1872 |
| 普通代码Agent正式交付 | 10/16 | 1328 | 5048 |
| 普通代码Agent加入已写但未交付模型的事后执行 | 16/16 | 同上 | 同上 |

普通代码Agent使用实际Codex/Python循环，自主发现联合依赖、修正仪器换位并复用方法。6题因token预算停止而未交付；全部学习结束后，原样执行它已写出的 `model.py`，6题全部通过独立终评，未增加模型调用、学习观测或代码修改。[事后执行记录](../artifacts/unified_research_20260912/secondary_authored_models.json)单列，原始交付结果保留。双方16题误差均接近零；这批没有体现预测精度优势。

默认系统少用10.84%观测、62.92%学习仪器费用。前8题普通代码观测更少（744对992），后8题默认系统更省（192对584）。普通代码自身后半段也减少采样和调用，这一顺序变化不等同于其记忆消融。双方最终16题评测均使用4096行观测与4096仪器费用。

普通代码共66次模型调用、1,406,375报告token、4.50秒学习阶段Python执行；事后执行另用1.23秒Python、496次既有训练行评分、1536行独立评价。每题最多6次调用、80000 token按调用间用量停止，末次调用可能越过该值；Python执行上限60秒。代码组的行评分量不包含LLM推理和任意Python拟合工作，不能与符号搜索计算直接比较。真实对照配置保持原有 `gpt-6-astra` / `ultra`。

## Limitations 与后续

后续对象关系研究发现：本批Code接口未提供同次付费测量返回的对象前后状态，Hegel可以使用这些转移。因此对象任务并非完全相同证据权限的比较；原结果保留，后续对照已补齐该接口。

本批是有限构造机制上的开发比较。八类机制及四步历史、多项式和残差组合构成当前发现范围；仪器来自已有目录，普通发现阶段仍可能一次购买全部仪器。尚未统一一般风险分布、任意隐状态、其余结构族和22项元先验，递归仍主要围绕残差分解；默认48题中12次子问题已求解，但最终均选择其他候选，本批尚未显示递归分解自身的独立收益。SC-KG的点式程序接口仍不支持直接部署历史程序。

第二轮出现了明确的知识积累收益，不能据此概括任意长期任务的稳定净收益。下一步应扩展到参数与机制持续变化、旧知识长期失效、风险目标，以及研究方法自身的更一般修订；新增能力继续进入本次共同任务接口和对照。
