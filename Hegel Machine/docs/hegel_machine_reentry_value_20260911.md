## 未知内部最优点对照

已有[优化空间诊断](../artifacts/sc_kg_reentry_value_v053_20260911/headroom_diagnosis.json)：544 例中 383 例达到各自已知整数全局最优，八个实际重入任务中有七个如此。为保留实际优化空间，新增三个最优点不同的任务；控制器只能取得含噪观测，最优点参数仅由模拟器和评价器持有。

冻结 0.52 与普通 SC-KG 共享 32 次付费初始观测，各再用 32 次在线观测；原生候选行为保持原样。[实际结果](../artifacts/sc_kg_unknown_optimum_pilot_20260911/result_brief.json)如下，目标值越低越好，三个任务真最优均为 0.35，六个最终建议全部可行。

| 任务 | 初始最佳可行值 | 普通 SC-KG 终值 | 黑格尔机终值 |
| --- | --- | --- | --- |
| 1 | 0.42478 | 0.37600 | 0.35000 |
| 2 | 0.45082 | 0.40800 | 0.35138 |
| 3 | 0.38602 | 0.38108 | 0.35022 |

平均最优值差距从 0.03836 降至 0.000533。三例均从付费数据拟合目标模型，实际购买目标改善实验分别为 1、1、2 次；未发生研究范围重开或新增目标模型替换，结果支持现有目标建模与实验选点组合的效果。

[任务实现](../scripts/sc_kg_unknown_optimum.py)与[配对运行入口](../scripts/run_sc_kg_unknown_optimum_study.py)已保存，新增三项任务语义测试通过。试跑新增 672 次物理调用（96 初始、192 在线、384 评价），连同两版重入比较，本轮合计 1344 次。Hegel 初始研究计算 6507、在线目标研究计算 30802；原生 KG 部分计时为对照 5.16 秒、Hegel 6.22 秒，未显示计算节省。

## Limitations 与下一步

当前 GP 的一步终值模拟没有表达完整的假设修订收益；局部预测失败也不能直接等同于该位置没有测量价值。两版重入简化均未取得可采用的结果。

新对照只有三个稳定、可分离二次目标任务，原生 GP 的基函数也能表达它们；两臂共享 Hegel 初始观测，不是独立冷启动或普通 Code Agent 对照。尚不能据此确认递归修订收益、跨任务泛化或长期净收益。下一批扩展到未知最优点发生机制变化及目标含交互项的任务，再比较修订是否改善最终决策。
