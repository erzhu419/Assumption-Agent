## Limitations

两组8任务是有限机制对照，且自然组没有负迁移；撤回效果来自独立的真实观测回归案例。来源配对收益尚不等于多知识删除消融的因果贡献。对象迁移等其他入口尚未统一接入。本批相关计划先于回传排队，新收益没有被后续筛选消费；稳定长期净收益仍未成立，四类总目标仍未整体验收。

下一核心：让新来源反馈作用于尚未执行的研究选择。先比较待执行计划的实际来源与适用条件，保留已有有效计划；只有反馈改变候选选择时才支付重新研究费用，并在含正负迁移的自然序列中检验追加投入和撤回是否产生净收益。
