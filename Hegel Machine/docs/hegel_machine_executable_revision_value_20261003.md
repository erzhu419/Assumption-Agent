# 可执行修订估值试验：主线保留0.173

对应最新 [GPT6 advice 第五、六节](../markdown/GPT6_advice.md)，实现并试验了[可执行修订估值器](../artifacts/confirmation_value_risk_share_20261003/runtime/src/hegel_machine/cognition/condition_revision_value.py)：从仍符合全部已付数据的阈值解释出发，模拟现有修订器会采用的程序，再在普通付费背景上估计预测损失下降；无程序改变不计即时预测收益。报价接入当前任务的条件研究和共享预算中的仪器回访，保留真实确认与独立收益反馈。

首版0.175将收益除以整项任务的常数预测基线误差，造成早停：固定12链、168项终测从137降至117达标，MSE从.02112040升至.05913671。30项失守、10项恢复，源码与负结果完整保存在[首版实验](../artifacts/confirmation_value_20261003/README.md)。

0.175.1改为按尚未解决的版本风险报价，已解释的大幅响应不再稀释边界修订价值。39项相关测试通过，包括真实程序、响应和历史共同增加已解释控制项后采购判断不变。

原12套装置及新增12套装置的对照全部完成：36条新学习链、504项新终测。新装置的0.173基线实际重跑，原装置复用已完成结果；下表均为0.173→0.175.1，总计算包含终测。

下一步重点是具体研究方案之间的机会成本，以及预计收益与真实修订收益的偏差反馈。当前局部预估仍不能可靠决定停研，继续调静态采购门槛不足以完成这一核心。

## Limitations

目前只覆盖单一仪器阈值，使用有限端点和代表性命中轨迹近似；没有给尚未实际使用的知识添加未来收益。两个优先核心——可靠研究投入与确认、可归因的长期知识净收益——仍未整体验收。
