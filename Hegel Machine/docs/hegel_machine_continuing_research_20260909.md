# 黑格尔机 0.20：持续测量、概念演化与研究投入

日期：2026-09-09。方向依据为 `GPT6_advice.md` 及其引用的研究审视方案。

本轮推进三个相连的缺口：在同一问题中重新选择仪器；把合并、反例、拆分采纳和后续调用连接起来；让已保存实验、学得方法和普通修订依据实际续研收益竞争。

## 实现与验证范围

研究投入保存公开条件下的实际新参考轨迹收益和整轮费用。区间变窄不直接当成预测收益；尚未试过的具体问题可探索，已测无收益的相同条件不会因为多了几行数据而自动变成新机会。新证据、控制支持或解释结构变化能够改变适用条件。未支付得起的有效计划保留为待办。

测量研究使用现有三种稳定装置和新增的持续变化装置。新装置在运行后产生第二个驱动作用，研究依据实际残差重开仪器比较，再用新读数继续原问题。检查包括持续研究状态恢复、旧观测与新增费用，以及稳定装置是否重复支付无必要的试测。

概念演化比较使用已付费的新轨迹，记录实际选择并绑定知识产物。在独立后续任务中，通过正常候选竞争检验拆分概念是否被再次调用，同时保留合并仍然有效的对照。

## 完整任务实验安排

代码更改前保存 0.19 认知源码，先运行新种子 4507 的 65 题两臂基线。当前版本选择 2027、2539、3181、4507 四个种子，各执行完整 65 题的学得方法与普通研究两臂；前三项承接已知退步实例，4507 是本轮预先确定的新实例。研究均从空知识库开始，每次访问最多 96 观测、24000 研究计算，最多两次访问，五个任务分区保持原有顺序。独立评估在两臂研究停止后进行。

三组专项功能完成后运行认知测试及 13 阶段整机。整机检查暂停后恢复、实际测量重选、拆分产物再调用和延迟反馈交付。结果无论正负都保留，单项功能执行成功与完整任务精度、代价的改变分开报告。

## 结果

本轮完成三组功能、四个种子的 520 次任务覆盖及 13 阶段整机。整套回归通过 **488 项**；随后实际运行暴露的收益归一化修正通过 **20 项相关测试**。三个新增归一化用例包含在后者中。

### 研究机会模型的实际修正

四个方法臂共执行 32 次追加研究：12 次学习参考轨迹上的正收益、20 次零收益。只有所选且实际执行的路线接收整次访问的费用和收益；未执行的保存实验不领取方法访问的收益。专项恢复用例确认，同条件零收益会阻止再次购买实验，而未解决问题仍然保留；新增外部交付与可用预算变化能够使相应待办继续执行。

运行也暴露了一个零基准问题：2539 某次实际收益为 0.0625，但初始误差为零，原归一化比例达到 **6250000**。本轮将机会模型用于排序的收益限幅为 **[-1, 1]**，与已有方法收益模型一致，同时保存绝对收益、原比例和参考行数。新测试验证这种比值不会挤掉更划算的方法。上述八条已执行学习序列中，没有已选机会使用超出此范围的历史收益报价；修正影响其留下的未来价值估计。原始运行记录保留原值。

## Limitations

1. **投入价值尚不能稳定预测。** 新机会模型能停止已测无益投入，也会错过后来有益的风险修订。不同研究路线整轮收益与费用共同出现，当前记录不足以分离各步骤的因果贡献。
2. **实验价值与最终预测收益还存在落差。** 定向实验能找到边界反例，新的代表轨迹可能给出零收益；完整序列的 20 次零收益访问说明冷启动探索仍昂贵。价值估计需要更好地连接实验结果、候选保留及未来行动风险。
3. **观察与表示空间仍有限。** 仪器菜单、程序原语、结构操作与整机阶段由项目提供。新测量案例覆盖一个运行中激活额外驱动的装置，尚不能代表任意机制变化、真实仪器设计或开放问题生成。
4. **外部与代码对照范围未扩大。** 装置和延迟反馈仍来自本地独立进程；四个种子来自既有生成器。普通 Python Agent 使用 2026-09-08 的真实运行，本轮重新运行黑格尔机且没有新增模型调用。模型 tokens、自由 Python 运行时间及候选行计算分别报告。

下一步优先处理完整序列已经暴露的风险任务停研与实验投入选择：让停止、追加代表性观测、追加区分实验和保留多个候选，在固定行动成本下比较其实际后续作用；进一步检验未试机会是否能以较少投入估计价值。中途换仪器和概念后续调用已经具有实际运行依据，后续沿这些路径扩展更复杂的变化条件。
