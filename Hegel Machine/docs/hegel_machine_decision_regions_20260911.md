# 0.55.1：决策相关实验与候选保留

2026-09-11。本批实现并运行了局部对称区分实验、目标单独变化时的新范围GP比较，以及未完成研究的末段推荐复测。**默认仅保留“新拟合失败不抹除原候选”的修复；主动选点和GP替换沿用0.55。** 新实验的源码、运行器和负结果均保留。

## Limitations 与下一步

局部拟合的低值方向仍可能错误；新范围GP的冷启动误差未被后续收益抵消。末段复测虽能纠正旧推荐，也会挤占尚有价值的验证与探索。下一步应让同一次末段观测继续检验未决候选，并比较复测与取得新区分证据的收益，重点复查 `goal_completion_2_center_change` 的0.35225→0.45368退化。跨任务知识独立收益、开放世界能力及稳定长期净收益仍未完成；本批未新增普通Code Agent对照。
