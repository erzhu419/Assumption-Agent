## Limitations

原八题是已知开发任务；新八题来自相同四类装置，没有新跑普通代码对照。程序搜索计量与普通 Agent 的 Python 时间和模型用量分别记录；本轮研究墙钟时间为 12.14 秒，旧记录为 10.96 秒，计算计量下降不等于运行时间下降。开放世界能力与稳定长期净收益仍未证明。下一步将这次有效的表示修订用于更长任务序列，检验其知识复用收益和研究投入选择。
