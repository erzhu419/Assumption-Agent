# 来源回报的四臂归因收据（0.181.0续研）

本轮把来源归因从观察性记录推进到同一批冻结报价的来源消融。先用真实 successor continuation 取得 `concept_0002` 的正回报，再冻结报价、任务顺序和每题执行上限，分别运行四个掩码：保留全部回报、删除坏来源、删除好来源、删除两者。全程离线，外部模型调用为 0。

运行命令：

```bash
PYTHONPATH=src:tests python3 scripts/run_source_feedback_attribution.py
```

正来源的预获取不是手工写入分数：`concept_0002` 的真实回报为 `paired_gain=0.0028830678753000976`，`retained_normalized_gain=1.0`，状态为 `confirmed`。四臂共用 4 个任务、8 个冻结来源报价和每题 `24` 行观测、`120` 实际执行计算的共同上限；筛选计算单独记账。各臂最终均为 `132` 行观测，执行访问账相同；筛选路径因坏来源撤回不同，保留全部／删除好来源为 `526` 计算，删除坏来源／删除全部为 `532` 计算。

自然四臂的实际选择在四个任务上完全相同：原始机制和重复原始机制选择 `concept_0002`，当前系数变化选择 `concept_0001`，含噪机制选择 `concept_0002` 但保持 `unresolved`。因此这组自然来源掩码没有产生独立的“删除好来源后改选”行动分叉；删除坏来源也没有改变未见损失。这是一个可解释的负结果：当前 fixture 中两个报价的即时预测收益略有差异，调度器本来就会选择较好的候选，来源回报没有机会成为决定因素。它不能被解释为好来源没有贡献。

为避免把调度选择误当成来源本身的质量，收据另外对每个冻结报价做同一前缀、同一未见响应的来源反事实重放。结果是：原始机制中 `concept_0002` 的未见损失约 `2.90e-20`，`concept_0001` 为 `8.31e-4`；系数变化中两者角色互换，分别为 `4.97e-20` 与 `8.31e-4`；含噪机制两来源均约 `0.969845` 且未决。这个读数确认了来源的条件化独占拟合质量，但不等于已经证明长期投入净收益。

代码级归因回归随后覆盖了同一 visit 中相同程序先单源、后联合执行的边界。`producer_outcomes` 现在把 `joint_source_ids` 与 `lineage_id` 纳入比较作用域，单源结果不会再被同一 probe 的联合结果覆盖；旧 singleton 回报若带有显式 `source_id`，也不会被另一来源复用。新增作用域测试与现有知识回报、联合来源回归共 24 项通过。该修正只完善贡献账本，不把局部归因结果当作长期净收益证明。

## 结论与限制

这一步还加入了一个明确标记的 tie-controlled 对照：先从各臂删除坏来源回报，再把同一任务的两个即时收益归一到相同值，只测试来源反馈允许承担的次级排序作用。保留 `concept_0002` 的 confirmed 回报时，两个原始机制任务选择 `concept_0002`，未见损失约 `2.90e-20`；删除该回报后两题选择 `concept_0001`，损失约 `8.31e-4`。系数变化和含噪任务不因该回报改变选择，说明响应条件门仍然生效。这是来源反馈改变投入选择的受控证据，但不是自然任务上的长期净收益证明。

因此，本轮完成了一个真实正回报的来源消融协议、共同执行上限、来源反事实质量读数以及 tie-controlled 选择效应，修复了“有回报但没有来源归因对照”的缺口。它还没有完成多来源联合知识的交互归因和错误撤回的整链收益：自然四臂无法识别好来源的边际调度贡献，tie-controlled 对照只隔离了单个好来源。随后续研已在[自然近似平局收据](hegel_machine_source_feedback_natural_near_tie_20261004.md)中用未改动报价和显式收益分辨率取得两项自然行动分叉；下一步应把这一规则带入多来源联合序列，同时测量独占贡献、确认命中、追加成本和未见质量。

与 0.181.0 的关系仍是同一未发布主线的增量续研：没有改版本号，也没有把旧的无 `response_signature` 回报静默迁移到新条件。
