当前十项状态见[目标完成度](hegel_machine_advice_goal_status_20260909.md)：0.26 的十类功能均已有有界执行闭环，开放世界能力与稳定长期净收益仍未达成。下文保留 0.8.0 的缺口诊断，不是当前待办清单。

日期：2026-09-08。核对对象：本地 0.8.0 工作树，基底 HEAD 为 `20fd401121842c4755826d3b19f0b944b97542e2`。认知主线包含尚未提交的代码，本文判断的是这些实际文件。

## 已经实现且参与运行的能力

单任务内已经接通观测、竞争解释、可执行候选、主动实验、前瞻比较、采纳与回退。联合数值坐标、历史表示、二值可见状态和多输入实验都能改变真实预测。依赖计划会把中间程序交给下一步骤；这项能力已有实质实现。

程序、参数化模板和子表达式会进入后续任务；系统能保留原参数、重新拟合、重绑定变量角色。知识的支持范围会影响执行，真实反例可以限制或撤销条目。概念删除及派生内容删除已有入口。风险任务也已经使用固定外部代价进行拟合、校准和行动。

会话已经持有共享总预算、任务进度、知识和搜索经验，能够跨进程恢复。搜索经验已经改变状态、联合坐标和依赖计划的配额。这个运行基础可以直接继续扩展。

[已有结果](cognitive_runtime_v6_results.md)记录了 135 条序列、1,755 个任务实验；持续会话覆盖 65 个任务、68 次访问，其中 57 个达到学习侧阈值，8 个保留未解决状态。`completed` 表示允许的访问已经结束。当前进度与资源可从[小型会话汇总](../artifacts/hegel_machine_session_summary_20260908.json)直接读取。

### 最紧迫的连接缺口：会话恢复还没有恢复思考状态

`ResearchSession` 保存未解决问题的文本和树，但下一次访问直接调用新的 `CognitiveAgent.run(environment)`。控制器重新建立空的观测、参考集、查询列表和候选池，重新购买初始观测，从常数解释开始。共享知识可以帮助这次学习，但旧问题内容没有被调度器或计划执行器消费。

`EpisodeResult` 在内存中确实持有观测；[序列化](../src/hegel_machine/cognition/models.py#L178)只写出观测数量。知识库也确实保存了[部分反例的原始观测](../src/hegel_machine/cognition/memory.py#L366)，但完整的已获得证据、候选与计划状态没有恢复到后续学习。

因此，当前“继续研究”的实际粒度是带共享知识的任务访问。原构想要求继续解决的“联合坐标尚未确定”“两种历史解释尚未区分”等具体疑点，还需要可执行的延续机制。保存这些数据的直接用途是节省重新测量、继续拟合，并让子问题的答案改变下一步。

### 搜索经验和实验经验的连接程度不同

`PlanAllocation` 的经验会实际影响搜索分配。`choose_valuable_probe` 也会根据当前候选近似计算任务风险的下降，两项功能都存在。

但控制器仍固定优先尝试状态转换实验，随后才尝试其他任务价值实验；实验准备计算量和风险校准额度也按固定方式安排。历史上某类实验取得的后续收益，并未进入一个能够改变这些选择的持久策略。会话首轮固定覆盖所有任务，之后按任务级失配或最近风险收益安排重访；它还不能比较不同任务的具体下一步机会。

已有负结果使这个缺口具有直接的开发价值：[0.8 报告](cognitive_runtime_v6_results.md#L49)中，stateful 的实际行动损失为 0.360615，关闭主动实验为 0.325879；而相同消融又把二值状态错误从 137 行增至 499 行。主动实验对不同目标的价值不同。下一次改动应让系统依据目标与经验决定实验投入，而这项能力的效果仍由实际运行判断。

### 迁移、语言生长和观测分组仍有三个后续环节

现有作用域可以生成有效守卫，但[反例修订](../src/hegel_machine/cognition/memory.py#L370)主要选择支持域内撤销、域外单轴区间限制或任务上下文排除。多变量条件、潜在情境与独立子机制尚未成为通用的适用条件学习对象。将旧域成功证据和新域反例一起用于构造条件模型，是保留有效知识的下一步。

抽象当前会[实例化回普通程序树](../src/hegel_machine/cognition/abstractions.py#L72)。这已经有搜索与参数拟合价值；进一步的语言生长需要让抽象成为可调用定义，并成为后续搜索的构件。有效的新概念完全可以用已有语言定义；其价值来自后续使用。是否还需增加新的底层运算，则取决于测量对象与任务能力。

`observed_classes` 当前生成的是经验分组报告。控制器把实验前后的类变化写入动作记录，然后仍按候选比较结果维护程序池。分组结果尚未用来改变后续检索、压缩或实验策略。主动区分已经实现，关于“如何区分”的知识还需进入后续决策。

## 六族先验的具体覆盖

旧 `ontology.py` 注册了六根、22 叶；`laws.py` 中的[对称](../src/hegel_machine/laws.py#L136)、[守恒](../src/hegel_machine/laws.py#L196)和[局部性](../src/hegel_machine/laws.py#L341)残差，以及 `recognition.py` 对给定候选绑定的比较，都有实际计算。当前 `cognition` 没有导入这些模块，因而它们尚未成为认知主线的自主发现能力。

| 先验族 | 已进入认知运行 | 后续需要具体对象承接的功能 |
|---|---|---|
| 压缩与充分表示 | 复杂度选择、稀疏组合、历史选择、简化与模板复用 | 低秩分解、可学习投影、充分状态、压缩后按反例恢复自由度 |
| 分解与机制复用 | 加性、交互、子表达式、角色映射、中间程序依赖 | 条件独立、局部影响范围、可干预模块、单个机制失效后的局部替换 |
| 几何与动态 | 有限历史、启动分支、二值可见状态、联合阈值坐标 | 连续潜在状态、自由递推、快慢变量、尺度分离、稳定性与耗散规律 |
| 不变性与物理结构 | 角色改名、单调方向和简单代数组合的特例 | 对称作用与输出变换、守恒组合、边界与量纲、拓扑结构及跨对象关系 |
| 异常与不确定性 | 残差位置和尺度、尾部拟合、区间、固定成本行动、简化候选 | 主动区分噪声、稀疏异常、结构不足和作用域失效；选择扩张、简化或保留未知 |
| 认识论原则 | 前瞻比较、主动区分、反例、撤销、搜索收益记忆 | 来源互补的证据组合、可复用研究问题、实验策略学习与跨任务机会成本 |

这些缺口应通过具体的发现—实验—应用过程补齐。例如，守恒能力需要让实际测量支持某个组合量，再让该规律改变预测或实验；结构对应需要对象、作用和组合关系。变量重命名已经有用，进一步的结构迁移则需要更丰富的语义对象。

## 下一步按整条运行链建设

**第一包：延续研究状态，并学习下一步研究动作。** 在 `models.py` 和 `controller.py` 中提取可恢复的任务研究状态，持有已付费观测及轨迹边界、已有与竞争解释、未决子问题和下一段计划。`session.py` 重访时直接把状态交回控制器，保留既有证据用途，并只为新查询增加观测支出。已有 `ResearchQuestion` 和 `RevisionPlan` 继续承担问题与执行，证据变化决定继续哪一分支。

随后让计划、观测和校准形成可比较的下一步选择。复用当前研究经验机制，记录行动在后续预测或固定成本决策上的实际收益；观测和计算分别受预算约束。新学到的知识能够给旧问题带来新的解法时，该问题重新进入日程。完整运行应呈现：第一次留下两个未决解释，恢复后使用旧证据继续，在新的区分实验后修订并形成知识，再让该知识推进另一个旧问题。

**第二包：条件知识与可调用概念一起生长。** 用保留下来的旧域成功观测和新域反例学习条件组合；将可复用子程序提炼为后续搜索可直接调用的定义。进一步的实验针对概念的适用条件，研究结果分别更新参数、条件或机制组成。这个包把“存了多少抽象”推进为“哪些概念成为后续思考的构件”。

**第三包：通过新环境扩展观察与结构先验。** 先接一个带连续隐状态或可选择测量的实际交互环境，并实现对应状态更新、观测表示和行动反馈。再以守恒、局部性或对称中的具体一类贯通结构发现，复用旧数值残差函数。环境提供可操作对象和测量能力，Agent 从证据中学习规律及其成立条件。其余先验沿同一接口扩展。

**第四包：方法与长期研究本身可修订。** 在上述运行轨迹上提炼有条件的实验及求解方法，让失败可以改变方法步骤和适用范围；加入持续到达的新任务与延迟反馈。同环境的完整普通代码 Agent 对照随这一能力比较补齐，用实际任务收益回答整套组织方式的价值。

当前最合理的施工起点是第一包。它直接补上证据、问题、行动、知识之间的缺口，也为后续可调用概念、条件理论、潜在状态和元先验演化提供共同运行基础。

## Limitations

- 本文是当前工作树的功能核对与施工调整，没有新增算法、测试运行或实验结果。引用的数值来自已有 0.8 运行产物。
- 当前效果证据来自公开、已用于开发的有限合成任务。语言、测量与研究策略仍有固定的开发者边界，整机会话跑通不能代表开放世界构想已经完成。
- 十项功能是对相关文档的系统归纳，不是均等权重的完成度计分。原文涉及的一般拓扑、任意元算子及新理论发现仍包含研究问题；应逐类明确可操作对象和能力范围。
- 当前真实模型接口提供受限提案；本轮已有结果不能支持优于完整普通代码 Agent 的结论。正式轨道已有成果继续按其对应范围解释。
