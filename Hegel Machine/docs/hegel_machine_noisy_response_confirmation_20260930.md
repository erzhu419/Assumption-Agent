## Limitations

原七步题的普通配对增益4.19085e−5、裕量4.47743e−5，实际新响应均值更好仍被保留父模型；更严采用门槛没有自动提高认知。两轮是不同新装置，只各自与同组0.131比较。当前实验限无仪器、无对象、无目标历史的平方损失响应；一般条件分支、更广泛组合和完整Code/LLM对照仍未完成。
