# 响应签名计算收口（20261004）

`transfer_condition` 需要用付费响应的粗签名区分系数变化和噪声变化。原实现对每个观测都重新做一次留一回归；长历史下，这个重复的三次方求解会拖住来源筛选和后继报价。

本轮保留均值、幅度和残差三个签名字段，把残差改为一次整体岭拟合后计算 RMSE。`tests/test_cognition_knowledge_returns.py` 的响应 regime/noise 区分仍通过；来源回传与后继 fixture 从原先长时间无结果恢复为定向回归通过，相关来源反馈测试为 18 项全通过。

这只是计算收口，不扩大签名的科学含义：残差仍是粗粒度、带内样本拟合偏差的条件读数，不能单独证明跨机制迁移或长期净收益。
