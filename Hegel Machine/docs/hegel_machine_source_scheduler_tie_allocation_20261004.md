# 研究投入平局的完整执行成本（2026-10-04）

`condition_coverages` 已经能在 `UnifiedResearchAgent` 的转移条件循环中复用已付证据，但原全局 scheduler 在收益完全相同且没有来源回报时按队列顺序选第一个计划。这样会优先购买更重的完整访问，消耗本可留给后继任务的稀缺观测、测量或计算额度。

`choose_research_visit` 现在为每个可执行单项和组合记录实际分配的资源份额。即时收益相同、知识回报也相同时，先选完整执行份额较小的计划；有实测知识回报时仍先按该回报处理近似收益平局，明显更高的即时收益不受影响。决策事件同时记录 `selected_resource_share` 和平局候选份额，便于审计。

新增回归覆盖两个同任务、同收益但 80/80 与 20/20 完整报价的选择，确认选后者；原研究组合、来源回报和 JSON 恢复测试保持通过。

2026-10-04 审计发现的执行顺序回退已修复：完整收益、知识回报和资源份额相同后，先比较首访收益密度，最后才按 index 决胜；四个密度顺序回归及来源选择回归通过，见[修复结果](hegel_machine_narrow_cycle_repair_20261004.md)。限制：`condition_coverages` 对新后继报价的完整成本重估仍需独立接线，局部少买探针不代表整个访问免费。
