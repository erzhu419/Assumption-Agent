# 黑格尔机 0.8.0：持续研究整机、联合状态表示与反例修订

日期：2026-09-08。方向依据：[GPT6 建议](../markdown/GPT6_advice.md)、[完整审视方案](../markdown/Hegel_Machine_Vision_Progress_and_Research_Critique.md)与[早期建议和路线](../markdown/GPT_advice&roadmap.md)。[整机目标与系统路线](hegel_machine_system_completion_20260908.md)说明本轮与原构想的关系。

本轮把黑格尔机推进为能够保存、恢复和继续研究的运行系统。共同入口连接了任务日程、总预算、观测、竞争解释、依赖计划、表示修订、实验、决策、知识和研究经验。联合状态规律也进入了这条链：系统能学习多个输入的组合，为它构造实验，让已观察到的反例推动更大的理论被采用。

完整版本对照运行了 **135 条序列、1,755 个任务实验，全部完成**。另一次实际持续会话覆盖 **65 个任务、68 次学习访问**，跨进程恢复后保留原有结果，生成可继续加载的知识库。两类运行分别回答算法改变的作用与整机生命周期是否接通。

认知测试 **160项通过**，包含联合坐标、遗漏变量实验、已有反例驱动更大理论、跨任务研究反馈，以及会话保存恢复、资源扩展和风险重访。完整记录见[测试输出](../artifacts/cognition_v6_final_tests_20260908.log)。

## 1. 本轮怎样改变系统

`ResearchSession` 持有任务进度、未解决问题、共享知识和整场研究的资源。它先覆盖任务，再按学习记录选择值得重访的问题；每个完整任务访问后保存 checkpoint。重新启动进程可以继续，显式增加总预算或访问上限也可以继续未结束的研究。CLI 支持按顺序组合五个任务分区；Python 接口接受仅提供 `spec` 与 `observe` 的交互环境。

`KnowledgeLibrary.research_experience` 保存研究行动的实际收益。`PlanAllocation` 根据可见的二值、数值或风险目标及单／多输入条件组织经验，反馈来自新预测的改善和真实计算支出。反馈覆盖状态搜索、联合坐标和依赖计划；它会改变之后的预算分配。变量名称和任务标签不构成经验分组依据。

状态搜索先比较单变量解释。若其最好的状态条件规则仍有残差，就在预算内用观测学习共享的仿射坐标，再分别拟合进入、退出与启动条件。方向、系数、阈值和历史由观测决定；产物仍是可执行的普通 AST，可以进入抽象与角色迁移。预算不足时优先产出一个完整联合解释，再细化额外启动规则。

联合实验解析候选中的仿射边界，在公开控制范围内同时改变多个输入，并准备不同的历史状态。启动条件在轨迹第零行直接测量。每次最多购买三个成对实验点，同一区间最多两个，之后先用新证据拟合，避免一条长实验挤掉后续修订。

候选筛选为在当前样本上同样拟合良好、却使用不同变量组合的解释保留比较机会。非风险任务中，若一个更大的程序解释了已有反例，其改善超过复杂度增量，且代表观测和新预测均未明显变差，也可以被采用。`counterexample_gain` 单列这部分证据；原有 `fresh_gain` 仍表示新轨迹上的差值。

## 2. 对照设计与整体结果

比较使用保存的 0.7.0 算法包 `artifacts/cognition_v5_reference/` 与当前 0.8.0。九个配置分别为旧版本、完整新版、关闭联合状态坐标、关闭联合状态实验、关闭跨任务研究经验、关闭主动实验、关闭知识、固定模型和普通程序搜索。

五个分区均已用于开发。种子分别为 development 的7／11／19、confirmation 的23／47／83、forward 的101／211／307、continual 的401／503／607和stateful 的809／907／1009。各配置共享任务、初始观测、公开查询能力、最终评测和每任务96个观测、24,000个计算单位的上限，实际支出可以不同。核心学习算法在这一整组运行中保持不变。

## 3. 联合表示、实验与研究经验的作用

stateful 的24个二值状态任务共12,288行，其中3,911行发生真实状态转换。

| 配置 | 状态错误数 | 切换行错误数 | 平均平方误差 | 平均观测 | 平均计算 |
|---|---:|---:|---:|---:|---:|
| 0.7 参考 | 375 | 164 | 0.022280 | 994.00 | 217,252.00 |
| 完整 0.8 | 137 | 84 | 0.008108 | 973.33 | 213,508.67 |
| 无联合状态坐标 | 411 | 126 | 0.022975 | 979.67 | 211,591.00 |
| 无联合状态实验 | 183 | 112 | 0.010831 | 968.00 | 206,424.67 |
| 无跨任务研究经验 | 192 | 115 | 0.011364 | 973.33 | 211,087.67 |
| 无主动实验 | 499 | 159 | 0.029517 | 612.67 | 106,732.00 |
| 无知识 | 150 | 78 | 0.008878 | 981.00 | 201,666.67 |
| 固定模型 | 2,113 | 26 | 0.449482 | 1,066.67 | 112,428.00 |
| 普通程序搜索 | 249 | 142 | 0.014737 | 881.33 | 167,968.67 |

状态分类错误率从 **3.05% 降至1.11%**，真实切换行错误率从 **4.19% 降至2.15%**。切换行指标只统计真实发生切换的位置，固定模型在这些行上的低错误数不能代替整体状态预测质量。

双输入组合 s08／s09 的错误由312行降至76行。其中s08由163降至9，s09由149降至67。联合坐标、联合实验和研究经验的对应消融都增加了状态错误；三个部件在这一任务序列中实际共同起作用。

知识收益并非只有一个方向。相对无知识，完整系统在前四分区都减少观测和计算；stateful 则平均少用7.67个观测、多用11,842个计算单位，状态错误减少13行而切换行错误增加6行。研究经验提高了stateful的状态准确度，但风险行动损失也随之增加。条件迁移与按目标选择研究策略仍需改进。

## 4. 实际持续会话：保存、恢复、再研究

整机会话按五个分区的顺序载入65个任务，种子809。会话的任务查询种子随任务索引和访问次数改变；它的查询日程不同于上面的配对版本实验。

第一次命令完成10次访问后结束进程，保存了9个概念、594个观测和123,119个计算单位的进度。第二个进程仅使用 checkpoint 路径继续运行。最终记录中的前10次访问与暂停文件完全相同。

最终运行覆盖 **65／65个任务、68次访问**，实际使用 **3,876个观测、812,228个计算单位**，在总上限12,480个观测、3,120,000个计算单位内结束。57个任务达到学习侧误差阈值，8个仍保留未解决记录。产生 **66个具体概念、229个抽象条目**；发生2次最终直接复用、13次最终抽象复用，并实际撤销了4个概念。支持范围的调整记录覆盖49个不同概念。

开发中的首个会话会因为风险损失非零而不断重访。现在，对已有比较结果的风险任务，调度要求最后一次比较仍有超过最低改善量及波动幅度的正收益；尚未完成比较的任务继续保留机会。停止理由是 `no_observed_revision_gain`，损失和未解决问题照常保存。

这一修正将重访从8次降至3次，少支出467个观测和108,971个计算单位。独立的会话后评测仍表明重访价值不稳定：c04损失增加0.027943，n11减少0.004621，c05持平。58个平方损失任务的首访／最终平均误差均为0.000893；7个风险任务的平均pinball由0.218557变为0.221888。新的会话已经能够依据经验继续研究，进一步准确判断重访价值仍是实际研究问题。

### 直接运行

在项目目录执行：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition session \
  --partitions development confirmation forward continual stateful \
  --seed 809 --checkpoint artifacts/my_hegel_session.json --steps 10

PYTHONPATH=src python3 -m hegel_machine cognition session \
  --checkpoint artifacts/my_hegel_session.json

python3 scripts/evaluate_cognition_session.py artifacts/my_hegel_session.json \
  --output artifacts/my_hegel_session_evaluation.json

python3 scripts/run_cognition_v6_research.py \
  --partitions development confirmation forward continual stateful \
  --output-dir artifacts/my_v6_research
```

研究程序与知识库均可直接加载。会话的`completed`表示所允许的覆盖与重访已结束，任务学习状态分别查看`tasks`与`unresolved_tasks`。

## Limitations

- 五个分区都是公开合成环境，现已全部作为开发依据。三个种子的版本差值不代表开放环境或独立隐藏任务中的普遍效果。
- 状态模型读取已经实际观察到的历史输出；这里没有把有反馈预测作为自由递推预测的证据。
- 运行内能够学习坐标、状态规则、参数、作用域和研究配额；原始算子与搜索过程仍由开发者提供。通用潜在概念、任意新传感器、全部通用先验与开放世界理论发现尚未完成。
- 风险调度使用自适应学习记录，正的最近修订收益不保证下一次重访有净收益。三个重访的负结果已保留。
- 本轮使用本地程序搜索。真实模型生成接口的历史运行见[0.4.0报告](cognitive_runtime_v2_results.md)，本轮未新增模型调用，不能据本轮结果宣称优于普通LLM代码Agent。
- 开发试跑保存在`cognition_v6_development_20260908`、`cognition_v6_integration_20260908`、`cognition_v6_counterexample_20260908`、`cognition_v6_probe_development`与会话的`*_development_20260908`产物中；它们不混入最终对照。
