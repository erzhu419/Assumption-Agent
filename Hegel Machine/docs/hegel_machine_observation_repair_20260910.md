## Limitations 与下一步

三个单次异常病例最终目标回退，绝对增量为 0.016080、0.037166、0.039921；约束预测改善尚不能保证优化收益。首题修复改变轨迹后，终端推荐选中实测目标更低、真实目标却更差的点；后两题取消错误研究，也失去了旧验证偶然找到的好点。下一步让有价值的目标研究独立触发，并改善带噪目标的终端推荐。

残余误重开来自新种子 1643110349：两套预测器持续低估，复测仍支持失配，系统在异常注入前已进入研究；同一种子的混合病例后来真变机制，两版均未完成修订。这需要区分预测器失配与机制变化，并允许研究中按新证据调整适用范围。

当前异常判定针对独立复测下的单次冲突，连续偏差及更一般的观测机制仍需研究。整体目标仍是十类功能已有有界闭环、稳定长期净收益尚未达成，见[十项目标核对](hegel_machine_advice_goal_status_20260909.md)。
