## Limitations

有限采样只确定连续读数门槛的区间；开发误报与仍存区间歧义相符，未逐行重构终测来证明全部失配来源。训练和确认近零误差仍不足以可靠判断研究完成。当前覆盖有限窗口、二次响应、单个不可控观测条件和无额外目标噪声，更广结构与联合研究选择仍有缺口。独立臂是完整黑格尔机，当前普通Code及模块消融尚未补齐；外部LLM对照按用户安排暂缓。

下一主线：让竞争解释共同生成和改写区分实验，积累可迁移、可撤回的门槛约束，并据未辨明范围决定追加观测、保留多解或重开研究。
