## Limitations 与下一步

本批接入普通数值仪器；对象聚合、多尺度和风险研究仍有独立流程。对照中的关闭策略臂关闭现有研究策略整体，不是仅关闭新增选择入口；本批未新增普通Code对照。当前经验条件没有区分“已有适用的控制修订结构”和“只能重新搜索响应模型”，把首次新装置的重测收益迁移到了能以零测量修订的后继任务。下一主线是先用当前程序与已付证据判断研究方法是否适用，复用实际准备结果，再选择投入；随后扩展对象和风险任务。
