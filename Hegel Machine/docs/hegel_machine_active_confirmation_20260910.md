## Limitations 与下一步

主动确认可以提前修订和排除偶发异常，但新带噪组的目标回退表明研究动作的净价值尚未解决。其中种子 1443210241 的旧版在验证中测到优良点 `[0,0,0]`；新版提前一次调用完成修订，随后还有六次优化，却始终未测该点，最终目标从 0.5 回退到 1.2948。下一步优先让区分实验兼顾实际优化收益和目标模型覆盖，并判断确认投入是否值得。当前约束失配后的重建也会更新目标 GP，尚需按各输出自身证据缩小修订范围，保留仍有效的知识。一般结构发现与稳定长期净收益仍未达成；项目整体状态见[十项目标核对](hegel_machine_advice_goal_status_20260909.md)。
