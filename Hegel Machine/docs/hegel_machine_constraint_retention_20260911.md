## Limitations

这是双输出的取舍，尚未提高最终优化结果；新例约束平均改善也不代表逐例改善。最差新增目标退化来自局部比较拒绝有用候选：独立评价中候选 MSE 为 0.000467，GP 却由 0.002247 升至 0.041829；两版均没有安装目标程序，不能归因于已安装程序的校准漂移。见[具体诊断](../artifacts/sc_kg_constraint_retention_v051_20260911/passive_mixture/objective_regression_diagnosis.json)。

下一步让被局部比较拒绝、仍能解释后续错误的目标候选重返研究，并选择能区分其适用区域的实验。冻结程序均值而沿用 GP 协方差更新仍是工作近似；本批未重跑 vanilla 或普通 Code Agent，开放世界与稳定长期净收益尚未达成。
