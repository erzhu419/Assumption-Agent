# 研究投入、有效确认与知识贡献，0.157.1

本轮实现三处核心修复：失败确认后的修订预留下一次独立确认、噪声重复及旧反例复评资源；未实际执行的研究只保留已付费用，不生成“该方向失败”的经验；实测反例撤回当前目标上的完整迁移程序，保留原知识、部件和不同参数的修订。检索、迁移拟合和普通回访已接入撤回检查。

此前512计算的小任务未执行机制研究，却把旧模型的确认失败记成方向反证，误导下一任务。修复后，120000上限的后继实际用96行观测、31142计算完成，独立确认误差1.71e-19；原先失败的3项知识生成及回访集成测试恢复通过。实际搜索后没有改善仍记录真实零收益，不按“程序没变”掩去失败。

相关回归共56项：54项通过，2项风险校准旧失败在冻结0.156及当前版本中一致，原断言与证据保留。测试及运行记录见[实验目录](../artifacts/research_investment_attribution_20261001/README.md)。

## 长序列比较

固定12个新实例，每个13阶段；48条学习链及624项独立终测全部完成。两条已见开发链单独保留，不混入正式结果。

新版较0.156：条件误差低20.49%、计算少1.11%，但含噪误差高18.64%、观测多67行、CPU多29.71%。含噪整链1胜4平7负，条件2胜8平2负，不能称整体改善。条件任务四臂均无误报完成。

12条链均实际删除采用过的知识。完整组较删源组条件多解决12题、计算少3.84%，表明这批知识有条件贡献；但含噪整链仅2胜1平9负，均值收益由少数较大改善拉动。新增撤回记录26条，关闭它后156题误差及计价费用全平，独立优化收益仍为零。

## Limitations 与下一步

两个核心尚未全部闭合，0.157.1保留为研究候选。下一步先定位本批含噪退步，并撤销被共同实测反驳参数的实验规划资格，保留结构重拟合；再让知识贡献与不适用证据改变实际投入和迁移选择。当前撤回限具体目标，单组来源删除不能代替多份知识的贡献交互，稳定长期净收益未成立。删除对照一次中断的原始证据、额外开销及修正后重跑单列于实验目录。普通Code／同一LLM对照继续按用户安排暂缓，本轮全离线。
