# 有信息的局部时序线索与完整边界研究

0.154.0对应最新[GPT6_advice.md](../markdown/GPT6_advice.md)的候选发现与主动检验：局部条件拟合有实际改善，即使仍未精确，也能提名完整响应研究。同一时宽的平滑、窗口内与窗口外解释共同竞争，保留原局部失败、背景和未识别状态；完整程序在共同已付响应上重新拟合、比较。

已经拟合响应的未测边界，按整批启动及完整时间窗口的预测损失选择实验背景；较差完整解释的高分歧不再覆盖这个问题。实际拟合、规划、采购和新确认继续使用原预算，预测读数只决定合法控制，实测读数仍由环境产生。

54项直接相关测试通过，包含真实付费前缀、正常研究、新确认及完整窗口风险计算。已识别响应仍优先获得拟合资源。

开发root03的108行前缀，三种完整响应共同拟合耗8964计算、零采购，窗口内训练误差近零，另两种仍失配。正常任务的边界规划背景已经改变，但三次概率／预算判断仍拒购；实际180观测、180测量、229746计算，新确认误差1.15e−18，边界预测歧义0.488227，任务保留未决。

先完成两族的78条学习及自然续研，再完成507项终测，无外部模型调用。同批旧0.153／新0.154／新版逐题重置的数值达标62/84、57/84、56/84，平均MSE为0.203734、0.279719、0.437519。新版对旧版逐题9胜57平18负、整链4胜1平7负；误差增加37.30%，含终测计算、观测、测量、CPU分别增加28.61%、2.19%、1.40%、44.27%。风险误差与计价资源全平，pinball为0.0205405、覆盖率85.98%（目标分位数90%）。[完整比较](../artifacts/informative_structure_research_20261001/README.md)保留费用与开发结果。

正式完整竞争拟合35→198次，产出600个响应候选，其中164个使用非精确但有实测增益的局部支持；跨背景实际实验1→20次。匹配这些候选的独立新确认6→8次，接受0→2次；两题最终同程序仍保有有效新确认，但边界均未决。整轮方法回访仍为7次，实际改善5→7、含筛选计算1487075→786631；这部分节省被其他研究费用抵消。本轮未通过整体收益验证。

## Limitations

最大单题回退root06 p2：局部W5／窗口外解释后来拟合近零，但共同原响应完整拟合仍为12.82–16.26，实际新确认5.234和6.731均失败。较差解释的巨大预测分歧仍驱动了早期实验，后续广搜耗尽计算，最后48行已购确认未被评估；最终程序未确认。该题计算128422→319992。只读[案例证据](../artifacts/informative_structure_research_20261001/worst_numeric_case.json)未发现新版曾得到又丢掉已验证好解释。

下一核心：保留有用结构线索，撤回失配的具体参数及其规划预测，让跨背景反例改写步骤；按购测／修订后预计剩余的原响应损失比较实际可支付动作，并留下拟合与新确认费用。当前决策尚未充分连接信息概率与预测收益。四项既有全套失败本轮未重测；更广结构、稳定长期净收益及当前普通Code／同一LLM对照仍未完成。逐题重置臂是完整黑格尔机，外部LLM对照按用户安排暂缓。
