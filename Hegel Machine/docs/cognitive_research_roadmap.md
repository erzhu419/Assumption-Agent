## 1. 愿景与可检验问题

原始愿景包含发现可执行的新理解、主动寻找区分证据、修订理解方式和将经验积累为知识。robust 的动机要求系统能扩大可能世界；刚体、质点与分解的例子也要求系统能够主动简化。

当前科学问题是：

> 当旧模型失配、解释尚不可区分，或重复求解成本过高时，Agent 能否在有限预算下选择实验，构造有效的表示、关系或不确定性修订，将有用内容积累为知识，并在后续未见任务中降低累计损失与学习成本？

有用的新概念可以是旧运算的可复用抽象。表达能力增加、搜索压缩、参数迁移、结构迁移和世界规律发现分别评价。一次经验是否改变后续学习，是贯穿这些问题的检验。

整机目标包括从任务进入、取得观测、提出解释、执行实验、修订程序到持久知识与下一项研究的连续路径。研究能力的改进需要进入这条路径；当前任务的误差降低、以后任务的成本变化和未解决问题的推进，共同决定后续投入。

## 2. 当前已实现的研究机制

| 研究部分 | 当前执行路径 | 对应比较或测量 |
|---|---|---|
| 持续研究会话 | 保存并恢复旧观测、候选和计划；支持新任务、外部证据及新知识重开旧问题 | 暂停恢复、旧证据继续使用、条件反例与累计成本 |
| 具体区分问题续研 | 零拟合误差时仍保存待做实验及后续比较额度，恢复后实际执行 | 新轨迹上的反例与修订、追加访问净成本 |
| 历史分支保留 | 给未区分的成熟机制有限比较位置，按实际历史需求取得代表轨迹 | 已有完整知识直接复用、错误历史候选退出 |
| 联合边界实验 | 同次覆盖起始和不同成熟状态，实际响应确认准备条件 | 边界缩小、准备失败、程序化实验知识更新 |
| 失败驱动的方法修订 | 区分方法排期和实际执行时的证据，重复无效修补后执行结构研究 | 后继实际获得预算、产生候选并接受新轨迹比较 |
| 共享测量阶段 | 进程仪器研究沿用整机知识库，形成的概念继续进入结构研究 | 13 阶段入口、跨进程恢复和三项测量效果 |
| 跨任务研究经验 | 按观测任务形态保存新预测收益/支出，改变状态、联合坐标与依赖计划的预算 | `without_research_memory` 与实际配额变化 |
| 竞争解释 | 残差问题树组织多个修订方向，候选收益由实际程序得到 | 记录候选被测次数、fresh 结果和选择变化 |
| 依赖计划 | 子步骤传递中间程序，按新观测上的实际收益调整后续计划预算 | 单步与联合计划、计划分配轨迹 |
| 联合变量搜索 | 多个变量组合共同拟合系数，有限增添、删除和替换项，分别比较历史深度 | `greedy_joint_search` 与完整联合搜索 |
| 分轮资源分配 | 在搜索和选实验前预留查询后的候选比较工作 | 查询后实际比较、修订及累计成本 |
| 起始历史分支 | 基础拟合在不同深度间轮流分配预算，再探索更复杂分支；用 `available(k)` 执行 | 整条轨迹损失与起始阶段损失 |
| 状态转换搜索 | 原始变量与拟合联合坐标共同解释进入、退出及起始阈值，比较历史深度 | `without_joint_state_coordinates`、状态分类及转换行错误 |
| 主动观测 | 构造连续控制轨迹，以有限候选估计单位观测的任务风险下降，结合控制与历史覆盖 | `raw_disagreement`、无主动实验、无构造 probe |
| 转换实验 | 从候选坐标构造多输入控制组合，在不同准备历史下比较相同输入 | `without_joint_state_probes`、实际查询与转换错误 |
| 自适应时域 | 代表性轨迹随候选需要的历史增长，并服从公开长度与剩余预算 | `short_horizon`、实际查询长度及分时域损失 |
| 新轨迹比较 | 固定候选、取得参考轨迹并比较，然后选择定向实验；定向反例阻止提前结束并保留下一轮参考额度 | fresh 比较、定向反例与实际停止原因 |
| 经验等价 | 新证据前后重算候选预测分组，保留原程序 | 观察原一致解释如何被新实验区分 |
| 抽象 | 从完整程序及有用子表达式抽取常数槽和角色槽 | 无抽象对照、抽象重拟合次数与成本 |
| 结构迁移 | 按当前证据筛选结构、重拟合和映射角色，实际迁移反馈影响后续搜索 | 角色重命名任务、无映射对照与迁移测试成本 |
| 等价表示化简 | 候选比较及知识学习移除严格等价的局部冗余，保留必要历史与共享定义 | 零衰减状态、共享调用、已有知识归并 |
| 知识研究回报 | 后续适配、共同轨迹比较及最终保留结果改变检索和模板顺序 | 完整序列与仅关闭收益排序的消融；未比较的费用单独保留 |
| 迁移调度 | 原参数与重拟合结构共同测试；已支持迁移早停，两类当前证据均较差的旧候选退出当前候选池 | `without_transfer_scheduling` 与 `without_knowledge` 分别比较 |
| 条件作用域 | 记录支持区间，使用反例形成条件或情境排除 | 范围收缩、上下文冲突和撤销分别计量 |
| 同范围反例 | 已支持情境内的新反例撤销具体程序及相关传播 | 同任务机制变化的后续行为 |
| 风险预测 | 直接 pinball 拟合与位置、尺度共享尾部证据的候选共同竞争，使用累计参考轨迹比较 | 风险任务预测损失与 `without_tail_fit` |
| 决策校准 | 经验选择投入，一条新轨迹拟合，两条独立后续轨迹比较保存和拟议决策；缺少后续证据时保留旧校准 | 实际行动损失、采用或保留、覆盖与校准成本 |
| 模型生成 | Codex proposer 提出同一语言中的程序与新 probe | 显式模型对照、调用数、耗时和报告 token |
| 知识干预 | 清空全部知识或删除指定概念及派生模板 | 对之后质量、搜索和实验成本的配对影响 |
| 多种子研究 | 对同种子同 episode 结果配对，以种子为重采样单位 | 差值、区间、覆盖与失败分母、累计资源盈亏 |

这些机制已经有可执行路径。它们对哪些任务有效、付出的成本是否值得，以及组合后是否优于普通工具，由实际报告回答。

## 3. 运行入口

整机入口可以将五个公开分区组成连续研究，先运行两个任务访问再恢复：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition session \
  --partitions development confirmation forward continual stateful \
  --seed 809 --checkpoint artifacts/hegel_session.json --steps 2

PYTHONPATH=src python3 -m hegel_machine cognition session \
  --checkpoint artifacts/hegel_session.json
```

每个完整访问后保存一次 checkpoint，恢复时继承任务顺序、配置、知识与已用资源。`--total-observation-budget`、`--total-compute-budget` 和 `--max-visits` 限制整场研究，也可在恢复时显式增大以继续未解决问题。`completed` 与 `unresolved_tasks` 分别表达访问结束和问题是否仍有误差。

已取得比较结果的风险任务使用最近仍显示的修订收益安排重访：达到最低改善与当前离散余量时继续研究，否则保留未解决损失并记录缺少新收益。尚未完成比较的任务保留继续研究机会。普通预测任务继续按相对失配重访；两者都使用学习侧已经取得的证据。

固定序列和算法研究继续使用以下入口：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition run \
  --output artifacts/cognition_run.json

PYTHONPATH=src python3 -m hegel_machine cognition compare \
  --output artifacts/cognition_comparison.json

PYTHONPATH=src python3 -m hegel_machine cognition research \
  --partition development --seeds 7 11 19 \
  --output artifacts/cognition_research.json
```

通用入口可使用 `--systems` 选择当前研究问题需要的配置：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition research \
  --seeds 7 11 19 \
  --systems cognitive_agent without_knowledge single_step_planning \
  --output artifacts/cognition_selected_comparison.json
```

`run --memory PATH` 保存与恢复知识库。`compare --concept-id ID` 指定删除对象；删除发生在首次迁移前，并记录实际移除的概念和派生模板。`run --proposer codex` 或 `hybrid` 接入本机配置的模型；`compare`、`research` 的 `--include-llm` 才增加模型臂。模型预算可通过 `--llm-calls-per-task`、`--llm-token-budget` 和 `--llm-timeout-seconds` 设置。

每次输出同时生成 `_summary.json`。先阅读小型汇总中的任务覆盖、错误、质量与成本，再按需要查看单 episode 的学习轨迹。

版本比较使用 `artifacts/cognition_v5_reference/` 中保存的 0.7.0 算法包与当前 0.8.0 实现。九臂命令如下：

```bash
python3 scripts/run_cognition_v6_research.py \
  --partitions continual stateful \
  --systems reference_v5 cognitive_v6 without_joint_state_coordinates \
    without_joint_state_probes without_research_memory without_active_experiments \
    without_knowledge fixed_model program_search \
  --output-dir artifacts/my_v6_research
```

上述九臂也是脚本默认配置。默认分区 continual 使用种子 401、503、607；development、confirmation、forward 分别保留 7/11/19、23/47/83、101/211/307。stateful 使用 809、907、1009。各臂共享环境、初始和目录实验、最终评测与预算上限，默认每任务 96 个观测和 24000 个计算单位；自适应查询与实际消耗可以不同。

`--partitions`、`--systems`、`--seeds` 用于缩小范围，`--resume` 继续同一设计的保存结果。多分区请求中 stateful 最后运行。五个分区均已提供本轮开发依据。每个分区保存 `*_runs.json` 与 `*_summary.json`，总表为 `summary.json`，仅首个种子保留少量详细病例。这套比较使用本地搜索。

`without_joint_state_coordinates` 保留原始变量状态搜索，`without_joint_state_probes` 保留旧转换实验，`without_research_memory` 关闭跨任务研究经验但仍保留任务内反馈。无主动实验与无知识分别检验观测和长期积累的作用。更早的状态、迁移、尾部及特定概念干预仍可通过通用 `compare` 研究。

## 4. 开发依据与任务范围

开发序列有 17 个 episode，涵盖参数、历史、迟滞、非线性、风险、冗余变量、角色映射、无关任务和已支持任务的机制变化。任务目标与可见能力固定，机制标签只供评测使用。

confirmation 包含三步历史、不同参数区间以及非线性与历史/交互的组合，共 12 个 episode。forward 包含带符号的参数区间、四步历史、角色重命名和延迟机制反例，也有 12 个 episode。

continual 包含 12 个 episode，组合线性、平方、交互和二至四步延迟、新变量角色、固定 q 的偏斜异方差风险，以及同上下文机制变化。其初始查询为三条四步轨迹，训练最长 32 步，最终评测为八条独立的 64 步轨迹。旧四个分区的结果均已用于后续修订，现在都是开发依据，原生成器继续保留供版本回顾比较。

stateful 是 0.7.0 增加的 12 episode 序列：不同阈值、转换方向与控制角色的滞回，角色重命名与双变量组合，同一任务和上下文的状态条件变化，以及线性、平方、交互、历史、无关任务和偏斜风险。八个 episode 使用二值状态输出，其余保持数值任务；这些类型标签仅供评测使用。

stateful 训练最长 32 步，最终评测为八条独立的 64 步轨迹，种子为 809、907、1009。0.7.0 的首次结果已用于 0.8.0 改进，因此五个分区现在均为开发依据；历史首次评测记录保留在相应版本报告中。

同一分区内，不同种子产生不同输入和随机实现。反复使用的 validation 属于开发选择，最终评分在 episode 返回后进行。研究报告区分程序实现、开发效果与确认结果，不将完成运行本身算成能力通过。

## 5. 当前比较应回答什么

| 比较 | 需要解释的问题 |
|---|---|
| 固定模型与可生成候选 | 实际程序修订是否带来作用？ |
| 保存的 v5 与完整 v6 | 本轮整体修订怎样改变同环境下的质量与成本？ |
| 无联合状态坐标与联合表示 | 多个控制量共同决定状态时，表示修订是否有效？ |
| 旧转换实验与多输入实验 | 改变控制组合是否使新的状态关系更容易被区分和学到？ |
| 无研究经验与持续研究经验 | 记住研究步骤的实际收益能否改善后续预算分配？ |
| 无状态搜索与状态条件阈值 | 观测到的两值输出能否形成有效的转换规则，起始行为是否解释正确？ |
| 无转换 probe 与定向转换实验 | 相同控制下改变准备历史，能否缩小阈值不确定性并减少转换错误？ |
| 无迁移调度与保留参数共同测试 | 已支持知识能否减少重新学习，同时减少低收益旧候选的反复比较？ |
| 旧风险路径与新增尾部拟合 | 共享尾部、累计参考证据与新轨迹校准怎样改变固定代价下的损失和成本？ |
| 贪心与可修订联合变量组合 | 保留多个组合、删除和换项能否恢复被早期选择遗漏的关系？ |
| 固定与自适应代表性时域 | 延长查询是否打破短段等效，并改善后段预测？ |
| 旧区间路径与新增风险学习 | 直接分位数拟合及新查询校准怎样改变固定代价下的损失与成本？ |
| 普通程序搜索与认知控制器 | 竞争问题、计划和记忆是否超过相同工具直接搜索？ |
| 原始分歧与任务价值选实验 | 预计任务风险下降是否比单纯扩大预测分歧更有用？ |
| 回顾式与新轨迹候选选择 | 在保留计划和迁移反馈时，新证据参与选择带来什么影响？ |
| 无起始分支与学习起始模型 | 历史尚不足阶段的表达能力是否改善整条轨迹预测？ |
| 无主动实验与主动 probe | 观测选择是否改变后续修订与总成本？ |
| 无构造 probe 与连续实验构造 | 除了从给定目录选择，生成新实验是否有额外作用？ |
| 单步与依赖计划 | 中间表示及组合的收益是否覆盖额外计算？ |
| 无知识与持续知识 | 获得知识的前期投入是否被后续使用收回？ |
| 无抽象与抽象重拟合 | 结构复用是否超过记住具体参数？ |
| 无角色映射与结构迁移 | 变量角色改变后，结构对应是否帮助学习？ |
| 特定概念存在与删除 | 具体收益是否依赖那个概念及其派生内容？ |
| 模型生成对照与完整控制器 | 统一观测和执行接口下，模型生成自身与系统组织分别贡献什么？ |

直接执行旧程序与重新拟合抽象分别统计。无关任务、超出支持区间的新观测和同范围机制变化也分别解释，避免把任何迁移失败都当成原知识错误。

通用 `compare` 保留固定模型、普通搜索、主动观测、知识、计划、抽象、角色映射、构造实验与删除干预等对照。当前版本脚本测量保存的 v5、完整 v6、五项消融、固定模型与普通程序搜索，共九臂。整机会话另记录任务日程、知识变化和恢复后的继续研究。

## 6. 结果与知识盈亏

主要结果是最终预测或行动损失，以及获得该结果所需的观测、计算、时间和模型消耗。平方误差和不同风险目标按适用任务分别汇总。

知识资源账记录获取期额外投入、迁移期节省和全序列净变化；质量变化另列。一个概念可能提高预测却增加计算，也可能减少搜索而不改变最终损失。这些差别保留为实际结果。

所有尝试 episode 保留在覆盖和失败分母。候选在取得本轮代表性轨迹前固定，fresh 指标描述这批证据与保留或回退决定的关系；没有 fresh 检验的修订单列覆盖缺口。独立最终评测再对修订前后程序、回退程序与恢复程序作反事实比较，测量最终预测结果上的错误接受和错误回退。迁移候选的实际测试次数、范围收缩和撤销使用不同计数。

多种子配对报告以同一 episode 的结果差为基础，以种子为 bootstrap 单位。版本脚本的差值为“其他臂 − v6”，正值有利于 v6。配对覆盖和失败与收益一同报告。

版本脚本在学习结束后另按历史长度 0–7、8–31、32 及以上对最终程序计分。分组区分起始阶段、训练可达到的后段与更长时域，额外评测单位和时间单独记录；最终标签继续留在评测侧。

二值状态任务使用固定 0.5 预测阈值，报告分类错误率、两类均衡错误率、转换行错误率与各自分母，并按相同历史长度分组。转换行由真实前一输出与当前输出是否变化确定，轨迹重置从低状态计起；测量发生在最终评测侧，统计复用同次预测。实际查询长度与学习成本用于判断减少分类错误所需的代价。

## 7. 后续研究投入

0.7.0 将 83.2% 的剩余状态错误定位到双输入组合，并显示总体分类与真实切换行错误可能走向不同。[0.7.0 结果](cognitive_runtime_v5_results.md)据此成为联合状态表示与多输入实验的开发起点。0.8.0 已将这两条执行路径接通，质量、资源取舍与仍未解决的病例见[本轮结果](cognitive_runtime_v6_results.md)。

系统性建设继续围绕整场研究展开。[功能缺口报告](hegel_machine_functional_gaps_20260908.md)保留 0.8.0 的原始差距。[0.9.0](hegel_machine_functional_implementation_20260908.md)已把实际观测、竞争程序与未决计划恢复接入控制器，并使不同失配情境中的实验、重拟合和校准选择使用持久收益经验。

[0.10.0](hegel_machine_callable_concepts_20260908.md)已把学得程序变为后续搜索能调用的定义，支持嵌套组合、共享执行和条件知识约束。[0.11.0](hegel_machine_measurement_and_state_20260908.md)已经以进程装置接通测量选择和连续潜在状态，并保留累计解释及按证据选择概念。[0.12.0](hegel_machine_integrated_research_20260908.md)已把这些行为接入执行；后续研究重点转为长期收益、适用条件和更丰富的任务机制。

知识方向继续发展组合条件与适用范围。新的坐标和状态关系能够成为抽象，后续任务应分别判断原参数、角色映射、组合结构和范围条件是否继续成立，并由实际反例触发重拟合或收缩。长期运行需要解释有用知识的保留、过时知识的修正，以及这些改变是否收回学习成本。

尾部学习仍以实际决策收益为目标。位置、尺度、情境变化和校准观测之间需要共同选择；总体拟合或区间变宽不能代替真实行动损失的改善。

更广泛的通用先验需要具体环境承接。当前压缩、稀疏组合、局部历史、分段状态、机制复用和不确定性已部分可执行；守恒、对称、低秩、拓扑与一般潜在状态等主张需要相应对象、候选及实际观测操作。[整机完成路线](hegel_machine_system_completion_20260908.md)按六个根类组织这部分建设。

外部环境通过共同的观察、动作和目标接口接入。扩展能力时把任务从开始到知识复用的整条链一同运行，持续区分“已接通”“实际有益”和“仍需研究”，由完整结果决定下一步投入。

## 8. 专门形式结果与历史成果

结构规律 verifier 可检验候选的局部性质；有限闭包与 membership 可回答特定语言问题。它们可以为值得分析的对象提供额外证据，现有冻结文件、产物和结论保持原身份。

## Limitations

- 当前候选、抽象及模型生成输出受有限 primitive 语言约束。任意新传感器、开放世界元算子和通用理论发现仍需要不同范围的证据。
- 动作调度、依赖计划、probe 生成、模板拟合和条件作用域使用有限启发式；实现这些结构尚不证明它们具有普遍或稳定的累计优势。
- 五个分区的生成器均公开且均已提供开发依据，不能充当独立托管的隐藏基准。
- v5/v6 的总差值包含联合状态坐标、多输入实验、候选保留与研究经验，需要结合消融解释。整机会话完成表示允许的访问结束，未解决误差另列。
- 二值状态搜索由两值可观测输出提出条件阈值；连续状态搜索支持有限递推族，尚不覆盖一般潜在状态推断；固定阈值的分类指标也不表示恢复了真实机制。
- continual 与 stateful 的最终 64 步轨迹超出最大 32 步训练查询；后段结果是在这个公开模拟系统中的时域外推证据。
- 残差区间驱动的行动是具体决策实验，尚不等同一般分布鲁棒控制和外部风险保证。`worst_case_loss` 是各观测所学区间两端损失的最大值再取平均；旧模式中的名义零宽区间使该值恒为零；新模式的 nominal 可以带经验区间与后校准，仍不能据此评价真实测试尾部损失。
- fresh 指标衡量当时证据与决定的关系；独立最终误接受/误回退仍只相对已比较程序，不提供最佳认知操作标签，也不含复杂度收益。少量种子的区间可能粗糙；最终结果需连同配对覆盖和失败解释。
- 程序计算单位、实测时间与模型 token 是不同资源。模型用量缺失时保留未知，失败中的未报告支出不能被解释为零成本。
