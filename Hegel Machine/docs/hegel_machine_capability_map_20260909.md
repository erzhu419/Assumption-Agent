黑格尔机已经具备一条持续执行的研究链：从实际观测提出竞争解释，选择实验和表示修订，用新证据比较候选，保存可调用概念、实验与方法，再在后续任务中复用、修改适用条件或撤销。新测量、连续状态、对象与尺度、递归依赖、局部机制修订、延迟反馈和普通代码 Agent 对照也已有实际入口。

当前应把建设重点放在这些能力之间的选择与积累：什么知识值得留下，哪些分支还缺区分证据，什么时候继续参数修复，什么时候值得改表示，以及这笔投入能否减少后续任务的总损失和费用。

## 可运行的整机入口

新增动态议程使用 `cognition agenda --checkpoint ... --request ...`；`cognition agenda-demo --checkpoint artifacts/agenda.json` 会运行实际三进程示例，展示问题动态到达、跨能力选择和延迟回执。

在项目根目录，持续任务研究使用 `session`；`--steps` 限制本次新增访问数，后续命令加载同一状态继续：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition session \
  --partitions development confirmation forward continual stateful \
  --seed 1237 --checkpoint artifacts/capability_session.json --steps 2

PYTHONPATH=src python3 -m hegel_machine cognition session \
  --checkpoint artifacts/capability_session.json
```

跨能力整机使用 `frontier`，包含持续任务、测量、实验迁移、方法投入、局部机制、七类对象研究及延迟实验：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition frontier \
  --checkpoint artifacts/capability_frontier.json --steps 1

PYTHONPATH=src python3 -m hegel_machine cognition frontier \
  --checkpoint artifacts/capability_frontier.json
```

实验未返回时会保存等待状态，结果到达后再次使用相同入口。阶段顺序由 `frontier.STAGES` 给定；阶段内部由对应 Agent 选择候选、测量或修订。

独立执行测量、对象结构与普通代码对照：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition lab \
  --backend process --checkpoint artifacts/capability_lab.json --steps 1

PYTHONPATH=src python3 -m hegel_machine cognition structure \
  --readout window --variant exchange \
  --memory artifacts/capability_structure_knowledge.json \
  --output artifacts/capability_structure.json

PYTHONPATH=src python3 -m hegel_machine cognition code-compare \
  --workspace artifacts/capability_code_workspace \
  --output artifacts/capability_code_comparison.json
```

代码对照需要本机已配置的模型，执行时会产生真实模型调用。已有对应运行可通过 `--code-results`、`--hegel-results` 复用，并用 `frontier --code-comparison PATH` 纳入整机报告。详细实验提交格式见 [0.12 运行入口](hegel_machine_integrated_research_20260908.md)。

## Limitations

1. **整体收益仍需改进。** 0.22 三组完整方法序列相对 0.21 的平方误差均相同，风险预测三组下降，行动损失两组下降、一组上升；合计多 366 行观测、13521 计算。关闭方法选择臂则平均行动损失上升，仍未形成稳定净优势。5501 的 n11 方法臂行动损失从 0.387566 降至 0.285046，4507 的 n11 仍退步。537 项认知回归、六个 65 题序列与 13 阶段整机均已完成，见[0.22 报告](hegel_machine_discriminating_research_20260909.md)。此前失败与运行保留在对应版本报告中。

2. **表示与装置范围有限。** 程序语言、可用仪器、对象字段和基本研究动作由实现提供。连续状态覆盖有限递推与读出族；结构发现覆盖加权守恒、平移/置换、邻域、总量、有限窗口、低秩投影、局部模块、慢变量、有限图连接及分段响应等具体族。任意对称群、拓扑、通用非线性隐状态、新传感器设计和开放世界本体形成仍未覆盖。二值状态分支会读取已观察到的历史输出；连续累积程序可以沿输入历史执行，两者的状态任务口径不同。

3. **观察方式的再修订仍有具体边界。** 测量 Agent 已能根据中途残差重新购买和比较通道，并恢复未完成的测量研究；候选仪器仍来自预先给定的目录。结构研究会在已提供的对象子集和尺度候选间选择并实际改测量。未来仪器读数情景主要来自经验路径，通用传感器生成模型仍未学习。

4. **递归与方法修订已有执行基础，开放式重构仍有限。** 系统能修改节点依赖、用答案驱动父问题、修订步骤与适用条件，也能反驳结构先验。概念拆分现已接通实际采纳、知识绑定与后续调用；基本动作、结构候选族及多数问题生成规则仍由开发者给定。外部目标与最终评分保持固定。`frontier` 是可恢复的阶段整合，阶段顺序尚由程序定义；65 题 `session` 的任务选择及阶段内部研究选择已有自主调度路径。

5. **知识价值的估计仍依赖有限后续经验。** 当前记录能覆盖生成后未比较、比较后拒绝和真正保留的成本，收益会改变实际选择；对未知后续任务的价值预测、多个知识与方法共同作用的收益归属仍不完备。观测不足的分支需要实验机会，已经被反例否定的参数则需要修订或退出，两种情况必须由实际研究过程继续区分。

6. **现有外部交互和对照的范围明确。** 装置与延迟任务是本地独立进程，尚无实体仪器或项目外任务的完整运行证据。自由 Python Agent 的任意拟合计算、模型用量和运行时间分别计量，其评分行数不能直接当作与程序搜索等价的总计算成本。0.26 四种装置八题比较已完成；0.27 修订后在这八题的整体 MSE 低于已完成的普通代码 Agent，并完成另一组同生成器新种子研究。代码代理的扩展运行单列。五个公开合成分区均已参与开发，新种子是同一生成器的新实例；0.20 的普通代码比较复用了 2026-09-08 的固定 Python Agent 结果，并重新运行当时黑格尔机三题；两部分来源和实际费用分别记录。

下一阶段的核心工作是把已经存在的能力连接得更有效：从具体知识及其尚未解决的证据需求出发，联合安排保留、实验、结构修订和跨任务投入，使局部学得的解释带来后续可以反复兑现的收益。
