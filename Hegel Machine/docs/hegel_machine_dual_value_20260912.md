## Limitations 与下一步

开发集目标、约束预测MSE仍增加1.18%、29.41%。主要退化任务中，53个真实约束均值为正的评估点，GP均值误报非正从21增至53；最终推荐仍可行，该统计不等于错误可行性认证。[诊断](../artifacts/sc_kg_dual_value_20260912/revision3/constraint_prediction_diagnosis.json)定位到末段观测替换后同一GP的区域偏差。下一步应让目标观测的投入选择同时考虑约束知识质量，并改进当前局部近似对后续模型更新的模拟。跨任务稳定净收益和开放世界能力仍未完成，本轮未新增Code Agent对照。
