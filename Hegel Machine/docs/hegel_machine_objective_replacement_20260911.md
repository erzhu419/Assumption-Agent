# 目标模型替换的独立研究

2026-09-11，0.50.0 已纳入认知主线，比较基线为 0.48。采用依据是整体与新例目标解释改善，终值和可行性保持。

约束范围的修订现在只提出一个待比较的目标 GP。系统在真实实验前，用已有数据分别预测旧模型、拟议替换与冻结目标候选，再用同一条实测比较。拟议替换须独立胜过当前模型；同一轮若已有获支持的目标候选，也须胜过它。证据不足时保留旧目标模型，约束修订照常完成，待决替换继续消费后续已付费观测。

实验覆盖按具体比较对象记录：旧目标候选曾用过的控制可以检验新的拟议 GP；同一比较中的重复控制不充当新的区分点。实际目标 GP 改变时，冻结候选转用对应的事前预测与后续实测。

首版只用原均值下界：15 例中 14 例终值持平、1 例退化，未扩大运行。失败中拟议 GP 在十个控制上全部更准，却因改善幅度不均而未获采用。后继版保留原规则，补充正平均改善及单侧符号尾概率 ≤ 0.05 的一致胜出依据；五连胜可获支持，四连胜不足。目标程序自身的原采用条件保持不变。两版源码及负结果分别保留。

实际采用 54 次目标 GP 替换，34 次由一致改善支持，50 次在约束修订后的后续实测中获得支持。新增比较为 671 次 GP 拟合、7978 条拟合记录、1971 条预测和 1222 条比较计算；含比较计算的目标研究开销增加 0.83%。本版实际运行 211 次优化、9056 次物理调用，连同失败首版共 9536 次。74 项针对性行为测试通过，测试未新增物理模拟。

## Limitations

当前收益是目标解释选择改善，最终优化结果尚无增益。新例约束退化主要来自一例机制变化任务，MSE 从 0.000164138 升至 0.003753914；其目标预测改善，终值相同。两臂前 28 次在线观测及约束程序完全相同，最后四次由内区探索变为边缘采样与三次原点确认；GP 对程序的读出斜率从 0.921 漂移至 1.401，而冻结程序自身 MSE 仍为 0.000167647。

下一步让末段目标确认与区分约束程序、GP 读出的实验共同竞争预算，并保留获支持的约束程序作为预测竞争者。自适应选点与重复判断下，符号尾概率不是校准置信度。本批未重跑 vanilla 或普通 Code Agent；开放世界与稳定长期净收益目标仍未达成。
