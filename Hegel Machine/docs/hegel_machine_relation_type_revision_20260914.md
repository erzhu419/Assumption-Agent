# 残差驱动的关系类型修订

2026-09-14，0.82.0。本批落实[原建议](../markdown/GPT6_advice.md)的假设提出与修订：已有半径关系不能解释残差时，提出守恒的左右单向输运，并在原事件、窗口上下文中比较完整响应。

类型候选、执行语义和实际区分实验已接通。方向类型逐边传递有符号数量，源减、目标加，焦点只控制读出；相同公开接口不披露类型。旧定义保留，修订程序与参数区间按当前类型保存并供后继调用。

[固定比较配置](../config/cognition_directed_relation_composition.json)包含12套新独立装置，每套依次运行总量、事件、组合、窗口、右向变化、右向改名、左向变化、返回原对称关系。两版各96个相关阶段，独立样本是12套装置；两版使用相同实验室、观测权限和预算。

## Limitations 与下一步

当前仍在对称、右向、左向三种预设关系中选择，类型变化保持原半径；对象字段语义公开。尚无本批真实Code对照，原构想仍未全部完成。记账计算下降未带来整体加速：左向阶段累计耗时833→1,547秒，两个修订程序增至3,429和4,607节点；返回阶段78→318秒，测量费用0→4,104。具体耗时热点尚未定位。

下一重点是残差驱动的关系条件合成，并控制连续修订的表达膨胀：用对象角色及已有比较、逻辑算子组合条件，与调参和撤销竞争；用“仅源数量高于目标时输运”检验固定位置、交换数量的区分实验，再考察复用、返回及完整成本。
