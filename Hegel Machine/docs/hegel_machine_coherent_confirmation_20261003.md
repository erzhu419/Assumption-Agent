# 同一读数分布下的区分实验（0.172.0）

修订确认现在用同一份已付局部残差分布计算读数命中概率与新旧解释的预计分歧。区间互斥、时间窗口内的交叉项和启动预测共同计入，旧反例不再作为新实验必然重现的读数。规划计算仍受原15000额度约束；普通研究流程保持原样。

52项相关测试通过。三个真实已付前缀的开发比较中，新旧方案均采购24行，均未取得新区分证据；新方案的预计分歧明显降低，三例合计计算反而增加947。因此估值一致性修复本身不等于实验收益提高。

固定长序列的24条学习链、336项终测全部完成，全离线、0外部模型调用。仅替换为0.171确认规划器的对照精确复现其168题及12条链账本。新版与对照逐题预测全平，均137/168达标，平均MSE为.0223840；后7阶段均70/84，MSE为.0176599。新版增加96行观测/测量和184350计算（0.41%）；实测研究及终测CPU为3015.26对3204.36秒，少5.90%。实际区分从13/40批变为14/41批，两臂均27批未区分，新增局部改善未转成终测收益。保留估值一致性修复，完整结果见[配对统计](../artifacts/coherent_confirmation_20261003/compact_results.json)。

## Limitations

相邻实测残差之间采用均匀质量，重复值保留点质量；一般非线性响应及跨事件非线性交互仍采用条件代表值与矩近似。开发前缀缺少完整中间研究状态，两臂从相同已付数据重建，不能当作历史确认阶段的精确重放。

正式比较均为已见回归，root12/p9仍未改善；短链、知识删除/撤回独立收益及外部模型对照本轮未重跑。CPU为本次实测，不能据单轮下降宣称稳定长期净收益。

下一核心：把修订确认的边际价值接入共享预算。目前新估值主要改变实验背景，条件修订仍通常采购固定24行，pair路径没有追加分配。首批未区分后，应比较改背景、追加确认与暂缓的实际价值，并与其他任务竞争余款；新旧解释的区分区间与新解释自身的未决边界分别处理，逐批保留实际反例及收益，不能机械增加样本量。
