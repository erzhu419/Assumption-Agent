# 八项原生能力的联合实现

**后续论文实验已替代本页的对照结论：**旧逐题独立臂缺少无先验条件搜索，
96/96对84/96不能单独归因于跨任务知识。现已补齐相同表达语言，完成30个新种子、
630次运行与分机制干预；见[论文实现与证据](hegel_machine_growth_paper_evidence_20261006.md)。
以下保留当时原型记录。

本轮把八项缺口接入同一个持久化研究器 `GrowthResearcher`，通过现有
`Program`、`Observation`、`TaskSpec`、`KnowledgeLibrary` 和付费仪器接口执行。
新增约1,300行运行与实验代码、550行针对性测试；原论文三组结果保持。

| 对应缺口 | 已接通的运行行为 |
|---|---|
| 1．先验失效后生长抽象 | 从实测残差生成乘积与高阶组合，确认后保存词法参数化定义；后继任务实际调用定义并改变搜索。 |
| 2．旧理论成为新理论的特殊情况 | 从旧模型误差学习条件边界，形成保留旧分支的可执行 `if`；边界附近追加实验收窄适用区间。 |
| 3．不同表面表示下的共同规律 | 按响应比较匿名角色排列；公开坐标范围提出单位、偏移变换，再用实测选择；新增单位变换端到端测试通过。 |
| 4．识别观测不足并恢复区分 | 固定控制的重复实验识别未解释变异，付费比较辅助仪器，以新增观测能否改善预测选择表示。 |
| 5．失败后产生可复用研究程序 | 从实际证据依赖编译研究DAG，重绑定实验并执行；失败反馈限制适用条件，后续修复形成改变步骤的子版本。 |
| 6．不确定性、简化与恢复复杂度 | 重复残差决定是否引入随机响应方差；简单模型取得新确认后采用，任务变化失配后重新调用复杂解释。 |
| 7．改变提出、检验假设的方法 | 学出的定义进入候选语言，研究程序进入后继采购和拟合过程，两者都接受新任务反馈。 |
| 8．主动恢复区分能力 | 表示缺失触发新测量，条件边界未明触发边界实验；共同进入研究、确认和跨任务积累闭环。 |

## 运行与结果

从项目目录执行：

```bash
PYTHONPATH=src python3 -m hegel_machine cognition growth --checkpoint artifacts/growth_session.json
```

该命令执行八阶段序列并逐题保存知识；已有文件会作为下一次运行的知识起点，
`--tasks 3 4` 可指定接下来执行的任务。Python入口可直接接收符合上述接口的实验环境。

八阶段为非线性发现、匿名角色迁移、局部条件变化、隐藏输入、仪器改名迁移、
随机响应、线性简化、原规律返回。独立终评在两臂训练全部结束后执行。
[最终12个新种子的结果](../artifacts/research_growth_20261006_final_12/summary.json)：

| 指标 | 共享知识 | 逐题独立 |
|---|---:|---:|
| 达标且获新确认 | **96/96** | 84/96 |
| 观测行数 | 10,396 | 12,248 |
| 测量单位 | 8,560 | 8,848 |
| 计价计算 | 1,633,959 | 2,043,746 |
| 实际CPU秒 | 72.90 | 14.83 |

共享知识少15.12%观测、3.25%测量、20.05%计价计算；CPU耗时为4.91倍。
各阶段在12条共享序列均达标；独立臂的12个失败均在局部条件变化。
种子8612和8620计算更贵，8617、8620、8621测量更贵。开发阶段的边界遗漏失败及
[首批8个新种子](../artifacts/research_growth_20261006_joint_8/summary.json)均保留。
35项新功能及相关语言测试通过，全部研究和测试为离线执行，外部模型调用为0。

## Limitations与下一步

八项均已有可执行的有限实现，完整开放世界构想仍未完成。本入口覆盖标量响应、
有限表达式组合、可观测阈值条件、公开控制和可选仪器；跨领域证据目前是匿名坐标、
单位和偏移变化，尚无真实异构领域验证。已有时序研究器继续承担历史状态任务，
新的联合研究器不迁移需要历史的旧程序。研究程序来自已执行动作的重组，尚不能
发明新的底层实验工具；不确定性当前是重复证据支持的响应方差。

本批跨任务收益主要来自条件化旧模型，不能据此给每个模块分配独立贡献；
方法重放在部分任务仍额外采购。逐题独立臂是相同搜索器清空跨任务知识，
普通Code/真实LLM对照仍待后续低价模型实验。候选行计费也不等于CPU工作量。

下一步在现有联合骨架上逐项调整：先减少方法错迁移的额外采购与实际运行时间，
再扩展异构表示、研究步骤与实验工具；不再为八项分别重建一套入口。
