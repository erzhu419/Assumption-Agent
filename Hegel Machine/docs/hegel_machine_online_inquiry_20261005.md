# 在线子研究、冻结迁移与同模型对照

三项共用一个校准响应实验室。主结果是正确解释、独立预测及支持研究是否改变决策；预算只作为共同约束。英文论文已加入 Sections 4.7–4.8、5.10–5.11 和 Figure 6。

## 本轮结果

在线递归和迁移已完成 6 条开发链、另 30 条正式源任务链。每条正式链冻结源知识，再独立运行“结构同/异 × 表面同/异”四个目标；三个研究器具有同样的 96 个候选和实验动作。

| 研究器 | 确认且独立终测正确 | 错误确认 | 重用旧定义 | 采样前改写旧步骤 |
|---|---:|---:|---:|---:|
| 递归、方法可修订 | 120/120 | 0 | 60 | 47 |
| 平铺主动研究 | 120/120 | 0 | 60 | 0 |
| 递归、旧方法冻结并允许回退 | 120/120 | 0 | 60 | 0 |

一个真实执行例中，父问题先打开坐标子问题，后者打开校准子问题。校准证据返回后确定第二个控制量是驱动量，父研究发现旧探针让二次和绝对值规律同为 1，遂把探针改为令四个剩余规律预测均不同的位置。改写发生在实验之前。单独改变校准回传的机制测试会改变父研究的解释和实验，错误分支随后不能通过新鲜确认。

每个研究器都在 60 个同结构目标中经过重新识别后调用旧定义，在 60 个机制变化目标中采用替代定义。迁移检验因此包含“表面不同但结构相同”和“表面相似但机制不同”。旧定义调用不等于跳过当前研究。三臂均全对，未观察到递归或方法改写的独立准确率收益。

真实 LLM 三臂已实现普通 Code/ReAct、文字经验、可执行研究知识，均由 ruoli.dev 的 `gpt-6.1-sol` 提议并执行 Python。GPT 正式批次注册 180 个任务位置，尝试 16 个：9 个完成且通过独立终测，6 个服务失败（5 次空响应、1 次流提前结束），1 个研究额度耗尽，164 个未启动。77 次调用已知至少 305,535 tokens，6 次调用缺少 usage。

目标任务单独统计：Code 完成并正确 2 个，文字经验 1 个，Hegel 1 个；每臂原计划 30 个。只有 1 个 Code—Hegel 配对目标，双方均正确，没有完整三臂配对。该 Hegel 目标与源任务结构和表面均相同，实际调用继承的实验程序和预测程序，仅刷新证据记录，未改写程序或创建子研究。其目标观测数 12，Code 为 24；单例不构成比较优势。另一个 Code 源任务先用完 24 行观测，未给确认预留 3 行，随后重复提交直至 token 上限；这是实际研究分配失败，不能归为服务故障。详见 [GPT 批次](../artifacts/online_inquiry_llm_20261005_main_30_run3/RUN_STATUS.md)。没有使用 GPT 订阅，旧中断批次单独保留。
后续按用户选择换成 `qwen3.8-flash`，接入实际可用的原生 Chat Completions 工具格式，并单独冻结批次：9/180 个任务被尝试，1 个 Code 源任务通过，6 次服务失败（5 次模型不可用、1 次超时），2 次工具格式失败，171 个未启动；无完整目标或迁移链。40 次调用已知至少 198,600 tokens。详见 [Qwen 批次](../artifacts/online_inquiry_qwen_20261005_main_30/RUN_STATUS.md)。

该批结束后，修复了格式错误直接结束研究的问题：有用量的格式错误作为已计费反馈，允许在原额度内纠正；不执行无效动作，服务故障仍停止。29 项针对性测试通过。修复未追改冻结结果，也尚未再次运行外部模型。英文稿已同步。

## 文献带来的取舍

- 假设生成和验证已有直接先例；本论文应突出支持条件能变成研究对象，证据会改变后续研究，程序可带条件复用。
- 从记忆和技能研究借鉴“实际使用＋删除或冻结干预”。保存了一份产物本身不足以证明价值。
- 从 Red Queen 借鉴机制消融与外部结果。当前任务已有明确预测目标，可直接评估；无需新增评估器共演化来扩大系统。
- 框架可以覆盖 RL、稳健决策与因果，但本稿先用一个有限实验族展示机制。实验不必逐个覆盖所有概念联系。

## 局限与下一步

在线问题类型和候选语言由代码给定；留出的是源到目标的组合，四类原语都已公开。当前不证明开放世界发现、自主生成任意递归结构，或优于普通 LLM Agent。平铺对照的成功是正式结果，继续微调这批已全对的任务不是当前主线。

下一步仍缺足够完整的同模型三臂比较。已有真实程序复用案例，但不能用连接短测或单个成功案例替代该比较。GPT、Qwen 中断批次均保留。

Google 官方 `gemini-3.5-flash-lite` [独立批次](../artifacts/online_inquiry_gemini_20261005_main_30/RUN_STATUS.md)已按用户要求停止：55 条链有完整训练记录，另三条部分运行，未进行独立终测。1,748 份响应全部有缓存命中，但合法动作仍大量停留在重复运行检查代码；缓存、非缓存开发诊断也都未完成。旧 Qwen 在同一源任务八次调用后提交了正确模型，但它整批只有九个任务且多数被服务故障截断，两者不能当作充分的模型排名。现在按用户新授权改用 ChatGPT 订阅的 `gpt-6-luna`，先验证完整开发链。

订阅 Luna 的完整开发链已通过：三臂六个任务均通过新观测确认和独立 256 点终测，MSE 均为零；21 次调用全部有缓存命中。Hegel 在新表面表示下调用未改动的源实验程序，再根据观测把预测器从 `c704` 改绑到 `c409`，没有发生子问题递归。三臂全对，尚无准确率优势。[正式 30 链批次](../artifacts/online_inquiry_luna_subscription_20261005_main_30/RUN_STATUS.md)已于 20:59 完成全部 90 条链及独立终测。目标任务 Code 29/30、文字经验 29/30、Hegel 26/30，尚无整体优势；Hegel 三个目标耗尽确认所需观测额度，最终触及 token 上限，另一个遇到模型容量不足。894 次调用中 878 次有缓存命中，已知输入 tokens 的 70.3% 来自缓存。由于 Codex 输入开销，三臂共同 token 上限提高为 30 万；16 次调用与 24 条观测不变，原 6 万上限开发失败保留。
