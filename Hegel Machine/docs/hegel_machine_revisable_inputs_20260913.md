## Limitations 与下一步

纯关系变化6题的测量为4608对3456，增加33.33%；部分窗口后继仍重复测量。对象角色、聚合和时间算子仍由开发者提供；联合修订尚不等于自主发明对象或任意研究操作。当前消融未单独确认输入研究程序重放的独立收益。搜索计算采用现有逐行计费，不能等同原语总步数或LLM推理成本。

本轮未增加真实LLM调用。与已有Code对照匹配的原8题中，黑格尔机学习观测772、测量4248，Code为669、2460，仍未全面胜出。Code原正式交付5/8，另外3份预算内程序原样终测也通过，合计8/8；该比较不覆盖校准或关系变化。

下一步转向从干预证据形成对象划分与局部依赖，并让竞争解释提出区分实验；22项元先验通用化、开放研究操作和开放分布收益仍未完成。对应[原目标进展](hegel_machine_advice_goal_status_20260909.md)。
