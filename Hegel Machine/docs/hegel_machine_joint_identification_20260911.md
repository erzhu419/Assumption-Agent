# 0.55：共享候选验证与联合识别实验

2026-09-11。本轮实现了双坐标识别、保留正向但未定的交互解释、共享未来观测比较，以及通过验证后编译安装。修复了两处选择问题：未通过验证的基础候选不再阻挡已胜过当前GP的交互候选；晋升后的解释不会继承基础候选的替换比较。**联合识别未采用为默认，默认选点恢复0.54；共享验证与候选身份修复保留。**

联合方案在52例开发中相对0.54为8改善、36持平、8退化，全部可行；未知39例平均最优值差距下降25.0%，两例交互候选经未来实测支持后实际安装。但独立新九例为2改善、5持平、2退化，平均差距增加35.2%。各臂共享初始观测，每题各使用32次在线观测：

## Limitations 与下一步

下一步让区分实验围绕候选预测的可行低值区域展开，按剩余预算共同选择识别、验证和实际改善机会；优先解决“补齐表示后无钱验证”和“候选被拒后尾部全域探索丢失好解”两种失败。原MD中的跨任务知识独立收益、开放世界能力和稳定长期净收益仍未完成；普通Code Agent沿用此前对照。
