# 冻结目标候选的持续验证

2026-09-11 完成，默认版本 0.48.0。

0.47 修复证据消费后，四次验证平均改善为正、差异较大的候选仍被直接删除。现在保留这种未决候选与原拟合参数，旧目标模型继续服务；共享普通优化及约束研究取得的新观测，每两条不同控制的未来验证再判断。预测先于实测，采用条件仍为平均误差改善减两倍标准误大于 1e-7；平均改善不为正则停止。候选、轮次及未决证据可随会话恢复。

436 例包括历史 409 例与预先固定的新 27 例，各臂总预算仍为 32 次初始观测加 32 次在线观测：

| 实测指标 | 0.47 → 默认 0.48 |
| --- | --- |
| 按可行性优先比较终值 | 2 改善、434 持平、0 退化；可行数 432 → 432；新 27 例终值全部持平 |
| 目标 GP 平均真实 MSE | 0.0185447 → 0.00197210，降低 89.37%；逐例 13 改善、420 持平、3 变差 |
| 目标研究计算 | 4,428,499 → 4,433,686，增加 0.117%；目标模型采用数 128 → 135 |

共同可行的改善来自 `value_precision_3_objective_only_change_noise_0.03`：目标 3.23921 → 2.75624，降低 14.91%。另一改善例 `value_precision_3_mechanism_change_noise_0.03` 仍不可行。432 个共同可行案例的逐例相对改善均值为 0.0345%，中位数为零。

同时实现并比较了有限未来情景的主动续验规划，完整实验没有产生追加续验购买。共享续验消融覆盖全部 55 个实际续验入口：16 例先行运行含 3 个入口，再补其余 52 例；另 368 个没有续验入口的路径复用。68 个实际消融与完整版本的轨迹、预测、模型采用和终值全部相同，完整规划却多用 39,247 计算。因此默认采用共享版本；主动规划实现及冻结实验保留。本批完成 408 次主实验优化器运行和 68 次消融，共 17,536 次实际模拟器调用（含新增初始观测和离线评价），历史可复用数据未重测。默认路径 28 项针对性测试通过，覆盖轮次等待、恢复及零追加规划；这些测试未调用模拟器。[精简结果](../artifacts/sc_kg_objective_validation_v048_20260910/passive_completion/adoption_summary.json)与[完整研究目录](../artifacts/sc_kg_objective_validation_v048_20260910/)保留比较和费用。

## Limitations

经验误差判据没有概率覆盖保证；保留候选的收益已出现，主动购买续验的独立收益尚未出现。旧目标 GP 被约束范围修订重建后，历史优势可能不再适用：`completion_value_2_mechanism_change_noise_0.00` 的候选仍被采用，目标 MSE 从 0.000882 升至 0.021839。下一步应保留候选，但重新取得相对当前模型的比较证据，并处理约束范围混合旧机制数据的问题。新增 27 例没有终值收益，稳定长期净收益与开放世界目标仍未达成；本批未新增 vanilla／Code Agent 对照。计时来自不同运行时段，计算减少不代表已验证墙钟加速。
