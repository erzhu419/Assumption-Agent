# 研究范围与目标预测器修订

2026-09-10，0.38.0。

研究中已恢复的预测再次失配时，系统复测反例并重划后段范围；否决则恢复原研究。目标规划按新证据批次启动并保留后期计算。辨识实验从多个已测可行位置补充缺失方向，冻结候选通过四次未来实测后实际更新目标 GP/HVD；后续约束重建保留已学目标程序。

新种子的三个目标独变案例全部实际采用新预测器（第 57、58、57 次调用），平均目标 **3.6891 → 2.7834**，目标 GP MSE **1.50360 → 0.00189**。三个旧目标独变开发案例也全部改善。原机制变化失败恢复可行；主组未触发研究范围再次修订，该链的效果见[仅改研究范围的独立重放](../artifacts/sc_kg_research_scope_v038_20260910/scope_only_development/compact_summary.json)保留前 13 次在线调用，目标 **3.6853 → 0.5**。

全组目标与约束搜索合计 **3,695,861 → 1,924,607（减少 47.9%）**，目标规划的 GP 预测控制数 **523,842 → 34,223**。本批对照与开发重放实际新增 6,400 次在线调用（主组 6,176、失败开发 192、独立重放 32），另有 384 次初始观测和 1,920 次独立评价，共 8,704 次模拟器调用；实际新增搜索 2,618,806，初始研究计算 18,981 另计。相关范围、目标与 SC 测试共 56 项通过；约束重建保留目标程序的串接行为由真实集成测试覆盖。

## Limitations 与下一步

全体目标平均差为 **+0.00581**，尚不能认为整体性能改善；旧开发组的联合变化出现较大回退。总可行数相同，但修复一个原不可行案例的同时，另一个案例变为不可行。目标研究可能占用后段观测，使约束研究启动偏晚、验证不足。下一步让同一次实验同时推进目标与约束候选，依据共同剩余观测安排取证次序。

目标解释仍限于仿射和加性二次关系，新目标程序用于当前优化任务，跨任务目标知识复用尚未接通。[原 MD 十项目标核对](hegel_machine_advice_goal_status_20260909.md)继续区分有界执行闭环与尚未完成的整体科学目标。
