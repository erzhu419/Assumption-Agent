主线保持 **0.178.0**。本轮按最新 [GPT6 advice 第五、六节](../markdown/GPT6_advice.md)实现了用新付费实验选择局部／共享读数模型，并在修正版中先为已有区分实验保留计算。候选代码及测试均已归档，0.179.1的44项相关测试通过；生产恢复后的12项回归通过。全部项目实验离线，外部模型调用为0。

最终对照含24条续研、336项终测，其中复用2条基线及28项基线终测；另保留初版失败证据。见[完整小表](../artifacts/narrow_confirmation_20261004/correction_extension/combined_summary.json)及[代码、协议与负结果](../artifacts/narrow_confirmation_20261004/README.md)。

## Limitations 与下一步

这些是历史受控任务的回归，部分CPU比较跨运行时段；不能宣称稳定净收益。本轮停止继续调读数池。下一核心回到**具体知识的后继贡献归因，以及负贡献如何改变采购和错误迁移撤回**；研究投入与有效确认仍未整体验收，四类主线完成状态不变。
