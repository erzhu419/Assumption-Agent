# 0.131–0.154 的退化与目标复核

复核确认旧能力发生退化：冻结的0.154在0.131原任务上，平均响应误差增加40.69%，总计算为2.75倍。近期新任务也连续退步；主要问题是研究决策未收敛，失败候选又持续成为后续比较的起点。最近大量工作集中在条件窗口，不能换算整个 advice 的完成进度。本轮保留源码与已有失败，完成历史复核和固定旧能力回测。

## 固定旧能力回测

固定0.131原来的12套装置、六个含噪窗口阶段、配置与预算，两版分别空库开始累计；24条学习链及自然回访全部结束后统一完成144项独立终测。[原始比较](../artifacts/version_direction_audit_20261001/old_capability_anchor/comparison.json)与[协议](../artifacts/version_direction_audit_20261001/old_capability_anchor/protocol.json)已保存。

| 平均响应MSE | 1.253004e−5 | 1.762824e−5 | +40.69% |
| 含噪观测预测MSE | 1.140168e−4 | 1.192717e−4 | +4.61% |

12条链中10条平均响应误差上升，六个阶段均值全部变差。旧0.131本次逐题响应误差、学习费用和完成状态完全复现其历史结果。这提供了旧能力受损的直接证据，任务难度变化不能解释本次差异。

实际轨迹显示：旧版72次含噪响应重拟合提案、288次比较、51次选择和确认，在新版全部为0；新版转而发生73次条件配对实验研究、280次配对干预评估。含噪平滑任务的研究路径发生了实质变化。

## 具体哪里出了问题

1. **新条件实验挤掉旧含噪修订。** [统一控制器](../src/hegel_machine/cognition/unified_research.py)第1994–2010行已有实测噪声支持并暂停扩搜，但第4298–4306行在主确认前另调条件实验；第1104–1120行入口只以近零误差判断是否省略，没有消费噪声结论。旧回测root01首次访问，两版动作10同样确认噪声；新版随后购买72行条件实验、花58920计算，再做确认与重测，观测用到216/240。旧含噪重拟合代码仍在第4585–4598行，但要求剩余预算的一半至少16行，此时只有12行，因此无法启动。0.134.1冻结代码没有此前置条件入口，0.135加入；当前0.154实际轨迹证实预算挤出。
2. **失配参数仍有权指导实验。** [实验规划](../src/hegel_machine/cognition/observed_condition_experiments.py)用候选预测极差评价部分结构分歧。root06 p2已有完整拟合误差约0.52、36.54、37.13、39.67，仍按3837的预测分歧采购。应保留可修订的结构线索，同时撤销已被共同实测反驳的具体参数预测权。
3. **规划、采购、追加投入没有共同的收益含义。** 规划器已有整窗口预测损失，[采购器](../src/hegel_machine/cognition/condition_research_returns.py)却只比较“信息概率×可靠性”与资源占比，方法回访另用历史增益和归一化分歧。低概率高损失的边界与坏模型的巨大分歧因此可能得到相反的错误投入；缺的是预计减少原任务损失的完整动作比较。
4. **失败后广搜能耗尽确认计算。** 统一控制器把失败确认后的剩余计算交给广搜，下一轮先买观测再检查评估费用。实际坏例买了最后48行却无法评估，计算128422→319992，终测MSE约0→8.55666。这是已发生的预算调度缺陷。
5. **局部知识回报没有形成后继采用。** 最新完整拟合35→198次、程序50→600个，匹配新确认仅6→8次；接受的两题仍边界未决。方法回访局部改善5→7，但整轮收益经验后续采用为0。更多可执行产物并未证明积累更有用。

上述坏例及费用见[实际轨迹](../artifacts/informative_structure_research_20261001/worst_numeric_case.json)，最新整体比较见[0.154结果](../artifacts/informative_structure_research_20261001/README.md)。修正单位应是“选动作→研究或采购→修订→独立确认→下游收益”的完整闭环，不再逐入口加一种候选。

## 四类目标还差多少

主要操作和研究框架已经存在，尚不是收尾阶段：联合发现仍缺可靠组合，动作选择仍缺核心算法整合，知识积累仍缺稳定净收益与删除消融，外部对照仍缺当前完整任务结果。详见[四类目标现状](hegel_machine_goal_completion_20261001.md)。这些是四类能力，不是四个小补丁，也没有可据此计算百分比的同质工作量。

下一轮先恢复被新研究路径挤掉的有效含噪修订能力，并固定有正面证据的比较基底；解决失配参数规划权、动作价值和完整确认预算三个相连问题。随后在已实现表示／关系／窗口的有限未见组合中检验自主选择，并保持相同预算池与回访条件做知识删除和错误迁移撤回。外部模型完整对照依用户安排继续暂缓。

## Limitations

历史0.131的72题含噪窗口与历史0.154的84题条件仪器任务在结构、预算和评价口径上不同，不能直接比较分数，也不能跨新种子批次连乘误差变化。本次固定回测使用已见旧任务，回答能力是否保留，不作为新任务泛化证明；原runner无独立历史字节副本，使用原报告所引同名runner，旧版结果与学习费用已精确复现。框架自身的completed不是独立终测solved。没有逐版重跑，不能声称重拟合归零恰始于0.135；代码与真实失败轨迹支持以上诊断，尚无消融能把整体退步全部归因到某一个入口。

实验Agent使用离线搜索；本轮外部模型调用为0。编码模型变化可能影响开发取舍，但没有相同起点、任务和预算的编码模型对照，无法证明退化由6.1-sol本身造成。当前任务逐题重置臂仍是完整黑格尔机，不是普通Code。
