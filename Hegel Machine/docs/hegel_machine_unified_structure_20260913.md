# 对象、关系、事件与尺度进入统一研究

2026-09-13，0.61.0。对象归约、邻接作用、事件差分和时间窗口已与参数、状态、风险、仪器研究共用 `UnifiedResearchAgent`。粗/细尺度由观测比较决定，细测量可免费汇总；后续按选定尺度实际采样。守恒、平移、置换及局部性假设接受付费干预，反例进入后续拟合。

知识还会传递研究方法：旧参数失效后，系统沿用已学关系族，用当前观测重新估计参数和作用范围，再执行边界实验与新轨迹比较；关系族失效则恢复广泛搜索。方法来源成为新概念的父节点。普通 Python Agent 已接入相同对象视图、查询和评分接口。

三种子、四组、每组12题的最终比较如下；每个模型在整段学习结束后接受256行新观测，风险损失单独计算。

默认系统相对无记忆少用 **11.82%观测、6.59%测量费用、20.29%搜索计算**，且多解出一题；15个后继任务的对应节省为30.90%、17.61%、46.30%。六个后继任务实际复用了结构研究方法，三道重命名总量题复用了短调用。锚定机制的守恒、平移和置换假设，以及非局部机制的局部性假设，均在实际干预中被反驳。

本批同时修复了两种实验设计错误：端点历史试验产生全零事件输出；少量随机试验遗漏已学关系的作用边界。现在采用判断使用多样轨迹，结构迁移还会重新探测当前边界。[初版](../artifacts/unified_structure_20260913/comparison/summary.json)、[第二版](../artifacts/unified_structure_20260913/comparison_revision2/summary.json)及[最终结果](../artifacts/unified_structure_20260913/comparison_revision3/summary.json)均保留。三版合计实际执行252次任务研究、45,848行学习观测和64,512行终评观测；未受影响的对照直接复用。

对象测量、结构干预、表达式执行、噪声反例、方法来源、会话恢复及普通Python接口的相关回归通过。新增配置可直接运行：

## Limitations 与下一步

这些是同一组三种子上的修复回归，尚不能证明开放分布上的稳定净收益；主动实验比被动实验购买了更多观测和测量。一项局部性命题仍为 proposed，预测通过不等于所有结构命题已确认。对象角色、结构算子与研究步骤仍由开发者提供，任意新概念语法、跨结构组合及一般研究程序生成尚未完成。普通代码接口测试使用模拟决策与真实Python执行，本轮未新增真实LLM对照；SC-KG仍需能够消费历史与结构程序的接口。

下一步把学得关系与研究方法用于更一般的结构组合和后继任务规划，并补新分布上的真实普通Agent比较。[原目标完成度](hegel_machine_advice_goal_status_20260909.md)已同步。
