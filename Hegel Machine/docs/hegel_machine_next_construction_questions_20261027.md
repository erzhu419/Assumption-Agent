### 18.1 科学主线首要缺口：保存了竞争预言，没有直接判别这些预言

`conditional_experiments.propose_conditional_structure_experiment`保存两个候选在特定`readout_step`的`delta_predictions`；`native_condition_research.plan_native_structure_experiments`将其放入`forecast_witnesses`。当前源码中，对该字段的后续消费只有有限作者检查“存在”。实测回调进入通用native拟合，然后把目标和重新拟合的宽度／位置候选返回，尚未将原预言与对应实测差值直接比较。

准确地说，**新数据会影响模型评分，但“为何购买这个实验”的特定命题没有得到自己的回答**。`structural_inquiry.execute_native_condition_research`还固定把这个子题返回为`inconclusive`。不宣布唯一机制是正确的，但不能因此省掉“哪项冻结预言符合本次观测、哪项被反驳、是否双方都不符合”的有限结论。

最小调整是在现有回调中，使用实际映射后的参考／干预记录及原读出位置计算实测差值，与已存两项预测对质；判别先于新拟合，结果接回现有子题答案和父修订。无需重新运行已付预测器。历史`inquiry_revision.complete_revision`已有冻结预测对新观测计算prospective误差，`_check_local_relations`已有“实测线性差值与预期值”的数值检查，可复用其读出与计费机制。新接口需要适配的是配对差值及候选引用，不是新日志体系。

结论须限定对象：反驳一份固定参数预测器，不等于反驳整个宽度／位置结构族。若双方失配，保留这一结果，并由既有联合拟合检验同结构参数是否足以解释；拟合完成后仍失配，才继续提出结构或表示修订。不要把任何结果都固定转成“再拟合一次”，也不要把较小误差自动写成某个结构已获证明。
