# 竞争解释与实测修订

2026-09-13，0.68.0。非等价的对象解释分别拟合并保留为可执行程序。公开控制域与已学仪器模型用于预报区分实验，主循环购买实际观测；新数据先检验旧程序，再修订机制或校准。程序需要同时解释全部已付资料与本批新反例，旧反例随对象模型和元先验保存。重拟合预算不足时保留最新反例，后续随机轨迹的一致不能重新采用已被实测反驳的同一程序。唯一预测胜者仍不等于唯一对象归属。

未决关系半径也形成竞争程序；实际边界观测更新允许区间。恢复阶段找到的新结构进入同一主动研究步骤，随后取得新轨迹确认。后继可以调用已经确认的机制。

## 实际结果

实验顺序为焦点响应、增加位置作用的读出、同读出后继、事件后继。物理转移保持不变，两组使用相同匿名装置；每题仍为512观测、6144测量、480000搜索计算预算。学习结束后每题用四条独立64步轨迹终测，通过阈值1e-6。

开发旧0.67通过2/4。新版第二次开发运行仍只有2/4：新机制通过短确认，但未识别的关系边界导致独立终测失败，错误程序还被后继复用。失败日志与运行保留于[开发第二版](../artifacts/object_competition_20260913/development_v2/summary.json)。随后修订搜索投入、恢复阶段主动研究、已支持程序的边界更新与半径竞争。

修后开发4/4，最大MSE3.37e-19，终测全部免测量。完整序列学习观测1139→979、测量4530→3810、计算856552→740331。首次新读出研究实际购买两次竞争实验，均区分候选；后继直接复用只需46观测、132测量、791计算。见[开发第三版](../artifacts/object_competition_20260913/development_v3/summary.json)。

## Limitations 与下一步

当前仍在有限对象角色与结构程序族中研究；本批对照是0.67，没有新增真实普通代码Agent运行。一般对象发现、22项元先验通用化和开放任务上的长期净收益仍未完成。

下一步从竞争程序及已学边界直接构造定向实验，再把有效步骤积累为可重绑定的研究程序，用后继实际收益选择追加投入。整体目标状态见[原目标复核](hegel_machine_advice_goal_status_20260909.md)。
