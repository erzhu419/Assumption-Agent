# 对照GPT_diagnosis_v6的项目现状、剩余差距与阻塞

证据截至：2026-10-25最新259／455冻结终测。基线：GPT6评审的`ca3ef0357bf4a4345b173a6d9b27a570f7efbc9d`；本报告随本次项目提交发布。依据为[v6诊断](../markdown/hegel_ca3ef035_review/GPT_diagnosis_v6.md)、[三项交付](../markdown/hegel_ca3ef035_review/Codex_Next_Iteration_ZH.md)、[系统诊断](../markdown/hegel_ca3ef035_review/Hegel_ca3ef035_Systematic_Diagnosis_ZH.md)，以及后续实际回执。附件中的建议与已发生结果分开记述。

## 1. 当前距离目标还有多远

**数值检查及目标诊断已经完成实际交付，问题组织、跨Episode结构归纳和修订消费也已经产生可执行行为；“学得知识改善未见后继研究”的科学闭环尚未建立。最新预测终测是负结果。**

现在的首要阻塞已经不是“新对象没被访问”“没有拟合预算”“候选未进入强池比较”。这些在最近一轮都已实际完成。当前缺的是：学得对象在什么条件下值得采用、失败时怎样形成有辨别力的研究问题，以及在未曝光后继上能否改善预测、错误迁移、任务完成或总成本。

不能给出一个有依据的“完成80%”：检查器可靠、执行链可用、局部改稿有用、独立研究有效，是不同验收层级。按v6三项交付衡量：

| 交付 | 已完成 | 尚未达成 |
| --- | --- | --- |
| D1：数值验收 | 生产1e-10回归、稳定最小二乘诊断、固定723结构的同数据同split复核 | 本批没有因此得到合格关系；数值修复不能代替留出成功 |
| D2：学什么、参数是什么 | 历史角色与冲突审计、拟合状态引用、精确编辑／参数提案／结构修订分流 | 完整输入充分性、跨来源科学角色与一般适用条件仍有UNKNOWN |
| D3：来源→对象→应用→后继 | 真实来源结构抽取、冻结对象、实际拟合导出比较、父稿采纳、局部对照、原分布冻结终测 | 当前终测失败；当前对象的未曝光来源外收益、自主区分实验、完整学习策略优势未建立 |

这不是“只差补最后一个接口”。剩下的是效用与研究能力的实证主张，其中一项已经得到明确负结果，其余需要各自对应的问题、材料和对照。

## 2. 假设扩展成问题，具体做到了什么

现在的核心对象不再只是“一条函数加分数”。问题保存主体、上下文、用途、答案类型、可执行查询和分辨标准；理论保存程序／参数、角色／单位／历史窗口、支持、作用域及反例。问题语义变化会保留旧答案与意义版本。没有可执行查询的自然语言问题会提出作者工作请求，不会被自动当成已解决。

| 能力 | 当前实际入口 | 已有行为与边界 |
| --- | --- | --- |

## 3. D1：哪些失败已被数值问题解释

原问题是固定正则解承担了严格参数可达性判断，导致精确可表达关系也可能被拒绝。现复用原槽拟合，保留初始／正则结果，增加稳定最小二乘和秩／条件诊断，原1e-10不放宽。

同原723结构、数据与split复核结果：

| 类别 | 数量 | 解释 |
| --- | ---: | --- |
| 稳定求解纠正原训练误拒 | 16 | 这部分确有数值路径问题；16例随后仍全部留出失败 |
| 满秩返回解仍训练失配 | 431 | 不能再只归因于固定正则偏差；结论限于受检固定特征跨度 |
| 秩亏、参数识别未建立 | 276 | 保留UNKNOWN，不能把拟合计算完成写成唯一参数已识别 |
| 原全部必要检查通过 | 0 | 本批仍没有合格的精确参数映射 |

因此，D1交付是完成了，而不是“数值修复没有用”；它纠正了16个训练误拒，也明确数值问题无法解释全部失败。有限非线性试探失败仍不证明整个结构无解。

证据：[D1实际切片与汇总](evidence/numerical_fit_d1_20261021.json)、[原报告D1](hegel_machine_executable_evidence_repair_20261013.md#2026-10-21-d1数值验收与固定历史结构复核)。

## 4. D2：哪些目标问题已分流，哪些仍无法决定

### 参数角色与坐标

按实际基函数、变量、时间／guard及公开单位审计原723项：684项输出角色未对齐，12项输入未对齐，27项完整计算视图可比。输出可比共39项，并不等于39项全部输入也可比。27项返回解仍训练未过，其中9项满秩、18项秩未决。

这意味着不能直接把不同程序的同名hole当作同一种科学系数，也不能把裸坐标上的16个留出失败全都解释为角色已对齐后的泛化失败。原16项位于输出角色未对齐类。参数角色诊断已接入处理，未知部分没有被默认为合法。

### 输入是否足够

已发现42个训练视图冲突，覆盖126个旧提案；它们否定相应原始坐标视图的单值目标。冲突并不自动否定角色对齐后的完整问题。完整13输入没有已知相同输入对，既没有给出冲突证据，也没有证明输入足以决定after参数。

现已定位11次修订、13端点的拟合数据及冻结算法引用；等权、中心缩放、正则与非迭代求解方式可追溯。但原数值设计矩阵、中心／尺度和实际求解输入输出并未全部数值重建。因此，“原拟合状态的来源已定位”与“所有状态已完整数值复原”必须分开。

### 学习用途已改变

- `exact_edit_map`：主张精确复制after参数，继续按自己的原合同验收。
- `parameter_proposal`：作为下一次世界拟合的起点／区域，实际要求整稿重拟合；拟合后成功不继承为精确映射成功。
- `structural_revision`：提出结构、保留组件和待重新识别参数，交已有世界拟合与预测评价。

上述分流已经进入实际入口，无需再建一个同义接口。单位别名与系数单位按公开声明处理，原声明不足仍UNKNOWN，没有默认填无量纲。

早期11条同形系数漂移已保留为诊断材料。后来补入两次真实native来源的65→267、65→195结构修订，所以不能再照搬v6旧截点，把当前来源全部说成常量重拟合。来源仍只有两条主要物理历史，覆盖不足的问题没有因此消失。

证据：[D2角色、冲突及来源切片](evidence/parameter_target_d2_20261021.json)、[来源整步](evidence/parent_research_continuation_20261023.json)的`complete_source_steps_20261024`及`parent_reference_learning_20261024`。

## 6. 当前真正卡住的六项能力主张

### 6.1 修订的适用条件尚未学成

当前对象学习到“可以怎样改程序”，两次来源提供了尝试父预测门控的依据；尚未学成“当前反例与使用范围下，何时值得这样改”的一般规则。类型／单位／父匹配的合法性也不等于这种修订有预测效用。本次终测给出实际失败证据，但没有单独证明失效是容量、参数拟合还是条件不当造成。

能改变此处判断的工作是：从已有真实失败和反例形成带作用域的待检验关系，说明它会改变哪项候选或研究动作；有明确差异后，再冻结新的后继材料与公平对照。继续扩大同97行搜索不能提供这个证据。

### 6.2 当前区分实验问题尚未操作化

规划器不是缺失算法。历史[0.69程序分歧](hegel_machine_program_disagreement_20260913.md)已有12题／36次区分采购，[0.135条件实验](hegel_machine_conditional_experiments_20260930.md)也有252题记录。当前`FindDistinguishingExperiment`同样存在。

实际缺口是当前用途仍挂在已回答的单点Readout上，没有把剩余反例、具体竞争解释、父答案目标和合法动作组成一个待解问题。入口需要`target_query`、版本化`claim_refs`及合法公开实验面板；缺少作者实验程序是原合同状态，并非恢复丢失。补一个文件路径不会自动给出这些科学内容。

下一项可验收行为应是：明确哪两种当前解释在哪个合法动作上预测不同，选择为何影响父用途，执行后怎样更新支持或研究方向。并列或缺证据继续保留。

### 6.3 自主选题和投入没有本轮对照

议程、问题选择及完整单位分配已有代码。当前`build_agenda`仍按已声明、可支付的工作及固定次序组织研究；本轮195用途和公平四轮由协议指定。这验证了研究执行连续性，没有验证系统自主发现最值得研究的问题或学会合理投入。Astra指出预算、表示和阶段问题，不能倒算为Agent自主发现。

### 6.4 新父模型上的再次递归修订尚无本轮证据

父问题续接与旧研究恢复已经成功。但当前195的两个子稿竞争，不证明“新模型出现新失败→系统自主开子题→再修该新模型”的整条轨迹。不能以节点增长或455战胜259多算一层递归。

### 6.5 当前对象的未曝光来源外迁移没有正结果

早期D3独立试点及15项任务确实执行过，结果和失败保留，不能说项目从未跑过后继。后续旧8／完整18、旧18／19及旧19／20是在曝光后的开发现场修复与追加可用性对照；早期试点不能替代最新对象与最终公共修复版本的独立后继。

259／455终测只是原分布的评估者终测，不是跨来源迁移，也不是绕过96行确认。要回答当前对象迁移，需对象、策略和后继范围在任务参与形成或开发之前冻结，记录错误迁移、预测及全部来源成本。本轮负结果不支持立即扩大独立批次。

### 6.6 整套问题架构相对普通研究的净收益尚未建立

旧19和完整20都启用问题架构、完整强池和早期PR3历史，差别只是继续开放新20。它不能识别整个问题架构、固定PR2和持续归纳策略各自的作用。

v6的A强档案／B同档案＋固定PR2／C=B＋归纳学习仍是对应设计。数值、单位、调度、存储和效率修复共同提供；对象个体留删、冗余类留删、完整学习策略分别解释。旧语言能重构某对象不是排除条件；同预算下的打平应保留。
