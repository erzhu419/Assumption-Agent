## Limitations 与下一步

- 新九例目标研究计算96408→156351，优化耗时21.07→24.70秒；约束平均 MSE 上升42.6%。交互变化组目标 MSE 上升24.2%，没有完成变化后交互头安装；仍有两个研究停在采集、一个比较未决。
- 一个旧机制变化任务过早采用局部仿射解释，随后已发现失配，却未完成第二轮修订；现有已安装目标头又阻止重建原始GP参与替换，目标 MSE 0.00206→0.06034。下一步让失配的已安装解释重新参与模型竞争，并改进沿用局部小CV的续研门槛。
- 旧边界失败仍在：目标修订已提前完成，但一次偏负读数与偏小噪声估计使推荐点实际满足率94.23%，未达95%。下一步优先让目标改善与边界均值、噪声复测共同竞争预算，并提高复杂关系实验的覆盖效率。
- 本轮推进原建议中的“主动检验、选择修订、实际行动”。跨任务知识积累的独立优势、开放世界能力和稳定长期净收益仍未达成；普通 Code Agent 沿用此前对照。
