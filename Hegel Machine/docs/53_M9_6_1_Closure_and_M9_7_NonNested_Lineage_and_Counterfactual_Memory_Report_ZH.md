2. **有限见证经验覆盖不等于符号等价证明**：`EmpiricalCoverageReceipt`（`supported_on_witnesses`）仅代表新分支在隔离容器探针下通过了历史正见证集（显式计入容器 CPU 墙钟耗时），**不构成全定义域数学等价证明**；因此旧分支 `b00, b01` 始终以不可变方式完整保留。
