## 哪些成果保留，哪些评估重做

- **保留**：0.180 回报写入、0.181 待执行报价刷新与局部行动分叉、共享成本去重、响应签名求解收口，以及 24k 实际复用。固定库胜出、八个随机机制未见反馈收益等负结果同样保留。

- **重做整链评估**：正常 `session.run` 从空库学习→后继调用→机制变化→取得反例→限制或撤回→原适用条件再利用。统一记入源学习、筛选、失败研究及确认成本；旧 330/1290 等受控续访账不代表从零学习总账。算法控制臂可继续使用；passive 同时移除了主动实验和自适应回访，不能解释为纯单模块效应。
- **更新当前集成验证**：旧 86／43 项通过属于各自代码状态；当前 41 项通过也不能替代上述实际失败的功能。修复后复验受影响模块与两个 session 失败即可，先不重跑全项目所有历史实验。
