方法的最低启动资源与推荐采样量分开报价；实验根据已付读数估计取得区分证据的概率，并比较不同批数的完整费用。重拟合后新出现的稀有边界可使用已访问任务的剩余资源，同时保留其他待研究任务的启动额度。程序在分批观测期间冻结，取得反例或边界缩窄就停止采样、转入修订，并预留修订后的新确认。未命中记录进入下一次实验选择和采样校准。

## Limitations 与下一步

0.160保留为研究候选，本轮没有净收益，两个优先核心尚未完成整体验收。信息概率仍是已付读数上的估计，CPU变化不作算法因果归因。下一核心是区分响应重拟合收益与追加边界研究的边际收益，让实际后继损失和成本改变投入，再用来源删除及撤回对照检验知识贡献。外部Code／同一LLM对照按用户安排暂缓，本轮实验全离线。
