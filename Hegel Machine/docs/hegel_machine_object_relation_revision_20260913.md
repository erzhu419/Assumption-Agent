# 组合内部关系修订与连续区间研究

2026-09-13，当前0.80.2。旧组合失配时保留已有调用，在完整事件、窗口上下文中修订内部关系；关系解释不了已付反例时，重测原轨迹的仪器读数并修订标定。离散候选只剩一个后，仍按证据支持的连续区间提出新候选与实验；紧凑边界求解接受完整程序预测比较，不能激励响应的复用步骤可转入新求解。

两批均为六套独立装置，三/四对象各三套，每套依次经历总量、事件、组合、窗口、关系变化、返回原关系。统计单位是整套装置的六阶段序列。每题上限512行观测、6144测量费用；每套学习结束后以四条64行新轨迹终测，MSE≤1e−6，失败全部保留。

## Limitations 与下一步

剩余三失败为同一装置的事件、组合和窗口任务，两版完全相同。[诊断](../artifacts/relation_interval_confirmation_20260913/remaining_event_failure.json)显示：事件的半径区间已保存，但调用只执行一个点值；同一条近边界轨迹的事件误差传播到两个后继。下一步让现有区间进入完整调用的竞争预测及追加研究选择，并继续扩展任务相关关系先验。

当前仍是给定对象角色、既有邻域关系族中的修订，尚未自主提出新的关系类型。精度改善伴随额外投入，不能据此宣称稳定净效率优势。真实Code与结构化搜索使用不同计算单位与先验；此处是完整系统比较，0.80.2新六装置没有新增Code运行，也不是同一LLM的模块消融。
