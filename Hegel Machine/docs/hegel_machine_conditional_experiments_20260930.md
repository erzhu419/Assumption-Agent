## Limitations

范围为公开标量、单门槛、算术分支及有限窗口，正式噪声0。累计仍3题未达标（变界七步1、返回旧环境2），独立2题未达标（变界及改名七步各1）；另有1个达标题仍标未决。低预算仍可能随机确认漏掉门槛，[真实负例](../artifacts/conditional_experiment_20260930/limited_budget_negative.json)保留。稳定长期净收益、多条件/未测门控及完整Code/LLM对照尚未完成。
