## Limitations 与下一步

独立样本是12套装置，72个阶段相互依赖。本批接通了能力，但更窄区间未换来新装置的精度或总体费用收益；用时来自不同运行时段，不能据此认定新版更快。本批未新增普通Code比较。

下一重点是**残差驱动关系类型修订**：让对称邻域与单向作用等解释竞争，生成镜像位置干预，在完整组合与旧环境返回中验证、保存和复用。它是落实原MD“提出与修订假设”的下一项任务设计；追加精度研究也应结合后继实际价值选择。
