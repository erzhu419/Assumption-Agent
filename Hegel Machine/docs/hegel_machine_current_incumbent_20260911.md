# 模型重建后的候选比较

2026-09-11，实验已完成。两种方案均未采用，默认代码恢复为 0.48.0。

目标候选的历史优势针对当时的旧模型。第一版在目标 GP 重建后保留候选、重开四条未来验证，确实纠正了旧优势造成的错误采用，但把所有比较推迟到重建后会错过有用候选。

严格重置的 463 例已完成：终值全部持平、可行数均为 459；目标平均 MSE 从 0.00193246 升至 0.00462647（恶化 139.4%），新增 27 例从 0.00129235 升至 0.03623276。约束误差改善 8.62%，目标研究计算减少 4.00%，仍不支持采用。最大新失败在最后一步重建，撤回了候选，却没有剩余观测，目标 MSE 从 0.000741 升至 0.940883。本次实际运行 171 次优化，新增 7776 次物理调用；源码与负结果保留在[研究目录](../artifacts/sc_kg_objective_incumbent_v049_20260911/)。

第二版实现了提前比较：约束候选尚在验证时，按其拟议范围和当前已付费前缀拟合待替换的目标 GP，对同一控制先预测再取得真实标签。实际重建沿用同一拟合规则，范围吻合时使用此前的实测比较；四条比较及原误差改善条件保持不变。这一实现随[冻结源码](../artifacts/sc_kg_objective_incumbent_v049_20260911/anticipatory_comparison/method_source_anticipatory/)保留。

提前比较的 15 例开发实验已完成，终值全部持平；同一组案例的目标平均 MSE 为：

提前比较改善了两个历史全局预测失败和一例晚修订，但仍远差于默认，因此停止其完整批次及新增种子实验。新增费用为 480 次物理调用、36 次额外 GP 拟合、399 条拟合记录和 36 次预测；本轮两种方案共 8256 次物理调用。[完整结果](../artifacts/sc_kg_objective_incumbent_v049_20260911/result_brief.json)与[15 例比较](../artifacts/sc_kg_objective_incumbent_v049_20260911/anticipatory_comparison/replay_result_brief.json)均保留。65 项针对性测试通过，测试未调用模拟器；新增比较测试使用冻结实验源码，默认生产路径保持 0.48。

## Limitations

原短板尚未解决。四次正确作用域的比较也可能只覆盖局部，拒绝全局更好的解释；最后一步失败还遗漏了一个在旧比较出现过、但对新比较仍有价值的控制。当前证据表明，仅补齐这条预测也未必足以通过原采用条件。约束范围修订仍会自动重建目标 GP，其自身未先作为待采用假设与旧模型竞争。

下一步把目标 GP 替换作为独立研究决策：保留旧模型及已支持的目标候选，让拟议替换参与事前比较；按具体比较对象管理实验覆盖，并把能区分全局表示的控制纳入选点。开放世界与稳定长期净收益目标仍未达成。
