# 自然近似平局与收益分辨率收据（0.181.0续研）

本轮把上一轮人工归一即时收益的 tie-controlled 对照换成自然报价。目标转移律固定在两个已有来源报价的交叉点：`current_weight=0.5697373812934383`、`lag_weight=1.19`、无噪声。两个报价的原始 `expected_loss_reduction` 分别为 `0.580582640255361` 与 `0.580582640255364`，差距约 `3e-15`，脚本没有修改任何报价字段。好来源 `concept_0002` 的正回报先由真实 successor continuation 获取并确认为 `confirmed`；坏来源的负回报在四个臂开始前统一删除，以隔离好来源保留／撤回的因果问题。

运行命令：

```bash
PYTHONPATH=src:tests python3 scripts/run_source_feedback_natural_near_tie.py
```

四个臂使用同一批冻结报价、同一任务顺序和同一执行上限：原始收益排序保留好回报、原始收益排序删除好回报、收益分辨率排序保留好回报、收益分辨率排序删除好回报。每臂均为 `132` 行观测、`532` 计算，外部模型调用为 `0`。原始排序的两个近似平局任务都选择 `concept_0002`，删除好回报也没有改选；这就是微小浮点差掩盖来源贡献的直接负结果。

收益分辨率策略把 `1e-8` 作为相对收益分辨率，并将容差、落入容差的组合和选择依据写入 scheduler decision。保留 confirmed 回报时两个近似平局任务选择 `concept_0002`，删除回报后选择 `concept_0001`，行动分叉数为 `2`；未见损失从 `0.00019653073033326627` 变为 `0.00021204815922280093`，每题差约 `1.5517e-5`。移位机制和含噪机制两臂选择相同，说明响应条件没有把好来源信用迁移到不匹配或未决机制。

这一步完成了自然收益近似平局下的来源贡献归因，并把“何时允许知识回报影响投入”从隐含的浮点相等改成了可审计的研究政策。它没有证明长期净收益，也没有把微小质量差异夸大成普遍优势；真实优势仍然很小。随后续研已在[联合 lineage 收据](hegel_machine_source_feedback_joint_lineage_20261004.md)中验证多来源共享成本不再双计，但两个来源仍是冗余，后续需要互补来源组合和更长序列验证累计回报。

与 `0.181.0` 的关系仍是同一未发布主线的增量续研，没有改版本号。结果文件见[自然近似平局收据](../artifacts/source_feedback_natural_near_tie_20261004/)。
