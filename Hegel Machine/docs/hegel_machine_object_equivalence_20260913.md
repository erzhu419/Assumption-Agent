# 有歧义的对象解释也能执行

2026-09-13，0.67.0。部分对象图可以枚举证据许可的完整划分，提出的机制在全部划分下重新绑定角色；按当前程序代数可化成同一表达式时，共享一次拟合并用于预测。代表划分用于生成具体干预；知识库保留全部备选，原对象模型仍为未完全识别。后继可以复用函数与未决关系。

两对象交换中，位置互换不改变相互距离；系统可以保留这两种解释并学习焦点、事件及窗口响应。守恒造成的焦点共线拟合通过实际选择性驱动干预区分。位置新增直接作用后，旧角色定义会被实测反驳，局部直接作用假说提供可撤销的归属锚定；直接作用消失时重新保留位置歧义。

## 实际结果

同预算开发基线0.66在八题中仅2/8通过，独立焦点起步MSE为0.0235。完整顺序为总量、稳定总量、焦点、事件、组合、窗口，以及直接位置作用后的焦点和窗口。每题512观测、6144测量、480000搜索计算预算；完整序列学习结束后，每题以4条独立64步轨迹终测。

首版开发仅4/8：重复拟合同一个等价机制耗尽当轮计算预算，焦点机制失败后，后继还丢掉了已由干预确定的归属。该[失败序列](../artifacts/object_equivalence_20260913/development_v1/summary.json)保留；修订共享等价拟合，并在实测仍支持对象关系时保留部分图。修后开发8/8，观测2219→1761、测量9378→6678、计算1728252→654458，终测全部免测量。独立焦点起步也通过，仍保留两个位置候选。

三组新装置的独立焦点起步已全部终测：旧版0/3，新版3/3，三题均实际采用共享机制且仍保留位置歧义。学习观测807→951、测量3546→3978、计算739539→361484；新版终测免测量，最大MSE为4.51e-19，见[独立起步比较](../artifacts/object_equivalence_20260913/focus_comparison_v1/summary.json)。

## Limitations 与下一步

等价仅覆盖当前有限角色候选与程序代数，最多枚举16种划分，截断时不宣称覆盖全部解释。局部直接作用仍是一项可撤销的先验；任意远程作用、潜在对象和新角色语法仍未实现。本批对照为旧0.66，没有新增真实普通代码Agent运行。

下一步让尚不等价的多个可执行解释直接提出区分实验，并用实际后继任务收益选择何时购买测量。原构想完成状态见[目标复核](hegel_machine_advice_goal_status_20260909.md)。
