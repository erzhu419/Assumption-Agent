# 从程序分歧生成定向实验

2026-09-13，0.69.0。程序中的条件与相互作用阈值直接提出分歧区间，利用已学标定在公开控制范围内求解输入，再用完整程序预测选择实验。维持与脉冲轨迹支持已有滞后、窗口、事件及展开后的调用。每轮实测先检验冻结预测，再修订校准或机制，并用新候选重新规划。

研究轮次合并进原有边界研究预算。已有程序继续解释全部资料及新实测时，暂缓对已尝试而无程序的划分重复搜索；所有可用解释失配时重开。未决划分和反例继续保存。计算收益来自这三项更新的组合。

## 实际结果

开发序列两版均4/4，新版12次程序定向实测全部区分候选，整体计算减少40.14%，测量增加1.89%。专项例子中，半径`.73100001/.73100002`的分歧被旧通用池完全遗漏，新方法用928计算得到有效实验候选。

三组新装置各执行焦点、新增位置作用读出、直接重复、事件后继四题；每题仍为512观测、6144测量、480000计算预算。学习结束后每题用四条独立64步轨迹终测，阈值1e-6。
