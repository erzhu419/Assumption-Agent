## Limitations 与下一步

这是一个新实例上的完整系统比较，不能证明稳定总体优势，也不是同一LLM开关黑格尔模块的消融。黑格尔机查询更多，Code数值误差更小，两者均满足预定精度。下一步改进仪器和机制变化时的投入选择，让直接修订控制量表示与重新标定参与比较；新增对象关系与风险任务的真实Code对照仍待补齐。
