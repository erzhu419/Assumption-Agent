# 研究包预算与时序识别

研究程序的多次拟合现在共用一个实际执行额度；还有可支付的测量替代方案时，为后续研究保留计算。观测修订按包含拟合、区分观测和确认的完整包报价，实际执行不能超过报价；报价准备的已付费用另计。机制修订不能先耗掉唯一可支付的测量—修订路径。

已有连续状态识别器进入原生研究选择，按一、二阶识别、可执行拟合及候选评分的完整费用竞争。它从付费历史生成只依赖输入的状态程序；成功候选仍须通过新轨迹确认。没有新增模型算子或外部模型调用。

## 同预算结果

[固定12种子对照](../artifacts/workflow_budget_20261006_main_12/summary.json)由旧实现实际生成共同前缀，再分别交给旧实现和修复实现继续。两臂保留相同知识与方法回报，观测、测量、计算上限不变；研究全部完成后终评，完整研究费用包含共同前缀与失败，终评费用另列。

共同前缀36/36通过。完整观测少2.91%、计算少18.17%，测量相同；每例计算差−37,793，配对95%区间[−40,445, −35,167]。新任务终评平均MSE从0.2344降至6.27e-18。首次重测时，修复版保留104行、67,504–76,698计算，旧版只有80行、20,069–35,653计算。修复版全部实际执行状态识别并确认成功，无需再购买联合条件实验。12例均保留，无执行异常。

101项相关测试通过。开发v1仅提前测量，任务仍失败；v2让小额时序识别获得完整执行机会后才通过。两份开发记录与正式批次均保留，未用正式批次调整算法。

## Limitations / 下一步

该对照评估整组预算与执行顺序修复，不能单独归因于方法回报。时序模型属于已有表达能力；新状态空间与开放领域研究程序的自主发现尚未验证。

12例传入需求都在回访筛选前被挡住：每例池中只余32行，调度器预先要求48行；尚余149,493–167,447计算，但实际候选筛选与回访均为0。这不构成新知识无迁移价值的证据。下一步先在已有付费数据上筛选来源，再按具体候选需要的修订和独立新确认报价，检验能否用剩余额度完成回访。
