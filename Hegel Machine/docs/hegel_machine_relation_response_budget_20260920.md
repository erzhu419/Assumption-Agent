# 跨仪器关系与响应研究（0.109.0）

本批推进最新 [GPT6 advice](../markdown/GPT6_advice.md) 的表示组合与研究投入选择：源关系先绑定当前对象角色，再消费当前校准；对象实验可按剩余行数分段，已付对象观测继续用于响应拟合。关系子树可与数量、事件和历史联合拟合，完整结构仍保留简单聚合候选，关系候选不再挤掉旧研究程序的重放名额。

研究动作不再把末尾两行仪器校准当作响应验证集；可支付时购买新比较轨迹，否则用全部已付证据选择候选，再接受新确认。搜索预算同时支付采用前的共同证据比较，防止生成有效模型后因无钱比较而丢弃成果。

已知开发题三档预算的终测 MSE：96 行 **0.450722→0.190521**；192 行 **0.432029→0.136663**；384 行均约 **3e-19**。中间版本的回归及最终结果均保存在[开发实验](../artifacts/relation_binding_budget_20260920/candidate5/summary.json)。

新装置复制使用同一个实际学得的来源，预先固定8套新仪器、接线、字段名及曲率，各跑三档预算、两版，共48次完整后继学习。全部学习结束后，逐题在4条新轨迹、共256行上终测。[协议与结果](../artifacts/relation_binding_replication_20260920)。

## Limitations 与下一步

这些是同一来源的独立后继任务，不是8条独立长期学习链。最终成功模型采用完整旧调用的响应重组，裸关系子树分支的独立收益尚未分离。低、中预算仍未达标；中预算第7装置 MSE 0.413730→1.288504，候选虽被新确认反驳，但已耗尽计算，无法继续修订。平均误差改善伴随更高测量与计算。

下一步推进成本更低的表示/响应联合发现，为校准后的响应竞争和失败修订留下资源，并覆盖无可靠来源的情况；多来源长期收益仍待解决。外部模型 benchmark 按用户安排暂停，后续由便宜模型完成；本批实验全部本地离线运行。
