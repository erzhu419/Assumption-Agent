## Limitations 与下一核心

当前限于给定算术与窗口算子；独立2题、累计5题未决，无限累积对照未解。累计比较同时包含知识、预算池和回访。一般条件分支、更广泛结构组合及真实LLM对照仍未完成。

下一核心是跨任务研究投入：累计67次程序研究产生526候选，最终无保留的回放标记，又执行79次坐标搜索；反向提供知识166次花费188万计算，仅3次排入回访。减少这些重复投入，让复用、重构和回传按后继收益共同选择；现有CPU按会话记录，函数级耗时仍需定位。
