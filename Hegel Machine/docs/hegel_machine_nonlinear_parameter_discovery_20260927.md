## Limitations

同为48/48，新有来源比新空库多33.97%计算、4.33%观测；即使不计来源，研究计算仍多15.98%。旧知识尚未带来整体成本优势。空库组也会跨任务积累知识，不是普通Agent对照。发现限于两轮坐标乘法组合，参数搜索限于两个局部和式、每式四系数及十二轮。一般条件分支和开放世界能力仍未完成。全离线，外部LLM/Code比较暂缓。

下一主线：让保留旧结构的参数修订与从观测重新构造表示共同竞争，依据实际收益选择研究路径。
