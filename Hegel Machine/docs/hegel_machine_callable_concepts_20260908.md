## 从学到一个规律，到用这个规律继续思考

知识库从已经学到的程序及其有用子表达式生成 `Definition`。定义保存参数化正文和来源概念；`Program` 中的 `call` 保存定义引用与实际参数。定义正文可以调用先前定义，所以新概念能够继续组成更高层概念。

`KnowledgeLibrary.callable_atoms` 把当前可用定义绑定到任务的变量角色。控制器把这些调用送入组合搜索；原始坐标与历史先完成可用拟合，仍有残差时，搜索可尝试调用的平方、乘积和线性组合。已经选入的调用还可作为依赖计划的当前解释与中间结果。原有模板仍承担参数拟合；可调用定义承担保留并使用已经学到的具体计算。条件变化、来源限制和撤销也参与调用的可用性判断。已有的区间守卫保留在调用专用索引中，普通模板筛选继续使用原模板池。

`EvaluationContext` 在同一观测上共享重复调用的结果。例如，计算 `g*g+g` 时可以只计算一次 `g`；多个候选使用相同参数调用同一定义时，也能复用这次结果。新实参产生对应计算，新观测使用新的求值上下文。

调用参数沿实际执行分支求值。历史模型在启动阶段选择当前观测分支时，不会提前读取尚不存在的历史参数。`expanded()` 提供与调用等价的普通程序结构，用于变量依赖、历史需求、边界分析与语义规模计算。

程序保存时将所需定义组织成闭包表，调用节点保留引用；恢复后仍执行这些定义。角色重命名改变实参，正文保持共享。研究状态通过相同程序序列化接口保存当前解释、竞争程序和未完成研究，恢复后可继续使用调用。

## 已跑通的发现与组合实例

任务 A 从观测中学出 `g(x,z)=x²+xz`。任务 B 的响应为 `g(x,z)²+g(x,z)`，输入仍是原始 `x,z`。A 的产物进入知识库后，B 的控制器实际产生并选择含有 `call(g)` 的平方与加和程序。

已完成的控制器实例中，B 在 100 条新数据上的平均平方误差为 0，使用 54 条观测和 12,046 单位计算。[控制器运行记录](../artifacts/callable_controller_final_20260908.json)保留实际程序与支出；研究状态的 JSON 保存与恢复也已通过对应测试。这个已学到的规律实际进入了下一任务的候选生成和执行。

进一步的嵌套、角色变化、保存恢复及共享计算，可从演示入口运行；省略 `--output` 时，小型报告写入标准输出：

```bash
PYTHONPATH=src python3 scripts/run_callable_concept_demo.py \
  --output artifacts/callable_concept_demo_final_20260908.json
```

[演示脚本](../scripts/run_callable_concept_demo.py)将概念学习、组合使用和共享求值放在同一条运行链中。[语言行为测试](../tests/test_cognition_callable_language.py)包含历史启动、嵌套定义、角色重绑定、JSON 恢复，以及共享调用和语义展开的数值比较。

这个局部演示已使用 seed 113 运行。每次学习使用 40 条观测，之后在 64 条新数据上测量；B 的两组使用相同的 3,600 候选乘行预算上限。C 在 JSON 恢复及 `u/v` 角色重绑定后，使用 B 的定义继续学习 `h²+h`。

| 任务或方法 | 新数据平均平方误差 | 实际候选乘行支出 | 调用深度 |
|---|---:|---:|---:|
| A：学习 `g` | 0 | 280 | 0 |
| B：使用可调用 `g` | 0 | 1,760 | 1 |
| B：原始坐标稀疏搜索 | 0.0323667 | 800 | 0 |
| C：使用可调用 `h` | 0 | 1,760 | 2 |

在相同 64 条数据上，B 的调用程序执行 704 个非调用节点，语义展开程序执行 1,472 个；C 分别为 960 和 4,544。将实际进入调用及缓存复用的次数也加入前者，B 为 896，C 为 1,344，预测完全相同。[演示结果](../artifacts/callable_concept_demo_final_20260908.json)同时保留学习支出、执行节点与调用统计。

本包完成了全部 **211 项认知测试**，包含原有研究与知识行为，以及新增的可调用语言、知识整合和跨任务组合；[测试日志](../artifacts/cognition_v010_final_tests_20260908.log)保存对应输出。复现命令为 `PYTHONPATH=src python3 -m pytest -o addopts='' -q tests/test_cognition_*.py`。

## 修正后的完整会话

沿用五个分区的 65 个公开任务与 seed 809，先运行 10 次访问后退出，再由第二个进程恢复。修正后的 0.10.0 完成 70 次访问，保留 65 份研究状态；最初 10 次记录原样恢复，5 次重访都使用旧证据且没有重复初始查询。2 次研究由新增知识激活。

学习证据上 58 个任务达到当前充分解释标准，7 个保留未解决。会话结束后的平方损失平均由首次访问的 0.00331006 降至 0.00213145；风险任务平均 pinball loss 为 0.226722。5 次重访中 3 个改善、0 个变坏，观测共 3,890 条，计算共 980,377 单位。损失保持在 0.9.0 的水平，计算比 0.9.0 的 978,612 增加约 0.18%。

[会话摘要](../artifacts/hegel_machine_v010_final_summary_20260908.json)与[后评测摘要](../artifacts/hegel_machine_v010_final_evaluation_20260908_summary.json)保留这些结果。该序列的最终程序没有采用调用；本包的高阶表达与共享执行收益由前述独立组合任务具体展示。整体质量尚未超过更早 0.8.0 的结果，原有状态与风险任务仍有改进空间。

开发运行曾因 548 个区间守卫副本进入普通模板池而明显退化：正确的历史规律没有获得筛选机会，平均平方损失增至 0.0403254。修正把区间守卫限制在调用索引，并让普通坐标和历史先完成拟合；同样序列恢复为上述结果。新增回归验证多个任务范围和重复使用不会改变普通模板顺序、拟合支出与候选，同时保留真实条件调用。

## 成本的含义

现有研究预算以候选乘观测行的单位计算搜索、拟合与比较；54 条观测和 12,046 单位计算采用这一口径。求值上下文另外记录实际执行的非调用节点 `primitive_steps`、真正进入定义正文的 `call_evaluations` 和复用结果的 `cache_hits`；参数读取也计入执行节点。共享计算收益来自正文实际少执行的次数。`Program.size` 仍按语义展开后的规模计算，调用名称不会降低复杂度惩罚；定义正文、调用位置及其依赖都实际保存在程序或知识库中。当前候选乘行预算与执行节点统计分别报告。

## 完整十项目标的进展与余项

| 功能 | 已进入执行的能力 | 继续建设的行为 |
|---|---|---|
| 1. 延续研究与递归子问题 | 证据、竞争程序和中间步骤可恢复；调用也随研究状态恢复 | 保留并恢复累计证据更支持的旧解释；按证据生成必要条件、测量依赖和跨问题组合 |
| 2. 认知动作选择 | 实验、重拟合、已有坐标修订和校准会使用后续收益经验 | 抽象、停止、新测量及多个任务机会的统一选择 |
| 3. 条件知识整合 | 有效域、条件模板、例外候选及可用调用相互衔接 | 更一般的条件理论、独立子机制替换和多任务成功证据组合 |
| 4. 可调用概念与语言生长 | 定义、嵌套调用、共享求值、持久保存和概念搜索原子已经实现 | 按当前证据选择相关概念、避免同源变体占满候选；持续合并、简化或拆分定义，扩展对象语义 |
| 5. 方法论自身修订 | 固定动作和研究计划积累条件化收益经验 | 从研究失败生成方法步骤，修订方法结构与适用条件 |
| 6. 测量、潜在状态与尺度 | 现有变量与历史可组合并形成可调用结构 | 新测量通道、连续隐状态、对象与事件构造、尺度变化 |
| 7. 六族结构先验 | 数值组合、历史关系、条件知识和不确定性已有执行路径 | 低秩、局部机制、守恒、对称等的发现—实验—应用 |
| 8. 区分实验成为知识 | 已做实验、竞争解释和研究状态持续保留 | 跨任务调用区分实验，让观测等价改变后续检索与实验 |
| 9. 持续到达与外部环境 | Python 接收新任务、新证据；新增知识可定向激活旧问题 | 具体外部环境的在线行动反馈、测量生命周期与 CLI 接入 |

下一步先改进概念相关性选择与累计证据支持的旧解释恢复，同时让可调用概念进入更丰富的观察与结构发现环境：先给出实际可选择的测量和连续状态过程，再让学到的结构改变预测、实验和后续计算。区分实验与方法步骤也需要逐步成为能够复用和修订的知识。

## Limitations

- 开发会话 s08 曾出现累计参考证据更支持联合状态解释，但因新批观测打平且程序更大而未恢复的情况；本次修正会话没有重访损失恶化，累计证据支持的恢复规则和竞争解释保留仍需要专项改进。
- 当前概念原子仍按有限的来源与复杂度顺序选择；大型知识库中同源条件变体可能挤占其他相关概念。按实际证据学习相关性和多样性的选择机制仍需完善。
- 目前定义使用已有程序语义组合。新测量对象、连续隐状态、多尺度机制和广泛结构先验仍有明确实现余项。
- 当前局部对照中的原始稀疏字典使用二阶坐标，可调用概念把已学规律组合成四阶及更高阶关系；它不替代自由程序搜索或普通代码 Agent 的完整对照，也不说明整体性能已经优于 0.9.0 或更早版本。
- 共享求值降低具体程序的重复执行，当前候选乘行预算尚未根据这种节省重新定价；执行节点统计与耗时也不是同一度量。
- 程序闭包表内的定义各保存一次；知识库独立定义记录可能重复携带依赖闭包，全库存储去重尚未完成。
- 研究图和动作选择仍采用有限诊断、计划与经验机制。十项目标整体继续进行，持续会话结束只表示达到该次运行的停止条件。
