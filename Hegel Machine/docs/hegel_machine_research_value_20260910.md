# 按观测费用比较研究序列

2026-09-10，0.44 研究实验；未采用为默认策略，当前默认版本仍为 0.43。

上一批整体黑格尔机已在原生 SC-KG 对照中取得收益；新增的硬延期策略却带来多个目标退步。本批保留所有原候选，先完成原单步决策，再用剩余计算比较同点短序列。

每条模拟路径逐次更新 GP、噪声模型与观测历史，使用原完整推荐集合计算净收益，再除以计划观测次数。一次实验即使不能立即确认被测点，也可能通过改变其他位置的预测改善推荐。长方案须得到配对比较支持，才改变下一次实际动作；取得实测后重新规划。

真实观测仍为 N64，单步精度与序列预测共用原 512 次估值额度。本轮先为原单步估值付费，再用当轮剩余额度决定可计算的序列长度；原单步与新序列的费用分别记录。原始单步 KG 数值保持独立，序列选择另有诊断。

## 实际结果

[默认黑格尔机对原生 SC-KG](../artifacts/sc_kg_vanilla_research_value_v044_20260910/default_comparison_brief.json)按可行性优先比较，观测预算均为 N64：

| 对照 | 胜／平／负 | 可行解：vanilla → 黑格尔机 |
|---|---|---|
| 累计 355 例，共享初始观测 | 339／11／5 | 313 → 351 |
| 新 27 例，独立冷启动 | 26／0／1 | 21 → 26 |

新冷启动中双方均可行的 20 例，目标值逐例平均降低 27.28%。本批唯一退步为 `research_value_1_objective_only_change_noise_0.03`：黑格尔机目标值更低，但推荐点实际不可行。普通 Code Agent 沿用[上一批八题结果](hegel_machine_vanilla_and_completion_20260910.md)：完成模型数 7 → 8，测量费用 1900 → 1008，共同七题误差均接近零，黑格尔机没有精度优势。

相对默认策略，[355 例配对](../artifacts/sc_kg_confirmation_value_v044_20260910/result_brief.json)为 **0 改善、355 持平、0 退步**；两臂均有 351 个可行解，新 27 例也全部持平。

161 轮序列比较中，3 轮支持长方案，2 轮实际改变原动作。额外使用 22,222 次模拟后验更新、118.70 秒，未改善最终结果。该时间已包含在完整 KG 评分内。目标 GP 误差 1 例下降、1 例上升；约束 GP 误差 2 例上升，其余持平。

默认接入已撤回，[冻结代码](../artifacts/sc_kg_confirmation_value_v044_20260910/method_source_v044/)、运行入口与全部结果保留。84 项相关功能验证通过，恢复后默认 SC 25 项测试通过。研究新增真实模拟调用共 9,440 次，含初始数据和评估；历史数据与不受影响轨迹已复用。

## 下一步

旧失败点的单次观测为 −0.08342，而独立评估真均值为 −0.04472；测前估计噪声方差约 0.000380，评估场景为 0.0009。最后一轮仍有复测报价和预算，不能归因于没有复测机会。下一步用同一机制范围内的已付重复观测和测前残差提出替代噪声模型，再以新的实测比较其校准效果。真实评估值只用于定位问题，不进入拟合。

## Limitations

本批序列方法最多比较四步同点观测，模拟期间冻结模型结构；单位观测收益未求解整个剩余预算的最优策略。整体优势限于这些任务与观测预算，尚不能推及开放世界及稳定长期净收益。SC-KG 与黑格尔机的额外认知计算分别记账，N64 相同不代表总计算费用相同。
