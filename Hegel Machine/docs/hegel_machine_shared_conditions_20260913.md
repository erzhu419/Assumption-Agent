## Limitations 与下一步

正式任务仍为有限门条件先验与仿射控制，历史和标定由行为测试覆盖；本批未新增真实Code对照或重跑未进入此次条件循环的对象序列。原构想的一般结构语法、开放研究操作和稳定长期净收益仍未完成。

下一步共享多个可调用版本的拟合与选择：本批重新拟合计算仍为每组21840，占新版总计算约38%；应减少相同依赖的重复拟合，同时保留不同机制的实际竞争。
