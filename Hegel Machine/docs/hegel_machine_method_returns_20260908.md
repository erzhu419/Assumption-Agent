# 黑格尔机 0.13.0：方法适用条件与追加研究收益

日期：2026-09-08。承接 [0.12.0 整合研究](hegel_machine_integrated_research_20260908.md)，继续落实 [GPT6 建议](../markdown/GPT6_advice.md)及[具体方案](../markdown/Hegel_Machine_Vision_Progress_and_Research_Critique.md)中“研究方法成为知识、投入选择以实际认知收益为依据”的方向。

本轮已把方法适用证据接入普通控制器和任务调度，修复状态拟合不完整、筛选丢失已知反例和重拟合未优先保留当前结构的问题。功能闭环已运行，整体预测效果尚未稳定改善。旧存档的 11 个未解决问题重新研究后，按 0.002 的改善门槛，7 个改善、1 个恶化、3 个不变。方法选择与普通选择的配对结果分别报告，避免把基本求解修复的收益算成方法知识的优势。

## 从实际失败到代码行为

0.12.0 中 c05 只剩约 0.000227 的归一化超额损失，源方法仍用约 0.899 的收益计算机会，导致价值被高估。f10、s02、s07 的部分实验取得真实反例，但后续拟合只有约 491–765 计算单位；已经增长的观测集需要约 690–1038 才能完成开态、关态及启动分支。有些完整候选已经生成，筛选的小样本却漏掉启动反例，候选因此未进入后续比较。

对应实现如下：

- **按已有证据判断适用。** `method_conditions.py` 保存当前表示、公开损失目标、已获历史与控制覆盖、当前残差和动作反馈。方法分为有证据支持、需要探索、当前不适用。表示修订允许从原始变量进入已获历史；不会要求目标先有待发现的表示。旧存档缺少情境资料时仍可探索。
- **目标约束收益与支出。** `ResearchMethods` 用目标剩余误差限制源收益，按照下一步费用和目标观测规模估计计算量，同时检查单次访问预算。不同数据规模的实际计算费先折回源行数再更新，避免重复缩放。目标在相同表示和实质相同证据下已完整执行的无益动作，不能通过不同方法编号再次取得优先权。未完成拟合的实验反馈不作为方法反例；多步方法保留中性准备后的续步机会。
- **方法与普通计划竞争。** 尚未获得迁移支持或目标适用性仅属探索的方法首步，不替换不同的普通计划；当普通计划选择相同动作时，它仍可获得真实迁移反馈。已经开始的方法保留后续步骤。纯覆盖采样不抢占目标当前已有正区分力的实验；跨任务的新方法机会需要明确适用支持。
- **重拟合当前解释。** `refit` 先提取当前完整结构并拟合其参数，再比较便宜的当前变量模型。它不再先将小配额花在其他库中结构的搜索上。
- **完成状态修订。** `state_search_work()` 按实际观测和分组报价，控制器优先支付完整基本状态拟合；联合坐标和更深历史使用余量。`state_transition` 成为可选择、执行和反馈的具体研究动作。
- **保留已知反例。** 筛选在原计算额度内扫描当前解释的实际误差，至多用三分之一样本名额保留大反例，其余保留代表样本。候选进入完整旧证据和新轨迹比较后才决定是否采用。
- **反馈整次续研的真实结果。** `continuation_feedback` 用同一批新取得的代表轨迹比较保存解释与最终解释，保存绝对收益、归一化收益及费用。相同程序不会因为验证集分母改变而获得虚假收益。无益重访结束后，旧残差本身不再触发下一次重复访问；实际新证据、新知识或另一适用步骤可重新打开问题。

## Limitations

方法适用条件仍来自有限的公开表示、动作和观测统计，尚不是可自由发明的研究理论。控制覆盖分箱与实质残差变化用于判断是否值得重新尝试；只增加行数不保证产生新信息。费用按已测动作和数据规模估计，完整方法的真实价值仍需要后续任务检验。

学习侧的 `continuation_feedback` 属于自适应证据，不能替代独立评价。尾部校准仍可能在程序未改变时降低决策质量，状态边界修订也可能由少量新观测获得错误支持。五个环境分区已用于开发，另一随机种子不构成外部环境证明；本轮没有重跑外部普通代码 Agent，0.12.0 的三题对照继续作为历史结果保留。
