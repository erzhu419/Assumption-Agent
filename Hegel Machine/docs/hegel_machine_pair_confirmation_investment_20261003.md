# 修订确认的追加投入（0.173.0）

冻结旧、新解释的首批确认后，系统按实测未区分经验、预计信息价值和完整费用决定是否重规划，再用新增读数改实验背景、追加确认或暂缓。每批按各自启动预测比较；取得区分证据或出现响应反例就交回原修订流程，逐批结果保留。研究使用会话已分配的共享预算份额，并预留最终比较与条件评估费用。

63项测试通过，覆盖实际追加、换背景、暂缓、反例不被后续覆盖及普通研究回归。三个已付前缀开发案例均没有新增区分：首版先重规划后拒绝采购，多用41554计算；补上重规划自身的前置报价后，同样案例避免41410无效计算，仅增加144次实际预测比较。两轮开发原始结果均保留，见[研究目录](../artifacts/pair_confirmation_investment_20261003/README.md)。

24条学习链、336项终测已完成，全离线、0外部模型调用。较保留单批确认的同源对照，达标均137/168，逐题1胜167平0负；平均MSE低5.65%，后7阶段仍70/84、MSE低14.31%。唯一改善为root12/p9的.213890→.001599，仍未达标。观测/测量少192行、计算少102603（0.23%），本次研究及终测CPU从2788.58增至3883.10秒（39.25%）。见[完整配对结果](../artifacts/pair_confirmation_investment_20261003/compact_results.json)。

新机制实际追加12批，其中root12/p3的一批取得独立区分，其余11批未区分；获准重规划18次，规划后购新观测12次、拒绝6次。p3实测后研究排序改变；p9没有直接追加确认，新版仅回访1次，对照回访3次，对照后两访采用的阈值修订在新版没有发生。见[追加批次](../artifacts/pair_confirmation_investment_20261003/actual_additional_pair_batches.json)与[p3至p9的路径诊断](../artifacts/pair_confirmation_investment_20261003/root12_pair_diagnosis.json)。控制组精确复现0.172的168题与12条账本。

## Limitations

信息价值是独立区分机会的估计，不能直接当作预测精度收益；重规划前使用当前已付最优实验估值，可能暂缓尚未发现的更优背景。追加确认受当前回访分配额度约束，尚未作为独立待办跨任务排序。开发预算两臂相同，但已付前缀重建不等于完整历史重放。

正式比较均为已见回归，改善集中1/12条链，实测CPU增加；稳定长期净收益仍未成立。p9改善不能归为直接确认命中，尚未用独立消融分离新增证据与费用/排程的影响。本轮未重跑短链、知识删除/撤回消融及外部模型对照。

下一核心：让保留的具体确认问题参与跨任务投入选择，直接比较继续确认、重新拟合和暂缓，并检验新增证据与方法费用各自对后继结果的贡献。
