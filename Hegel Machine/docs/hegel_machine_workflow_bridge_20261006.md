# 新研究方法与旧统一研究器的衔接

新 `GrowthResearcher` 和旧 `UnifiedResearchAgent` 现在共享 `KnowledgeLibrary.research_workflows`。旧研究器从实际采样、拟合及新轨迹确认中积累可执行步骤；后继任务在旧预算内重放，失败证据交回旧观测修订流程。新增方法支持 Growth 的仪器比较步骤进入旧拟合回调。标量续研仍沿用旧执行器。

旧来源回传已经能找到产生概念的方法，区分执行成功和知识产物的后继回报。同步修复等价来源重复领取独占收益、删除方法后的编号复用、同公共任务名的回访反馈丢失。方法删除对照保留编号计数器及全部预测知识。

## 实验

[固定协议与结果](../artifacts/workflow_bridge_20261006_main_12/results/summary.json)采用已有仪器时序任务：6组有限历史、6组递归历史，每组六任务。从同一实测两任务前缀分叉，仅清空一臂的方法列表；两臂都可继续学习。完整成本包含前缀、失败、修订与确认，终评为研究结束后的随机轨迹及正负脉冲。

两臂均72/72通过新轨迹确认与终评，12/12组实际存在可删除的方法知识。

| 整链指标 | 保留前缀方法 | 删除前缀方法 |
|---|---:|---:|
| 确认且终评通过 | 72/72 | 72/72 |
| 观测行数 | 4,334 | 4,092 |
| 测量单位 | 9,006 | 8,328 |
| 计价计算 | 1,038,795 | 1,011,121 |
| 训练CPU秒 | 59.21 | 54.44 |

保留前缀方法在本批多5.91%观测、8.14%测量、2.74%计价计算。实际重放26次对33次；删除臂仍能从后继任务重新学习，并发生2次程序步骤修订。结果显示执行已接通，保留前缀方法的额外净收益尚未成立。两臂在本批均无需任务回访。

旧的任务8有限预算回访另作[接线回归](../artifacts/workflow_bridge_20261006_main_12/unresolved_return.json)：真实调度器从未完成任务出发，利用后继知识重开研究、比较、确认，并将收益回传到产生知识的方法。付费比较误差从0.3338降至6.64e-20，新轨迹确认误差4.28e-19；方法收到一条已确认的正回报。该案例用于验证调度与反馈连接。

## Limitations / 下一步

三项资源差值的配对95%区间都跨零，因此本批不能证明稳定变好或稳定退化；12组覆盖的仍是已有受控任务族。
本批59次重放的知识回报优先级均为零。该冻结版本的生产条件与消费条件共用同一精确匹配字段。任务8的两者响应签名不同，因此即使回传成功，该回报也未用于选择方法。[后续需求实验](hegel_machine_workflow_demand_20261006.md)已分开两种条件并验证选法改变，任务收益仍未成立。此处接通的是共享方法库及旧时序执行、反馈路径，未覆盖所有历史研究分支，也不代表181个版本全部整合。

相关回归共111项通过。实验全部离线，外部模型调用为0。冻结副本包含源码及运行脚本，可从 `artifacts/workflow_bridge_20261006_main_12/frozen_source/` 执行 `python3 scripts/run_workflow_bridge_study.py --cohort --output /tmp/workflow-bridge-reproduction`；回访案例使用 `--return-regression` 并指定一个新JSON输出文件。
