# 实测噪声与研究路径修复

0.155.0保留当前结构能力，修复条件实验忽略已付噪声证据的问题。证据绑定实际程序、渠道、验证轨迹和已购观测；仍解释当前误差时暂停额外条件扩搜，保留响应重拟合及独立确认。程序或证据变化可重开，已有条件结构的边界实验继续执行。29项相关测试通过，包括修复前真实失败的旧任务、条件发现及含噪窗口／系数变化。

先行比较发现，冻结0.137在原0.131的72题上与0.154逐题预测完全相同，直接退回0.137不能恢复该能力。因此本轮采用当前版上的定点修复。随后36条完整学习链及自然回访全部结束，再统一完成240项终测；无外部模型调用。协议、费用及逐题结果见[实验记录](../artifacts/research_routing_repair_20261001/README.md)。

修复较0.154误差下降27.20%、记账计算减少40.52%、观测增加1.07%，整链10胜2负。原0.137条件组合任务上，0.137、0.154、0.155均84/84，逐题预测与计价费用完全相同，结构能力保留。保留本次修复；相对0.131仍有2.42%误差差距与63.75%计算开销，完整恢复和稳定长期净收益尚未成立。

剩余开销主要来自首次研究：较0.131多2440554计算，回访与筛选分别少139722、82355。剩余25次条件研究中，18次已有噪声支持，但后续机制实验新增观测使旧支持失效；6次噪声支持不足，1次当前训练损失超出实测噪声范围。机制实验仍用确定性近零标准判断反例：root01第二题的同一模型新误差8.96e−5被判反例，随后又购72行条件实验、耗68875计算，最终仍选择原程序。已修入口的证据绑定正常失效，下一问题是新实验的反驳是否成立。

## Limitations

两组都是已见能力回归，不是新任务泛化或普通Code对照；本轮未改动的仪器路径没有重跑新任务。CPU实测含噪组510.48→549.42秒、条件组375.81→489.98秒；候选两族并行8个worker、基线单族4个，不能据此将时间变化归因到策略，也不主张运行加速。旧含噪任务无达标阈值，completed不是独立精度验收。

下一核心：让新的机制实验区分含噪偏差与可重复的结构反例，再决定是否追加条件研究；同时保留真实反例重开能力。随后处理失配参数的规划资格与完整确认费用。继续保留0.131旧能力和0.137条件能力两个固定参照。
