# 后继需求开始影响研究方法选择

方法的执行适用条件与知识的消费条件已分开。统一会话从已访问、未完成任务的付费观测生成需求；方法库按该消费者条件匹配实际回报。已解决任务、未确认收益和共同来源回报不提供独占正信用。可执行性与采样、测量、确认预算先于选择检查，纯命令方法也不再被无关仪器费用挡住。

[固定12种子对照](../artifacts/workflow_demand_20261006_main_12/results/summary.json)先真实学习方法并取得一次来源回报，再接收独立研究器实际采集的未完成任务。两臂共享全部前缀、预测知识和方法，仅移除一臂的方法回报记录；全部训练完成后终评，完整研究成本包含前缀与失败，终评费用另列。

12/12例都有两个可执行方法、真实确认回报和匹配需求。保留回报均选 `method_0`，移除回报均选 `method_1`；生产与消费条件不同，回报现在实际影响选择。

## Limitations / 下一步

这里只检验已有任务预算内的选法。历史知识已存在于库中，其回报不能直接解释为再次生产知识的边际收益。需求是重复公共实验得到的已知条件；一般化到新消费条件、更多测量视图，以及判断是否值得启动额外研究仍待验证。

[开发轨迹](../artifacts/workflow_demand_20261006_development/case_63007001_r2.json)定位到下一处执行瓶颈：两臂首先花约7.7万计算拟合同一表示；随后报价240计算的机制修订，实际连同确认花约1.8万。换测量时只余约2.4万计算，有效测量后的联合修订需要48行、却只剩32行。下一步应让候选生成、拟合、区分观测和确认作为完整研究包参与预算分配，避免换测量前耗尽资源。提前测量能否解决任务仍需实测；本轮不追加预算或改动冻结结果。
