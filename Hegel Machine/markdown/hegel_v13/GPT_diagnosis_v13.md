# 四、最需要修的断点：实验没有取得，却可能被记成新实验已执行

这一项不是理念争议，而是具体控制流问题。

当前普通入口的区分探针回调包含：

```python
p_rows = acquire(..., probe=probe_obj)

if p_rows is not None:
    return p_rows, actual_transitions

if ep_obs_rec and ep_trans_rec:
    return ep_obs_rec, ep_trans_rec
```

也就是说：**新购测失败时，返回此前已有的整段记录。**

而上层调和器只要收到非空返回，就执行裁决，并将**刚才请求的探针ID**写入：

```text
paid_probes_executed
```

没有检查这些记录是否真的由该探针产生。

## 本轮实际复核

我从固定源码提取该回调与裁决路径，令`acquire`返回`None`：

- 回调仍返回旧记录；
- 实际成功的新购测次数为0；
- 结果中却出现`new_probe_not_executed`作为已执行探针。

**这是源码片段级复现，不是证明本次所有成功episode都触发了这个问题。**不能据此把23个成功归零，但在修复前也不能把探针ID数量直接当成真实区分实验的数量。

## 怎么改？

允许三种明确返回：

| 返回 | 更新规则 |
|---|---|
| 实际执行了新实验 | 使用真实执行ID、轨迹和费用更新 |
| 复用确切同协议的旧实验 | 保留原执行ID，不新增独立样本数 |
| 无法取得 | 保留未决，不对请求的干预作支持或反驳 |

普通旧资料当然可以再分析。**错误不是复用旧数据，而是把旧数据冒充成另一项请求实验的结果。**

这应复用现有证据与执行合同，不需要新建日志平台。

**这解释了一个重要区别：**

目前新路径比较擅长：

\[
\text{已经取得一个成功新解释}
\rightarrow
\text{整理它与旧解释的关系}.
\]

还没有充分闭合：

\[
\boxed{
\text{新旧解释都不够}
\rightarrow
\text{形成支持性子问题}
\rightarrow
\text{取得新答案}
\rightarrow
\text{改变父研究}.
}
\]

这不是说原研究器从来不会失败修订，而是**这条新增分支调和路径没有把自己产生的失败研究接回去**。

```text
实际被测程序版本
实际反例与测试条件
哪项父预测或行动仍未解决
子研究允许返回什么
答案应改变哪个参数、表示、绑定或实验
```

有预算就进入现有研究队列；没预算就保留待处理状态。

同时，应限制被反驳声明在该范围内的支持。**保留旧计算，不代表继续保持其未经限定的适用资格。**但也不能因为目标上的一次失败，就删除旧来源中仍然成立的所有知识。

# 六、目前所谓“作用域”，有一部分实际是路由分类器

这是本轮最重要的概念与算法诊断。

## 1. 结构不同，被直接当作彼此的范围负例

普通调和器会读取其他分支的`_branch_regime_signature`。只要结构签名不同，就将其pilot摘要放进：

```text
out_of_regime_ces
```

再用于缩小当前分支范围。这个过程没有先要求：当前分支经过合法绑定后，确实在那份数据上预测失败。

但：

\[
\boxed{
\text{属于不同模型类别}
\neq
\text{一方在另一方数据上被反驳}.
}
\]

一个复杂规则可能在局部条件下退化成简单规则；两个不同机制也可能在某个任务范围内给出相同后果。

## 2. 这部分不一定要删掉

它仍然可能是一项有用的经验：

> 某种观测摘要出现时，优先尝试某一模型族。

这是一种**候选路由／搜索偏好**，完全可以通过后继效果验证。

问题是，不能因此自动认定：

> 其他模型在这个世界中已被证伪，可以永久排除。

所以建议分成两条状态：

**经验性路由条件**：可以来自不同成功结构的标签，优先影响排序。

**世界适用范围**：需要对该声明的实际检验、明确范围及反例，才限制其科学资格。

**这不是要削弱你的成果，而是给当前最可能有效的对象一个准确身份。**如果一个学得路由规则帮助新任务更快研究，它已经有价值，不必伪装成物理定理。

## 3. 新分支也不是旧范围的自动补集

当前部分裁决会从旧guard的边界反向构造新分支范围。

但在开放假设集合中：

\[
\neg H_{\rm old}\not\Rightarrow H_{\rm new}.
\]

旧解释之外还可能有第三种机制。复合guard的逻辑补集也不一定能由反转一个阈值表达。

**补集可以是下一范围提案，不能直接成为已验证范围。**

# 七、作用域消费者还存在两个具体问题

## 1. “没有pilot”被编码成“观测统计都是0”

`compute_observable_regime_features`在没有schema或没有转移时，返回的阻断率、方向量、最小有效差等都是0。

本轮控制中：

```text
obs_unconditional_block_rate < 0.1
```

在没有任何pilot数据时，会被普通guard消费者接受。底层显式传“没有pilot”的验证器能够拒绝，但实际普通调用没有执行同样的前提检查。

因此应返回：

\[
\text{值}+\text{有效计数}+\text{协议身份}+\text{可用时点}.
\]

空集合的最小值、零分母比例是**未知**，不是0。

消费者至少区分：

```text
接受 / 拒绝 / 未知
```

未知可以触发合法pilot或保留候选，不能静默按接受或拒绝处理。

这并不是说本批所有目标都没有pilot，而是当前接口还允许一种不正确的判断。

## 2. 日志说剪枝了branch，对应承诺却可能仍进入普通池

当前`pruned_scope_ids`保存的是：

```text
branch:concept_A
```

后续过滤`consistent_comms`比较的却是：

```text
world_commitment:0000
```

两者不是同一身份。

本轮执行该真实过滤块的最小控制，分支被记为剪枝，对应承诺仍然留在池里。

因此，当前观察到的收益可能同时来自：

- 正确分支被提前排列；
- 某些家族没有抢占预算；
- 其他前提审计排除了候选；
- 而不是报告所概括的完整“作用域隔离”。

应补明确的：

\[
\text{branch}\rightarrow\text{commitment}\rightarrow\text{source/version}
\]

映射。

但一个族可能有多份独立支持，**不能因为一个来源分支不适用，就把整个共同结构全局删除。**

# 九、当前还需要怎样解释确认和统计？

## 1. 真实的边界假确认，需要研究，不应靠放宽门槛消失

生命周期目标`1005000`内部24行近零，外部48行出现约 \(1.70\times10^{-3}\) 的误差，说明某些阈值区别没有被内部确认覆盖。hegel_v12_autonomous_lifecycle\_…

下一步可以利用已有相容参数区间提出边界区分实验，**不是读取真实阈值**。

购买这些数据后，它们可以成为下一版本的研究材料；但不能同时充当该版本的独立终测。随机分布评价与定向边界诊断也应分开。

## 2. 来源复验，不等于新家族又得到一次独立确认

把多个来源整理成 \(H^*\) 后，在原来源记录上重验，是合理的保持性检查：

> 新表示没有丢掉过去已得到的成功。

但这些数据已经参与了来源模型与家族形成，不能每次重验都增加一份独立支持。真正的来源外效用，仍要由冻结后的新目标检验。

## 3. “0.21题回本”应收窄解释

\[
16,049.5 / 77,623.54 \approx 0.207
\]

可以作为：

> 在共同来源经历已经存在的前提下，记账调和维护成本相对当前普通基线目标差额的摊销比。

它不是整个系统从零开始0.21题回本，也不覆盖额外观测、墙钟权衡及基线修复后的变化。

# 十、下一轮具体怎么走？

我建议只做三个交付，不再扩成新的大型版本目录。

## 交付A：修证据身份与失败返回，不新增科学任务

主要入口就是当前文件，不需要新框架：

| 入口 | 具体修改 |
|---|---|
| `_exec_reconcile_probe` | 区分新执行、确切历史复用和未取得；不再回退成伪新探针 |
| `adjudicate_branches_on_paid_evidence` | 将反例绑定到真实被测版本和范围；返回有父用途的待处理问题 |
| `reconcile_competing_branches` | 实际向上返回并入队子问题，不只保存裁决字符串 |
| scope统计与消费者 | 未知值、样本数、时点和协议一致 |
| 分支消费 | branch与commitment身份映射正确 |
| 普通重构 | 缓存完整的实际产物，而不是只缓存前一层 |

用现有回执和小型控制验收。**不要把这些回归通过再当成新的独立科学成功。**

最重要的新增测试，是一个“两个解释都被真实新观测反驳”的普通入口案例。它必须实际产生子研究，并改变父模型或下一实验；预算不足则明确保留未决。

## 交付B：确认当前学到的究竟是路由规则，还是世界适用范围

保留现有有用启发式，但明确它的证据类型。

加入两个很窄的保护案例即可：

**案例一：**不同结构标签，在当前声明范围内预测等价。不能把它们自动当成彼此反例。

**案例二：**粗摘要相同，但边界条件不同。不能因为guard一致就永久合并。

然后对一项实际路由规则做保留／移除，检查它改变的是排序、拟合、购测、采用，还是最终预测。

**如果它只是路由规则却真正有用，可以作为当前贡献。**没有必要等它变成普遍物理定律才认可。

## 交付C：冻结M0，用新源链重做一个收紧的主实验

优先比较：

1. 优化过的普通lazy archive；
2. 学得分支／路由组织，\(H^*\)不优先；
3. 相同组织加 \(H^*\)。

所有组共享真实原始来源，包括调和过程中额外取得的数据；公共数值修复与工具也共享。普通组允许在预算内重构等价知识。

当前8条评价源链已经被审阅、诊断，下一次修复后的结果应另用未曝光物理源链。统计按来源链配对，不把同一来源的3个目标当成完全独立的样本。

主要结果应当是：

> 严格任务完成、未见预测、误确认、错误迁移／错误拒绝、覆盖，以及完整资源成本。

不是新节点数量，也不是调用了多少次`reconcile`。

**如果优化后的普通组打平，就缩小主张；如果分支组织仍然有收益，这已经是v4核心目标的一个有效有限实例。**

# 最终判定

我认为这次应该给出一个比此前更积极、但有边界的结论：

> **v12已经跨过“只是把工具接上、主要由脚本手工推进”的阶段。有限语言中的自主假设形成、历史分支整理和后继消费已经有真实执行证据，也出现了可定位的未见任务改善。**

但还不能说：

> **真实冲突已经被完整、正确地处理，且新统一假设本身已经使强普通研究之上的能力提升得到充分证明。**

目前最需要修的不是再提出一种更宏大的理论，而是这三件事：

\[
\boxed{
\text{让证据身份准确}
\;+\;
\text{让真正的失败触发子研究}
\;+\;
\text{让效用归因对应实际有用的知识}.
}
\]

**\(H^*\)删除后打平，不是必须修掉的失败。**真正要避免的是为了证明“新抽象有用”，不断改变任务或削弱旧方法。

如果最后发现：有效的是从真实经历学出的适用／路由关系，它能在可靠证据下正确保留、限制和召回旧假设，并帮助未见任务——**这同样忠实于你的黑格尔机原始构想，值得作为明确成果。**当前距离这项有限成果已经比上一版近，但上述证据与执行缺口仍应先收口。
