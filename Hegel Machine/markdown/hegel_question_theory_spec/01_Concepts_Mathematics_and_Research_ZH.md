## 0. 本次要解决的不是“怎样再优化一次”

当前需要补的是：让 Agent 明确选择一个值得回答的问题，形成能承担可检验后果的假设，决定哪些已有理论可用，再把答案变成下一次研究的可执行资源。

这个目标同时包含两个循环：

1. **问题内研究**：解决当前任务、研究其支持前提、选择并实施修订。
2. **跨问题理论形成**：从多个实际研究中抽取共同结构、适用边界及研究方法，并检验它们对后继学习的价值。

宏观问题不天然高于局部问题。“两种定理是否存在结构对应”可以有价值，也可以空泛；“参数在哪个区间”可以很局部，却决定一整个理论能否检验。应依据它回答的内容、后果及证据要求区分，而不是依据语言显得多抽象。

以下内容分三种证据等级：

- **仓库事实 [G]**：本次确认的代码与说明；没有重跑付费模型或源任务。
- **外部研究 [R]**：文末给出原始论文、作者或出版社链接。2026 年 arXiv 工作按预印本处理。
- **建议 [P]**：针对项目的设计，不宣称已经实现或一定带来增益。

## 1. 函数可以表达假设，但函数不自动等于科学假设

### 1.1 函数、程序与经验承诺

写出

\[
y=f(x)
\]

只是一个数学对象或程序接口。把它用作科学假设，还要知道：`x`、`y` 是什么，怎样测量，允许哪些干预，在哪个范围内，误差是什么，哪些条件被认为稳定。

例如同一条 `y=2*x`，`x` 若分别表示输入电压、时间或校准后的传感器读数，科学承诺完全不同。代码相同不等于经验意义相同。

本项目已有的

\[
h=(\phi,p,s,\Gamma)
\]

已经抓住重要内容：表示、程序、作用域、支持前提。[G2；原论文 §3.1]

对确定性模型，它预测点值；对随机模型，它可能预测条件分布；对结构规律，它约束一个模型集合。例如

\[
f(-x)=f(x)
\]

只要求偶对称，允许无穷多个不同函数。因此它不是一条已经拟合好的响应曲线，却仍是精确假设。

一般可以写：

\[
\mathcal M_H=\{m:m\text{ 在声明范围和解释语义下满足 }H\}.
\]

这是语义定义，不要求程序能够枚举整个集合。

### 1.2 微分方程需要附带问题设定

\[
\dot x=F_\theta(x,u,t),\qquad y=G_\eta(x,t)
\]

通常不足以给出唯一预测。还需要初始条件、输入过程、时间尺度，有时需要边界条件以及噪声和测量模型。它们可以是已知上下文，也可以是待估参数或子研究对象。

不得因为一组初值不对，就把整个动力学族判为错误；也不得因动力学方程正确，就把未识别的初值当成免费已知输入。

### 1.3 “放大／缩小信息”是部分函数的解释，不是函数的一般定义

线性映射 \(z=Wx\) 可以沿某些方向放大或抑制；非可逆表示可以合并原本不同的输入。这是有用的局部图景。但常数、置换、排序、逻辑谓词、随机核和状态更新不是同一种滤波器。

把旧特征确定性地组合为新特征，可能使有限学习器更容易使用已有信息；不能仅凭这种变换说获得了新的外部观测。若变换丢失信息，后续拟合不能从被丢掉的区别中恢复真实差异。

原始零填充失败是一个明确实例：公开历史本来不同，作者的表示将它们合并，导致确定性预测的经验误差下界。[G4]

### 1.4 暂时采用，不是一直肯定

有效的工作状态应该是：

> 在当前任务、尺度、证据和误差容许下，暂时使用；同时保留未解决替代解释和失效条件。

“尚未遇到反例”不自动意味着“已得到充分支持”。单个异常也不自动否定整个随机模型。新观测可能触发参数、观测绑定、范围、噪声模型、表示或结构的变化；这些是竞争解释，不应硬编码为永远逐项排除的单一路径。

## 2. 问题的精确定义：它要求世界告诉我们什么

### 2.1 问题可以表示为可能模型上的查询

当答案唯一确定时：

\[
q:\mathcal M\to\mathcal A_q.
\]

\(\mathcal M\) 是考虑的可能模型，\(\mathcal A_q\) 是答案空间。例如：

- `parameter(m, threshold)` 返回某参数；
- `predict(m, experiment)` 返回预测；
- `even_on(m, domain)` 返回一个关系在该模型上是否成立；
- `transport_residual(m1,m2,T,Q)` 返回某映射在给定实验族上的误差。

程序在候选模型上运行可产生预测答案；真实世界的答案仍需实验、资料或推导。**这不是允许 Agent 调用隐藏真实模型。**

对“找到一个足够好的解释”之类允许多个答案的问题，更一般的形式是：

\[
\operatorname{AcceptableAnswer}_q(m,a)\in\{0,1\},
\]

而不是假装每个世界都只有一个唯一的正确程序。答案类型也可以是公式、映射、参数集合、条件性结论或研究程序。

### 2.2 问题、答案与假设

问题：该响应是否需要历史？

候选假设：当前值已充分；有限历史充分；需要更长记忆；当前测量有延迟。

研究程序：组成复位、不同输入路径、共同尾段及读出，检验这些假设的区别。

答案：在已测范围内，固定无历史表示被具体见证否定；某有限历史族仍相容，但更长历史未被排除。

这四项不应存成同一个字符串。

### 2.3 问题不等于获得答案的算法

“阈值在哪”可用二分、批量拟合或回忆旧区间回答；算法可以改变，问题保持。

反过来，同样调用一次拟合器，可能在回答不同问题：预测精度、对称约束是否可行、某个参数是否可识别。代码动作相同不代表问题相同。

### 2.4 已有研究真正提供了什么

Rothe、Lake、Gureckis 将问题建模为可执行的组合程序，并按信息性与复杂度等因素生成问题；验证场景是受限游戏中的人类提问。[R01] 询问语义研究则系统区分陈述的信息内容和问题要求解决的事项。[R02]

对黑格尔机应借用的是**问题有可计算语义**，不是直接照搬某个游戏的语法或假定真实环境可被穷举。

## 3. “元函数”应该拆成几个不同对象

| 数学对象 | 典型形式 | 在项目中的职责 |
|---|---|---|
| 预测程序 | \(p:X\to Y\) 或条件概率核 | 预测世界 |
| 结构约束 | \(V_R(p)\ge0\) | 限制哪些模型满足某种规律 |
| 问题 | \(q:m\mapsto a\) 或解关系 | 指明想知道什么 |
| 先验 | \(\Pi\) 或 \(p(\theta)\) | 偏好哪些可能解释 |
| 研究策略 | \(\pi:(D,K,b)\mapsto\text{action}\) | 决定怎样继续研究 |
| 理论修订算子 | \(\mathcal U:(K,D)\mapsto K'\) | 改变可用理论与联系 |

它们都可以被进一步研究，但不因此变成同一个“meta function”。

**泛函**通常是函数空间到标量的映射，例如 \(J(f)=\int(f-y)^2\)；**算子**可以把函数映为另一个函数。泛函分析研究空间、连续性、算子、对偶及相关结构，不是“先定义空间，然后找最优函数”的同义词。函数空间不必自带唯一基，也不必具有 Hilbert 空间的正交基结构。

## 4. 正则化与先验：等价的条件、非等价的部分

### 4.1 最直接的对应来自取负对数

给定同一参数化、相同参考测度及似然：

\[
p(\theta\mid D)\propto p(D\mid\theta)p(\theta).
\]

MAP 是：

\[
\hat\theta_{MAP}=\arg\min_\theta\{-\log p(D\mid\theta)-\log p(\theta)\}.
\]

如果

\[
p(\theta)=Z^{-1}\exp[-\lambda R(\theta)],\quad 0<Z<\infty,
\]

那么最小化负对数似然加 \(\lambda R\) 与 MAP 相同，忽略的是对所优化参数不变的 \(\log Z\)。这是概率与优化的一个精确桥梁，而不是仅因拉格朗日对偶或 Legendre 对偶。[R17–R19]

若损失写成平均负对数似然，而先验固定，则先验项前系数要除以样本数；不能在从求和改为平均时仍声称对应同一个先验。

### 4.2 复杂先验对应什么正则项

| 先验 | 负对数项，忽略真正与当前优化无关的常数 |
|---|---|
| 独立零均值 Gaussian | \(\frac1{2\sigma^2}\|\theta\|_2^2\) |
| 独立 Laplace | \(\frac1b\|\theta\|_1\) |
| 相关 Gaussian | \(\frac12(\theta-\mu)^T\Sigma^{-1}(\theta-\mu)\) |
| Gaussian 混合 | \(-\log\sum_k\pi_k\mathcal N(\theta;\mu_k,\Sigma_k)\) |
| 分层先验 | \(-\log\int p(\theta\mid\eta)p(\eta)\,d\eta\) |
| 带基分布的关系偏好 | \(-\log p_0(\theta)+\lambda V_R(\theta)+\log Z_R\) |
| 模型结构／程序先验 | \(-\log p(\text{structure})-\log p(\theta\mid\text{structure})\) |
| 硬约束 | 在可行集内为0，集外为 \(+\infty\)；另需说明集内基分布 |

几点关键限制：

1. **混合不是把惩罚相加。** 混合倾向允许多个模式；惩罚相加对应密度相乘后的重新归一化，含义不同。
2. **分层边缘化不等于联合最优化。** 对 \(\eta\) 积分与挑选最佳 \(\eta\) 得到的目标一般不同。
3. **比较超参数或结构时，归一化常数可能不能丢。** 优化协方差时要保留 \(\tfrac12\log\det\Sigma\)。比较不同硬约束区域也不能随意忽略其体积。
4. **不一定存在正规先验。** 例如只惩罚导数、只惩罚图上差分，常数方向可能不受约束；需限定基分布、边界或增加适当项。
5. **零测度等式集合不能靠普通密度截断直接归一化。** 精确约束通常应改参数化或使用约束流形上的参考测度。
6. **在同一数据上学出的先验／规则，不能当作独立的新证据再乘一次。** 应采取层次模型、数据划分、序贯协议或明确经验 Bayes 的含义。
7. **MAP 与完整后验不是同一产物。** MAP 不提供所有模型不确定性，且对非线性重参数化通常不保持同一数值众数。

### 4.3 函数空间里的先验与正则

有限核方法中，核岭回归与 Gaussian likelihood 下 GP 后验均值存在精确联系；但“GP 是 RKHS 中一个带普通密度的随机函数”一般是错误图景。无限维空间没有可随意采用的平移不变 Lebesgue 密度，GP 样本路径也通常不在它对应的 RKHS 内。[R19]

因此第一版黑格尔机应在明确的有限参数或已有 GP 后端中使用这种联系，不要自己实现一个笼统的“无限维先验转正则器”。

### 4.4 正则的滤波直觉：有用但必须加条件

在线性 ridge 中，拟合值的谱系数含

\[
\frac{s_i^2}{s_i^2+\lambda},
\]

所以设计矩阵的小奇异值方向被压得更强。这里是某个问题诱导的谱，不自动等于物理时间频率；低奇异值也不自动等于噪声。真实快速变化和缓慢漂移噪声都可能存在。

### 4.5 更接近“高阶先验”的变分形式

给定先验概率测度 \(\Pi_0\)，且归一化有限，考虑：

\[
\min_{\nu\ll\Pi_0}
\left\{\mathbb E_\nu L_D(h)+\tau\operatorname{KL}(\nu\|\Pi_0)\right\}.
\]

解满足：

\[
\frac{d\nu^*}{d\Pi_0}(h)
\propto \exp[-L_D(h)/\tau].
\]

取 \(L_D=-\log p(D\mid h)\)、\(\tau=1\)，恢复通常 Bayes；采用其他损失是 Gibbs／广义 Bayes 更新，需要解释温度、相关性和校准。[R17]

**这是有条件的统计机制，不允许把任意 LLM 分数归一化以后叫“真实后验”。**

### 4.6 对本项目的具体建议

将规则编译到以下用途之一，而不是都塞进损失：

- 精确成立的形式约束 → 结构化参数化或受限搜索；
- 不确定的世界结构 → 可撤销的软偏好，并保留不服从它的竞争候选；
- 原始实测检验 → 似然／检验或残差，不再当作独立先验重复计数；
- 研究经验 → 提案和实验选择偏好；
- 元先验 → 跨任务评价，证明它改善的是未来研究而不只是当前拟合。

## 5. RL、收缩、紧致与相似性：需要分开四个对象

### 5.1 不是所有 RL 方法都靠收缩证明

折扣有限 MDP 中的 Bellman 算子有重要收缩性质；策略梯度等方法则可以直接研究梯度、优化与收敛性质，不以证明整个研究程序为压缩映射为前提。[R14]

Euclidean 空间本身就是 Banach 空间的一个例子；不需要从 Euclidean 空间“跳进 Banach”才能度量函数。

### 5.2 Bellman 收缩究竟比较什么

当奖励有界、\(0\le\gamma<1\)，并固定同一个环境与行动语义，

\[
(TV)(s)=\max_a\{r(s,a)+\gamma\mathbb E[V(S')\mid s,a]\}
\]

满足：

\[
\|TV-TW\|_\infty\le\gamma\|V-W\|_\infty.
\]

它比较的是**两个值函数经同一个算子更新后的差异**。由此可得同一固定问题中迭代对初始值的遗忘和唯一不动点。

它不表示：任意两个实际轨迹、任意两个策略或两个不同科学机制彼此相似。近似拟合、投影和环境变化后，也不能不加条件继承这一性质。

### 5.3 两个直接反例

\[
T_1(v)=\tfrac12v,\qquad T_2(v)=\tfrac12v+100.
\]

两者收缩率都为 \(1/2\)，不动点分别是0和200。因此共同收缩率不决定共同目标或机制。

收缩也不等于紧致。\(\ell^2\) 上 \(T(x)=x/2\) 是收缩；但单位基序列 \(e_n\) 的像两两距离为 \(\sqrt2/2\)，没有收敛子序列，所以这个算子不是紧算子。

Banach 不动点定理只要求完备度量空间和自映射收缩条件，甚至不要求空间具有线性结构。

### 5.4 更接近你的直觉的是预测状态与 bisimulation

预测状态表示用未来多步、行动条件化观测表达状态。[R16] 对你当前问题，实用形式是：

\[
S_Q(h)=
\big(P(\text{未来读出}\mid h,\operatorname{do}(\text{行动序列 }q))\big)_{q\in Q}.
\]

同一共同尾段输出相同，只约束一个有限测试；不是所有未来行动都不可区分。

在有限 MDP 中，bisimulation 度量可以同时比较奖励与转移。一个折扣形式是：

\[
(\mathcal Fd)(s,t)=\max_a
\left[|r(s,a)-r(t,a)|+\gamma W_d(P(\cdot|s,a),P(\cdot|t,a))\right].
\]

在相应条件下 \(\mathcal F\) 是收缩并定义固定点行为差异。[R15] 这里的逻辑是：**先规定行为差异，再用收缩证明这个差异定义可计算且稳定**，不是“收缩本身就是相似性”。

本项目首版应先使用现有有限预测签名；只有已经有明确可比较的行动、奖励／目标、状态和转移模型时，才加入 bisimulation 后端。否则可能用错误模型计算出极精确的错误距离。

### 5.5 对理论生长不要强制全局收缩

加入新观测会暴露旧区别；加入新模型可能增加不确定性；新任务可能使旧合并失效。这些都是学习。要求整个理论谱在每步都收缩到一个固定点，反而可能禁止必要扩张。

可以证明局部推理算子稳定，不能据此宣布开放式科学研究整体必然收敛。

| 方向与原始工作 | 问题／假设的载体 | 可借用的部件 | 不能由此推出 |
|---|---|---|---|
| 询问语义 [R02] | 信息状态、问题待解决事项 | 区分陈述真值与问题答案 | 已有自动科学实验设计 |
| Question Asking as Program Generation [R01] | 可执行问题程序 | 问题语法、组合生成与复杂度 | 受限游戏效果等于开放科学能力 |

| Reiter diagnosis／ATMS [R04–R05] | 冲突、候选诊断、支持环境 | 从前提冲突产生竞争调查 | 经验残差自动定位唯一错因 |

| 2024 active rules [R07] | 语言规则与可执行预测 | 候选提案、概率更新与实验 | 自由生成候选等于完整后验 |

| PSR／bisimulation [R15–R16] | 行动条件未来／行为距离 | 任务相关的状态比较 | 当下输出相同意味着机制等同 |

这些方向不是要全部串成一个巨大算法。第一版的核心组合是：**问题程序＋有作用域的模型／约束＋带后果的研究路由＋有证据的库归纳**。

## 7. 2026 年两项最直接的近邻，应该怎样借鉴

### 7.1 Induction and Inquiry via Probabilistic Reasoning over Language and Code

它把候选表示成自然语言和 Python，使用 LLM 辅助顺序概率推断，并将实验作为区分候选的手段。2026-09-01 v1，预印本。[R08]

可以借鉴“提出者与信念更新分开”；不能把本项目已有几个回归器的票数直接改叫后验。

### 7.2 Model Discovery Agent

MDA v5 把结构、参数和随机隐轨迹分开估计，并让失配触发候选结构扩展。它明确披露有限候选池、近似证据、确定性截断及未提出模型的质量不在归一化中。2026-09-27 v5，预印本。[R09]

可以借鉴“生成结构和数值推断分工”；不建议此刻替换全部黑格尔机。先在一个小型概率后端中比较收益与成本。

## 8. 勒夏特列—楞次：应作为研究问题，不应作为已知答案模板

原始 MD 的 v0.2 已经限定：它是远域类比，不无条件保证净扰动幅度缩小；必须分别绑定适用条件、受控量、时间顺序和可比观测。[O2]

建议形成三项明确问题：

1. 二者在哪些类型与尺度上可能保持同一种关系？
2. 哪些映射与前提让这种对应可执行检验？
3. 新问题是否满足这些前提，迁移后产生什么原来没有的预测？

候选答案可以只是一个局部响应方向 motif，而不是“二者都是相同负反馈系统”。负号不自动保证稳定：抽象递推 \(x_{t+1}=-2x_t\) 每步反向，却幅度增长。

第一项实证优先使用形式无歧义的匿名变换、平衡、有限记忆和作用域任务；不要直接把这个著名类比当唯一训练答案或验收标签。

## 9. 综合判断与优先级

**应融入主线：** 问题程序语义；假设族与实例分离；任务／尺度相关观测签名；结构对应；可撤销前提；有父用途的子研究；跨任务理论归纳。

**应作为可选统计后端：** 负对数先验正则；广义 Bayes；参数／结构层次后验；任务相关信息价值。前提、归一化与不确定性要如实标注。

**应延后：** 通用 bisimulation、全局研究算子收缩定理、任意函数空间自动发现、一般对偶／范畴证明器。它们不能成为当前机制打通的前置条件。

**应明确放弃的等同：** 函数＝完整科学假设；泛函＝找最优函数；所有正则＝某个正规先验；收缩＝紧致＝不同轨迹相似；旧语言全失败后才允许构想新理论。
