**结论：有实质实现、局部正向用途及真实负结果，但用户要求的“自主从经历形成假设—主动修订/融合—改善同工具强普通研究的独立后继”尚未被当前证据完整建立。**

不能再说项目只有语义库、没有可执行假设，也不能说全部问题已经闭合。最值得保留的是模型族表示、局部反统一、目标端重新标定、索引语义失效修复及方法负迁移的诚实记录。最需要修的是科学证据入口、实验归因以及研究调度与脚本编排的界限。

## 2. 三版计划的实现进展

### 2.1 v10：从研究动作选择回到世界结构

### 2.2 v10.2：可信语义与公平归因

上一轮证明域和Lean声明的整改仍应保留，不需要为了本轮主线再全面Lean化。当前范围内的精确有理证书只证明给定模型的结论；不把未证的环境覆盖当作已成立。

### 2.3 v11交付A：大部分工程修复真实存在

`_prior_state_fingerprint`现在覆盖除内部缓存字段以外的内容；group key绑定语义版本。部分构建将完整指纹设为None，并标记pending，不再按complete缓存。普通持久缓存实际提供版本失效、规范化与去重。查询记录未召回、未测试、预算不足、不一致和实证反驳。

这些属于真正的施工改善。当前静态缩放也诚实报告普通缓存与结构索引近乎打平：M=72时双方2/6，目标记账计算约116003.3与116097.3。其价值主要是实现正确与更新效率，不是额外科学发现率。

### 2.4 v11交付B：有模块行为，但不是完整自主生命周期

分支模块不是空壳：确实会比较预测、执行探针、缩域、抽出常量槽、逐分支检查与传播撤回。专项链也确实购买了真实观测。

- 已有好预测器，但资源内未完成确认/投影流程；

源码内冻结种子/评价合同有价值，但同一脚本中的哈希不独立证明开发过程中从未看到这些任务。当前应准确写“脚本预先固定的评估配置”；不凭空指控挑种子，也不把seed不重合升级成整个研究过程的独立性证明。

## 4. 最高优先级：科学证据入口有两个实质缺陷

### 4.1 源确认门槛跟着看到的误差改变

`run_v11_branch_lifecycle_study.py::_discover_real_source`：

```python
assert mse_s is not None and mse_s <= 1.5e-2
minimum_improvement = max(1e-7, float(mse_s) + 1e-6)
remember_confirmed_selection(..., confirmed=True, confirmation_loss=mse_s)
```

这不是事先登记的固定确认标准，而是先看误差，再构造一定覆盖它的门槛。新假设可以尚不完美；也允许研究一个预先声明的近似模型族。但应保存为provisional/approximate并明确容差，不能通过抬门槛生成confirmed。

不能由此断言每个实际源都不合格：B中多项来源新点误差确实接近机器精度。整改应逐源复核原始误差和原合同，保留真正合格者，重新分类其他来源；不全盘撤回已有真实成功。

反统一函数又采用：

```python
eff_fresh_tol = max(tolerance, 1.5e-2) if all_slots else tolerance
```

在调用者传1e-7时，仅因出现参数槽便将新点容差放宽150000倍。这不是“更一般模型应该自动更宽松”的合理原则。重构、识别不确定性、近似预测合同应该分开，且由研究命题确定，不能由候选形态悄悄改门槛。

### 4.2 范围缩减的支持统计存在人工补值

八阶段脚本在没有找到某类正支持时，把 `obs_min_active_donor_q` 与 `obs_min_active_gap_dq` 写成0.45；另一些情况又将实测较小值改成0.42。然后把这些数值作为旧假设的支持区域，交给缩域器。

这是把实验设计常量当成已经观察到的支持统计。scope_guard可执行并不意味着它来自真实证据。

缺少支持时应返回未知，或经预算取得所需数据；不能为保证B5测试成功而补出支持。后面脚本还把学到的H0 guard替换为手写方向guard，再测试旧域返回，因而也不能用这个返回成功来确认原缩域规则有效。

## 5. 生成与融合由谁决定：脚本和Agent需要分清

### 5.1 真环境标签影响了源研究路径

`_discover_real_source`对 `relation_condition == "always"` 用一条冷启动路线；否则走固定43补丁目录及专项pair sweep。实验室构造器当然可以知道真实机制，但研究者的路由不应根据这条隐藏标签变化。

应将世界生成留在harness，将所有来源交给同一公开研究入口。入口可以根据实际残差、候选分歧和可执行支持依赖，选择原有研究器。这样才能判断是哪条经验启发了哪项研究。

### 5.2 真实的新对象是什么

当前最明确的新结构是：

`q_src > 0 AND q_src - q_dst > theta`

从两个同向、同形但阈值不同的谓词中抽取theta参数，保留半径参数，再在目标重新标定。这是有内容的有限抽象；不因使用已有原语就不算学习。

但实验脚本明确选择同方向的H1/H2作为“应该融合”输入，又选择Hleft作为“不应融合”输入，并写出左右方向guard。所测的是给定配对下的结构变换能力，不是自动从混杂历史库里发现哪些规律有关、哪些必须保留分歧。

### 5.3 主Agent现有接线主要是消费端

`UnifiedResearchAgent._propose_schema_structures`在branch开关下读取预装参数族，筛scope，执行Pass-0标定，再进行普通承诺实例化与修订。消费是真实的，且会改变候选和研究开销。

这不等于生成链已经接入：来源形成、冲突问题生成、挑选要调和的历史分支、对scope取得支持、发布家族以及反例返回，仍主要由专项脚本串联。下一步要补的是这些决策的生产者与普通caller，而不是再复制一个同名框架。

## 6. 分支正确性：三个本轮独立执行的局部反例

### 6.1 容差相近不是严格等价

源码 `_programs_algebraically_identical`将相差不超过1e-9的常数认作相同；上层可能据此输出`proved_absent=True`。

考虑 `p(x)=1[x>0]` 与 `q(x)=1[x>5e-10]`。在 `x=2.5e-10`，二者分别为1和0，但短函数判定identical=true。

这不是细小MSE误差的问题：比较器会把很小的参数差放大成离散决策差。精确等价应基于精确规范表示或声明域上的证明；近似等价需要单列距离、域与误差界。不能拿近似常数比较签发严格合并。

### 6.2 第三个同类分支加入就失败

当前反统一先将0.22和0.46变成`theta_0`。继续与第三个相同骨架、阈值0.34的程序合并时，已有arg与const无法对齐，返回None。

这直接阻碍用户要求的“分支多了以后进一步统一”。修复应支持已有参数槽的替换环境、多分支一致绑定、完整多槽目标标定，而不只是扩展两个分支的测试。

### 6.3 没有支持标记的新根被默认视为有依据

`propagate_premise_retraction_invalidation([{"claim_id":"new_root","status":"candidate"}])`返回`valid_grounded`，因为无依赖根的`independent_empirical_support`默认True。

独立支持必须显式引用可用证据和作用域；缺信息默认未决。循环检查本身能正确拒绝本轮的无根双向循环，这项已有能力保留；不能用循环控制通过掩盖根节点的宽松默认。

三个探针使用最小Program适配器，没有执行仓库整个模块或实验。应在真实仓库加入对应回归并复核传播影响。

## 7. 其他重要不足

### 7.1 家族身份没有覆盖完整语义

新family ID只hash反统一的边谓词骨架。相同阈值骨架在左向与右向、不同读出或不同支持域下，会产生同一个ID。方向仍存储在对象内部，因此列表消费未必立刻错误；但按ID撤回、引用、统计和版本归属会产生碰撞风险。

应分别维护共享谓词骨架ID和完整世界家族ID；后者含方向、角色结构、单位/历史合同、作用域和参数共享关系，不能只靠一个局部AST。

### 7.2 当前“类型化反统一”范围比名称小

实现主要比较操作名、名字、lag及递归子树，把不同const变arg；没有完整物理维数证明。目标实例化只填`slots[0]`。新量纲映射对全部列统一使用y_scale/q_scale，不适合q平方或立方列。

不要立即设计通用类型系统。先把支持范围写清楚：线性q列、单theta谓词、特定角色类型；超范围返回不支持或补对应可证明转换，再逐步扩大。不能静默套用错误转换。

### 7.3 作用域验证还不是完整科学合同

guard目前主要靠关键字黑名单防止task_id/seed进入；陌生字段换名字仍可能通过。作用域重叠主要读取外部bounds，而没有证明bounds与guard一致。区分探针的合成未严格以两个scope的交集为可行域。

应绑定实际可用变量、来源、时点和单位；检查guard是已知上下文条件还是需要先做标定的观察统计。过去已付转移可用于决定当前装置的候选，不应被误当作每个未来样本的已知状态。

### 7.4 探针预测的sensor proxy和实际控制并非总一致

差异搜索的内部传感器轨迹使用过u=0.25q，而输出的相应pair控制把u设为0；另一方法proxy直接以控制值替代传感器值。它们可作为启发式提出者，但预测分歧不是已证明会发生在实际执行探针上的分歧。

应通过已识别仪器映射预测实际观测，或把可实现性作为子研究义务。最终仍用真实观测验收，而不是凭proxy分歧直接判反驳。

### 7.5 新ConsumptionEvent仍混合候选与实际采纳

Pass-0/1里`parent_after`会直接填第一个新候选，`probe_after`填“parametric_slot_calibration”等字符串。它们说明生成了候选或执行了内部标定，不证明真实父模型已经换成该候选，更不证明购买了一个新物理探针。

分开记录generated/selected/adopted、proposed_probe/executed_probe及后效，复用现有事件链即可。方法M1的实际探针ID差异记录比这部分更强，应保留。

### 7.6 成本账本仍存在常数代替实测

条件源返回 `og_s.get("compute_spent",45000)`，而所读helper返回字段是`compute_cost`。C脚本又使用index预算+8000计反统一，开发每项probe加350但实际执行两次35k审计；M1账本的“induction_and_selection_compute=324”不包含四候选×四任务的完整选择运行成本。

这些不等于所有目标成本都错，也不意味着必须用CPU指令作唯一成本。但来源形成和维护费用既然是协议的一部分，就必须从实际事件回传，不能使用默认常数补齐后声称全额分账。

## 8. K×M研究为什么尚未隔离核心命题

`_run_episode_with_km`中：

- K0只有两个初始源；K1额外拥有四个来源及由它们形成的家族；
- K1设置branch_reconciliation=True，打开新Pass-0标定；K0及E为False；
- E拥有共同原始priors，却没有相同的运行时家族形成/快捷标定机会。

因此B-A同时比较更多来源、新家族对象与执行路径；B-E比较的是当前端到端组织/算法包，不是纯粹的假设表示因子。

干净实验不能强迫所有组执行同一动作——研究组织本来就应改变动作。但所有组应有相同合法工具与原始信息，并能在预算内自行重建相同对象。需要明确被屏蔽的是哪项保留知识，而不是把通用目标标定能力一并禁用。

## 9. M1负迁移：是真研究结果，而不是又一次没接线

M1从真实开发probe后效拟合特征权重，并在独立开发选择题晋升。它在未见任务中实际改变探针10/12，产生29项方法消费，结果却下降。

注意实际晋升的是`disagreement_plus_scale`：其部分权重来自回归，部分被人工截断/下限化，scale惩罚0.5人工固定。报告中的原始回归向量不是最终全部执行权重。固定ensemble_std规则在开发选择上也与最终规则打平。应准确区分数据拟合、规则模板和选择结果，不把全向量都写成纯粹自主归纳。

最合理的候选解释：训练回报只偏向方向、半径和阈值不确定性下降，缺少对执行器非线性标定、完整纯控制交付与确认资源的价值；pair探针u=0可能牺牲这些内容；小选择集可能偏好某个局部尺度。但这些仍需开发阶段匹配干预验证，不能仅凭事后残差就宣布唯一根因。

本轮正确处理：保留M1为已测试的负迁移方法，普通默认先保留M0。不能在这批已曝光目标上调好M1再称新的独立成功。已有失败可成为下一阶段开发资料，另用新目标评价。

## 10. 下一阶段只做三个交付

### A. 修可信证据与局部语义

冻结原回执，追加勘误。取消后见确认门槛、人工支持补值、近似常数严格等价、未知根默认支持；修多分支反统一、完整family身份和真实成本。重放同一开发病例做回归，不宣称新的独立收益。

### B. 把现有调和算法接成一个普通研究循环

世界构造器只给公开spec与acquire。研究器从实际失败形成问题，自行选择历史分支候选，调用已有reconcile/anti-unify，在真实新观测下比较并更新。所有来源采用同一入口；harness不按relation_condition切换研究器、不补guard、不手装结论。任务序列仍可由研究者设计；区别在于不替Agent作科学选择。

### C. 一项新的、同工具同历史的冻结效用实验

优先验证K，不急于让M也成功：固定可靠M0，给普通缓存、未巩固的同历史库和自动调和库相同工具、原始来源、标定入口和预算。允许普通组重构等价族，允许打平。对自动形成的H*做删除/保留的反事实干预，原始来源保持不变，检查实际候选/探针/预测及终局。

在完成固定生成器的开发验收后，新的评估源改变阈值组合、作用域覆盖与接线，独立单位为源链。保存形成失败，不用assert中断后只发布成功分母。终局严格完成、外部预测、误确认、旧范围退化、成本分别报告。

方法层后续只研究“哪项区分实验值得执行”，使标签对应完整父用途而非单个宽度指标。仍沿用原执行器，不新增大框架。

## 11. 可以怎样写论文结论

当前可支持的窄表述：

> 在有界匿名对象动力学任务中，系统实现了可执行承诺、局部反统一、目标参数重新识别与前提引导研究。开发者编排的实验链中，参数化知识有有限后继效用，学得probe评分策略出现负迁移。若干可信语义和缓存问题已修复；完整自主调和与同工具强普通研究的因果增量仍待进一步检验。
