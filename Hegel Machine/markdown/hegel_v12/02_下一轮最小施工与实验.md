# 下一轮最小施工与实验合同（eee787bf之后）

这份文档是建议施工规格，不是已经完成的能力；不授权付费调用、隐藏扩额、覆写旧回执或操作外置封账盘。复用现有Program、WorldStructureCommitment、KnowledgeLibrary、ResearchQuestion、Probe、统一研究入口与预算系统。

## 1. 不改变目标，不继续外扩

主命题：共同底层工具、共同原始历史、同等总预算下，运行时形成/修订/调和的可执行假设，使未见任务更可靠，或在相同性能下减少完整研究资源。

不要求无任何人工先验，不要求权重训练，不要求在无限环境全面领先。不得以新的RSI最高等级代替上述有限目标。暂不扩展新PDE、SOS或通用证明器；也不重建已修的SVD、完整列保存、缓存框架。

## 2. 交付A：修复本轮发现的语义与证据问题

### A1. 确认合同

入口：`_discover_real_source`、`propose_anti_unified_generalization`与知识写入。

1. 运行前固定分别适用于来源实例、结构家族和最终目标的误差合同。可有不同合同，但必须事先明确，不因见到候选误差而变。
2. 删除 `max(1e-7,mse+1e-6)` 式后见门槛和“有theta就放宽至0.015”的隐式规则。
3. 不合格来源可以保留为候选或近似假设，结构仍可用于研究；不得写已确认，后续消费者须知道哪些支持未成立。
4. 把现有来源逐一按原合同重新分类。原始新点已经曝光，只能作为开发证据；必要的新确认另取得，费用另记。
5. 没有fresh数据是unknown，不是误差0；训练、选择、确认各有独立引用。

验收：同样的误差与同样合同，无论候选有没有参数槽，确认结果一致；失败来源保留，不因assert退出而丢失分母。

### A2. 支持与范围

入口：`shrink_claim_to_observable_scope`、guard验证、实验脚本。

- 删除0.42/0.45等人为覆盖实测统计的路径。所需支持缺失时返回`scope_unidentified`，或在授权预算内提实验。
- 支持标签引用实际证据、命题/程序版本和作用域；未声明独立支持的根默认为未决。
- guard可用变量须来自真实公开信息清单，包含单位、有效时点、是否需要先购测。黑名单只作防护，不作可观测性证明。
- guard是候选范围假设：要检验保留区、排除区和边界。不能由一项分隔统计直接覆盖整个未来域。
- bounds与guard必须一致或显式标记保守包络；scope重叠未知不默认为无冲突。
- 比较应限定在共同实验语义与合法重叠域；若条件需先标定，则先开该子研究。

验收：没有支持分隔时不得得到空guard的“已缩域”状态；当前后验结果不能直接成为同一步预测前可用条件。

### A3. 等价、反统一与身份

入口：`_programs_algebraically_identical`、`anti_unify_programs`、目标标定及family ID。

1. 精确等价与近似一致分开。比较器阈值相差极小，也不能用常数容差签发全域严格等价。
2. 支持已有参数槽与新具体值的增量匹配，并维护每个分支的替换环境。参数共享按角色与来源绑定处理，不能因数值偶合就绑定。
3. 支持完整多槽标定；不支持时明确拒绝，不静默只填第一个槽。
4. 家族ID绑定完整语义。共享predicate ID可单独保留；方向/读出/scope不同的世界族不能共用唯一科学对象身份。
5. 量纲变换只在受支持的结构上执行。非线性列用真实维度幂次；未知类型返回unsupported而非套线性比率。
6. 撤回只影响依赖已失效支持的结论；独立证据仍有效者保留；无根循环不得自我支持。

最小回归：
- `x>0`与`x>5e-10`不被当严格相同；
- `.22,.46,.34`三个同骨架分支可得同一参数族，交换输入顺序不改变语义；
- 两个不同方向的相同predicate家族有不同科学ID；
- 无证据新根不变成grounded；
- 两参数谓词能完整绑定或明确unsupported；
- q平方量纲变换不使用q一次方系数规则。

### A4. 预算及遥测

- 来源第一阶段、两次局部生成、公开sweep、额外拟合、巩固、反统一、开发选择都从实际返回汇总；删除45000、8000、350等填补实测账本的常数。估算可以存在，但字段明确estimated，不与measured相加后称实测。
- 对主循环与fallback，在操作前分配剩余预算；外层不得仅事后发现超额才拒绝计分。
- ConsumptionEvent区分候选产生、真正采纳、探针提出、探针执行。`parent_after`来自实际采纳结果，不填第一候选；没有购测就不能填一个看似probe ID的字符串。
- 不必保存全部庞大日志。保存能重建一个关键对象来源、变更、消费与结果的最小链即可。

## 3. 交付B：普通入口上的一次完整自主调和

### B1. 隔离世界构造与研究器

实验脚本只负责预先生成任务与预算，以及调用同一研究入口。真机制标签不得用于决定走unconditional路线还是条件补丁路线，也不得决定哪两个假设该被融合。

允许固定原语和候选语法；它们对所有组相同。研究器可以根据实际数据从有限目录选择，结论称“有限语言中的发现”；不必包装成任意语言创新。

### B2. 调和事件由实际失败/重叠产生

普通循环的最低需求：

```text
新观测或新候选返回
→ 更新该版本实际支持/反驳
→ 检索同语义且可能重叠的旧假设
→ 找可执行差异；无差异证据不自动等价
→ 在授权下购测区分实验
→ 对每个被检验声明分别更新
→ 提出缩域、参数族、表示修订或保持竞争
→ 用旧有效区/真实反例/新点检验
→ 存为可复用对象
→ 当前任务继续，后效返回原理论问题
```

反统一pair候选由类型、角色、结构差异产生，不按“right/left真值家族”从harness喂配对。不能先写`conflict=True`代替实际重叠与预测分歧。

### B3. 不把“研究未知”做成停机

找不到合格融合可保留条件分支；所有当前模型都失败时，提出对父用途有辨别力的观测/表示/局部结构问题。预算耗尽返回未决，不能宣布整个语言被否定。无支持的复杂提案可入候选档案，但默认使用较可靠旧方法。

### B4. 一条开发链的最低内容

形成H0，正常迁移；在新域失败后形成H1；另一段真实经历形成H2；系统发现相关性并检验是否可形成H*；加入一个确有冲突的分支；至少发生一次正确保持分歧和一次有支持的统一；旧条件返回；最后未曝光新源检验。

不要求每链必然合并成功。没形成就是研究失败/未决，应留在分母。任务顺序可以由研究者设计，科学决定不能由harness预写。

验收重点不是八个stage标签，而是：一个新增对象的源码内容和证据确实由运行时经历决定；拿掉它会改变真实研究行为；在旧有效域和新域具有可核验结果。

## 4. 交付C：干净的知识效用实验，方法学习先保留负结果

### C1. 固定M0先测K

组别建议：

- R：优化普通档案。可用全部原始经历、缓存、候选语法、目标标定、局部修订；允许重建等价家族。
- K-fixed：相同起始知识和历史，但不保留本轮新增H*；来源数据仍可访问，以隔离新增对象的价值。
- K-reconcile：相同工具和历史，由普通入口自主产生并维护新假设与分支关系。

所有组拥有相同family拟合API；不可通过关闭一组Pass-0通用标定能力制造“知识内容效果”。处理因子可以改变优先级与预算使用，但须在事前声明。

### C2. 两类干预各回答一个问题

对象删除：从冻结后的库删除H*，保留原始经历、旧分支和工具，重新运行目标研究。它测对象直接效用；普通组可能重建H*，这也是结果。

结构关系删除：保留相同预测程序，删除作用域/支持关系或替换为原普通组织，在不关闭求解器的前提下比较。它测组织关系效用。

不要把“一个更强候选”与“整套递归架构”混为单一处理。

### C3. 新评估与指标

旧B/C队列已经用于诊断，后续只能作为开发/回归。新评估在完整提出者、候选语法、工具、容差、失败处理与预算冻结后生成。

独立单位为真实源组/整研究链；同时改变关系参数、可观测范围、分支到达顺序和匿名接线，不只重复两组相同阈值。所需链数由开发阶段方差与计划检测效应决定，不事后挑种子。

必须分别报告：

- 所有形成尝试及失败；
- 严格任务完成；
- 外部冻结预测误差及信息时点；
- 内部确认后外部失败次数；
- 旧有效域/少数分支的退化；
- 支持的源形成/维护成本、目标成本、墙钟时间；
- 对象真实调用及改变候选、实验、最终预测的链。

不事后改变“纯控制交付”或确认门槛来让表格好看。若多个指标权衡，报告原指标，不以任意加权总分抹去。

### C4. M1的下一次学习

当前M1负迁移保留，默认M0。新方法候选应考虑完整研究状态：角色未识别、作用范围未识别、执行器标定不足、待确认资料缺口，而非只优化方向/半径/阈值宽度之和。

先在开发阶段做匹配干预验证失败原因，再生成新策略。允许线性评分器，但其监督目标要关联完整父任务与资源；不得直接把事后知道的失败原因手写成“学得策略”。若使用手写修复，作为工程baseline，与真正由经历形成的版本分别报告。

更强M1→M2可随后在新的独立评估中检验；二代开发选择打平不是主目标完成，也不是当前K学习必须等待的前置。

## 5. 停止规则与交付物

A失败：停止相关科学claim，不在其上叠加更多世界。

B只有脚本机制例：保留为组件验证，不称自主完整链。

C与强普通档案打平：结论为该范围未见额外效用，缩小论文主张；不得削弱基线。

C有正收益：报告范围、失败和置信界；优先独立复制，不马上扩展到“通用哲学谱/RSI全部实现”。

最少交付：修复diff与行为回归、一个完整普通入口的真实知识链、一个冻结同工具协议及独立原始结果。文件数、测试数、hash数、图节点数均不作科学完成指标。
