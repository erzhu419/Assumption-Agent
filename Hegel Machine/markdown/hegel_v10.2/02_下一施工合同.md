# a66cd82b之后：最小歧义施工合同

## 1. 目的与范围

主线仍是v4：从研究经历形成可检验知识，再让这些知识改善后继的解释和研究。v10新增工具保留，不以重写为前提。当前优先级为：**可信语义 → 同能力归因 → 一条知识生命周期**。

本合同不授权新付费模型调用、隐式扩大实验预算、覆盖旧回执或改动外部封账盘。所有新运行写入新目录并引用固定版本。

## 2. 交付A：证书、确认与报告修正

### A1. 统一证书的任务语义

输入：固定模型、初态、动作合法域、状态合法域或分析域、成本函数、目标、时间/预算约束。

必须先确定state_bounds的性质：

- `physical_legality`：执行器、规划器、证人和不可达验证均采用。
- `analysis_region`：需要独立的包含/归纳义务，未成立则只有条件结论。
- 未声明：不能默默用默认盒域证明全域不可达。

共享实现负责检查维数、有限参数、成本与fuel非负条件、初态合法性和目标矩阵完整性。禁止一个消费者忽略另一个消费者证明中关键使用的约束。

可采用的返回语义：

```text
witness_verified_in_declared_model
impossibility_verified_in_declared_model_with_domain_obligations
conditional_impossibility_domain_unverified
unknown
invalid_certificate
```

这些状态可以映射到现有结果对象，不要求新增一套框架。未证实的物理假设留在支持前提中，不自动变成环境事实。

### A2. 形式声明与实际证据对齐

最小选择是：保留Python精确证书检查，停用“Lean已证明”的宣传；Lean导出状态为`draft_only`。

若保留Lean claim，则必须：

1. 真实定理包含当前模型、任务、目标、域与证书义务，而不只是定义V。
2. 编译命令与返回码保存。
3. `#print axioms`及实际定理名保存；核查定理指向当前版本且非空洞。
4. Python与Lean模型具有明确对应；数值有理化不隐藏。
5. 可达、不可达、每类不变量分别实现，不套同一个水库模板。

本交付不新增SOS、通用定理生成器或三维物理模型。

### A3. 科学证据身份修正

对Phase2B源候选：真实fresh48通过事实保留；将写入知识库的确认误差/行数改成该48行的实际结果和引用。validation继续标为开发选择材料。

对SDE：原`oracle_zero_noise_drift_mse`重命名或附明确定义为无噪孪生轨迹误差。不能直接引用为带噪条件风险。在线completed、随机路径损失、孪生指标分别显示。

对Phase5C：将4类故障改为单一端口增益家族四实例；89.92%明确为名义计划估算，除非真正补跑匹配实验；8/8与0/8改为求解/检查能力对照。

### A4. 来源与旧账

原回执不可覆盖。生成一份勘误索引，列出旧claim、实际支持、纠正原因及新证据位置。不把size+mtime检查称为逐字节哈希一致；它能支持未观察到该元数据变化，不能替代内容哈希。后续需要内容完整性时对指定小型封账文件作只读SHA256，不扩大扫描范围。

## 3. 交付B：一次同等能力的开发归因

### B1. 固定什么

固定：实验室公开接口、所有物理家族求解器、Program原语、数值精度、角色解析工具、审计/探针工具、已付历史、候选上限、提出者及调用上限、世界确认标准。给所有组完整而相同的合法能力访问权。

不必强迫所有组执行同一序列。研究组织的作用本来就是改变调用顺序；但不能用禁用某组工具来制造优越性。

### B2. 比较什么

三种对象明确区分：

1. **工具效果**：旧求解器vs新增求解器。原Phase3/4/5可以保留，正确命名。
2. **知识内容效果**：同工具、同历史，原始档案可重建vs已巩固知识可调用。
3. **依赖组织效果**：相同角色化模型、相同内容、相同操作空间，是否提供/使用实际支持依赖。

先选第2或第3其中一个，不同时用一个宽泛三臂表宣称二者都隔离。

### B3. LLM最小匹配

依赖实验两组都可见同一：父模型、角色及单位、原始数据、候选语法、拟合/校验函数。区别仅为依赖线索。没有线索组仍可自行推导它；不禁止更聪明的基线。

想研究“局部补丁vs从头生成”，另列该因子，不再叫依赖单因子。模型调用、token、推理强度和时间分别限制并记录；不要以调用次数相同假装可见信息相同。

### B4. 必须可重建的结果链

```text
公开问题和父对象
→ 候选来自什么证据/提出者
→ 使用了什么保留知识
→ 实际选择的研究/探针
→ 实际结果
→ 父模型变化
→ 新轨迹预测
→ 知识后效更新
```

报告各阶段数量；不能只保存最后pass布尔值。

## 4. 交付C：一项有限、持续的科学学习实验

### C1. 推荐学习对象

使用已有开放关系谓词或非线性驱动，不增加新benchmark专属原语。学习对象为：一个有范围的结构模式、哪些参数需目标识别、哪些前提被后续使用。

允许失败、仅局部有效和未知。不要求在所有源上形成同一规律。不得按“需要正例/负例”反复挑seed。

### C2. 具体生命周期

- 源：观察、提出、检验；保留产生过程和全部失败。
- 冻结：生成器/策略和学得对象在目标曝光前冻结。
- 迁移：改变参数和对象数量，正常复用或拒用。
- 反例：改变一项旧承诺；不能直接告知正确新机制。
- 子研究：答案必须改变父模型、实验或当前判断；独立诊断程序不能只写文字。
- 修订：保留不受影响部分，重新检验受影响范围。
- 返回：旧条件再次出现，检验是否恢复旧知识而非强行沿用最新模型。

一条开发链只做接线与行为资格化。后续任务链数量按完整预算和所需统计分辨力预登记；物理来源为基本样本单位，不能把同源48行当48个独立世界。

### C3. 强普通基线

A允许使用所有通用工具、共享来源、检索与重新拟合，允许重建等价方法。C的持久对象属于被研究处理，来源形成/维护费用单列。共同旧库形成成本共同承担，不重复计入某一臂。

分别报告源成本、目标成本和序列累计，不用未经定义的单一加权分数抹掉资源权衡。

## 5. 必须通过的行为验收（不是新增科学样本）

1. 同一任务语义不能同时得到认可的可达证人与无条件不可达结论。
2. 本报告给定盒域反例必须由合法性检查或未证域状态正确处理。
3. 初态域外、动作导致域外、负成本、维数不合与目标截断不被静默接受。
4. 有理化改变数值时，输出所证明的实际有理模型及其范围。
5. 不含定理的Lean文本不能标成proof_verified。
6. 有限N核验不能返回all_arity_proved。
7. 单调性/非负性所需方向和域前提不只存在于注释。
8. supplied_model工具试验和learned_model真实研究有不同来源标记。
9. 确认行、选择行和拟合行可区分；已有真实确认不丢失，也不重复计数。
10. 旧世界假设被反驳后，其计算可以保留，但失效支持不能继续用于当前决策。
11. 完整列和参数共享经过保存/恢复/重绑仍保持；零权重列不丢失。
12. 局部变更使所有真实依赖失效，但无关结果可复用；同名步骤不混淆具体实例。
13. 同工具普通基线能合法调用所有新增求解器和检查器。
14. 依赖消融不同时给处理组额外角色答案或不同的候选语法。
15. 无实际调用的对象不生成“使用后无益”标签。
16. 未完成、未交付、行政中断、科学反驳分别统计，不给缺失MSE填0。
17. 噪声孪生误差不被自动输出成真实带噪历史的条件期望风险。
18. 新代的错误知识不会因为source_status=supported永久通过；未解决的替代解释保留。
19. 原API无私有字段访问只是必要检查；运行时允许信息清单和传输内容也要可审计。
20. 所有调用和成本都来自真实事件；公式估算与实测字段分开。
21. 来源/目标首个通过者选择如实保留失败分母，不回写原结果。
22. 测试全通过与科学效果不混称；局部28项通过不称全仓兼容已证。
