# Hegel M2：原始目标、历史能力、里程碑与文献证据审计

固定版本：`9115f9adf9dad1f52f106a2ab14babe8b68243dd`。审阅日期：2026-11-19。本文为并行审计的历史与文献子报告；当前实验复算、反事实运行与消费者接口的最终结论以主审及另外两个专项报告为准。

## 一、核心判断

当前 M2 最需要修的，是“经验改变知识、知识改变后继研究”的真实接线和因果归因。局部条件树森林、多精度对象、跨域映射、近失例修订这些方向与项目初衷一致，应当保留。有限函数族、合成环境、确定性程序、早期四簇实验都可以作为阶段性切片；不能仅凭这些简化就宣布项目失败。相应地，真实文件系统、子进程和 AST 摘要也不能自动证明开放创发、科学一般化、图结构独立优势或完整 RSI。

有一项直接、最新且不需要援引宏大哲学目标的验收缺口：V16.7 的 **09报告第96行**把下一步 M2 定义为“开放代码工作区与在线 LLM 自主合成接线”，明确要求代理从实际残差自主提议 `ClaimContract / ObservationMap / ScaleMap / program_steps`，并“替代固定插件语法枚举”。V16.8 的 `open_workspace_wormhole.py` 使用固定 `_WORKSPACE_SYNTHESIZER_SCRIPT` 生成各预定函数族模型。它完成了一段工作区与评测接线，但这与“09所约定的M2全部完成”之间仍有实质距离。

这个缺口应表述为“已有开放作者能力未接到这条 M2 路径”，而不是“整个 Hegel 从来没有开放语法、LLM 创发或真实 Python 工作区”。历史代码与原始结果明确反驳后者。

## 二、原始目标究竟是什么

初始五篇长文是多轮讨论，包含提案、反驳、后续修正，不能把任何一段助手意见提升为唯一项目规范。若按用户在《黑格尔机》的明确要求和随后反复澄清综合，目标可以拆成四个可检验环节。

### 1. 假设空间自身能够改变

《黑格尔机.md》1–46行区分在给定假设空间中选一个假设与扩充表示语言：当已有22类元假设表达不了反复出现的残差时，允许形成新的谓词、类型、关系、算子或先验。这一目标在1186–1228行以及2430–2442行重申；后者清楚区分：A确认、B参数或范围修订、C发明。A/B是必要基础，C是长期目标。

因此，仅从一个预先规定的函数族中识别出参数，不应计作语言层新发明。反过来，一个阶段只验证A/B并非无价值；需要把它的证据层级写对。

### 2. 新知识要保留旧经验中仍成立的部分

《Hegel_assumption.md》560行附近把哲学历史的工程含义写成从旧概念边界生长、保留有效部分。《黑格尔机.md》1861–1921行列出候选扩展需要面对的要求：旧成功、新残差、限制情形、表达能力、复杂度、可区分的新预测等。

这支持局部范围修订和分支，而不支持把所有知识排成一条全局强弱直线。新反例推翻一个强单指数式，不必推翻更弱的诊断程序或其他范围内已经验证的关系。保留森林与局部回退符合这条原则。

原典方面，已存在本地《哲学史讲演录》第一卷全文。本轮核读导论约1006–1055、1270–1340行：Hegel讨论诸哲学的内在联系、具体性的展开以及哲学与其历史同为发展中的体系。它为项目提供思想来源，不构成任何特定工程算法必然有效、任何新假设都可从历史自动推出的实验保证。

### 3. 一般化必须改变未来的搜索或实验

《黑格尔机.md》403–443行已经警惕“检查用户提供的候选”与“系统自己生成候选”的区别，736–760行要求程序库改变未来搜索，而非只保存答案。

对当前M2，真正有意义的闭环是：原始经历→竞争候选→区别性检验→新条件/程序版本→未来目标上可追溯的实际动作。若近失例只添加 `CEGAR` 名称，或删改所学对象不能改变动作，则还没有证实这条闭环。若内容确实改变了探针、回退、拟合或停止决定，即使内容只是小型DSL中的程序，也已是值得保留的阶段成果。

### 4. 效用相对于会学习的普通方法成立

后期的V16.5主计划进一步把目标具体化为：同模型、工具、源历史、主动采样、程序归纳、缓存和重建权限下，在冻结未见分布中维持质量并降低生命周期费用，或提高完成率。它不要求其他方法永远不能学会同一知识，而要测持久化、条件组织、召回和消费的真实收益。

这也是为什么给普通组或条件技能组缺失历史消费、映射或误差检查会破坏核心论证。纠正这些缺口属于实现用户自己的研究目标，不属于为了审计而削弱项目愿景。

## 五、关键文献到底支持了哪些机制

### 1. ALIGN更贴近本项目的近失例条件修订

[ALIGN2015原文](https://www.qrg.northwestern.edu/papers/Files/QRG_Dist_Files/QRG_2015/McLure-Friedman-Forbus-AAAI15.pdf)全文7页主文本轮已读。pp3–4的具体机制是通过结构检索寻找相似但标签不同的例子，从正负方向候选推断形成包含/排除条件，再用后来正例去掉过强条件；多个簇可以保留不同条件。候选被检索到与条件检验通过是不同步骤。

对M2最有用的对应是：`nm_M2A`到底导致哪条可执行条件改变？后来的正例能否修订误排除？同一条件删除/改写是否改变目标动作？论文支持这些机制设计，不自动证明M2已经执行这些机制，也不证明全部跨域科学规律。

### 2. CEGAR是受合同约束的抽象精化，不能凭名称继承保证

[Clarke等JACM2003](https://cse.usf.edu/~haozheng/lib/verification/abstraction/cegar-smc.pdf)本轮核查§1、§3及§4.1/4.2。§3的性质保持有明确模型/公式/抽象函数条件；§4.1首先判断抽象反例能否在具体模型中实现，若是伪反例则细化抽象以消除它。

Hegel把失败观测用于局部模型或范围修订，可以合理称“CEGAR启发的反例驱动修订”；若没有上述语义对应，就不应暗示继承模型检测中的完备性或无假阳性保证。M2当前修复重点不需要全面移植符号模型检测，只需要确保真实冲突确实驱动了实际合同变化。

### 3. 结构映射产生可检验的候选，不是保证正确的AST同一性

Gentner1983本轮读pp155–159；其核心区别是关系系统的对应与对象表面属性的相似，并由对应关系产生候选推断。ALIGN进一步给出匹配、检索、条件检验的算法组合。M2 AST骨架可用来召回候选；变量、单位、符号、数值常量和观测协议的合法转换仍须另外验证。

当前 `canonicalize_python_model_ast` 优先读取 `_CORE_LAW_EXPR`，再退回`predict`的return式；`_SkeletonNormalizer`将数值常量规范成NUM。即使生成器诚实提供这些表达式，所得digest也只证明某种规范化语法相同。若把它直接叫物理定律发现或语义同构，就跨过了尚未证明的步骤。主审的变异控制可具体检验这条边界。

### 4. DreamCoder/LILO/Stitch提示“抽象被以后使用”才是关键

DreamCoder PLDI2021本轮核§2.4/3：从现有程序中归纳可复用组件，并使新库影响之后搜索。LILO本轮核§3：压缩得到新函数、更新library、重写已有解、为以后生成提供命名与说明。Stitch核了LambdaUnify/作用域及重写正确性相关段落。

这些方法允许有界搜索和固定基本算子，因此不能以M2不是无限开放搜索来否定它。关键区别是是否真正形成新可调用抽象、重写或影响后续解法。文件被写成Python、两个模板拥有同一digest，尚不足以证明这一点。

### 5. HExA本身有条件、错误经验与跨任务重写

[HExA v2](https://arxiv.org/html/2606.29315v2)本轮核B3/B4/B6/B7。它的技能包含适用情境、机制、例子和来源，保存失败经验，并从跨源任务库选择、去除表面实体、重定向到新任务。论文展示结果使用static injection；不能要求每个baseline都做within-seed更新才算忠实。

因此比较中的`O_HExA_CodeSkills`若只获得无条件平面模板或被禁止携带同样的scope/误差合同，不足以代表HExA式条件经验消费。可以保留“受启发的本地简化baseline”标签，并准确说明能力边界。

### 6. HippoRAG服务召回，不替代科学证据

[HippoRAG2](https://arxiv.org/html/2502.14802)本轮核摘要与§3方法；三元组/段落索引和PPR用于候选检索。PPR有潜力在异质名称之间找关系路径，但找到了路径不能自动证明映射可执行、组成误差合格或目标外推正确。

对当前M2，保留图边与未来PPR扩展很合理；比较图本身贡献时，同内容Flat也应能拿到相同端点、映射、近失例条件与误差信息。让Flat忽略误差规则再说“只有图能防非传递”属于把消费者能力差异算成存储拓扑收益。这项判断首先是实验设计推论，不依赖声称HippoRAG论文已经替Hegel证明了什么。

### 7. MathRSI/AWM的可借鉴点是调用链和证据边界

MathRSI本轮查看的是固定官方实现材料，未找到并声称读完一篇统一“MathRSI论文”。本轮完整读官方`docs/SKILL_ACCEPTANCE.md`：结构/接口检查、历史成功、真实行为试用和长期研究效用必须区分，通用提速/RSI效果需要额外评测。此前本地材料包含实际输入覆盖、原caller接回、共同演化和独立检查的完整原件，可用于后续适配。

AWM本轮仅重读摘要并核旧审计的定位材料，不能冒称重新全文阅读。旧原文的模型内证明与环境符合性区别，以及构建抽象后测后继问题成本的实验结构，与Hegel接线/归因目标相合；其数值不作为本轮独立重验证据。

## 六、合理简化与必须修的问题分界

| 合理保留的阶段简化 | 不应由此直接推出 | 必须补的最小证据 |
|---|---|---|
| 有限函数族、人工共享原语、确定性归纳 | 已完成09要求的在线开放作者与合同创发 | 明确切片命名；复用现有作者入口完成一条残差→新程序/条件→未来消费链 |
| 合成环境、新参数种子、重命名与单位变化 | 已覆盖独立学科机制或开放世界 | 分开新参数/新表征/新过程/新机制；冻结后独立过程检验可后续进行 |
| AST标准化做召回 | 科学同构、符号不重要、数值参数可任意丢弃 | 保存并执行合法绑定、协议、输出尺度、误差和当前目标检验 |
| 近失例后增加分支 | 发生了经验驱动修订且提高效用 | 修改/移除该条件改变实际动作；确认失败不授权更强主张 |
| 小库保留森林/图结构 | 小库下图必然胜过同内容Flat | 同内容同权限同映射，单因素对照；平局或轻微额外成本可接受 |
| 代理费用与少量簇早期诊断 | 真实LLMtoken/研究时间已节省，总体分布效用已证 | 调用向量、代理权重、源与校准投入、失败分母分别报告 |

不建议为解决这些问题另造更大框架，不建议全砍森林/多尺度，不建议先加几十个同模板种子。最有价值的下一步是把一个已经存在的开放作者和一个具体多精度对象接进真实消费，再用对等baseline检验这条链。
