## 二、第一手数学资料

### M1 — ISS

- 标题：Certifying Interventional Agreement Among Observationally Equivalent Causal Models。
- 作者：Sourena Khanzadeh、Daniel Platnick、Marjan Alirezaie、Hossein Rahnama。
- 固定版本：https://arxiv.org/pdf/2609.32247v1 。
- HTML：https://arxiv.org/html/2609.32247v1 。
- 实际读取：§3 定义 1、命题 1，§4 的算法/证书条件，连续版本命题 4，以及附录 B 命题 6；PDF 第 6、22 页已渲染并视觉核对。
- 支持的结论：精确回答的局部等价与反向超度量性质；连续容差证书另有真实模型包含、观测误差条件；模型失配需另外检验。
- 本地缓存：`sources/ISS_2609.32247v1.pdf` 及同名 `.txt`。
- 获取方式：网页正文抓取未成功；已从官方固定版本 PDF 下载并核读，因此本报告依据 PDF 而不是失败网页。
- 限制：没有核验论文所有实验，也没有把其模型类内证书直接移植成 Hegel 全域证书。

### M2 — Kron 原论文

- 标题：Kron Reduction of Graphs with Applications to Electrical Networks。
- 作者：Florian Dörfler、Francesco Bullo。
- 发表：IEEE Transactions on Circuits and Systems I, 60(1), 150–163, 2013。
- 作者原件：https://motion.me.ucsb.edu/pdf/2011d-db.pdf 。
- 实际读取：开篇前两页，特别是端口电流—电压方程、Schur 补和被消除节点注入的对应映射。
- 本地缓存：`sources/DorflerBullo_KronReduction.pdf` 及 `.txt`。
- 限制：未声称已完整核查全文每一个拓扑/谱定理。报告的状态空间动态消元公式属于直接代数推导，不冒充该论文对任意动态系统的保证。

### M3 — van der Schaft 2015 章节

- 标题：Physical Network Systems and Model Reduction。
- DOI：10.1007/978-3-319-21003-2_11。
- 官方大学原件：https://pure.rug.nl/ws/portalfiles/portal/64854097/Schaft2015_Chapter_PhysicalNetworkSystemsAndModel.pdf 。
- 实际读取：§11.2.4 详细平衡耗散相关式；§11.3 的聚类式 11.26–11.32、指定输出及分区条件；§11.4 的快慢约化式 11.36–11.39 与结尾对近似性质、快慢选择的讨论。
- 支持的结论：保持网络结构与保证指定输入输出近似是不同要求；动态约化的快慢分离与精度需要额外条件。
- 本地下载状态：本地直接下载返回 403；本轮使用成功 web 正文。不得声称本地有该章节完整 PDF。

### M4 — 近似模拟原论文

- 标题：Approximation Metrics for Discrete and Continuous Systems。
- 作者：Antoine Girard、George J. Pappas。
- 发表：IEEE Transactions on Automatic Control, 52(5), 782–798, 2007。
- DOI：10.1109/TAC.2007.895849。
- 作者原件：https://georgejpappas.org/papers/J29.pdf 。
- 实际读取：摘要、有关观察距离的基础定义、定义 10–11、命题 2、模拟距离相关段落。刊页 786（PDF 第 5 页）已渲染视觉核对。
- 支持的结论：固定正容差关系一般不构成通常意义的传递关系；两个模拟误差在组合时需要相加。
- 本地缓存：`sources/GirardPappas2007_ApproximationMetrics.pdf` 及 `.txt`。

### M5 — 聚类约化原论文

- 标题：Structure-preserving model reduction of physical network systems by clustering。
- 作者：Nima Monshizadeh、Arjan van der Schaft。
- 固定版本：https://arxiv.org/pdf/1403.4789v1 。
- 获取方式：原文来自官方固定版本 PDF 本地下载；大学条目用于交叉核对元数据。
- 实际读取：摘要、指定输入输出下的误差分析、定理 6；PDF 第 6 页已渲染视觉核对。
- 支持的结论：文中 H2 误差结果有 almost equitable partition 和特定输出条件，不能用于任意聚类、任意读出。
- 本地缓存：`sources/MonshizadehSchaft2014_Clustering.pdf` 及 `.txt`。

### M6 — 作者 RG 讲义

- 作者：David Tong。
- 标题：Statistical Field Theory, Chapter 3: The Renormalisation Group。
- 官方作者网页：https://www.damtp.cam.ac.uk/user/tong/sft/sfthtml/S3.html 。

- 限制：本轮未从该材料推出雪花、蜂巢、水/氨或经济模型属于哪个具体普适类。

## 三、本轮独立解析核验

`verify_multiscale_contract.py` 使用 Python 标准库，可通过以下命令复算：

```bash
python verify_multiscale_contract.py --output multiscale_contract_verified.json
```

输出包含六个有明确用途的核验：

1. 三个标量回答表明固定 ε 接近关系不传递。
2. 两个不同衰减率的状态求和不必形成自治闭合粗动力学。
3. 全局严格凸梯度系统的有限幅度共轭响应仍可能增强；同点局部 Schur 界继续成立。
4. 理想零阻回路在固定初态与同终点输入下，没有稿件所要求的输入历史差异见证。
5. 两种 SLS 拓扑对应不同 τ 和冻结刚度。
6. 双指数模型可以完全松弛，故该性质不依赖单模。

没有调用 Hegel 接口，没有访问模型服务，没有拟合或选择测试集，没有由这些数学核验推算任何项目成功率。
