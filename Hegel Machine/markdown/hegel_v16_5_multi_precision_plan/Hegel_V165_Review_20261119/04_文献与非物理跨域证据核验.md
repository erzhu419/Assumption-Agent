## 3. 最影响方案判断的三组现代实证

### 3.1 Continual-ARC：数值大体引对，指标与外推必须限界

U02:L36 的程序库数值可在 v3 Table 1 找到：GLM 程序库的 `S_seen=0.81`，两个程序库的 `S_held=0.03/0.05`，后两项区间均跨零。它们是 Eq.(4) **相对同一系统 reset 版本节省的反馈预算比例**，不是成功率、迁移概率或整套系统的计算成本节省率。

Appendix A 明确说明：该基线每题保存一个完整程序，所测学习器没有保存可复用低层原语；作者将未见任务迁移不足归于这些具体学习器，并引述程序库学习可以形成共享原语的既有证据。故本结果支持“整题缓存的保持效果不能替代跨题获取能力”，不支持“精确可执行程序本身无法泛化”。[S01：§2.3–2.4、Table 1、Appendix A]

**对 Hegel 的改变：**保留同题保持和未见任务两种评价，同时加入可抽取、组合、缓存程序原语的普通对照。不能先把 ordinary 限定为逐题整段答案缓存，再把新题差距归于 Hegel 的理论图。统计上应区分“本次未显示稳定正收益”与“已证明迁移收益恰为零”。

### 3.2 Hu 等：存在有用的反转案例，没有普遍反转定律

U02:L37 选取的 A→B 数字正确：ALFWorld Raw 的 FWT 为 −9.5 pp，Insight 为 +6.5 pp；BabyAI Insight 为 +9.0 pp。但 Table 3 的反向 ALFWorld Insight FWT 为 **−2.5 pp**。Table 4 的 ALFWorld Insight BWT 两方向为 **−1.0 / −3.5 pp**，直接否定“消除反向遗忘”。

FWT 是“先学源再学目标”相对“只学目标”的差，不是零样本迁移。ALFWorld A→B 两方法最终成绩为 71% 和 72%；不能把两个不同基准上的 FWT 相减，称为抽象方法最终高出 16 pp。研究每环境只选一对任务族，表示、检索粒度与方向均影响结果。[S02：§2.3–2.4、Tables 3–5]

**对 Hegel 的改变：**把本段改成“同任务表现不能预测跨任务表现，必须实测迁移方向及负迁移”。它支持加入相容迁移、部分共性、误导性近邻与旧任务回访；没有直接证明多精度 DAG 是胜因。原始经验、摘要、细粒度技能、周期检索都应是可调普通方法，不宜把其中一种预先定义为低级失败组。

### 3.3 HExA：确实是强竞争基线，能力不能被概括成无结构文本库

U02:L38 引用的投石机 11%→44% 是论文特定跨任务合成设置的结果，不是所有目标或全生命周期收益。B.3–B.4 的技能有适用条件、例子、来源和奖励排序，错误条目含诊断、原因与修正；跨轮过程可以细化、合并、替换旧原则。B.8 明确其层次来自反复抽象与组合，只是没有显式树。

B.7 还定义了逐步实验后确认、限域、丢弃技能的可选模式；但作者明确当前结果使用静态技能注入，不能把可选模式当作已测结果。反过来也不能声称 HExA 在设计上没有反例修订。它没有由论文建立 Hegel 式可执行范围证明、透镜校准和精度边语义，这仍可成为待测差异。[S03：§4.4、B.3–B.4、B.7–B.8]

**对 Hegel 的改变：**`O_HExA` 至少保留条件化技能、失败恢复、来源、跨轮演化与合成能力。应明确采用论文静态推断版本还是可选动态版本；若增加动态版本，单独报成本。Hegel 的新增价值应表述为“显式可执行治理能否减少错误迁移或总成本”，不能预定为“有 DAG 必胜扁平库”。

## 4. 真正可迁移的机制，而不是再增加一排论文名称

### 4.1 SME / MAC/FAC / SAGE：召回、对应、候选与范围修订各有角色

作者对 SME 的描述是：输出关系对应、候选推论和结构评价；MAC/FAC 先用便宜内容向量筛选，再对少量候选进行结构比较。U02 对这两点的理解正确。[S04–S05]

本次补核 **ALIGN（AAAI 2015）** 提供了比“同指纹建立桥接”更接近本项目的方案：SAGE 对对齐案例增量聚类，用同簇出现频率描述关系；ALIGN 召回结构相近但标签不同的 near-miss，产生包含/排除条件，再用后续例子修订过强条件，同一概念可有多簇。它依赖给定标签与关系表示，结果是两个分类任务的证据，不是一般科学因果发现的保证。[S06：pp.566–569，Fig.4–5]

可以只借其中一个小环节：已有对象的相似候选与真正矛盾证据都进入同一对齐器；把未匹配关系作为待测范围条件，不直接当成已知因果。形成新版本时写出哪些例子引入了哪个条件、哪个后续例子迫使它撤回。频次、相似度、模型信心均不得直接等同世界支持。

### 4.3 LILO / Stitch：使“形成新抽象”有可执行证据

LILO 的循环是真正的程序搜索、压缩、改写与命名文档：候选程序通过解析、类型和执行检查，Stitch 发现可复用代码片段，AutoDoc 帮助后续模型理解新原语。其抽象不是由好听名字获得成立资格。[S09：§3、Alg.1]

对 Hegel 的有限借鉴是把候选研究程序写成可展开的组合：保存绑定、输入输出和来源，检查展开前后在合同上的行为，再验证后继任务是否更便宜。压缩目标和代码长度可以筛候选，不能代替未见任务的全成本收益。没必要为了借入这点先重建通用 DSL 或新框架。

## 5. 非物理跨域簇：哪些能变成可测程序

### 5.1 饱和簇：保留有条件的模型族，删掉两点验证与机制万能解释

以下是对 U05:L47–55 所给公式的直接代数核验，不是论文实测：

\[
y_{A}(u)=\frac{1}{1-f+f/u},\qquad
y_{M}(u)=\frac{V_{\max}u}{K_m+u}.
\]

在量和参数域合法、分母非零时，两者都可写为

\[
1/y=\alpha+\beta/u.
\]

但参数对应不同：Amdahl 中 `α=1−f`，Michaelis–Menten 中 `α=1/Vmax`；后者不是串行瓶颈占比，量纲也不同。若先把输出按各自上限归一化，则可以得到同一个有理函数形状族；这种坐标与单位约定必须记在映射里。

两次无噪声测量最多确定预先选定模型族的两个参数，不能检验这个模型族。许多别的曲线也经过同样两点；`f=1` 的理想完全并行情形也没有有限 Amdahl 饱和上限。逆变换会改变观测噪声的分布，不能忽略后继续沿用原容差。

**可执行版本：**先在两个点拟合候选，用至少一个未参与拟合的位置检验预测；若更关心调参决策，则直接设计能区分“双倒数曲线、分段瓶颈、线性、非单调或状态依赖”的资源干预，并按结果选择下一动作。有限观测只能在所测范围拒绝线性预测，不能自动证明无穷远渐近线，更不能唯一推出“串行瓶颈”。

对于 `min(c1u1,c2u2)`，可以保留单调凹性和局部资源竞争问题；但两瓶颈可能并列，扩容后瓶颈会转移，观测与探测有代价。应删除“当前唯一”“瞬间省去全部”的表述。所谓回退收益必须由具体剩余候选与节省动作证明。

### 5.2 二分簇：保留真正正确的弱条件，精确写出找到什么

U05:L62 有价值：在有限有序离散输入、确定且可重测的二值 oracle 下，两个端点标签相反就存在某个相邻翻转；不需要整个区间单调。保持异标签端点并折半，可在对数次查询内找到一个相邻翻转。

但 U05:L66 的“首个有效故障切换点”可能被理解为全局第一个；非单调情形不能保证这一点，也不能以对数查询找出全部切换。U05:L61 的巨大局部差值也不足以证明真正不连续：陡峭连续曲线、噪声、协议或隐藏状态都可能产生这种观测。

**可执行版本：**让结论类型明确为 `some_adjacent_flip`；只有独立支持单调条件时才升级为 `first_global_threshold`。连续控制还需目标容差、复测协议和取中点可执行性。HExA 的“诊断悬崖后换搜索策略”可作为候选启发，但不能替代这些前提。[推导针对 U05；HExA 背景 S03]

### 5.3 Goodhart / Lucas / 适应 / 背压：可共享研究问题，不能先赋予同一被动松弛律

U05:L70 的建设性部分是：研究“策略改变以后，环境或群体分布是否也改变”，而不是只对旧数据拟合。但“短期与长期表现不同”不唯一识别隐藏适应状态；“冻结内生环境”也未必是可执行实验。需要可获得的干预或可信模拟克隆、相同背景条件以及清楚的结果通道。

Perdomo 等的原始模型通过 `D(θ)` 表示部署规则改变后分布改变；收敛结果要求光滑、强凸性和足够小的分布敏感度，并非任意政策都会缓冲。其原框架还要求同一规则诱导同一分布；Brown 等后来专门引入分布自身的状态依赖。这支持显式历史模型，而不是用“反身性”省略它。[S10–S11]

背压原论文研究的是特定排队网络、可行调度约束和到达率稳定区域，不是所有网络都服从物理能量耗散。它的证明性稳定机制也不能靠词语“压力/积压”从 RL 电路继承。[S12：论文首页摘要与问题定义；未逐条复核其全部定理]

因此，经济代理指标、生物演化、排队限流和被动化学可以共享 **“当前效果是否依赖过去干预；反馈是否改变后续分布；哪些输出仍可比较”** 的问题模板。U05:L71 中的被动缓冲不等式必须分别建立；策略反馈也可能放大偏差，不是先属于耗散父类、失败后再补超调分支。这里没有核验具体耐药临床或生物实验，不能把本报告当作该领域已建立的统一实证。

## 6. 从“分层保留”到“实际改善”还差什么

### 6.1 有效父命题和收益承诺应分开

若一个父命题在当前目标的明确范围内仍被独立支持，且其排除决策的推导合法，那么这条已证明的排除结论可以保留。U05:L37 的“100% 保住搜索空间剪枝收益”却还需要目标映射成立、排除集合相关、求值成本可接受等额外条件。保存父节点、没有反例或在源域成立都不能替代这些条件。

更弱的真命题可能对当前决策完全没有区分力；检索、校准、范围测试也可能抵消搜索节省。正确的输出应是“保留了哪些已验证后果、排除了哪些候选、付出了哪些额外调用”，而不是依据节点层级推断收益。强 ordinary 也应允许保留仍然成立的局部知识。

### 6.2 同指纹只建立候选联系，不能建立已证映射

U05:L88 将共同 `ProbeSignature` 和 PPR 联系说成虫洞的通用数学定义。作为检索索引它可以实现；它没有自动给出角色映射、尺度变换、历史重放或推论保真证明。相同粗指纹也可能对应不同机制。PPR 图上较短的连接不等于物理或数学流形上的同构。

建议把桥接边标为 `candidate_alignment`，注明由哪些观测召回。只有通过本次目标的合同检查后，才能产生可消费的转移承诺。这样既保留大胆寻找类比的功能，也让错误联系能被真实反例撤回。

### 6.3 合成机制检验与实际跨域效用应分开报告

U05:L103 的四族匿名 API 可以是有效的首轮方法实验。移除领域名词不会使手工选定的机制族变成无限通用；应明确哪些生成语法、探针、抽象模板已内置，哪些由普通研究流实际形成。U05:L105 给同一模拟器换成化学、经济、软件叙述，可测试跨语义表面迁移，但不是独立的现实世界验证。

不必因此停止首轮实验。应保留结构不同但共享决策问题的目标、误导性的同指纹目标和无法建立父层支持的目标，报告拒绝错误迁移的能力。否则系统可能只是在已知几类模板中选标签。

## 7. 最小下一步：只增加三个可核对结果

1. **一条从真实经历形成的新研究程序。** 输出来源经历、对齐关系、开放参数、候选预测和实际反例；一个 near-miss 导致新增或撤回范围条件，旧版本与新版本都可重放。用 ALIGN/SAGE 借来的只是条件生成与修订步骤，不把聚类得分当支持。

2. **一个强对照下的目标改善。** 给 ordinary 原始经历与合法重建权限，同时给 HExA 对照条件化技能和失败恢复。比较相同目标、预算、可用工具、来源窗口；对照也可选择探针、抽象、回退和缓存。记录最终采用了哪个版本，哪些搜索实际少做，以及构造、失败、验证与维护总成本。

3. **一个保留父层却不值得复用的诚实案例。** 让系统能够输出“父层仍真，但此目标上没排除有价值候选或成本过高”，自动降为候选提示或暂不消费。这个例子能检验 utility gate，也能防止把所有失败解释为透镜、协议或尺度尚未调好。

SATzilla 式预解与预算门控、Minton 式效用记账值得保留，但预解自身也耗费资源，不能仅凭引入 stage-0 就宣布简单题开销问题已被彻底解决。具体成本设计与 DRD/EC2 条件见同包其他专题。

## 8. 归属与证据纪律

UD:L1–2 是用户希望把视野扩到多尺度和更广共性的提问；UD:L52–77 是 Google 回答的示例；UD:L79 以后关于 RG 固定点及忽略槽位的保证主要是 Gemini 后续主张。用户的探索目标不等同这些强断言。U05 的“任意领域通用定律”“100% 收益”和 U06 的自动忽略规则应归于方案文本，不应反过来当作用户要求必须预设为真。

本专题没有认定所有 55 篇有错，也没有认定附件只是空泛命名。判定是：关键路线已更具体，数个真实实证支持继续研究；**最关键的科学目标仍须由真实经历产生、经历范围冲突修订、在强普通方法可重建同知识的条件下，解释一个未见问题的净改善来完成。** 文献只能指导这个实验，不能替它报成功。
