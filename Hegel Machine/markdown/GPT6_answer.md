**我审阅了当前分支中这条研究链的关键实现。结论是：最有决定性的缺口，不是“模型不会写更深刻的假设”，而是系统目前缺少一个持续的、能被反例更新的“解释族及其跨条件后果”。**

现在很容易发生：

\[
\text{找一个拟合代表}
\rightarrow
\text{试它认为能成功的设置}
\rightarrow
\text{失败}
\rightarrow
\text{再找一个仍能拟合的新代表}.
\]

你真正需要的是：

\[
\boxed{
\text{解释族及共享前提}
\rightarrow
\text{未测条件上的预测}
\rightarrow
\text{取得证据}
\rightarrow
\text{限制或修订解释}
\rightarrow
\text{改变下一项研究}.
}
\]

**我建议优先修这条连接，而不是再增加一层 proposal prompt、子 Agent 或“假设深度评分”。**

本轮按 **`29065c7d4fc2e584e9b49c056fd0f54cdc615a8b`** 快照审阅，核对了数值关系研究、响应约束、实验选择、LLM 子研究和公共世界接口；没有重跑真实 Luna 和 529-action checkpoint，也没有读取隐藏环境机制来反推关卡答案。下面区分源码事实、机制诊断和建议方案。

完整的状态定义、伪代码、证据更新和实验设计已写成 Markdown，文末可下载。

## 一、代码里有三个比“提示不够好”更具体的问题

### 1. 只要目标还能提出设置，参考对象就不会参与这一轮实验竞争

在 `world_response_hypotheses.py::_select_response_experiment` 中，先生成目标对象的待试设置，再执行：

```python
reference_search = not experiments
if reference_search:
    # 才生成参考对象实验
```

这意味着：**只要目标对象还有一个可试点，就不会比较“回头研究参考对象”是否更有价值。**

但你的场景中，参考对象已经有正响应。围绕它们测量带边界、重复性或共享关系，可能一次约束多个目标。当前策略却把这类研究放在目标建议彻底耗尽之后。

这不是证明参考实验一定更好，而是发现：**目前它根本没有机会按研究价值参与选择。**

### 2. 联合求解器会继续制造“某个未试点可以成功”的代表

`world_response_constraints.py` 的实际设计是：

- 每个基函数族最多返回两个代表；
- 最多检查 128 个负响应析取分支；
- 将目标设置放进 LP，并要求该设置位于拟合激活带内；
- 再按靠近旧预测中心或最小归一化斜率 L1 选择代表；
- 最后复核这些代表是否符合已付响应。 

因此，返回结果是：

> **找到的、与已付证据兼容、并能为一个未试目标设置提供成功预测的见证。**

它不是可信后验样本，也不是这个族全部可能性的均匀代表。

源码已经诚实区分了“目标可达是设计条件”与“已观察到成功”，但在行动循环中，这种目标条件化代表仍然可能不断产生新的待试点。

这两个机制结合起来，就能解释一种潜在循环：

> 联合拟合继续找到目标候选 → 目标候选非空 → 参考研究继续被推迟。

它与你报告的停滞现象相容，但还需要消融确认其实际因果贡献。

### 3. 新解释加入和新响应确认，确实被当前接口语义卡住

`world_relation_research.py` 继续同一研究时主要使用 `previous.candidates`；`binding_changed` 检查旧拟合行及 basis，没有把新增 `hypotheses` 作为自动加入共同候选集合的事件。

同时，验证行通过整条引用集合与拟合证据是否互斥来筛选：

```python
set(row["evidence"]).isdisjoint(fit_evidence)
```

所以“旧物性记录＋新响应”的整行会被挡住。

而新的 proposal prompt 本来就已经要求同一 `Program` 跨多行预测、用实际反例、先比较再实验。**再写一次更强的同类提示，不能代替候选接纳与证据更新算法。**

## 二、问题一：最小解释对象是什么

### 1. 必须把“解释族”和“一个参数代表”分开

建议保留你已有的 `Program`，但在其外面明确：

\[
F=(\phi,p_\theta,\Theta,s,\Gamma,\mathcal T).
\]

| 部件 | 必须说明什么 |
|---|---|
| \(\phi\) | 哪些实际物性、控制和历史进入预测 |
| \(p_\theta,\Theta\) | 程序结构及允许的参数 |
| \(s\) | 在什么条件下提出预测 |
| \(\Gamma\) | 仪器含义、状态稳定、确定性等支持前提 |
| \(\mathcal T\) | 哪些参数跨对象共享，变量怎样跨对象对应 |

一个成员 \(h\) 才是固定参数、程序版本和绑定之后的具体预测器。

当前带模型可以继续使用：

\[
h(o,u)
=
\mathbf1\!\left\{
\ell\le u-p_\theta(\phi(o))\le r
\right\}.
\]

但“共享一条带”“同一物性作用于所有对象”“结果是确定性的”都是待研究的工作假设，不是环境事实。

**否定一个成员，通常只说明那组参数错了；只有对整个明确限定的族存在不相容证据，才能否定该族。**

### 2. 怎样区分解释、查表和条件拼接

不要让另一个 LLM 判断“这句话是否有深度”。看三个实际后果：

**第一，共享了什么。**  
新对象是否仍使用同一参数或关系，而不是每来一个对象就新增一个自由参数。

**第二，预测发生在什么时候。**  
是否在看到新对象响应前，固定了其预测。

**第三，适用范围有没有实际跨出去。**  
在未用于修订的对象、设置或条件上，有没有得到支持。

查表可以保留为操作记忆，但不能在尚未观察的新对象上，通过默认值或临时重新拟合获得“跨对象解释成功”。

同样，局部子假设不需要自己独立覆盖很多对象。**它可以通过父解释产生跨条件后果。**例如只研究一个参考对象的校准，只要结果改变两个目标的未测预测，就不是无意义的局部性。

### 3. 三类修订要保留不同的不变项

| 修订 | 改什么 | 不能做什么 |
|---|---|---|
| 参数修订 | 同一结构下的系数、端点 | 换代表后忘掉旧反例 |
| 作用域修订 | 可观察条件、适用范围 | 缩域之后倒过来说原来那条广义主张从未失败 |
| 表示/观测修订 | 新特征、特征变换、历史、仪器解释 | 换了预测对象或评价含义，还声称是同一问题上的成功 |

例如：

\[
p_{\mathrm{new}}(x,z)
=
p_{\mathrm{old}}(x)+\alpha g(z).
\]

在 \(\alpha=0\) 时恢复旧族，或在 \(g(z)=0\) 的条件下保留旧预测。

这种特殊情形关系可以直接检查。但**当前环境是否满足旧条件，仍需证据**，不能为了保守继承而保留已经被反例否定的全称命题。

## 三、泛函分析思路怎样落成一个可执行诊断

你原先最有用的思想，不是先找一个漂亮的距离，而是：

> **哪些解释差异，对当前实验不可见？怎样增加一个能看见它们的实验？**

对固定物理实验集合 \(Q\)，定义：

\[
S_Q(h)=\big(\operatorname{Predict}(h,e)\big)_{e\in Q}.
\]

若两个解释的 \(S_Q\) 一样，它们只是在这个实验集合下不可区分。不能因此永久合并，也不能推断在所有条件下等价。

### 1. 数值线性子问题可以直接找不可见方向

若：

\[
p_\theta(z)=b(z)^\top\theta,
\]

已有数值观测的设计矩阵是 \(X\)，那么：

\[
Xv=0
\]

表示沿 \(v\) 改参数，不改变这些观测的预测。

新实验满足：

\[
b(z_*)^\top v\neq0,
\]

才可能暴露这个方向。

这可以直接成为秩、零空间和目标可识别性检查。但**当前激活响应是区间内/外的 Boolean 观测，不能把它当成连续目标值直接套这个等式**；主路径应使用可行约束与响应签名。

### 2. 四种情况不能混在一起

| 情况 | 应采取的解释 |
|---|---|
| 同一族仍有多组兼容参数，存在能区分的合法 probe | 继续辨别参数可能合理 |
| 当前 probe pool 中所有候选一致 | 当前 pool 没找到区分，不是世界中不存在区分 |
| 可靠复核的同一表示对应不同响应 | 确定性充分表示或状态假设需要研究 |
| 某个明确族的相关分支都被可靠排除 | 该族与证据不相容，不等于整个旧语言不充分 |

**不需要先穷尽旧语言，才允许买新测量或提出新表示。**只要当前未识别的差异会改变目标预测，并且某个测量可能揭示它，就值得作为研究动作竞争。

## 四、问题二：避免逐点枚举的研究选择规则

### 1. 先持久化约束，不再只持久化代表

对固定解释族维护：

\[
V_t^F
=
\{\theta:\theta\text{ 与当前适用的已付证据兼容}\}.
\]

在族、作用域和证据含义固定时：

\[
V_{t+1}^F\subseteq V_t^F.
\]

可以换代表，但不能换一次代表，就把过去的约束和预测失败历史清零。

尤其需要分离两个查询：

**解释查询：**哪些模型仍解释历史？  
**行动查询：**其中有没有模型认为某个可达设置会成功？

第二种查询可以用于设计实验，不能反过来把“目标一定可激活”塞进第一种查询。

### 2. 不重新做全语言 closure，只查询一个小型未测后果面板

先选 **4 个未测物理条件**作为面板 \(T\)，例如包含另一个对象和若干不同设置。它没有隐藏答案，且不包括刚执行的当前 probe。

定义：

\[
P_t(T)
=
\left\{
(h(e_1),\ldots,h(e_m)):
h\in\bigcup_FV_t^F
\right\}.
\]

Boolean 情况下，4 个条件最多有 16 个结果签名。你不需要枚举整个连续参数空间，只需要询问：

> 某个联合预测模式，是否仍能由当前模型族实现？

求解器返回：

```text
SAT_WITNESS      找到执行检查通过的兼容见证
UNSAT_VERIFIED   对这个限定查询有可靠排除依据
UNKNOWN         分支截断、超时、数值不可靠或未完成
INVALID_BINDING  实验/对象/证据错配
```

**现有 128 分支截断不能成为排除证据。**暂时只能可靠提供见证、不能可靠排除的地方，就返回 `UNKNOWN`；这不妨碍系统继续做前瞻预测检验。

### 3. 为什么要联合签名，而不只看每个点的方差

假设两个对象各自都可能输出 0 或 1。

一个模型族允许：

\[
\{00,11\},
\]

另一个允许：

\[
\{00,01,10,11\}.
\]

它们的逐点取值范围完全相同，但前者具有跨对象约束，后者没有。

所以**每个目标的分歧、均值或方差，并不足以表示解释中的共同关系**。

### 4. 什么才是真进步

一次新观测之后，记录：

> 此前已经有兼容见证的某个未测联合预测，现在是否被新证据可靠排除？

如果只是：

- 一个参数代表被换掉；
- 代表从 40 个变成 26 个；
- 改了一次候选 ID；
- 又拟合出一个可成功设置；

这些都不自动算解释进步。

如果只知道刚测点失败，可以记录**局部覆盖增加**。但不能把它等同于“排除了一类跨条件解释”。

不同族参数维数也不再靠“剩余参数体积”比较——这种体积会随坐标和维数改变。比较同一物理面板上的后果，以及真正前瞻的预测结果。

### 5. 一个可以先做的调度规则

我建议首版采用以下有限规则，而不是声称找到最优研究策略：

1. **有受当前证据支持的直接任务动作，先完成任务。**
2. 否则，让参考实验与目标实验同时进入池中，优先选择能区分未测后果的实验。
3. 连续两个完整测试周期，若没有任务改善、前瞻支持或非局部后果缩减，且主要变化只是换代表，暂停同一目标的代表轮换。
4. 转而检查阻塞父预测的共同前提，或提出一个明确的表示/观测修订。
5. 仍无有效研究路径时，允许明确标为操作探索的覆盖搜索，或返回未识别。

“两轮”只是开发阶段可调整的调度超参数，不是显著性阈值，也不代表该族已被证伪。相同证据和相同方法下返回 `unknown` 的子问题，不自动反复重开。

伪代码的核心是：

```python
def research_step(state):
    events = read_new_public_events()
    valid, invalid = validate_event_bindings(events)

    # 顺序重要：先评价事前预测，再拿新结果拟合。
    score_previous_frozen_forecasts(state, valid)
    update_scoped_support(state, valid)
    append_family_constraints(state, valid)

    admit_explicit_new_candidates_without_deleting_old_ones(state)
    query_small_consequence_panel(state, keep_unknown=True)

    if supported_task_action_exists(state):
        return freeze_and_execute_task_action(state)

    actions = propose_reference_and_target_experiments_together(state)
    if has_nonlocal_discriminating_action(actions, state):
        return freeze_and_execute_best_test(actions, state)

    if not stagnating(state) and justified_refit_exists(state):
        return bounded_parameter_research(state)

    if blocking_premise_or_missing_observation_exists(state):
        return run_child_with_explicit_parent_return_map(state)

    if executable_revision_can_be_proposed(state):
        return propose_and_compare_revision(state)

    return operational_exploration_or_unresolved(state)
```

### 6. 这不能凭空消除所有“假解释”

两个任意可执行程序仍可能被人为写成在整个面板上互补。**任何有限分歧分数都不能单独证明它们是真正好的科学解释。**

本方案消除的是：

- 只填两列互补文本就获得解释分数；
- 复制候选改变票数；
- 代表更新冒充族排除。

更一般的过拟合，仍要靠允许输入、共享结构、复杂度和未来预测约束。当前 `contrast` 可以继续使用，但其局部分歧不能承担这一切。

## 五、一个例子：局部子研究怎样改变父解释和新条件预测

**以下是说明例，不是实际关卡的隐藏规律。**为方便展示，暂把激活带 \([1,2]\) 当成明确的工作前提；实际系统应保留其端点不确定性。

旧模型：

\[
H_0:\quad Y(o,u)=\mathbf1\{1\le u\le2\}.
\]

参考对象的已测特征 \(z=0\)，在 \(u=1.5\) 激活；另一个对象 \(z=1\)，在同设置未激活。

现在提出候选修订：

\[
H_1:\quad
Y(o,u)=\mathbf1\{1\le u-\alpha z(o)\le2\},
\qquad \alpha\in[0,2].
\]

子问题不是“下一段扫描会不会命中”，而是：

> **一个跨对象共享的物性偏移，能否解释当前差异？若能，能把偏移限制到哪里？**

| 实际子实验结果 | 对 \(\alpha\) 的累计约束 |
|---|---|
| \(z=1,u=2.4,Y=1\) | \([0.4,1.4]\) |
| \(z=1,u=2.6,Y=1\) | \([0.6,1.4]\) |
| \(z=1,u=1.9,Y=0\) | 大于 \(0.9\) |
| \(z=1,u=3.1,Y=0\) | 小于 \(1.1\) |

子答案因此是：

\[
\alpha\in(0.9,1.1),
\]

并带着共享偏移、固定带和绑定稳定等条件。

父研究随后对**尚未测过**的第三个对象 \(z=2\)，在 \(u=3.5\) 给出：

\[
u-\alpha z\in(1.3,1.7)\subset[1,2].
\]

所以剩余整个工作族预测激活；旧模型预测不激活。

这才是你要的连接：

\[
\text{局部子证据}
\rightarrow
\text{父解释改变}
\rightarrow
\text{未测条件的新预测}.
\]

同时，在 \(z=0\) 上保留旧行为；\(\alpha=0\) 时新族整体恢复旧模型。

但如果第三个对象实测失败，不能只新增一个任意 \(\alpha_3\) 后继续说“共享偏移已被确认”。那是共享假设、作用域、测量意义或带模型需要重新研究。

## 六、问题三：旧物性加新响应，应该怎样确认

### 1. 文件引用不重合，不是科学证据独立性的唯一定义

一次预测可以合法地写成：

\[
Y_{t+1}
\mid
Z_{\le t},U_{t+1},C_{t+1},\Gamma.
\]

这里：

- \(Z_{\le t}\)：已测物性；
- \(U_{t+1}\)：这次控制；
- \(C_{t+1}\)：当前对象与状态；
- \(\Gamma\)：物性稳定、校准仍有效等前提。

**如果模型和预测在新响应揭示前固定，旧物性完全可以作为条件输入。**

它新增的是“在这些已有条件下，新响应是否如预测发生”的证据，不是重新确认所有旧物性读数。

### 2. 对现有 row 做最小语义拆分

```text
conditioning_refs     旧物性、校准、固定上下文
outcome_refs          这次实际响应
acquisition_context   对象、状态、控制、读取类型
selection_cutoff      候选及预测固定时点
support_assumptions   复用旧条件所依赖的前提
```

验证“新响应”时，核心是 `outcome_refs` 未参与该版本选择，并且时间顺序正确；不再要求所有 `conditioning_refs` 都是新的。

不过：

- 物性可能变化时，旧读数不能默认继续有效；
- 多个新响应共用一个错误校准，不是多份独立校准证据；
- 轨迹相关和重复检验不能靠字段拆分自动变成统计独立；
- 随机模型中的一次低概率结果，不一定构成逻辑反例。

### 3. 必须明确三个不同时间点

**反例：**先前固定的预测，与有效实测冲突。

**拟合：**看到该响应之后，找到能解释它的新参数或程序。

**新确认：**修订后的固定版本，正确预测随后尚未揭示的响应。

也就是：

\[
\forall t\;\exists\theta_t
\text{ 拟合截至 }t\text{ 的数据}
\]

远弱于：

\[
\text{事前固定的 }\theta
\text{ 正确预测下一次结果}.
\]

你目前的代表轮换问题，正是落在这个差别上。

### 4. 新旧候选滚动比较，不应该靠暗改列表

新候选要有显式加入操作：

```text
登记新版本和修订类型
→ 在所有适用的已付记录上筛查
→ 保留旧版本及其实际支持/反例
→ 对同一新实验冻结新旧预测
→ 新结果逐版本更新
→ 再允许下一次重拟合
```

可以复用 `research_update`，但要增加共同候选表的版本或候选增量。不要把新族另开一个问题之后，就认为父研究已经完成了新旧模型比较。

### 5. C5/C4 错配应该由公共更新器挡住

一个测试计划必须绑定：

```text
测哪个命题
哪个对象、状态和控制
期望读取什么物理结果
哪些旧读数可以作为条件
哪些程序版本在事前预测
结果允许更新哪些解释
```

若实际返回 C4 响应，而计划检验 C5：

> 标为无效绑定，保留记录供纠错，但不能更新 C5 的支持。

C4 的证据当然可以通过共享模型改变 C5 的预测；**但必须沿明确的跨对象关系传播，不能冒充 C5 的实测。**

这样，临时 Python 仍可负责提出提案和解析，但不再每次重新发明“这条记录到底确认了哪个命题”的规则。

## 七、问题四：最窄的对照实验怎么做

### 1. 主实验先固定候选内容，不同时测试一切自主能力

529-action 前缀已经是开发材料，应保留为诊断案例。

另建小型同接口世界：三参考、两目标、可测物性、控制及激活结果。包含：

- 参数修订就足够的情况；
- 需要共享特征或新测量的情况；
- 共享前提失效或仍不可识别的情况。

家族、种子和实际机制不提供给研究端。

首轮允许使用有限公开候选族。这证明的是**研究机制**，不是任意科学发现。

### 2. 三个主臂足以先回答最重要的问题

| 臂 | 机制 | 主要比较 |
|---|---|---|
| **A：当前代表法** | 有限代表与 Boolean separation | 当前基线 |
| **B：平铺族级研究** | 持续约束、后果面板、条件化确认、参考与目标共同入池；无显式子调用 | 新的族级研究机制是否有用 |
| **C：父子族级研究** | 与 B 相同候选、工具和证据语义；未解前提形成子问题并显式返回 | 父子组织是否额外增值 |

所有臂获得同一冻结 proposal bank，或相同的初始候选集合。**不能只给 C 一个更好的候选，然后把优势归因于递归。**

B 必须能直接分析相同参考证据，不能故意做弱。如果 B 与 C 持平，结论应当是：

> 族级推理可能有效，显式递归没有测得额外优势。

这不是失败，而是与你历史 flat tie 一致的必要检验。

### 3. 四种贡献不能靠两臂结果一次性分清

**候选内容：**固定研究器，插入/移除同一批冻结新候选。

**更多探索：**在共同花费检查点比较任务和预测，同时分别报告实际动作、响应、模型调用及计算。

**父子组织：**比较 B 与 C。

**研究方法改写：**另在来源任务上学出方法，再冻结移植；任务知识和候选库相同，只替换研究程序。

方法改写如果同时偷偷增加了新候选族或预算，就不是纯方法效应。

不用第一轮就铺开庞大 factorial，但也不能说一个三臂 pilot 已经识别了所有交互。

### 4. 主要终点仍是任务和未测预测

优先记录：

- 是否完成目标任务；
- 未测对象/条件上的事前预测是否正确，以及预测覆盖率；
- 错误确认、错误排除与未解决案例。

大量负响应时，不能只看总体 accuracy；始终预测“不激活”也可能很高。应同时看正负条件、目标激活和覆盖。

代表数量减少、子问题数量、树深度和接口成功率，只是诊断量。

**最有说服力的机制记录应该是：**

\[
\text{实际取得子证据}
\rightarrow
\text{父程序或实验改变}
\rightarrow
\text{未测条件预测提前改变}
\rightarrow
\text{被新实测支持}.
\]

只生成 `bind`、扫描终于命中、或者回头拟合成功，都还不是同一个结论。

## 八、当前最应该怎么施工，以及会在哪些地方失败

### 建议施工顺序

**先修局部数学与证据闭环，再继续消耗真实模型调用。**

先让参考实验能与目标实验竞争；把目标成功查询从基础可行族中分离；保存解释族约束与成员前瞻记录；拆分条件引用和响应引用；显式加入新候选；最后接入子问题与真实 proposal。

最低限度的差分测试应验证：

| 测试 | 正确结果 |
|---|---|
| 候选复制一百份 | 不改变解释价值 |
| 一个代表失败、同族还有解 | 不误杀整个族 |
| 分支截断 | `UNKNOWN` |
| 旧物性＋新响应 | 满足条件时可以前瞻检验 |
| 新响应先用于拟合 | 不算该版本的新确认 |
| C5 计划接 C4 响应 | 不污染科学支持 |
| 目标仍有建议，但参考实验更有区分价值 | 参考实验能够被选择 |

### 这套方案不会自动解决的困难

如果激活窗口可以任意窄、处在不可达域，或所有可用测量都不能区分真正机制，长期负反馈可能根本不够。不能偷偷加入真实带宽或隐藏物性规律使问题可解。

如果大多数可行性查询都是 `UNKNOWN`，保守区分分数也可能全零。此时应回到明确的固定候选预测检验、支持性测量或操作探索，而不是假装完成了族排除。

如果模型仍然不能提出有用新结构，工具接通也不会解决它。应记录真实的空提案与错误提案，不能由评测器补出正确解释。

## 最终判断

**你现在已经有不少必要组件，问题主要是这些组件连接时使用了不合适的研究单位：它们经常更新“当前代表”，却没有稳定更新“这个解释到底共同承诺了什么，以及哪些未来后果已被证据限制”。**

本轮最值得增加的是：

\[
\boxed{
\text{持续解释族}
+
\text{小型未测后果查询}
+
\text{条件化新响应检验}
+
\text{明确的子结果返回}.
}
\]

它既不要求先穷尽旧语言，也不要求每次重测所有物性；但坚持两个必要约束：

**后见拟合不是前瞻确认；没找到见证不是排除整个解释族。**

这条窄路线最接近你原始构想，又能够直接利用当前代码，而不是再次把项目推向庞大的形式化基础设施。
