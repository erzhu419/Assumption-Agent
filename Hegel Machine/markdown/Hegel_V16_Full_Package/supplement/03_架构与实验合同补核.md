### 关于“半自动问题提出”应怎样评价

## 2. 仍会改变结论的六组合同缺口

### 2.1 公式方向修正了，统计识别与完整路径价值还没有自动成立

**原文：A:110–116、175；A:41–42、88。**

表格式或线性估计可以确定性执行，数据仍然有小样本误差、选择偏差与分布转移。账本中只有被选动作的结果时，不能据此直接知道同一决策前状态下另一路的成本。图检索再用同一组估计选择最高分候选，会进一步产生选择后乐观偏差。

A:112 未说清 `C_tree_solve` 是仅成功的树内求解费，还是包含失败、回退和确认的**完整策略费**。若是前者，式子遗漏回退后的普通求解；若是后者，须定义条件事件以免重复计费。对“最终都成功”的成本比较，还需成功概率、假确认及预算失败约束，不能让早停失败因便宜而被选中。

**建议替换 A:110–116 的承诺：**

> 第一版在开发源簇上，用相同决策前快照采集有限的配对动作轨迹，估计包含选择、绑定、探针、失败回退及独立确认的完整路径代价；缺少备选动作结果的记录标为缺失。仅在覆盖充分的情境使用经校准的成本区间，并同时满足预设质量约束；覆盖不足时采用有界调查或直接求解。区间方向按 A:114 保留，先称经验保守选择，不承诺对每题永不变慢。

无需因此加入完整离线 RL 工程。第一轮固定 PPR 权重，只学一个简单使用选择器，更容易识别它是否有益。

### 2.2 固定 pilot 先于门控，和“零税”路径存在直接矛盾

**原文：A:33–37、72–88、116、135。**

流程要求每题先做稳态、阶跃、叠加和前史探针，再构造三元组、跑检索、决定是否直解。因此直解分支已经付费；“毫秒级”也只是待测实现性能，不能免掉实际实验观测成本。一次 PPR 检索可传播多跳关系，但不等于一次邻接矩阵乘法必能完成所有多跳推断。

更关键的是，这些特征不是任何接口都能免费测出：等待稳态需要时间；历史对照要求合法重置与可对齐状态；守恒量可能不是传感器读数的直接求和。A:77 的“任何问题自动提取”应改为操作条件成立时执行，无法测定记为未知。

**最小修改：**在 pilot 前增加可直接求解/跳过检索的入口；每个探针列出所需控制、重置、等待及观测权限，普通组拥有同等调用或跳过权；pilot 成本进入全流程计费。可以验收“额外费用不超过开发期冻结的容忍量”，不能由选择器架构推导零费用。

### 2.3 Q 更新、图写回和外部检查点必须有时序防火墙

**原文：A:41–42、88、139、149、164、175。**

源阶段训练后冻结预算，并没有明确冻结问题树、selector、PPR 权重或测试期间的更新政策。流程又要求确认后将“真实净节省”写回 Q。单条实际执行轨迹能报告已发生费用，**没有配对反事实时不能报告另一策略本会花多少，更不能把该差值当真值训练。**

10%/25%/50%/100% 的外部检查点用于事后评价没有问题；若把外评 MSE、隐藏族信息、首次正确时刻或另一臂的结果送回选择器，正式目标就参与了训练。当前文档未证明发生了泄漏，也尚未排除这种实现。

**最小修改：**明确开发、校准、测试按源簇隔离；冻结模式下仅评测器读取外部结果，正式目标不更新库或门控。若要研究持续学习，另行预注册顺序更新模式，所有臂使用相同顺序和可见反馈，结果只允许影响后续题。两个模式分别报告。历史失败缓存也要绑定对象版本、协议、预算和证据条件，不能把一次预算失败固化为机制永久失败。

### 2.4 问题树可以是学习结果，但不能由测试表同时充当标准答案

**原文：A:55–64、77–81、128、130–134、162–163。**

M1 已写明目标变化率分支、正确 Q1 与 `Q_sign/Q_stab`；M2/M3 也写了应发现的守恒和历史问题。这些可以是**评测器的机制定义**。若同一张表进入 agent 的固定提问顺序、特征器标签或树构造器，则只能检验设计者提供的归纳偏置，不能单靠结果宣称系统从源经历形成了它。匿名变量名不能排除这种先验进入，也不能清除 LLM 已有的通用研究知识。

**最小修改：**区分共享实验原语、源阶段形成对象和评测器真值三份清单。保留实际候选问题、提出所依赖经历、被淘汰候选及选择依据；将树在目标前冻结。做一项同权限的源经历干预：去掉或匹配替换促成该问题的关键源经验，检查问题是否仍原样出现、是否仍改变后继研究。人工指定树可以保留作上界或调试组，不能混入自主形成组。

“8–12 通道天然需要 10^5–10^6 计算”“1–2 探针剪掉 90%”仍是待测假说。强普通可主动试验、结构化求解和学习策略，并非被指定为穷举器；不要通过禁用这些能力制造困难。

### 2.5 两种公平比较都重要，须分开回答

**原文：A:15 对照 A:139–146。**

北极星要求相同原始档案；主实验则让 H/O 独立跑相同源任务。**相同源任务不必产生相同观测历史**，这不是主实验天然不公平，而是回答的问题不同：

| 实验 | 共用什么、允许什么 | 能回答什么 |
|---|---|---|
| 整体系统比较 | 相同源任务分布、工具、预算；各自形成和保留自身历史、问题程序、概念及缓存 | 从源学习到未见研究，整套 H 是否较强普通更有效 |
| 同历史干预 | 同一冻结决策前历史和工具；移除指定派生对象及其专有副本；保留 raw history 和独立知识；允许有界重建、重新总结或直接求解 | 指定知识的持久化、组织或使用对后继决策的作用 |
| 同内容 Flat/Graph | 同对象、问题树、桥接元数据、门控、确认和候选尝试预算；只替换索引/排序方式 | 图组织的独立边际贡献 |

A:104 已承诺所有臂共享元动作，A:141 已承诺同求解能力，必须保留。A:142 的“平坦概念库”进一步明确**可存可执行问题、一般研究策略和组合程序**：若不允许普通组生成或保存同一知识，比较就变成知识表达能力消融。无需要求它原样实现 H 的图索引，但不能把理论上可重建的知识排除出其行动空间。

A:145 的同树去图组能识别索引贡献，不能再被用来证明“问题树优于普通记忆”。A:146 的删除合同还需明确对象专有副本、缓存、别名和派生索引的清理范围，不能把“子预算修好了”直接等同干净删除。

### 2.6 父节点回退与阶段验收，要保留未知和统计边界

**原文：A:56、58–61、85–86、93–96、148–164。**

A:60 已要求根 `OBSERVED_MATCH`，不能说它完全不检查祖先。剩余漏洞是“最近未证伪祖先”仍可能包含尚未检查的中间前提，根成立也不推出这些条件成立。需要给问题回答增加 `UNKNOWN/PROTOCOL_ERROR`，分别记录参数失配、绑定失配、叶前提被反驳、祖先范围不明；只有证据支持的相关范围可以用于剪枝，未知时做有界区分或回退。A:93 的“验证后 LCA 深度”可以作事后描述，不能免费成为路由前特征。

P1 的“保证不比普通慢”、P2 的“100% 拦截”、P3 的“零负迁移”应改成冻结样本上的质量、额外成本和失败率验收，并报告独立源簇数量与不确定性。库内 32/96 条经历不等于 32/96 个独立源簇。“显著”须有预先定义的主终点、样本量/精度规则及比较方法。

A:149 的 48 行外部 MSE 是当前任务的一种检查，不是新机制、非线性读出或噪声任务的通用正确性标准。保留外部评价，但按任务约定单位/归一化误差、边界 witness 和可区分的反例，另报首次有效候选与首次合法确认的费用。预注册源簇划分、正负/未知比例、预算、版本哈希、任务顺序和更新政策即可，不需再搭大型评测平台。

## 4. 建议给 Gemini 的最小修订指令

保留三层对象、P0、共享五类元动作、正确的成本区间方向、同内容 Flat/Graph 和全生命周期账本。先改正上表事实，不再用“普通完全冷启动却很便宜”论证必须换更难赛场。

随后只补四页级别的合同内容：**信息权限和冻结时序；可选且计费的 pilot 与完整回退路径；源经历到问题树的提案/选择/修订轨迹；整体比较与同历史干预的分离**。P1 先跑一个源形成的新问题程序在未见目标上改变行动的最小案例，连失败和普通重建一起记录。拿到该证据后，再决定是否需要大记忆 PPR、学习图边权或新增多物理环境。

这不会削弱跨领域目标，反而让最终能够区分：收益来自经历形成的提问程序、由设计者预置的领域策略、图排序、额外测试预算，还是强普通本来就能廉价重建的知识。
