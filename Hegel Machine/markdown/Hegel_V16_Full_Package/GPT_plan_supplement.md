## 三、最重要的新问题：作为树根的电磁不变量不成立

补交的文献综述 `03` 第34行，将下面关系作为核心不变量：

\[
\dot\Phi_{\mathrm{ext}}\Phi_{\mathrm{ind}}<0,
\qquad \Phi_{\mathrm{ind}}=LI,
\]

并称它由能量守恒与非负耗散保证。

**这个式子对有历史记忆的合法 RL 回路并不普遍成立。**

问题在于，它混用了三个不同的量：

- 外部通量变化产生的驱动电动势；
- 回路当前的电流；
- 电流储存的自感磁通。

RL 回路的电流受初始条件与储能历史影响，不能随着外部驱动反转立即反转。教材中的一阶回路方程和指数弛豫过程也明确体现了这一点。[OpenStax](https://openstax.org/books/university-physics-volume-2/pages/14-4-rl-circuits?utm_source=chatgpt.com)

### 一个直接反例

使用详稿自己给出的方程：

\[
L\dot I+RI=-\dot\Phi_{\mathrm{ext}}.
\]

取 \(L=R=1\)。过去外通量变化率为 \(+1\)，电流已达到 \(I=-1\)。在 \(t=0\) 把外通量变化率反转为 \(-1\)，则：

\[
\dot I+I=1,\qquad I(0)=-1,
\]

所以：

\[
I(t)=1-2e^{-t}.
\]

在 \(0<t<\ln2\) 内，电流仍然为负，因此：

\[
\dot\Phi_{\mathrm{ext}}\Phi_{\mathrm{ind}}
=(-1)(1-2e^{-t})>0.
\]

它违反了详稿要求的负号，但：

\[
\frac{d}{dt}\left(\frac12LI^2\right)
=
-\dot\Phi_{\mathrm{ext}}I-RI^2
\]

仍然成立，耗散 \(RI^2\) 也始终非负。

这是我根据方程构造并用独立脚本核对的解析反例，**不是新跑出的 Hegel 性能结果**。

### 为什么这会影响整个项目

如果把这个式子直接编译成父节点的硬拒绝条件，正常的历史反转场景就会被错误判为“违反哲学模型”。

按 Gemini 的流程，它会退回普通研究；问题不是必然拒绝整道题，而是**错误撤销了合法目标上的复用资格，可能丢失有效复用或增加成本**。

因此，下一轮应先明确：

- 检查的是电动势、电流，还是磁链；
- 初始状态与历史是否受控；
- 观察的是瞬态、稳态还是积分响应；
- 哪个条件支持方向关系，哪个支持稳定或耗散。

化学侧同样需要精确化。正的自由能曲率不能直接保证任意选取的扰动量与响应量都反号；具体方向还取决于耦合项和观测量。补核专题里给出了对应推导。

**这不会否定勒夏特列—楞次之间存在可研究的共同结构，但说明目前这张表还没有把那个结构正确写出来。**

## 四、Q1 提问树也存在同一类问题：没有固定“响应”到底指什么

详稿的 Q1 大致是：

> 静态输入下，响应是否归零？  
> 归零就走变化率驱动分支；不归零就走状态偏离恢复分支。

但是，前文把化学响应定义为**净反应速率**，又把电磁响应同时写成**电动势和电流**。

这样会产生几个直接冲突：

1. **化学系统达到新的平衡后，净反应速率也会归零。**  
   不一定归零的是平衡位置相对原位置的变化。

2. **静态磁通下，驱动电动势可以归零，电流却需要经过弛豫。**

3. **理想无阻闭环可以保留历史电流。**  
   按当前 Q1，它可能走不到树上为超导持流安排的叶节点。

4. **断路令导电电流为零，不代表感应电动势或端电压也必须为零。**

所以，当前 Q1 不能按所写语义把化学与电磁唯一分开。“恒定输入时输出零”也不唯一对应微分机制，还可能来自高通隐状态、门控、未激活通道等解释。

### 应怎样改

沿用已有 `QuestionSpec`，把每个问题落实成以下合同即可，不需要重建整套问题系统：

| 必须固定的内容 | 作用 |
|---|---|
| 可控制的输入及操作 | 区分设定状态、施加驱动与指定变化率 |
| 实际读出的物理量 | 避免把位移、速率、电流、电压互换 |
| 初始状态、历史及复位方式 | 防止隐藏储能或记忆改变答案 |
| 采样时间与判定窗口 | 区分瞬态、稳定后响应和积分量 |
| 各候选的不同预测 | 说明答案究竟排除了什么 |
| 变量绑定及其证据 | 防止沿提问路径偷偷更换对应 |
| 答案如何改变下一步行动 | 把问题变成真正可消费的研究程序 |

还要特别注意：如果系统的目标是发现磁通与 \(BA\) 的关系，基准却直接免费提供“保持 \(BA\) 不变”的操作，那么待发现的结构已经部分藏进接口里了。这个实验可以使用，但候选乘积关系的提出、绑定和检验都要有来源与费用。

## 五、另一个新增反例：非线性传感器会破坏“可见读数和守恒”

架构方案 `04` 为热传导到图扩散的迁移，同时加入了“不规则图”和“局部非线性传感器”，并认为守恒探针仍完全对应。

这里必须区分：

> **真实状态守恒，与传感器读数直接求和守恒。**

考虑两个节点的扩散，真实状态从：

\[
(c_1,c_2)=(2,0)
\]

逐渐变成：

\[
(c_1,c_2)=(1,1).
\]

真实总量始终为2。

但如果传感器输出是 \(y_i=c_i^2\)，读数之和会从：

\[
2^2+0^2=4
\]

变成：

\[
1^2+1^2=2.
\]

即使这个传感器在非负浓度域上单调，直接读数之和仍不守恒。

因此，M2 的实验最好分开：

- **第一轮：**已知线性读出、明确边界和操作，先检验机制相关的迁移。
- **第二轮：**增加未知传感器映射，单独检验校准、隐状态识别及其成本。

否则失败后难以分清：到底是知识不适用、角色绑定错误，还是观测层尚未识别。

这也说明你所说的“定义相似性”需要包含一个关键条件：**相似关系必须相对于具体操作和观测映射成立。**

## 六、对下一步方案，还应增加四条约束

### 1. LCA 深度可以用于索引解释，不能独自定义真实相似性

给树插入重复父节点，就能增加深度；把同样的逻辑压平，深度又会减少。两者的实际预测能力可能完全一样。

因此，“共同祖先有多深”可以是排序特征，但更重要的是记录：

> 在什么绑定与范围下，哪些操作—结果关系被保持，哪些仍未知，以及利用这些关系实际减少了多少工作。

另外，得到“验证后共同祖先”的过程本身可能已经支付了实验与绑定费用，不能再当成免费检索输入。

### 2. “通过 colimit 形成树”还不是经验学习算法

详稿定义了可执行问题的组成，这是进步；但还需要明确：

- 哪个经历触发提出新问题；
- 如何产生竞争的候选问题；
- 如何检验、修订或淘汰；
- 为什么保留这个提问顺序；
- 新目标到来前，究竟冻结了什么。

给定接口后组织图式，与从经历中发现接口，是两件不同的工作。范畴论可以约束表示，不能替代这段形成过程。

### 3. “零迁移税”应改为可测的额外成本上限

目前流程先做 pilot、提取关系、跑检索，之后才决定是否直接研究。这些费用已经发生，回退不会将它们取消。

应增加 **pilot 之前就能选择直解或短预解**的入口；迁移失败、回退求解和确认费用也都计入完整路径。第一版用简单、可审计的经验成本选择器足够，不必同时学习 Q、改变图边权和增加多个新环境。

### 4. 外部检查点和两种公平比较必须分开

在10%、25%、50%、100%预算处保存候选，再由隔离评估器事后检查，是合理的。外评结果不能反过来帮助代理选候选或停止，否则外部测试变成了额外实验通道。

同时，要区分：

- **完整系统比较：**H 与 O 跑相同源任务，各自形成历史，分别计费。
- **对象贡献干预：**从同一历史快照出发，只改变指定对象或组织方式；普通方法仍能读原始经历并重建。

二者都重要，但回答的问题不同。详稿两种表述都有，下一轮需要把合同写清。
