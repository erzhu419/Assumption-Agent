# 扩展互联网检索：只保留能改变最小方案的三项研究

日期：2026-11-19（Asia/Shanghai；对应 UTC 2026-11-18）。这是对既有结构映射、MDP 抽象、Stitch、AWM 等来源的增补。研究范围已扩展到互联网，不限于用户上传文献。以下区分论文内容与对 Hegel 的建议；没有重跑论文实验、审计整套外部代码或独立形式化验证其定理。

## 1. LILO：直接回答“LLM 能否接上程序压缩，再改善新题搜索”

**原始来源与版本**：Grand 等，*LILO: Learning Interpretable Libraries by Compressing and Documenting Code*，ICLR 2024；本次方法阅读使用 [arXiv v3，2024-03-14](https://arxiv.org/html/2310.19791v3)，同时打开 [ICLR 正式论文](https://proceedings.iclr.cc/paper_files/paper/2024/file/819cebb05f993840e8a52d7564c5c282-Paper-Conference.pdf)。官方代码：[gabegrand/lilo](https://github.com/gabegrand/lilo)。不能与另一个同名的 2026 年自然语言反馈贝叶斯优化项目混为一谈。

### 确实读到的方法与边界

LILO 把 LLM 与枚举搜索得到的解程序交给 Stitch 抽取共享函数，实际改写原程序，再由 AutoDoc 根据函数体和用例生成名称、说明，供下一轮搜索使用。生成结果经过解析、类型和执行检查。压缩目标同时计入新函数及改写后的程序长度；库可从基础 DSL 重新归纳，淘汰早期较差抽象。其离线评估冻结最终库、固定搜索器及预算，并允许无库基线从自己的解程序事后压缩出库。无 AutoDoc 的抽象曾降低 LLM 的求解表现；文档也会出错。实验覆盖三个程序合成域，不能据此保证开放科学假设的真实性或跨世界有效性。依据：§2、§3 Algorithm 1 / Eq.4、§4、§4.2。

### 对最小方案的实质改变——本审计建议

Hegel 的第一件可复用成果应是一个能执行的诊断程序，其函数体、绑定角色、适用条件和证据来自普通研究经历。LLM 可以提出抽象候选和名称，但入库依据需要包含：改写了哪些既有研究片段、原片段与调用新函数是否得到相同结果、在何种前置条件下等价，以及哪一个新任务真的调用了它。

这比直接计算“两棵提问树有多像”更接近可检验目标。树的相似度可以帮助找到候选片段，是否形成可复用程序仍由可执行语义决定。暂时不需要全库的范畴计算，也不需要把任意 Python 自动压缩成 DSL；从现有探针/拟合/残差比较操作中抽一小段即可。

建议把三个效果拆开记录：

1. **表达压缩**：新函数及版本元数据占多大空间，实际减少多少重复程序；零调用的漂亮抽象不算收益。
2. **消费便利**：同一可执行对象，只有匿名编号与带清楚说明时，选择/绑定错误是否减少。说明须能由程序和反例约束，不能成为新增科学证据。
3. **研究收益**：在未见任务上，相同原始经历、相同可用操作、相同预算的强普通方法也可以抽取、缓存同一个程序；持久维护的程序库仍节省了哪些真实调用、搜索或错误。

上述三个记录可以在同一小实验中取得。不要把 LILO 的三个组件变成三套平台工程。其评估给 Hegel 的最重要借鉴，是**把库本身的贡献从强求解器的贡献中分离出来，并让普通基线有事后归纳能力**。它的离线基线来自各自生成的程序，不等于 Hegel 要求的严格共享原始历史；这里仍需本项目自己的公平合同。

另读了 Appendix C.2：当时的 GPT-4 提示式压缩不及 Stitch。这个负结果只属于论文采用的模型、提示和程序域，不能推广成“现在所有 LLM 都不能发现抽象”。它支持保留可复核压缩/改写器，而非替代当前模型的实测。

## 2. ISS：分清“没有发现区分实验”与“限定范围内已经无法区分”

**原始来源与版本**：Khanzadeh 等，*Certifying Interventional Agreement Among Observationally Equivalent Causal Models*，[arXiv:2609.32247v1，2026-09-26](https://arxiv.org/html/2609.32247v1)。本次使用预印本全文；未确认同行评审状态。摘要页一次读取失败，但固定 v1 HTML 方法、定理陈述与讨论均成功读取。

### 确实读到的方法与边界

ISS 维护与历史相容的候选集合，选择候选预测不一致的干预，观察结果后排除相违者。只有在整个候选空间中，给定干预成本范围内不存在区分实验，才获得条件性的一致性证书；预算耗尽不等于该条件。保证要求真实系统属于初始候选类，且精确判定涉及完整版本空间。论文的精确实现依赖给定结构、受限干预及特定答案表示；最坏计算代价很高。若所有候选一起遗漏真实机制，分歧驱动探针可以安静地给出无效证书，需要独立验证探针检验类外错误。依据：§4 Algorithm 1、Theorem 2、Proposition 4，§6 Result 3，§7。

### 对最小方案的实质改变——本审计建议

不建议为 Hegel 新增通用 MILP 证明器。可先把分支调停的退出原因变成有明确语义的回执：

| 退出原因 | 可以更新什么 | 不应推出什么 |
|---|---|---|
| 实测区分探针排除一个实例 | 给该实例及对应证据加反例 | 整个连续参数模板均被反驳 |
| 已检查的有限探针集均无法区分 | 记录在这个有限集合上的经验等价 | 对全部物理干预全局等价 |
| 计算/实验预算不足 | 保留未决分支及剩余分歧 | 融合、删除或确认其中一支 |
| 对明确有限域完成穷尽/可验证判定 | 记录域和容差受限的等价依据 | 域外仍可复用或真实机制必在类中 |
| 所有候选对独立探针都预测错误 | 标记类不足，提出新候选或缩域 | 在旧候选中随便挑“最好”的作为已确认 |

可迁移的新点不是“再画一个提问树”，而是区分两类提问：一类询问现有分支之间哪里不同；另一类检查所有分支共同依赖的前提是否错了。二者必须共享总预算，记录各自取得的证据。这样才能避免一个分支库越来越自洽、却同时越来越偏离环境。

这也直接约束融合操作：两个分支暂时没有分歧，只能在已检验范围内合并重复表示；证据、未决边界和域外差异应保留。若只能搜索到“没有找到区分探针”，回执应保持 unknown，而不是借用该论文的证书名义。

## 3. AR：跨领域关系映射可扩大候选集，但不能代替研究闭环

**原始来源与版本**：Shen、Druckmann、Zou，*Unlocking LLM Creativity in Science through Analogical Reasoning*，[arXiv:2605.11258v1，2026-05-11](https://arxiv.org/html/2605.11258v1)。[arXiv 摘要页](https://arxiv.org/abs/2605.11258)仍列 v1。官方代码：[andrew7shen/ar_science](https://github.com/andrew7shen/ar_science)。已读方法、主要结果、限制、附录 C 与 D，以及官方 README，未运行代码。

### 确实读到的方法与边界

AR 先抽取对象和共享关系，生成跨域的部分映射，再检索对侧已有解法并迁回问题；它不要求原问题所有关系完全匹配。评价同时涉及生成多样性、新颖性与类比质量；四个计算案例另行选择有希望的方案实现。作者明确将端到端执行闭环列为后续工作。附录 C.1 的人评中，AR 较常被选为更有新意，但被判断“合理”的比例为 67%，跨域基线为 86%；这些是意见评分，不是实测成功率。依据：§3.2–3.3，§6，§7，Appendix C.1/D。

### 对最小方案的实质改变——本审计建议

Gemini 的“虫洞”想法可以保留为候选生成入口，输出至少应包含：映射的实体角色、保留的关系、没有映射的条件、拟迁移的操作、最便宜的失败检验。无需为建立完整图同构而丢掉局部但可用的类比；同样，也不能因为找到两个相似关系就自动确认世界假设。

例如 Lenz—Le Chatelier 类比，候选生成器可提示检查外部扰动、响应方向、受控量和储能/耗散角色。随后仍须由具体系统的方程、实验接口与边界条件给出测试。不能把“都有反抗变化”的语言直接提升成同一普遍定律。

对新实验最小增量，是给普通候选生成与类比候选生成同样数量的提议机会及总成本，并把失败候选也保留。以执行后新增的有效假设、实际排除的错误路径、未见任务净成本作为终点。结构相似度、多样性和新颖性分数只能解释候选来源，不能取代终点。

## 4. 检索取舍与引用入口

本轮还检索了可复用实验策略、因果抽象和最新科学类比研究。对仅返回摘要、页面读取失败或与既有方案重复的条目，没有据此增加实施任务。例如 *Validating Causal Abstraction Metrics on Simulated Complex Systems*（arXiv:2607.00267）检索得到摘要，但固定 HTML 无法读取，故不把其具体指标当已审阅方案；*Programmable Semantic Interventions* 更偏冻结网络的表征干预，不足以改变本轮最小研究合同。HExA、经验复用与 EvoScientist 由主代理另行覆盖。

三项增补分别改变三个局部决策：LILO 改“抽象要如何成为实际可调用程序及怎样公平测库”；ISS 改“何时有资格结束分歧并融合，以及怎样检查共同错误”；AR 改“如何生成可检验的跨域候选”。它们没有证明 Hegel 已经取得正净效用，也不要求一次性安装三套外部系统。
