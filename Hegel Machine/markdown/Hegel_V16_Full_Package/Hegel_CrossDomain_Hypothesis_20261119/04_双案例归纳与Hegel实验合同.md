# 双案例归纳：从两个研究经历提出可检验的新假设，并判断它是否帮助第三个问题

日期：2026-11-19。性质：给 Hegel 的最小研究与实施合同；没有修改项目或运行模型。下文示例是明确标注的设计演示，不是已经产生的研究回执。

## 1. 用户要的不是“找共同标签”，而是提出能承担新预测的共同关系

**两个跨领域案例足以触发有根据的候选提案，不足以证明该候选普遍成立。一个反常案例也可以提出假设；这里使用两个，是为了让候选同时接受两套经历的约束，而不是设置“样本数达到二就是真知识”的规则。**

例如，“两个问题都在中学学过”可能是真的，表达也很短，但它没有告诉当前研究：控制哪个量、观察哪个量、在什么条件下应出现什么结果，以及若结果相反要改掉哪项解释。这种元数据可以帮助检索背景材料，却不能据此获得机制推断或实验剪枝权限。它并非在所有任务中都无用；若目标是预测学生熟悉程度，学校标签可能相关。无用与否必须相对于当前研究目标判断。

建议把一条跨域候选写成：

> **若操作条件 S 成立，则在角色映射 b 下，实施干预 q，应观察到关系 r；这个结果会使研究行动从 a 改为 a′。目前支持来自 E1、E2；反例条件为 F；预期用途为 U，但效用尚未验证。**

它至少要回答五个问题：

1. 哪些可控量、状态、观测和时间条件被对应起来？
2. 它对尚未使用的数据或实验结果作出什么非平凡预测？
3. 还有哪些同样解释现有经历的竞争假设？
4. 什么可执行实验能使这些解释分开，或者暴露候选集合全都错了？
5. 若暂时采用它，具体会改变哪一步研究；形成、检验和误用的成本是多少？

“共同关系存在”“对目标的对应有效”“调用它值得”是三项独立判断。真实规律也可能暂时没有研究效用；有用的搜索启发式也不能自动升级为世界规律。

这五项支持一种研究方式：**经历约束候选，实验约束真假，后续任务约束效用。**它们没有证明两个任意案例一定能抽出共同机制。本次没有复现这些论文的实验。

## 3. 最小流程：先生成竞争解释，再把有用分歧编译为问题

### 第一步：把“案例”变成完整经历，而不是两段结论

每个源案例使用现有 episode/证据档案，至少保留：任务与允许操作、初始化/重置、控制与观测类型、付费探测、候选预测、实际结果、失败和最终程序。两段描述若来自同一次实验，不算两个独立案例；同一次长轨迹中的一千个采样点，也不是一千次独立的跨域支持。

同一经历内的多次干预当然能增加证据，但它们与跨装置、跨机制实例的独立复现回答不同问题。账本同时保存 `episode_id`、协议/批次身份和所属源簇，避免把重复引用、派生摘要或相邻时间点当成新增独立支持。

### 第二步：生成多个带类型的部分对应

从“能干预什么、能读出什么、先后次序与依赖”开始，提出若干 `AlignmentHypothesis`：例如暂时把两域输入对应为可保持的外部参数，再比较哪些合法读出可能扮演共轭响应角色。必须保留这是**候选对应**，而不是把物理名称一换就证明等价。

只要求保留当前诊断所需的局部关系；不要求全世界同构。参数值、对象数和合法表征差异可留作待绑定变量。对无法控制的量不能编译成免费干预，对未知读出变换不能假定可逆。

### 第三步：提出有限的共同解释，并保留不共同的解释

可用 LLM、现有程序的共享片段提取、带类型的结构泛化等方法提案。共享语法是候选生成器，不是经验裁判。初版只需一个小候选集合，附上“其他机制/目前不可判别”，而不要求一个无所不包的范畴合成器。

至少比较：独立局部规律、共同外因、真正的跨对象耦合、较窄的线性机制、带历史或非线性的扩展。候选数量与预算在开发期冻结；不能在看完目标答案后补入唯一正确候选，再计算事后命中率。

### 第四步：先筛掉不承担预测和决策的“共性”

采用三个实际门槛，而不是给“抽象程度”随意打分：

- **预测门槛：**候选对允许的某个新实验至少给出一种可区分预测；仅重复已知结果不够。
- **操作门槛：**能编译到已有合法操作，或者明确返回需作者补充的工作请求；不能把未实现的自然语言当已执行查询。
- **决策门槛：**指出至少两个答案分支如何改变下一行动；若所有结果都触发同一整套盲搜，它暂不构成有用诊断程序。

MDL/压缩可作为候选排序的一个信号，但应比较**带数据解释代价的代码长度**和真实程序重写。把句子压成“都是中学知识”既未解释观测，也未替代可执行片段；即使某个模型对两例有短描述，也仍可能过拟合，必须留出与反例检验。[R2、R5]

### 第五步：选择会分叉、值得付费的实验

对每个合法问题 q，列出各候选的预测范围或似然、可能结果和后继动作。优先选分歧大且足以改变当前决策的问题，保留少量检查候选集失配的挑战试验。避免只在候选共同擅长的区域查询。[R3]

可以用下面的**设计目标**，不把两例估出的数冒充校准置信下界：

\[
\operatorname{VOI}(q\mid s)=
\mathbb E_{y\mid s,q}\left[\max_a\hat U(a\mid s,q,y)\right]
-\max_a\hat U(a\mid s)
-c(q)-c_{\rm planning}(q).
\]

这里 U 指后继决策的预计完成质量与未来代价，q 及其选择费单列，剩余预算限制必须随状态更新。实务上先用候选预测表和小型开发对照，不必实现完整贝叶斯规划器。信息熵下降是辅助量，**决定同样行动的无关信息可以很多，但决策价值仍很低**。若单个探针价值不足，却有明确的两步互补计划，可以批准一个有预算上限的小组合；不能机械地每步无即时收益就判研究失败。[R3、R4]

### 第六步：生成三个相互引用的结果，并冻结

1. **Hypothesis：**可执行预测、范围条件、参数/映射、来源、竞争解释、反例及尚未覆盖条件。
2. **QuestionSpec/工作流：**如何购买观测、怎样解释答案、不同答案对应哪些后继动作、有效版本及 parent use。
3. **效用预测：**若在哪类目标上使用，预计替代/重排什么动作、花哪些额外费用、什么结果会推翻这项效用预测。

假设可标为“源内暂获支持”，效用仍标为“未测”。真实反例导致范围修订与版本变更；预算耗尽导致“未判定”，不能自动导致“规律被反驳”。新颖性只先声称**相对该系统已有持久对象或以前策略是新形成/新操作化的**，不要求对科学史首次发现。若旧程序已完整实现同一知识，只是改名，不算新机制；若将已有常识变成有证据、可调用的新研究程序，按实际变化描述即可。

## 4. 具体演示：两个不同领域的松弛经历，如何提出第三类装置上的问题

### 4.1 与主报告保持同一示例，不另扩手写基准

以下采用主报告已核定的**化学局部平衡—RL 电磁松弛 → 隐藏机械装置**模板。方程用于说明一条可能产生的候选链，**不是 Hegel 已自主发现该规律的运行结果**。物理适用条件详见同目录主报告/物理专题，尤其不能将感应电动势、电流和总磁链当成同一输出。

人类读者看到物理名称与评测器方程；正式 agent 只见预注册的操作、合法读出与它实际取得的原始历史。共享物理先验可以存在，并必须同等提供给普通方法。匿名化不能证明没有先验，也不能替代来源干预。

**两个源研究问题：**

| 源问题 | 可以用来约束候选的经历 | 应保留的差别 |
|---|---|---|
| S1：化学装置受一个小阶跃扰动后重新平衡 | 在明确局部线性、稳定平衡及固定外部条件下，读出共轭响应 p 的瞬时变化和其后的松弛；多幅度/复位操作检查局部比例与历史效应 | u 是累计物质扰动，p 是约定的线性化化学势变化；p 不等于净反应速率。最终响应可不为零 |
| S2：有阻 RL 回路受外通量阶跃后的松弛 | 以总磁链 ψ 为内部状态，以外通量 u 为输入；研究共轭输出 p=−I 的瞬时与后续变化，并检查 R>0 的耗散条件 | p 不等于总磁链；单模态理想模型中阶跃响应可衰减至零，但不能把这一终点强加给所有源 |

这些对应本身也应有来源与验证。若开发者直接提供正确 p 的语义对应，该试验测的是给定对应后的归纳/使用；若声称系统自动形成对应，就必须保存它从备选读出中提出、区分并选择该映射的轨迹。

### 4.2 不要见到“两者都会回落”就直接合并

至少保留以下竞争解释：

| 候选 | 当前可能解释什么 | 分叉方向 |
|---|---|---|
| H1：瞬时静态响应 | 稳态前后某些读数变化相似 | 连续时间采样是否存在可重复的松弛；不能只看两个终点 |
| H2：所有扰动最后完全抵消 | 可解释部分电磁读出终点 | 化学源的非零平台是否在新复位/新幅度下重现 |
| H3：稳定的单模态线性松弛，平台与速率可不同 | 两域可共享研究方法，而不共享全部数值或零终点 | 相同时间间隔的比例关系、新幅度叠加与反转预测 |
| H4：多时间尺度、非线性或额外历史 | 短轨迹也可能近似一条指数曲线 | 更长或不同时间窗口、新幅度、相同当前输入但不同前史 |

另保留传感器变换、共同外因或模型集合遗漏的调查入口。两个短轨迹都拟合 H3，不足以排除 H4；不得把有限范围近似线性升级为任意幅度、任意历史的定律。

### 4.3 可提出的共同假设：局部二次势中的一维耗散松弛

主报告使用的候选模板为：

\[
F(z,u)=\tfrac12az^2-bzu+\tfrac12cu^2,
\qquad \dot z=-mF_z,\qquad p=F_u,
\]

此模板中取 \(a,c,m>0\)、\(b^2\le ac\)，使二次势在 \((z,u)\) 上联合半正定。这是所选择二次势模板的结构条件，不宣称所有被动系统都必须有此形式。若从旧平衡施加小阶跃 \(\Delta u\)，随后保持 u 不变，基线扣除后的归一化输出为：

\[
y(t)=\frac{\Delta p(t)}{c\Delta u}
=1-\rho(1-e^{-t/\tau}),
\quad \rho=\frac{b^2}{ac}\in[0,1],
\quad\tau=(ma)^{-1}.
\]

这给出一个**可提出、可挑战的共同方向**：相同的初值/输入/共轭输出关系下，优先测试局部单模态松弛，并允许不同平台和时间尺度。它比“都反抗变化”多给出了时间轨迹、幅度与终点预测。它仍不是两例唯一识别出的物理本体；一般指数曲线拟合也不自动证明系统真的具有这个隐藏势函数。

伴随的问题可以是：

> 当前装置在可重复初始化和小阶跃条件下，是否支持同一局部松弛族？若支持，优先拟合少量动力学参数；若平台不同，保留参数差异；若多尺度/幅度响应不符，调查多模态或非线性；若映射或读出条件未建立，不执行硬剪枝。

**这段模板必须作为提案后的对象或研究人员的诊断上界。**正式自主形成组不能直接把它、完整问题顺序和目标答案塞进提案器，再把保存对象称为自主归纳。可以共享微分、拟合、受控阶跃、候选比较等原语。

### 4.4 第三个未见装置上的使用与可证伪预测

主报告的隐藏机械目标由评测器定义：

\[
F=\tfrac12k_1(u-z)^2+\tfrac12k_2z^2,
\quad\eta\dot z=k_1u-(k_1+k_2)z,
\quad p=k_1(u-z),
\]

这里 \(k_1,k_2,\eta>0\)，对应 \(\rho=k_1/(k_1+k_2)\)、\(\tau=\eta/(k_1+k_2)\)。agent 不获得隐藏 z、这些参数、方程或“这是 H3 正例”的标签；它得到与普通方法相同的位移设置、力读出、时间控制与初始化权限。

如果 source 学成的程序让系统提出阶跃后等时间间隔采样，那么在**无噪声、非退化单模态**假设下，三点可产生候选：

\[
q=\frac{y_2-y_1}{y_1-y_0},\quad
\tau=-\frac{\Delta}{\log q},\quad
 y_\infty=\frac{y_1-qy_0}{1-q}.
\]

要求 \(y_1-y_0\ne0\)、\(0<q<1\)。无响应退化时不能据此识别时间常数；有噪声且差值接近零时该比值会不稳定，需要多点拟合和误差合同。三点拟合不是三点确认：预测第四个时刻、用新幅度和反转协议挑战同一参数模型。**同轨迹第四点是未参与拟合的预测检验，不是新的独立 episode**；重新初始化的独立试验及新装置另行计数。

真正有待检验的收益是：经历形成的程序是否让系统更早选择这条合法研究路径，并减少别的探索、重复确认或错误试探。强普通也可以从同历史重建此程序，或直接进行三点/多点指数辨识；不能把对方规定为高维盲搜。若双方费用相同，或 Hegel 形成与绑定更贵，就没有该场景的净收益。

同一目标族预先保留两时间尺度、非线性、不同合法读出与未知前史等挑战切片；首次试验不要一次改变全部困难轴。第三机械领域仍共享候选抽象机制，不能称为迁移到任意未知机制。一个新装置成功只能证明一次链路成立，分布收益需要更多独立源簇与目标实例。

## 5. 最小实验：来源作用、真值支持和研究效用分别验收

### 5.1 冻结与留出

先将源经历分成提案/修订可见部分与未参与选择的独立确认协议。只有两条已有轨迹而不能购买新数据时，诚实保留“有待检验”，不要硬切轨迹尾部制造独立性。源内新初值、重新初始化和新装置参数的泛化等级分别标注。

问题程序、来源、候选集合、适用范围、选择规则及效用预测在第三族正式目标前冻结。第三族的调试装置与正式目标分开；查看目标反例后形成的新分支可以进入下一轮学习，但该目标从此不再是该版本的未见检验。外部判分只给评测器，不能当免费研究观测。

### 5.2 三个主要比较已经足够

| 比较 | 权限及操作 | 回答的问题 |
|---|---|---|
| H：持久诊断程序 vs O：强普通 | 同模型、工具、原始历史、预算及可保存知识权限；O 可总结、生成问题程序、检索、缓存、按需重建或直解，不被强迫付无用构造费 | 持久化、组织和使用方式是否带来完整成本/质量优势 |
| 同历史单对象移除 | 清理待测对象及其专有副本，保留 raw history 和独立支持知识；允许有界重建或直接研究 | 这个对象是否改变后继行动，而不只是报告里被引用 |
| 关键源经历干预 | 从提案前状态重做：完整双源、仅一源、或匹配长度/难度的无关替代源；同样预算与工具 | 候选及策略是否受关键经历影响；无需强求删一源后假设必消失 |

第三项中，单源也可能凭已有知识提出正确假设，这不构成失败。应比较提案概率、范围约束、反例处理和决策效率；若不看两源也同样形成，则不能把该知识的形成因果归给两源。匹配替代历史用于降低纯上下文长度、暴露量与难度变化的混杂，但匹配本身也要如实记录。

同历史对照回答对象作用；若另比较各自独立探索形成的完整系统，则源历史会不同，属于另一估计对象，不把两者混成同一因果结论。无需把所有对照做成大规模全因子实验；先冻结主 H/O 比较，另外两项选预注册关键对象做机制诊断。

### 5.3 主指标及通过规则

- **预测层：**冻结的候选预测在什么范围得到支持、被反驳或未判定；错误确认、错误拒绝和未知覆盖分别报。
- **消费层：**确切对象版本、目标映射、实际执行的 QuestionSpec、答案及 parent use、由此取消/重排/新增的动作。没有消费事件，不能只凭最终答案中出现同名词认定复用。
- **效用层：**固定预算严格成功率—预算曲线、首次合法确认费用、全部目标成本和失败；不只统计共同成功题。两者都失败也保留费用。
- **摊销层：**两源获取、候选形成、验证、维护、检索、绑定、失败回退、普通组重建及目标求解全部计入。报告有限复用前缀，不靠假设无限未来题把形成费摊成零。
- **不确定性层：**按独立源学习簇/独立装置实例分析；同一对象的多题、同一轨迹的多句或多行不充当独立重复。只有一个双源→第三族演示时不报总体显著优势。

先验收“产生了合理候选且可否证”，再验收“某个新目标确实消费并改变研究”，最后才验收“预注册分布上相对强普通有净收益”。最后一项未通过，不应抹掉前两项；也不能用前两项代替最后一项。

## 6. 分支、合并与停止：不以分支越多代表知识越强

| 新证据或争议 | 最小处理合同 |
|---|---|
| 新目标超出源范围，或前提尚未知 | 建立范围调查；不先把源假设判假，也不自动沿父节点剪枝 |
| 同范围、同协议下两个候选预测不同 | 提出分叉实验；预算不足则保留冲突和未知，不用多数票或更短描述裁决 |
| 稳定松弛获支持但单模态线性失败 | 保留有独立支持的较弱关系，撤回相关单模态/线性资格；多模态或非线性分支须重新验证，不机械复制全部旧权限 |
| 分支范围不交 | 条件并存；无需强制融合 |
| 分支重叠且可兼容 | 提出共享父程序/参数化合并，回归关键正例、有效拒绝和边界，检查消费者仍能区分；结构相似或代码更短不足以自动合并 |
| 旧拒绝被新证据证明错误 | 走经验纠错：撤回旧拒绝并传播受影响依赖；只在声称保真的重组中保持拒绝单调性 |
| 所有候选都失败 | 把候选集、读出和协议本身作为新假设对象；保留失败证据，不换个宽泛父句就宣布解决 |
| 新父假设只剩“系统会变化” | 若不产生新预测/新动作，保留为注释或检索元数据，不授予研究捷径资格 |

形成阶段也要计费和止损：当新增分支没有带来新的可区分预测、操作机会或预期决策改善，先去重、归档低支持候选，或停止本轮归纳。允许为一个明确分歧执行有界互补探针；无需每两步硬换路线。支撑真假的证据与使用频率分开，低效用可以退出默认调度而不删除仍有效的科学记录。[R4]

## 可供总报告引用的结论

用户提出的方向合理：让两个不同领域的研究经历共同约束一个有预测力、可执行、可修订的假设方向；避免把“共同标签”当机制。实现关键不是保证每两个案例都得出正确统一理论，而是让系统能够提出多个解释，安排区分实验，明确范围，并在新问题上接受“普通方法同样能重建、甚至更便宜”的竞争。最终价值以这个过程中新增了什么可用研究能力、实际改善了哪个未见任务来判断。
