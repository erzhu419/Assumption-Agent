# 电磁与控制推导复核：保留正确模型，收紧统一主张

本复核针对用户转来的统一推导中电磁与控制部分。原文片段由主审转交；不把其他 AI 未提出的主张加到它头上。原始资料检索与解析核算日期：2026-11-19。未改动 Assumption-Agent 仓库，未调用模型或重跑项目实验。

## 1. 主判断

**净磁链的低通传递函数可以保留；“所有动态响应都被当前扰动压在 0 与 1 之间”、由此推出普遍同构及无条件稳定，则不能保留。** 原推导把有符号诱导磁链与“抵消量的正幅值”混用了。一起修正这两处符号后，确实仍得到它给出的 RL 低通结果，而不是要把整段计算推翻。

| 原主张 | 复核判断 | 必要修正 |
|---|---|---|
| 净磁链/外磁链为 `1/(1+Ls/R)` | 在明确模型与零增量初态下正确 | 固定几何、线性常量 L、R>0、单回路 RL；磁链必须有符号 |
| 动态过程中分母 `1+τs>1` | 不成立的解释 | s 一般为复数，不能作这种大小比较；改述频率增益或指定输入的时域解 |
| 任意时刻响应比在 `[0,1]` | 即使普通被动 RL 也不成立 | 单调上升输入的特定比较界、频率幅值界、任意历史的瞬时比值是三个不同命题 |
| 弱不等式等价于 `|诱导|≤|外部|` | 还缺少相反符号条件，且幅值界本身也不普遍 | 给出有符号比例；不能把方向约束丢掉 |
| R→0 是积分控制 | 仅“电动势→电流”通道成为积分器 | “外磁链→电流”并不是同一通道；零电阻极限是总磁链守恒 |
| R→0 即 Flux Pinning | 术语与物理机制不匹配 | 区分完美导体的磁通保持、超导 fluxoid 量子化、Meissner 效应、涡旋钉扎 |
| 正的 DC loop gain 保证稳定 | 一般错误 | 看闭环极点、完整环路动态或适用的被动互联定理 |
| κ<0 就失稳、楞次定律失效 | 不能如此泛化 | 反馈增益正负不是稳定性的充分判据；主动元件也不会使 Maxwell–Faraday 符号规则失效 |
| 耗散或 Lyapunov 保证全过程严格下降 | 对任意外驱动不成立 | 非负耗散不等于储能永远减少；要保留外部供能项 |
| 两个给定传递函数同构 | 对原输入输出不成立 | 可比较一类有条件的松弛结构；改变输出为共轭响应后才有更精确的共同族 |

## 2. 从有符号磁链重做推导

以下是依据 Faraday–Lenz 与线性电感、欧姆电阻关系的自行推导；教材基础见 [E1–E2]。为免匝数混淆，用 \(\Psi\) 表示**磁链**，单匝时就是磁通，多匝共同链接时为 \(N\Phi\)。固定回路方向，并定义

\[
\Psi_e(t)=\text{有符号外磁链},\qquad
\Psi_i(t)=LI(t),\qquad
\psi(t)=\Psi_e(t)+LI(t).
\]

L>0 为固定线性自感，R≥0 为电阻；忽略电容、运动几何、铁磁非线性和辐射等额外状态。由总感应电动势与欧姆关系得

\[
\mathcal E=-\dot\psi=RI,
\qquad L\dot I+RI=-\dot\Psi_e. \tag{1}
\]

因此，若坚持原文的 \(\Psi_i=LI\) 是有符号量，就必须写

\[
\psi=\Psi_e+\Psi_i,
\qquad \Psi_i=-\frac LR\dot\psi\quad(R>0). \tag{2}
\]

原文一面定义 \(\Psi_i=LI\)，一面写 \(\psi=\Psi_e-\Psi_i\)、\(\Psi_i=(L/R)s\psi\)，相当于后半段换用了“抵消量”的符号，却没有声明。**两处符号一起纠正，最终方程仍是**

\[
\tau\dot\psi+\psi=\Psi_e,\qquad \tau=L/R. \tag{3}
\]

在零增量初态下——围绕初始平衡减去恒定背景磁链，且初始电流增量为零——有

\[
\boxed{\frac{\psi(s)}{\Psi_e(s)}=\frac1{1+\tau s}},\quad
\frac{\Psi_i(s)}{\Psi_e(s)}=-\frac{\tau s}{1+\tau s},\quad
\frac{I(s)}{\Psi_e(s)}=-\frac{s}{Ls+R}. \tag{4}
\]

若初始总磁链不为零，单边 Laplace 还包含

\[
\psi(s)=\frac{\Psi_e(s)}{1+\tau s}
+\frac{\tau\psi(0^-)}{1+\tau s}. \tag{5}
\]

不能把初态贡献偷偷算成外扰响应。若改以外部感应电动势 \(v=-\dot\Psi_e\) 为输入，则 \(I(s)/v(s)=1/(Ls+R)\)：这与式(4)的磁链输入不是同一实验。尤其不要一边使用电动势的阶跃，一边解读成外磁链的阶跃。

## 3. 不等式何时成立，以及一个不依赖初态作弊的反例

### 3.1 可成立的三种有限陈述

对式(3)、R>0、零初态，可直接解得

\[
\psi(t)=\int_0^t\frac1\tau e^{-(t-r)/\tau}\Psi_e(r)\,dr. \tag{6}
\]

因此：

1. 对非负、单调不减的外磁链，\(0\le\psi(t)\le\Psi_e(t)\)。
2. 对任意有界输入，\(|\psi(t)|\le\sup_{0\le r\le t}|\Psi_e(r)|\)。右边是**过去全部输入的最大幅值**，不是当前输入。
3. 对正弦稳态，\(|G(i\omega)|=1/\sqrt{1+(\omega\tau)^2}\le1\)。这是幅值增益；相位滞后仍会使瞬时比值不同。

原文“\(1+\tau s>1\)”不能表达这些结论：s 一般为复数；在频率分析中应讨论模。在时域则必须解响应并交代输入和初态。

### 3.2 零电流、零外磁链、零启动斜率的光滑脉冲

取 \(\theta=t/\tau\)，A>0，t≥0：

\[
\Psi_e(t)=A\theta^2e^{-\theta},\qquad
\psi(t)=\frac A3\theta^3e^{-\theta},\qquad
I(t)=\frac AL\left(\frac{\theta^3}{3}-\theta^2\right)e^{-\theta}. \tag{7}
\]

输入在 t≥0 光滑，外磁链和其一阶导数在 t=0 都为零，I(0)=0；延拓为 t<0 的零输入在起点为 C¹，无冲激电动势。把式(7)代入式(1)或(3)即可逐项验证。对任意 t>0：

\[
\frac{\psi(t)}{\Psi_e(t)}=\frac\theta3,
\qquad \frac{\Psi_i(t)}{\Psi_e(t)}=\frac\theta3-1. \tag{8}
\]

- t=4τ 时，净/外=4/3>1；诱导磁链与当前正的外磁链同号。
- t=7τ 时，\(|\Psi_i|/|\Psi_e|=4/3>1\)。连放宽后的幅值上界也失效。

这不是负电阻、外加初始电流、非线性或特殊超导效应。它发生在最普通的被动一阶 RL 中，原因是系统保留了过去输入的状态；下降阶段的当前输入已小于它的历史加权平均。式(1)始终成立，不能把反例叫作楞次定律失效。

更简单的一侧光滑脉冲 \(\Psi_e=A\theta e^{-\theta}\) 给出 \(\psi=(A/2)\theta^2e^{-\theta}\)、净/外=θ/2；式(7)只是额外令启动斜率也为零。

### 3.3 方向不能被绝对值抹掉

在 \(\Psi_e\ne0\) 时，

\[
0\le\frac\psi{\Psi_e}\le1
\iff -1\le\frac{\Psi_i}{\Psi_e}\le0. \tag{9}
\]

式(9)既要求幅值不超过，也要求有符号诱导项与外部项相反或为零。仅有 \(|\Psi_i|\le|\Psi_e|\) 允许同向叠加，因此不是等价命题；在外部项为零时，比例还没有定义。即使把反号条件补上，式(7)仍说明它不是任意输入的普遍规律。

## 4. R→0：守恒、时间尺度与超导术语

先取 R>0，对从零开始的理想外磁链阶跃 A，式(3)给出

\[
\psi(t)=A(1-e^{-Rt/L}),\quad
I(t)=-\frac AL e^{-Rt/L}\quad(t>0). \tag{10}
\]

理想阶跃对应一个电动势冲激；也可用有限但很快的上升沿近似，下面的长期极限结论不依赖理想尖沿。任意固定 R>0 等足够久，电流消失、总磁链达到 A。固定有限 t 让 R→0，则总磁链趋于零，电流保持抵消状态。因此

\[
\lim_{R\to0^+}\lim_{t\to\infty}\psi(t)=A,
\qquad
\lim_{t\to\infty}\lim_{R\to0^+}\psi(t)=0. \tag{11}
\]

**这两个极限不能互换。** R=0 本身必须从式(1)直接处理，而不能继续使用 I=E/R：

\[
\frac{d}{dt}(\Psi_e+LI)=0,
\qquad \psi(t)=\psi(0). \tag{12}
\]

守恒值由初态决定，并不必然为零。“完全抵消”准确地说是外磁链的**变化量**由自磁链的反向变化补偿。MIT 完美导电讲义也把 L/R 与观察时长分开，见 [E3]。

若输入是 v，R=0 时 \(I/v=1/(Ls)\)，确有积分器；若输入是 \(\Psi_e\)，则零增量初态下 \(I/\Psi_e=-1/L\)。所以可以说“电动势积分形成持续电流”，不宜直接说这个被动回路已经是带误差信号和参考值的积分控制器。原来以总磁链为误差的反馈式(2)甚至含 \(\tau s\)，不是 \(1/s\)。同一物理系统可有不同框图实现，框图名称不能替代对端口与状态的定义。

超导相关概念应保持以下区别：[E3–E6]

| 概念 | 与此模型的准确关系 |
|---|---|
| 完美导体的磁通保持 | E=0 与 Faraday 关系使已有磁通保持；需要初态，不自动排出原有磁场 |
| Meissner 效应 | 合适超导相和外场条件下的磁场排斥，涉及额外超导本构；不能只由 R=0 推出。也不能忽略穿透深度、临界场和混合态 |
| Fluxoid 量子化 | 超导闭合路径上磁通项与超流动量/电流项的组合量子化；一般不等同于所有几何下的裸磁通量子化 |
| Flux pinning／磁通钉扎 | II 型超导中的涡旋被局部缺陷或正常区域等束缚，牵涉钉扎力与退钉扎条件；不等于式(12)的一般磁链守恒 |

因此原文的“磁通量锁定 Flux Pinning”应改为“该理想闭合回路的总磁链保持初值”。如果要讨论超导环的真实实验，另加超导模型和工作区间，而不是把这些机制当成同一个词。

## 5. 正静态反馈增益不够；负增益也不自动失稳

对负单位反馈，闭环特征条件是 \(1+\mathcal L(s)=0\)。考虑本来稳定的三个一阶环节

\[
\mathcal L(s)=\frac K{(s+1)^3}.
\]

取 K=27>0，特征多项式为

\[
(s+1)^3+27=0,
\]

极点为

\[
-4,\qquad \frac12\pm i\frac{3\sqrt3}{2}.
\]

两个极点实部为正，所以失稳，尽管 DC loop gain 为正且反馈接线为负反馈。MIT 的原始控制教材直接给出同族例子：稳定区间为 \(-1<K<8\)，见 §6.3、Example 6.3-1/3 [E7]。反过来，这个区间也含负 K；“一旦 κ<0 必然不稳定”同样不是一般控制结论。

本例说明动态延迟和相位不能由一个静态符号取代，不意味着普通 R>0、L>0 的式(1)会自发失稳。式(1)的极点明确为 −R/L。若另引入负阻或有源反馈，它可从电源获得能量；能量账及闭环稳定性需要更新，Faraday–Lenz 定律本身并没有因此失效。

还可给出纯被动、稳定却超调的例子：串联 RLC、L=C=1、R=0.4，以电容电压为输出，电压传递函数为

\[
G(s)=\frac1{s^2+0.4s+1}.
\]

零初态单位阶跃的峰值为 \(1+e^{-\pi(0.2)/\sqrt{1-0.2^2}}\approx1.5266\)。它只用于说明“被动／稳定”不能推出任意观测量都无超调；不应把 RLC 的结论偷偷算作单一 RL 的结果。对于本审计，式(7)已经足够否证无条件点态上界。

## 6. 耗散的正确符号，以及何时存在递减量

式(1)乘 I，得到严格能量账

\[
\underbrace{\frac d{dt}\left(\frac12LI^2\right)}_{\dot W}
=\underbrace{(-\dot\Psi_e)I}_{\text{外部供能}}
-\underbrace{RI^2}_{D\ge0}. \tag{13}
\]

“耗散功率”通常指 D≥0；能量导数里的耗散贡献是 −D≤0。两种记号应分清。外部输入可以给电感充能，所以任意驱动下 \(\dot W\) 可正可负。脚本中的零初态脉冲在 θ=0.5 时就给出 \(\dot W>0\)，同时严格满足式(13)，没有违反被动性。[E2]

固定外磁链、不再供能时，\(\dot W=-RI^2\le0\)；R>0 且 I≠0 时才严格为负；R=0 时为零。一般被动系统的自然陈述是

\[
W(t)-W(0)\le\int_0^t v(r)I(r)\,dr,
\]

而不是“外界持续改变时总能量仍必须严格下降”。从半负定导数进一步推出渐近收敛还要检查不变集等条件；对于这里的标量 RL，直接解已经给出了收敛结论。

## 7. 两条原传递函数不是同一输入输出系统，但共同松弛族值得保留

即使接受原文化学通道的

\[
G_c(s)=\frac{s+k_-}{s+k_++k_-},\qquad k_+,k_->0,
\]

它与电磁总磁链通道 \(G_m(s)=1/(1+\tau s)\) 仍有不同的输入输出不变量：

| 性质 | 化学给定通道 | RL 总磁链通道 |
|---|---|---|
| 高频极限 | 1，含直接通过项 | 0，无直接通过项 |
| DC 增益 | \(k_-/(k_++k_-)\) | 1 |
| 零点 | −k_- | 没有有限零点 |
| 分母与分子次数差 | 0 | 1 |
| 正输入阶跃 | 先即时响应，后部分松弛 | 从零逐渐跟上外磁链 |

单纯改单位或时间尺度无法把这些区别消掉。称二者“都是一维稳定松弛系统”有意义；称上述物理输入和输出已经严格同构则过强。如果允许重新取线性组合输出、微分或积分输入，必须明确这个变换和实验上的可实现性。

**更建设性的共同模型**是选定内态 x、外控 u 与能量／势函数

\[
F(x,u)=\frac12 a u^2+bux+\frac12 c x^2,
\quad \dot x=-mF_x,
\quad p=F_u,
\]

其中 a,c,m>0、ac≥b²。在零增量初态下，直接解得

\[
\frac{p(s)}{u(s)}=a-\frac{mb^2}{s+mc},\qquad
\frac{p(s)}{a u(s)}=
\frac{s+mc(1-\rho)}{s+mc},\quad
\rho=\frac{b^2}{ac}\in[0,1]. \tag{14}
\]

对 RL 取

\[
x=\psi,\ u=\Psi_e,\ F=\frac{(\psi-u)^2}{2L},\ m=R,
\quad p=F_u=-I,
\]

即可恢复式(1)与(3)。这时 ρ=1，归一化共轭响应是

\[
\frac{Lp(s)}{u(s)}=\frac{s}{s+R/L}, \tag{15}
\]

**不是原来的总磁链低通输出。** 化学所给通道在数学上对应 \(mc=k_++k_-\)、\(\rho=k_+/(k_++k_-)\) 的同族式(14)；物理上还须核对该化学变量是否确实是所选势函数的共轭变量。这个对齐提供了有条件的共享模型，不是自动证明两个领域所有观测量相等。

此共同模型在外控 u 固定时有 \(\dot F=-m(F_x)^2\le0\)；u 变化时则是

\[
\dot F=-m(F_x)^2+p\dot u. \tag{16}
\]

因此它同时保留了可迁移的储能、耗散和松弛结构，也正确容纳外部供能、零耗散边界与历史依赖。名称“共同惯性”不如这个带有具体变量、端口和边界的模型准确。

## 8. 对 Hegel 的最小用途

这组推导适合保存成**一个带反例和适用域的研究程序**，而不是直接授予“勒夏特列与楞次已统一”的真值：

1. 先询问输入是水平、变化率还是电动势，输出是总量、诱导项还是共轭量；显式记录符号和初态。
2. 在保持—下降—脉冲协议中检验拟议上界，区分频率增益、静态响应与时域点态响应。
3. 拟合或推导状态与能量账，验证储能、耗散、外部功；遇到反例先检查端口映射和状态缺失，不直接宣称基础定律失效。
4. 形成分支：有耗散松弛、无耗散守恒、多储能共振、有源驱动。仅在相同条件和同一可观测量上比较分支预测。
5. 把式(7)和式(11)留作持续回归反例：新融合假设若重新推出任意点态 `[0,1]` 或无条件长时完全屏蔽，就应被拒绝或缩小范围。

这些步骤的正确性不等于 Hegel 已学到或已在未见任务上获益。后者仍要有真实形成经历、目标调用记录、独立验证与允许普通方法重建同一知识的成本质量对照。
