## 1. 主判断

Gemini 的方向中，值得推进的是“记住可执行的诊断问题及其适用边界”，以及“比较复用、重建和直接研究的真实代价”。但它把几个待检验假说写成了已成立的理论结论：

1. **当前账本不足以直接给每个新状态一个有统计保证的 `ΔQ_LCB`。** 可审计的确定性程序只是可复现；置信保证还需要可识别的比较、样本支持、误差模型和独立评价。
2. **计划中的优势下界公式本身不成立。** `LCB(Q_option) − 点估计(Q_direct)` 一般不是两者差的下界。
3. **回退普通方法不能消除已经支付的提取、检索、绑定、探针和选择成本。** 应承诺预算上限并实测决策开销，不能承诺“零税”。
4. **更困难的问题值得增加，但“只有组合爆炸才能证明不可替代”没有得到当前结果或文献支持。** 强普通方法也应有分解、主动提问、缓存和从原始历史重建相同知识的权利。
5. **“2–3 次探针剪去 90%”目前是性能目标。** 必须明确被剪的是什么、是否保留真机制、是否取消实际研究工作，以及探针和错误剪枝的代价。

下一步最合适的研究形态，是一个窄域、前瞻冻结、允许强普通重建的**带成本的策略选择实验**。可以把策略封装为 option；不必先实现完整 offline RL，更不必把检索相关性分数称为因果净价值。

## 4. 价值门控：先修数学对象，再谈学习算法

### 4.1 option 定义可用，价值保证需要另外建立

经典 options 将持续多步的行动表示为起始条件、内部策略、终止条件（LR09）。因此把一次“绑定旧假设—执行判别问题—局部修订—确认或退出”封装为 option 是合适的工程接口。状态至少要包含：当前观测、可用对象及版本、可访问历史、已经失败的绑定、剩余预算、研究器版本。只用 `s_pilot` 而忽略这些信息，会把成本和可行动作不同的情形混在一起。

候选对象的相关性、语义适用性和使用后的净价值应分开：

- 检索分数回答“值得检查哪一个”。
- 适用性检查回答“哪些前提已支持、被反驳、仍未知”。
- 价值选择回答“在剩余预算内，下一步这样做是否比其他允许动作更划算”。

PPR 权重可以帮助排序，但不能因为权重来自一个名为 Q 的函数，就把排序变成适用性证明或因果收益证明。

### 4.2 原式不是优势下界

设 Q 越大越好。原式为：

\[
\widehat\Delta_{\mathrm{LCB}}=
\mathrm{LCB}(Q_o)-\widehat Q_d.
\]

反例：真实 `Q_o=8`、其有效下界为 8；真实 `Q_d=10`，但点估计为 5。原式得到 +3，真实差为 −2。这是代数问题，与是否使用神经网络无关。

若有适用的联合覆盖保证，可以使用：

\[
\underline\Delta=\mathrm{LCB}(Q_o)-\mathrm{UCB}(Q_d),
\]

或在可配对实验中直接对差值构造下界。若 Q 实际代表成本，则先统一符号为 `节省=普通成本−候选策略成本`。成功与假确认不能被未经注册的成本权重隐去；宜先要求合法完成和错误确认满足预定标准，再比较资源，或事先定义明确的有界复合效用。

即便修正了公式，**对固定策略平均收益的下界，不等于对每个新状态的收益保证**。CQL 原文专门区分策略期望值下界和逐状态动作值下界（LR10）；不能把它的理论名称移植到任意账本均值上。SPIBB 的保守回退也依赖覆盖和基线等条件（LR11）。同时在许多 motif、阈值或相似性特征中挑最好的一个，再引用未经调整的单个区间，会引入选择乐观偏差。

### 4.3 离线账本目前缺少什么

已有运行只记录实际选择的路径。没选过的动作，其成功和成本不可从“看起来相似”直接得到；简单把被复用的题与被直接求解的题比较，会混入难度、可用历史与选择策略差异。离策略评价中的直接建模、重要性加权和双重稳健估计各有数据和模型前提（LR12），不是三种名称中任选一个即可补齐反事实。

建议第一版选取便宜、可克隆的开发环境，**在同一个决策前快照上运行两个备选策略**：

1. 普通研究，具有全部允许的原始历史和自行重建能力；
2. 选定对象的有限额绑定/提问/修订，失败后以剩余预算回退普通研究。

快照应包括 agent 可见状态、环境状态和随机状态；环境内部真值只能由评测器用于克隆与评估，不能进入选择器输入。两个分支的源历史、库版本、前置成本和总预算一致。开发期这样收集配对代价，比从六个来源不同的旧簇硬拟合“离线 Q”更可解释。它只识别指定快照分布上的局部策略效果；整条持续学习轨迹仍需独立的端到端比较。

先使用可审计的简单预测器或有限分组选择规则，并称其为 **经验收益估计/启发式门控**。按源簇划分训练、校准和最终评价；同簇的后继目标不能跨分割。未覆盖状态先回退；有足够独立数据和可说明的区间方法之后，才使用 LCB 的名称。无黑盒网络是可选实现，不是统计保证。

### 4.4 回退有成本，源成本也不能重复扣

若判断之前做了新探针或检索，即使最后直接求解，总成本仍是这些开销加普通求解成本。可行承诺是：复用共同必需的 pilot；对额外检索和探针设置明确上限；普通求解和最终确认留有预算；每次回退保存原因。SATzilla 就把特征计算计入运行时间，并使用短预解、特征超时与备用求解器（LR13）。

比较应同时有一个不承担多余 pilot 的真实普通策略，以量出决策开销；用于局部归因的匹配分支则共享相同已付 pilot。不能把两种口径混成“零税”。

运行时已付的源组织成本可以作为沉没成本，不必在每次局部动作选择时重扣；系统总体收益仍必须把源研究、组织维护和目标开销**各算一次**。构建新对象或当场重建的费用不是沉没成本，必须计入该动作。若要讨论摊销，应冻结目标序列长度和任务混合，报告真实前缀，而不只挑足够长、恰好转正的前缀。

## 5. 困难任务、相似性和探针削减的证据要求

### 5.1 困难度增加是实验因素，不是不可替代性的证明

当前某题普通计算约 5.8 万，最多说明当前 Hegel 复用流程不划算；它不构成“任何跨问题抽象都必然更贵”的复杂度下界。一个更短的有效筛选可能改善易题；一个昂贵的跨域绑定也可能在难题更差。

增加困难任务时应预先定义一个复杂度轴，例如组合数、不可观测状态维数或竞争机制数，并保留易、中、难分层。普通方法应能做结构分解、主动实验、局部规则缓存和相同原语搜索。把普通方法固定为明知低效的平铺穷举，只能说明该穷举器的缺陷。

可以在开发集调节难度避免双方都满分或都失败，之后冻结生成器和分层比例；不可观察 Hegel 赢在哪些实例后才定义“真正困难”的测试集。更复杂不等于更未见，换维度或变量名也不自动构成机制分布外。

### 5.2 匿名化不能彻底排除预训练影响

匿名角色名有助于减少词面捷径，但已知的结构和提问模板仍可能来自模型先验或程序员编码。主张“经验学出新提问树”需要来源干预：在保持任务、预算和其他经历的前提下，移除关键源经历或替换为匹配但不支持该树的经历，检查是否仍产生同样的树，以及未见目标行为是否随之改变。不得把预先硬编码的 Q1、完整新域叶节点或 oracle 机制标签注入系统后，再归功于自主形成。

应将两种相似性分开评价：检索上的可匹配关系，以及能预测“使用此经历会节省研究”的效用相关性。前者的召回率、结构同构或困难负例分类准确，不自动支持后者。让同内容的平面索引、图索引和可执行问题树获得同样的信息；比较哪种组织确实更快，同时容许普通方法自行形成等价知识。

### 5.3 “2–3 探针剪 90%”怎样转成可检验声明

先固定有限候选机制集或先验，并合并仅语法不同、预测等价的候选；否则可以通过重复低价值 AST 人为抬高剪枝比例。报告至少四项：

1. 被排除的候选质量/数量或后验质量，并注明其定义；
2. 真机制或所有仍与观测相容的机制被错误排除的比例；
3. 原本普通搜索确实会执行、现在被有根据取消的操作数及其成本；
4. 包含选问、探针、检索、重建、回退和确认后的总资源与严格完成率。

信息论提供一个简单检查：在均匀候选、无噪声、每次只返回一个二值答案且均衡分割时，三问把候选数降为八分之一，即剪去 87.5%，不是普遍保证的 90%。多值或连续读数可能携带更多信息，但其取得和解析成本也要计费。这个例子不是说三问永远不能剪 90%，而是说明必须给出观测字母表、候选先验和条件。

自适应次模性文献说明，贪心信息/覆盖收益的保证需要特定目标与分布条件，也讨论非均匀代价和噪声（LR14）。不能把“选信息量最大的问句”直接当作对任意科学假设空间的节省定理。高信息量问题还可能与当前任务的决策无关；应以剩余求解成本的变化验证其价值。

## 6. 强普通、移除与历史干预：不同问题需要不同对照

| 对照 | 信息与权限安排 | 它识别的问题 |
|---|---|---|
| **完整策略主比较：Hegel 与 O_strong** | 同任务源流、原语、研究 API、预算和确认标准；各自形成并带入自己的记忆；普通可总结、提问、筛选、缓存、重建 | 当前完整组织策略是否在源加未见目标上值得采用；不是单个组件的因果效应 |
| **同历史的局部策略配对** | 相同原始经历、库/状态快照、已付 pilot；只改变接下来的有界动作，双方可回退 | 指定上下文中使用新对象/问题树的边际效果；不能取代自主源形成的主比较 |
| **同内容 Flat 与 Graph** | 同样对象、证据与适用性规则；只改变索引组织和检索调度，构建费明确计账 | 图检索相对平面组织的作用；不能由此证明这些知识是自主生成或不可重建 |
| **完整载体移除，保留历史** | 预先选择待干预版本，删除其载体及独占派生副本；保留原始历史、普通能力及可选有界重建 | 被物化对象的贡献；不得强制重建到耗尽预算，也不能只删一张表留下等价副本 |
| **源经历干预** | 删除或匹配替换关键经历，再完整运行形成与后继使用；保留失败链和其他权限 | 新对象/问法是否依赖那段经历；不单独证明目标收益 |

第一次最小实验不需要同时铺开五个大型臂。主比较先做 Hegel 与 O_strong；少量预注册机制案例做快照配对和完整载体移除。只有证实检索已成为实际瓶颈后，再加 Flat/Graph。形成链条有疑问时再用源经历干预；不能在最终测试中只挑“恰好检索到新对象”的样本做唯一效用统计。

O_strong 无需免费得到 Hegel 的完整成品对象；它需要获得相同原始经历和重建同知识的能力，费用真实计入。同内容消融故意给两边同一内容，是为了隔离组织因素，须明确其条件性。普通方法能重建，恰是要检验在有限资源下保存这段知识是否值得，而不是必须规避的挑战。

## 7. 最小可证施工与停止条件

### 第一步：修清现有成本和默认策略

修有界可选重建、失败缓存、版本/范围与互斥计费；让“拒绝复用”留下实际成本。对 V15 两个真采用却更慢的 A2 做已有轨迹诊断，区分检索、绑定、重复搜索和确认开销。V15 数据只作开发证据，修后不能重新称它为未见测试。

### 第二步：先形成一个可执行的经验问题树

选择单一机制族与一个明确混淆族，例如有历史依赖与无历史依赖的关系；由普通源研究记录生成问题树，源中必须包含让叶分支失效的反例。保存每个问题的可执行干预、预测分歧、适用前提、结果证据和版本依赖。父节点仍未知时可以继续询问，不能将“未证伪”升级为已确认适用。

同一源经历允许 O_strong 形成自己的诊断策略。手写树可以作工程上限或开发控制；自主生成树必须另标，以免把设计者的洞见当系统学习成果。

### 第三步：开发期学习是否值得调用

在匹配快照中比较有限额问题树路径和普通研究；用完整结果与成本学习一个简单门控。日志至少含 `source_cluster_id`、`history_digest`、`object_version`、`observable_state`、`available_actions`、`chosen_action`、动作预算、每项互斥扣费、停止原因、严格完成和外部误差。若只执行部分动作，保存行为选择概率；未运行的反事实留空，不用启发式补成真值。

源簇间划分训练、校准与评估；按照拟声称的泛化范围额外留出机制/表征家族。小样本阶段只称探索性门控，不制造每状态的统计保证。所需确证样本量由预先定义的最小值得改善幅度及开发期簇间差方差决定；六个历史簇不足以支持复杂状态下的细粒度保守价值表。

### 第四步：冻结后只回答一个主问题

新源簇及其后继未见目标预先固定，保留易中难和兼容/不兼容分层。主表报告严格完成、假确认、未决、源加目标总成本、目标成本、顺序前缀和以源簇为单位的配对不确定性。双方都成功的题上可以展示成本，但须注明它是事后条件描述，不能替代全体样本的主比较。

门槛建议按证据层分开：

- **机制成立**：新问题树能追溯到经历，目标实际执行了相应问题并改变后继搜索；完整移除或经历干预有预期影响。即使净效用为零，也保留这一成果。
- **实例收益成立**：至少一个预先登记、未见目标在相同确认要求下由这条路径节省了实际工作；同时公开该簇全部目标和失败，不只展示赢家。
- **分布收益成立**：冻结主比较在预设质量要求下给出完整成本改善，报告区间和失败，不以单例或反复选阈值代替。

若树确实形成并被用到，但同内容普通策略追平，结论是“知识有用，当前组织没有额外净收益”；若只有手写树有效，改进知识形成；若结构识别好而使用更慢，改进调度和绑定；若问题本来无需历史，改进任务分布定义，但保留原来的失败结果。这样每种结果都能决定下一步，而不必用更大架构掩盖尚未识别的原因。
