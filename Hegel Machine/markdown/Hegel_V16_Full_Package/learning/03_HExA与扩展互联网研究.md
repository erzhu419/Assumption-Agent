# HExA：与“由研究经历形成可迁移提问策略”更直接的对照

日期：2026-11-19（Asia/Shanghai）。本次核读[论文v2](https://arxiv.org/html/2606.29315v2)（2026-10-09）的方法、§4.4、附录B、F、G相关段落，以及官方仓库少量接口；没有复现实验。应将它加入核心相关工作，优先级高于仅因“RSI”命名而相关的研究。

## 1. 相似之处已经足够具体

论文从实验成功/失败的对比中提炼策略，再保存错误及失败中的局部技能；bank具有原则、适用条件和来源。后续经历可修改旧内容，但作者明确说它**不是显式树**。跨任务合成使用源bank及目标描述，不使用目标轨迹。相关设置和边界见§3、B.3–B.8、§4.4。

这与用户期待的“经历改变下一步该问什么、怎样实验”已经高度相邻。Hegel不宜再将“外部记忆里存可复用研究策略”本身视为独特贡献。值得检验的差异应是：执行式前提、可重放范围检验、修订与分支的版本身份，以及相同原始经历允许普通方法重建时的净收益。

也不应反过来认为，HExA已经完成用户设想的全部治理。自然语言规则被改写，与系统能解释“哪个反例击中了哪个前提、为什么保留父节点、为何融合而非分叉”是两个层次。Hegel需要明确增加的能力及其开销，并用干预证明值得增加。

## 2. 强基线与成本：承认已有工作，也保留限制

论文有Episodic RAG和MemRL，并非只胜过无记忆ReAct；它们在相同训练实例上积累各自经验。不过公开协议的轨迹呈现限制为末12步、每条观测600字符；跨任务Table 20主要对照无记忆组。本文未确认“同一完整raw history、允许普通方法按需蒸馏重建”的实验（F.4–F.8、G.4）。

因此，可借鉴的是具有经验学习能力的基线，而不是把论文里的每个对照直接当作Hegel所需的最强普通方法。训练实例相同仍不保证实际经历相同：不同策略会观察到不同结果。研究完整学习系统可以保留这种差异；若解释一个知识对象的边际价值，就还需要固定历史与决策快照。

成本表有进步：Table 11列出建库actor与evolver token。但F.8.1另外列5个warm-start、51个训练、50个held-out；F.7出现`51 = 5 + 17×3`的不一致。**全部预热与初始蒸馏是否进入该表，本次不能确认**；该表也不是跨任务全部源库及合成成本总表。

这不推翻作者的观察，却限制“全成本更省”的引用范围。token不是全部模拟、检索和运行成本；每成功实例成本也不等于总预算更少。Hegel应保留作者已经做到的成本透明度，再补齐预热、生成、维护、选择、目标验证和失败回退的互斥账目，而不以摘要中的最佳成功率替代这些核对。

## 4. 值得加入的最小强普通基线

建议在现有窄域增加一种HExA式**紧凑策略与错误bank**，无需先移植整个物理环境。它从与Hegel相同的原始源经历形成“何时适用、如何实验、常见失败、来源”条目，允许合并、重写、重新蒸馏；它也能直接研究目标，不能被强制提前重建到预算耗尽。调用、上下文和维护费用全部计入。

初始主比较可以是Hegel的问题树与这一有能力的普通学习策略。另在少量预先登记案例中固定完整历史、目标pilot与预算，比较已有树和移除树后可选重建；不只挑树恰好获胜或被采用的题。若随后需要区分知识内容和组织方式，再给平面bank与树同样内容，做独立组织对照。

最低交付是一条能够回答用户原问题的链：普通研究遇到什么失败，系统因此新增了什么可执行问题；该问题区分了哪些仍可能成立的解释；新证据为何修改或保留旧分支；在一个事先未见目标上，它取消了哪些本来会发生的研究工作；允许普通方法重建后，这项节省是否仍超过全部额外费用。

若紧凑bank追平树，结论可以是经验知识有价值，但显式层级尚未增加净收益；若树只在冲突、范围变化中获益，就将贡献定位在这些条件。这样的结果比证明“树更高级”更能指导后续建设。

## 5. 引用范围

本文没有采用摘要里的“最高100%”等数字。论文事实只支持已述机制与协议，成本缺口标为未确认，代码结果限定于上述固定版本。扩大互联网研究应按问题选择来源；HExA提供了非常贴近的竞争解释，不能因为它不以自修改代码为中心而被排除。
