## 3. 复算与控制入口

先解压用户已有V15原包为某个目录，例如/absolute/path/v15_input，再在本包中运行：

~~~bash
python evidence/recompute_v15.py --bundle /absolute/path/v15_input --output recomputed_again.json
python evidence/scope_controls.py --bundle /absolute/path/v15_input --output scope_controls_again.json
python /absolute/path/v15_input/05_STANDALONE_VERIFY_V15.py --bundle-dir /absolute/path/v15_input --output author_verifier_again.json
~~~

第一条只重算保存结果，不验证原始物理测量本身；第二条为最小实际函数控制；第三条是作者提供的验证器，验证范围与独立科学效用不可混同。

本包evidence/results_protocol.md提供数值推导、逐簇表、AST失败诊断；evidence/scope_cache.md提供函数位置和边界；recomputed_results.json提供机器可读复算及trace_cases。
