- 放开 `O_strong` 保留同维全部有效历史候选（含单源及近失例）并采用 $S_d$ 对称 5 点/6 点 pilot 后，两臂在目标期物理测量费打平（`ΔMeas = 0.0000`，均为 `340.0`/簇），而 `Hegel_M2` 因条件定向召回免除同维多 schema 遍历，目标期逻辑计算节省 `ΔCompute = -179.0000`（实测 Python 子进程耗时 `0.865s` vs `1.079s`，默认 `λ=0.05` 下目标期净省 **`-8.9500`**，`4/4` 簇全负）。
