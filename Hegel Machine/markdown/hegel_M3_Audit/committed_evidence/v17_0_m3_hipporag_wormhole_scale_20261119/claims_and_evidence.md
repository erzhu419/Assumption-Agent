## 1. 大规模异质跨领域森林构建（`K = 36` 源与近失工作区，`23` 类可执行 Python 机理）
- 在 `2` 个开发簇（`m3_dev_01..02`）与 `4` 个独立冻结评测簇（`m3_eval_01..04`）上，每簇 `36/36` 个源与反例近失工作区 100% 严格通过，自动归纳为 **36 个活跃概念节点**、**27 个可观测几何/协议特征词（`sig:*`）**、**4 条树内纵向辩证细化边（`local_implication_edges`）** 与 **11 条跨树中间层横向虫洞（`HorizontalWormholeEdge`）**。
- 所有检索查询均通过 `validate_observable_query_signatures` 强校验（严禁任何 `schema:*`、`domain:*`、`truth:*` 等标签词进入索引或查询）。

## 2. 单因子受控 7 臂大规模评测（`672` 个未见目标工作区，全部 `96/96` 严格通过、`0` 假确认）
- **相对 100% 同元数据 `Flat_BM25_EqualMetadata` 与 `Flat_Overlap_EqualMetadata`**：
  - 目标期复合成本净省 **`-12.4879`**（`4/4` 簇全负），**目标期纯物理测量费（`λ = 0`）净省 `-10.0000`（`4/4` 簇全负）**，计入 `HippoRAGWormholeIndex` 更高建索引开销（`51.15` vs `7.20` 逻辑计算）后的端到端总成本仍净省 **`-10.2904`**（`4/4` 簇全负，平衡点 `N* = 13`）。
  - **精确机制归因**：`Flat_BM25` 在一跳直接词面重合目标上具有略高 `Recall@1`（`0.7826` vs `0.6957`），但在两跳跨协议非传递桥接目标（如 `T13`）上受单域反号干扰项稀释，`Recall@2` 跌至 `0.9130`（漏召回被迫退回全量探索）；而 `Hegel_M3_HippoPPR` 借助跨树虫洞随机游走实现 **授权 `Recall@2 = 1.0000`（`92/92` 零漏召回）**，每簇错误试算降至最低（`5.0` vs `6.0`），节省真实物理探针点。
- **相对关闭横向虫洞的纵向森林 `Forest_VerticalPPR_NoWormholes`**：
  - 目标期复合成本净省 **`-69.8999`**（`4/4` 簇全负），**物理测量费净省 `-60.0000`**，授权 `Recall@1` 从 `0.5652` 提升至 `0.6957`、`Recall@2` 从 `0.8696` 提升至 `1.0000`，错误候选试算从每簇 `13.0` 次降至 `5.0` 次（平衡点 `N* = 8`），直接在大规模干扰库中证立跨树横向虫洞的独立结构因果贡献。
- **证立“召回 != 授权”（相对 `HippoPPR_UncheckedRecall`）**：
  - 同一 PPR 图索引下，剥离 Tier-2 契约/排除谓词/`compose_wormhole_chain`/`ScaleMap` 审查后，每簇错误候选试算从 `5.0` 升至 `9.0`（`Hegel_M3_HippoPPR` 零子进程开销提前拦截 `108` 次违约候选），目标期复合成本恶化 **`+29.7650`**（`4/4` 簇一致）。
- **相对全历史强基线 `O_strong_AllValidatedPriors` 与条件技能库 `O_HExA_CodeSkills`**：
