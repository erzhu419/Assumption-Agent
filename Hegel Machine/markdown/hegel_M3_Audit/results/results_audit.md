## 9. 推荐的最小修复顺序

1. **先修实际消费和等价计价：** 让 HExA 的适用错误恢复技能进入候选；等价搜索工作统一记费；桥拟合进入 source ledger。
2. **重校准、冻结、重放：** 复用现有两 DEV / 四 EVAL 架构，在新价目下更新门控并保存状态，重新给出原始和修正费用两套结果。不沿用本报告未重算的归一化 N\*。
3. **拆清结论与统计单位：** 表格标注每簇、每题、四簇合计；Recall 使用相同查询分母并分开原始排名和授权后命中；展示单题贡献、DEV 分摊假设和随机顺序回本。
4. **再做有针对性的规模验证：** 固定机制和目标，仅改变候选干扰规模；补几种困难桥任务。有限机制模板在当前受控研究中是合理设计，本审计不要求先改成任意科学发现系统才认可结果。
