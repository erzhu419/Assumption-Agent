# 黑格尔机：未完成主目标的研究与实施计划

日期：2026-10-11  
依据：116 页 `manuscript(2).pdf`、五份原始构思 Markdown、上一轮重写审阅，以及 `03fa97b44b21741d40ec72e08dfc497cabdbbb4f` 的相关实现。  
性质：研究建议与待检验算法设计，不是现有成果报告，不是新的正式执行授权，不修改既有实验结果。

## 0. 主决定

下一条主线应是：

> **在没有被告知故障类型的情况下，从可复现失配中自主提出并检验表示、观测和关系修订；把成功的修订抽象成后续研究能利用、也能撤销的知识。**

第一篇论文可以按“有限的递归假设研究框架及机制证据”收尾。更强的概念发现、任务相关尺度、鲁棒化和元改进，应作为下一轮独立研究，不要求把全部终局愿景完成后才投稿。

关键区分：

- **实现缺口**：缺少生成新研究对象的算法，例如自动构造一个此前未提供的历史状态或实验程序。
- **采用缺口**：能力可调用，但 Agent 不触发、不消费返回答案，或没有完成前瞻检验。
- **证据缺口**：局部能运行，尚未证明对新任务有价值。
- **归因缺口**：效果存在，但不能排除更好候选、更多算力、普通代码记忆或人工接入造成的作用。

这些缺口需要不同的修复。不能用新增 schema 解决生成问题，也不能用接口测试解决泛化问题。

## 1. 基线与不应重做的工作

### 1.1 已经存在的基础

原论文与当前代码已经包含：可执行 `Program` / `Definition`；支持条件与调用依赖的区分；先提出再取得证据的在线子研究；测量与表示修订；可执行方法编写、实践和冻结执行；反例后保留旧计算；新旧数值档案在后继条件中的复用。

当前 `world_response_consequences.py` 已有四条件后果面板、基函数族去重、有作用域的历史排除复用；成员票数不被当作参数后验。不能再把这些描述成待从零实现的功能。

当前 `growth_methods.py` 从实际行动轨迹编译研究程序，并用成功和失败使用记录形成作用域；其中一种具体实现仍使用固定的五类诊断特征及分离阈值。它是可以扩展的入口，但不能由此推断整个项目所有作用域学习都只有这一种方法。

### 1.2 已有结果对下一轮的约束

原论文第 12–16 页表明：显式递归与强平铺控制在有限任务上可以打平；方法书可降低部分后继成本；保留旧程序有收益但条件标记未显示额外收益；完整模型对照为 Code 29/30、文字记忆 29/30、Hegel 26/30。

第 67–71 页的新旧档案研究表明：修订与保留可以各自在对应后继条件中有价值，但更复杂的实验选择并不总有用；某些选择器已被撤回。

因此，不将“结构更多、推理更深、分歧更大”直接当成进步。优先终点始终是未见预测、任务完成和错误承诺；成本是约束并单独完整报告。

### 1.3 本轮不做

不扩建签名体系，不重启全语言闭包枚举，不预置“23 条新先验”，不让 LLM 自评哲学深度，不要求产生人类从未知道的数学概念，也不将每一次开发者改代码算成系统自我改进。

## 2. 六项主目标：缺什么，怎样才算补上

| 主目标 | 当前能做什么 | 下一项实际变化 | 达成证据 |
|---|---|---|---|
| 新关系／新表示 | 有限族内拟合、组合、作用域修订 | 由证据合成未预装的关系模式、历史状态或输入变换 | 前瞻预测新条件；冻结后迁移；与同原语自由搜索相比的效果 |
| 观测与假设共同演化 | 选择给定 probe，校准后改 probe | 组合原始控制、保持、读取等动作，合成新的可执行实验程序和读出统计 | 新实验揭示此前不可见但任务相关的差异；学习收益而非只提高分歧 |
| 广义结构对应 | 匿名角色、单位和有限代数结构迁移 | 提出可拒绝的角色／动作映射及保留规律 | 表面变化时转移；表面相似而机制改变时拒绝；在异质接口下验证 |
| 理论综合与可撤销继承 | 多个新旧程序共存、反例限制应用 | 将局部修复归纳为共享参数族和可观测适用条件 | 未用于归纳的中间条件、旧条件和边界外条件；总复杂度和损害均报告 |
| 鲁棒化与任务相关简化 | 条件方差和世界变简单时的简化 | 学习应考虑哪些风险；在同一复杂世界内按任务省略细节 | 风险与常态效用；任务变化时恢复必要细节；反例能撤销简化 |
| 完整自主与有效元改进 | 有方法编辑和冻结迁移实例 | 冻结 runtime 自主触发修订；继承所得研究机制而非开发者补丁 | 多个独立来源链、统一强控制、方法移植、多代净收益与失败保留 |

第六项不是其他五项结果的相加。必须在同一个冻结运行中验证它们如何被选择与连接。

## 3. 先修订三条过强的旧设计要求

这是对原始设计记录的明确建议调整，不声称旧文件本来就这样规定。

### 3.1 允许试验新解释，不必先穷尽旧语言

“旧语言的全部可能都不行”是某些形式化表达能力研究的命题，不应成为每次经验研究的入口要求。

将三种状态分开：

1. 当前候选或搜索在预算内停滞；
2. 某个明确有限族在相应证据语义下已被排除；
3. 整个语言不可表达目标。

第一种足以分配少量预算尝试新表示；第二种能提供更强动机；第三种不作为日常前置条件。生成与沙箱实验可以宽松，应用和正式宣称必须有证据。

### 3.2 保留旧成功的解释范围，不保留所有旧信念

已经被可靠反例否定的全称命题不能继续作为不可撤销约束。保存的是证据、代码、历史范围和已知限制。

新解释可通过特殊情形、局部近似或组件关系解释旧成功。必要时也可以替代旧理论。不可要求每种正确学习都必须是形式逻辑中的保守扩展。

### 3.3 不是每种新知识都叫 meta-prior

固定以下语义区别，不额外新建五个互不相通的系统：

- `p`：预测对象响应。
- `phi`：从可获得观测／历史构造表示。
- `q`：组织实验动作并计算读出。
- `pi`：选择、安排和停止研究。
- `eta`：改变候选结构或研究方向的生成偏好。

一个学得预测程序可以成为优化器特征；一个新研究程序可以改变学习。但只有真正影响后续候选结构选择的对象，才在该意义上称为学得先验。其有效性要在后继任务中测试。

## 4. 一个共同的最小修订接口

复用现有程序、证据和父子返回机制，新增或补齐一个轻量的修订提案协议。不要求重写存储内核。

```text
RevisionProposal
  affected_object        被改变的预测／表示／观测／方法／先验
  executable_delta       实际代码或带类型的表达式变化
  required_inputs        已有观测与尚需购买的观测
  parent_and_scope       父版本、工作前提与适用条件
  competing_consequences 不同解释在什么未测条件下给出不同后果
  next_test              最短的实际辨别实验
  evidence_cutoff        生成与选择用了哪些历史证据
  reduction_or_preservation  有意义时才提供旧条件映射
```

不是每个候选都必须同时改六个对象。优先局部改动，但允许必要的联合修订，例如“新增历史状态＋构造能识别该状态的实验”。不得强制逐一修完所有参数、噪声和作用域后才触及表示。

执行端只核对访问权限、输入输出类型、环境绑定和预算。它不能替作者填正确关系、替作者宣布前提已成立，或把隐藏评价结果写入研究上下文。

## 5. 第一个核心突破：从失配中学出新的状态与实验

### 5.1 推荐的首个问题

使用当前数值实验接口与时序工具，研究：

> **为什么同一个当前控制值，在不同到达路径下有不同结果？Agent 是否会自己构造历史相关表示，并设计实验来区分记忆、测量延迟和随机波动？**

这是开发建议，不是对当前晶体关卡隐藏机制的诊断。不能据此向现有失败关卡注入“真正答案就是迟滞”。

原因是这类问题能同时检验：表示不足、实验组合、新概念、旧特殊情形、跨对象迁移、任务尺度与不确定性，而且可以使用现有 `Program`、历史观测和实际控制动作。

### 5.2 实验设计者可使用的说明例；不得交给被测 Agent

令一个模拟装置具有迟滞状态：

\[
m_t=\begin{cases}
1,&u_t\ge b,\\
0,&u_t\le a,\\
m_{t-1},&a<u_t<b,
\end{cases}\qquad a<b,
\]

输出由该状态决定。初始高层模型只有当前控制到输出的映射，但所有 Agent 都可以读取自己的完整历史并使用同样的低层程序语言。

在同一个中间值 `m`，从低处到达与从高处到达可能有不同结果。新实验不是库中一个叫 `hysteresis_test` 的预装动作，而是由已有原语组合：

```text
独立准备路径A：设置低值 → 保持 → 设置中间值 → 保持 → 读取
独立准备路径B：设置高值 → 保持 → 设置同一中间值 → 保持 → 读取
比较当前控制相同、历史不同的响应
```

“准备充分”和“保持足够长”也可能是工作前提。若公共接口不能恢复状态，不能伪造独立重复；应研究洗脱时间、限制比较条件或保留混杂。

单次差异不证明迟滞。替代解释至少包括测量延迟、未恢复状态、观测噪声和缓慢漂移。通过重复、路径次序、保持时长和独立读出缩小它们，而非把模拟器真实状态暴露给研究器。

### 5.3 系统应自主产出的对象

它可能学出一位状态、有限历史函数或另一种可执行表示；不强制与真实实现的源码相同。

验收依据是：同一程序和冻结绑定在新路径、新参数／新对象上给出正确前瞻预测；不需要为每个对象添加一个无解释的 ID 分支；在无记忆控制中拒绝不必要的历史依赖。

当 `a=b` 并约定边界规则时，可恢复无记忆阈值模型；在远离切换区的条件下，旧静态近似也可能仍有效。特殊情形需要通过相应条件验证，不以自然语言声明代替。

### 5.4 避免“人工已把答案写好”的两层实验

**机制调试层**可以给有限候选，以检查执行和前瞻评分是否正确。其结果只叫机制验证。

**自主发现层**不能向 proposer 提供正确模型名、方程、缺失变量名或诊断标签。给所有比较方法相同通用原语和原始历史；候选从数据中生成。评测器可以知道生成机制，被测 Agent 不可以。

开发者定义模拟器本身不是作弊。将模拟器机制、标识或专门为该机制写的完整解法作为 Agent 输入，才会破坏相应的自主发现主张。

## 6. 生成侧怎么改，不再只靠更长的 prompt

### 6.1 先构造“可比较的失败记录”

对每次固定预测，保存：输入／历史、预测、实际结果、程序版本、作用域、已知仪器绑定，以及结果是在拟合前还是拟合后取得。

从这些记录生成候选动机，例如：同一表示下的不同结果；训练拟合好但新对象失效；相同末态但路径不同；一项方法在某些证据模式下失败。它们是失配模式，不是自动判定出的真实故障标签。

### 6.2 三种生成动作共用一套执行检查

1. **局部程序修改**：增删输入、交互项、条件、历史聚合或递归状态；对应 `p/phi`。
2. **实验程序合成**：由设置、保持、读取、重复、顺序交换等公共原语组织新的实验；对应 `q`。
3. **跨成功／失败轨迹抽象**：把实际有效修订及其失败边界归纳为通用程序；对应 `pi/eta`。

首轮每次只让少量候选竞争，数量由开发预算确定。不要以“必须产生若干新概念”作为成功条件。没有有用候选时，正确输出仍是未解决。

### 6.3 两条实现途径

候选生成可用现有 LLM 编写接口；重复代码的抽象、参数抽取和反例检查尽量由确定程序完成。可以借用 DreamCoder 的库学习、LILO/Stitch 的程序压缩思路，但它们只解决可复用抽象的生成部分，不自动验证世界定律。

新名字、注释和文档有助于后续模型使用；它们不是科学支持。凡是语义筛选后的候选，都必须继续经过原始物理接口上的预测检验。

### 6.4 防止把“新概念”降成一条正确答案

把局部 `p_j(x)` 改为参数化结构 `F_alpha(x;theta_j)` 时，共享的是结构，允许各装置有限重拟合参数。必须报告目标端拟合成本。

禁止共享一个名字、内部却仍按对象 ID 查表。新结构可展开成旧低层代码并不构成失败；需要证明它为初始高层库没有提供的行为差异或有限预算搜索带来价值。

## 7. 从局部修复到真正的新关系／先验

### 7.1 世界规律和研究偏好分两条晋升路径

**关系路径**：对观测到的多个对象／任务提出共享关系、作用域和反例。

**研究路径**：从多次真实研究中学习，在什么可观察证据下应该先搜哪类结构、先做什么实验。

它们不能共用一个未经校准的“哲学分数”。

### 7.2 可执行的跨轨迹归纳

收集独立来源研究的程序和证据；把角色、单位和具体参数规范化；寻找可合并的程序结构，或由 LLM提出能压缩多个修复的共享模式。参数化时保留真实测量角色，不能用来源 ID 代替适用条件。

学习端可以使用实际成功、失败和资源数据。后继端检验时，冻结新抽象和共享部分，只允许协议声明的局部参数更新。

一个可选的研究先验形式是：

\[
\eta_\psi(h\mid z_{\mathrm{task}})
\propto \exp\{-\lambda L(h)+r_\psi(h,z_{\mathrm{task}})\}.
\]

这里的 `r_psi` 是学出的结构偏好或可执行评分规则。它是候选生成分布／排序，不是宣称模型为真的后验。未经 likelihood 与校准，不能称为 Bayesian posterior。

保留基础候选生成器的一部分预算，避免学得先验成为新的硬过滤器。是否采用及预算比例，在开发任务决定，再冻结到评价中。

### 7.3 先验收益必须具有因果可比较性

如果只从“过去选择了某方法，然后成功了”学习，难以分辨它是否优于未选方法。在可克隆的仿真检查点，执行配对的替代方法；真实不可克隆环境只在低风险条件随机分配可行研究动作，并记录选择概率。否则只能报告相关经验，不能将回报差异当作方法处理效应。

第一轮采用来源级离线配对学习，不必立即训练复杂 RL 调度器。

### 7.4 新先验的最小证据链

```text
多个独立来源出现可重复的结构性困难
→ 系统生成一个可执行共享规律／研究偏好
→ 在来源反例上修订其边界
→ 冻结新对象及说明
→ 在新来源或异质接口上实际调用
→ 相对旧先验、无该对象、错配对象改变后继结果
```

只有“被保存”“被检索”或“排名变了”都不够。收益可以是更好的预测或同等能力下更少实际成本；必须报告另一方向是否付出代价。

## 8. 观测空间、任务尺度与距离怎样继续推进

### 8.1 学的是可执行观测映射，不是直接搜一个宇宙距离

将一项实验写为 `q=(action_program, readout_program)`。对候选 `h` 的签名是它预测该真实过程的结果。

增加实验能揭示旧的不可见差异；改变 `readout` 可以关注方向、差值、累积量、延迟或方差。但统计量的有效性必须由共同物理任务验证，不能仅在新统计量下把旧错误“压没”。

### 8.2 重复数据与新信息的区别

新特征 `z=g(x)` 在给定全部 `x` 时不增加观测信息，但可能让有限函数类或有限预算学习器更容易表示有用规律。新增历史、测量或干预则可能真正扩展信息。

因此分别报告：

- 信息访问改变；
- 同信息下的表示改变；
- 同表示下的计算或搜索改变。

不能把三者都称为“将环境随机性变成知识不确定性”。

### 8.3 不用伪装的预测后验驱动研究

当前有限候选的重复个数不是概率。若使用信息增益或知识梯度，需要说明 posterior 来自何处；否则用它们作明确的有限启发式，并与普通策略比较。

可以借鉴 BAX“围绕所关心的输出选择观测”的思想，而不是纯粹减少全模型熵。当前已撤回的目标后果选择器说明：把这个思想接进系统仍须重新验证，不可因引用文献就视为有效。

### 8.4 短视选择的补救

对有支持依赖的候选实验包做有限二步前瞻：第一步校准／测量可能本身不减少目标误差，却使第二步的目标实验有效。展开只针对当前真实阻塞依赖，计入第一次测量、分支失败、恢复状态和第二步成本。

没有可信结果概率时，比较一组可行世界中的后果范围或经验证的保守摘要；必须保留模型集合本身可能错的选项。不要把对某些候选的最坏值当成真实安全保证。

### 8.5 同一个复杂世界的任务相关简化

保持环境动力学不变，改变外部任务：例如预测长窗累计量、预测瞬时峰值、预测阈值穿越。系统应自主选择不同必要表示，并在任务改变后恢复被省略的信息。

起步的简化对象是可执行映射 `psi(history)`，例如当前值、固定窗统计或学得状态。比较：简单表示、完整历史、系统选择表示。给所有臂相同访问权限，实际购买的数据可以不同。

简化需要同时满足：新任务独立评价下的非劣性、明确的实际资源优势，以及边界外拒绝或恢复能力。相对旧复杂模型预测相近不够；旧复杂模型也可能错误。

## 9. 泛函视角中值得真正证明的数学命题

以下是可承担方法正确性的小定理，不承诺其本身新颖，更不声称保证自动发现。

### 9.1 任务输出是否由已有观测确定

固定线性响应空间 `V`，观测算子 `T_Q f=(q(f))_{q in Q}`，任务输出算子 `T_tau`。

若 `ker T_Q ⊆ ker T_tau`，则任意两响应只要在 `Q` 下相同，就在任务输出上相同；因此在模型类内可以通过观测等价类确定任务输出。

若不存在该包含关系，则存在一个观测不可见但会影响任务的方向。这是值得寻找的新实验的方向。

这在给定线性有限基表示时可通过矩阵零空间或秩测试实现。对未知世界或一般程序，模型正确性与实验可实现性仍需证据，不能直接照搬为全局可识别证明。

### 9.2 任务相关近似的决策代价

设同一有限动作集上，真实预期损失 `J(a)` 与简化模型损失 `Jtilde(a)` 满足统一界：

\[
\sup_a |J(a)-\widetilde J(a)|\le\varepsilon.
\]

若 `atilde` 最小化简化损失，`a*` 最小化真实损失，则：

\[
J(\tilde a)-J(a^*)\le 2\varepsilon.
\]

证明：在两端分别使用误差界，中间使用简化最优性。这解释“何时省略细节不损害决策”，但从数据得到该统一界，需要独立评价、覆盖或额外正则性假设。实验平均误差不能冒充全动作统一界。

### 9.3 修订后的误接受控制

固定候选及适用范围，用新的独立测试轨迹比较旧／新损失。固定测试样本数可先用简单的有界差异检验；若需要连续检查，再使用适当的置信序列或 e-process。

每个候选版本单独编号并分配错误预算；不能修改候选后沿用旧版的检验优势。对第 `j` 个候选，若条件性误接受概率至多 `alpha_j` 且 `sum alpha_j ≤ alpha`，联合上界才可控。这里的条件性保证需要真实成立，而不是换一个字段名。

依赖轨迹必须按独立重置段／装置处理。非平稳任务需要明示范围或新的评价时期。对无法建立这些假设的开放实验，使用经验支持措辞，不签发普遍统计保证。

## 10. 鲁棒化：先修风险决策，后上一般 DRO

### 10.1 首轮不要求精确分出宇宙的两种随机性

区分可操作问题：重复测量后误差是否稳定？新增历史或测量是否减少外推误差？重置和保持时间是否影响分布？在当前可用信息下，哪些决策后果仍不可识别？

单个 residual pattern 可能同时符合多个机制。没有合法区分实验时保留不确定性，并作有范围的保守行动；不强制猜出唯一真实原因。

### 10.2 接入固定外部决策任务

复用数值模拟与后续 SC-KG 接口，但先在低维任务验证：

\[
\min_a \widehat{\mathbb E}[C(a,\xi)]
\quad\text{s.t.}\quad
\sup_{P\in\mathcal P_t} P(g(a,\xi)>0)\le\alpha.
\]

这是目标形式，不代表已有一般求解器。第一轮可用有限动作、少量可解释分布／区间候选以及公共支持边界，逐动作枚举求解。

系统学习的是区间、尾部或条件模型怎样随证据修订，以及何时应改变行动。风险容忍度、违规定义、紧急停机和外部效用不允许它为了过关而修改。

### 10.3 评价不只看“更安全”

同时评价违规频率及不确定界、违规严重程度、常态效用、动作／服务覆盖、实验代价。永不行动、输出无限宽区间，都不能自动胜出。

分开报告随机自然试验和主动压力试验。压力测试证明存在风险，不直接估计其日常发生率；若作重要性抽样，需要真实采样权重和支持覆盖。

普通 conformal 或 Wasserstein 方法的保证有数据及分布假设；自适应选择度量、半径和模型后需要新的校准或相应联合论证。不能只引用一个算法名称就继承其保证。

### 10.4 一个可用的数据量提醒

若固定策略在 `n` 次独立、同分布 Bernoulli 违规试验中零违规，单侧 `1-delta` 上界是 `1-delta^(1/n)`。例如 `n=30, delta=0.05` 时约为 9.5%，不是证明违规率低于 1%。在相同条件下，要将零违规的上界压到 1% 以下，约需 299 次试验。

这些是公式下的设计计算，不是项目新结果。策略经过筛选、试验有关联或环境漂移时，不能直接套用。

## 11. 跨领域结构对应：分三步做，不一下跳到真实化学和电磁学

### 11.1 表面改变、机制保持

同一结构采用新单位、匿名角色、控制顺序或接口命名。测试系统是否学习并验证正确绑定，而不是按名称找到答案。

### 11.2 表面保持、机制改变

保持措辞或数值边际近似，但改变响应方向、延迟、饱和、遗漏外部通量或对象边界。系统必须拒绝旧映射，或缩小其作用域。

### 11.3 异质模拟器中的部分结构迁移

再使用不同状态、不同动作空间和不同更新方程的两个受控领域，例如控制装置与排队／库存过程。共享的是某项可检验结构或研究策略，不是同一方程换变量名。

迁移对象要分别记录：不变的结构、需要新拟合的参数、新观测角色和可能失效的前提。完整原始文档抽取可放在之后一层；LLM 抽取字段必须回指观测或文本证据，缺失项保持未知。

不要求所有领域都能迁移。正确地拒绝错误类比是主要终点之一；类比的发现率和覆盖率也必须报告，不能靠一律拒绝获得高准确率。

## 12. 把局部修复综合成较一般理论

当前多个归档共存，是合理中间状态。下一步合并不能只按源码相似度，也不应默认合并总是更好。

候选综合：

\[
F(x;c,\theta),\qquad F(x;c_i,\theta_i)\approx f_i(x)
\]

其中 `c` 必须由可获得的上下文、观测或受检验的状态描述决定，不能简单等于 task ID。

检查三个不同方向：

1. 已知旧条件下，能否保留经验证的旧预测；
2. 未用于综合的条件组合或中间范围，能否给出正确的新预测；
3. 不适用条件下，能否拒绝或回到独立模型，而非强制统一。

总复杂度要包括新族、作用域选择器、编码精度和例外；不能只计一个新名字。若它只是把每个局部模型放进大 switch，按分段档案报告，不叫统一理论。

## 13. 核心实验布局：避免一次变太多

### 13.1 来源划分

- 现有晶体前缀、已消费来源和已看过结果：开发与机制诊断。
- 新的源过程／故障组合：形成阶段的独立评价单位。
- 未用于形成的后继对象／路径／任务：迁移评价。
- 另一套建模或程序接口：外部泛化检查。

同一 donor 的多个后继、多个模型作者尝试和同一源码多次运行不能增加独立来源数。失败 donor 留在分母，不只选能生成新概念的来源。

### 13.2 分层对照，不把所有功能全因子交叉

**试验 A：研究组织。** 给三组相同候选和历史，比较当前冻结控制器、平铺族级研究、支持式递归族级研究。回答候选相同时递归组织是否有价值。

**试验 B：发现。** 比较固定高层库、开放低层生成、开放生成＋已学概念。低层原语、语言模型、实验权限和总预算相同；固定库组的限制仅回答特定表达对照，不能代替强通用 Agent。

**试验 C：继承对象。** 从同一研究状态克隆，分别移植预测知识、研究方法、结构先验或二者。评价它们怎样影响新任务，避免把任务答案当作元学习优势。

**试验 D：完整 Agent。** 普通 Code＋相同可执行档案、Hegel、Hegel 方法冻结。三组都有重验、回滚、残差修复和所有测量工具；区别是控制组织和可学习对象，不是权限阉割。

每一轮先完成一个对照，再增加下一层。可以先不调用模型、回放已经产生的候选检验执行；这叫执行反事实，不叫新自主发现。

### 13.3 主要终点

优先：固定预算下独立预测损失、任务完成、错误确认、风险与覆盖。

资源：真实环境动作、测量费、模型调用与 tokens、主机时间、研究计算、来源学习与失败成本。没有共同换算单位时报告 Pareto 权衡，不强造总效率分。

机制：子证据是否改变事前预测／行动；新概念是否实际被调用；错误映射是否撤销；未访问过的条件是否有真正增益。程序名、图深度和候选数量不是主要终点。

样本数由开发变异和最小值得关注效应确定。可先用 8–12 个新源机制做可行性 pilot；这只是预算建议，不是显著性标准，不能把 pilot 跑到好看再称确认实验。

## 14. 有效 RSI：将“更会研究”从任务知识中分离

设初始任务知识相同为 `K0`，旧研究方法为 `pi0`，学得方法为 `pi1`，后继学习过程为 `Learn`。

\[
G(B)=\mathbb E_\tau\left[
R_\tau(\operatorname{Learn}(K_0,\pi_0;B))
-
R_\tau(\operatorname{Learn}(K_0,\pi_1;B))
\right].
\]

`G(B)>0` 的可靠证据才说明：在相同起点和预算下，学得机制让后继学习更有效。

做法：冻结基础模型、工具权限和外部评价；运行时产生新的方法／先验对象；在每个存档检查点，将它移植到共同初始知识，再测未消费任务。若元改进器本身被改写，还要额外测其产生后继方法的能力，不把更好的任务执行器直接称为更好的改进器。

建议先完成两次由系统自主形成并继承的有效修订，再延长序列。所谓“代”是同一次冻结运行的继承，不是开发者两次 push。长期曲线允许持平或退化；不要求单调增长，也不能通过换测试集掩盖遗忘。

来源学习、失败探索、维护、校准和后继执行成本全部计入生命周期比较。局部高收益并不保证整个研究过程划算。

## 15. 实施里程碑与决策规则

以下时间是单人主导、复用已有代码时的排程估计，不是研究成功保证。真正推进条件是证据。

| 里程碑 | 时间参考 | 主要交付 | 下一步条件 |
|---|---|---|---|
| M0：选定一个认知 runtime 和共同对照 | 第 1–2 周 | 知识／支持／行动所有权图；基线；现有前瞻记录核对 | 不再依赖临时人工提示才能完成一次研究返回 |
| M1：新表示＋新实验的最小闭环 | 第 3–6 周 | 一个匿名历史敏感问题族；联合修订提案；匹配无记忆／随机／仪器控制 | 至少出现可复现的自动生成—区分—新预测链，而非预装答案 |
| M2：可复用概念和跨轨迹先验 | 第 7–10 周 | 从多来源归纳共享对象；冻结移植；作用域反例 | 新来源有效且不是 task-ID 查表；错误迁移能撤销 |
| M3：任务尺度与风险扩张 | 第 11–14 周 | 同一复杂世界不同任务；低维风险任务；独立校准 | 简化可恢复，保守决策没有以零服务覆盖取巧 |
| M4：多来源完整 Agent 与元方法移植 | 第 15–20 周及之后 | 统一强基线、两个系统内继承步骤、全成本 | 来源级效应与归因能支持相应主张，否则限制结论 |

M1 不通过时，不进入“跨领域哲学发现”。先判断失败发生在候选生成、实验可执行、候选可区分、返回消费还是外部预测。M2 不通过时，把成果定为局部表示发现，不虚报新 meta-prior。M4 与强档案基线持平时，保留机制贡献，不通过削弱基线制造优越性。

第一篇框架稿不等待 M4。后续研究结果以新实验加入后续版本或新论文。

## 17. 失败时如何调整而不再次走偏

| 观察到的失败 | 下一次优先修改 | 不应采取的捷径 |
|---|---|---|
| 没有可执行新候选 | 简化提案接口；用结构化残差与少量真实使用例；程序压缩辅助 | 让 evaluator 手工补正确规律 |
| 有新候选但 probe 无法区分 | 检查状态准备、观测权限、共同物理输入；合成实验序列 | 无限增加候选／重试直到偶然成功 |
| 子问题解决，父研究不变 | 检查返回的具体可执行依赖与待执行动作 | 再加一段“请利用答案”的 prompt |
| 表面新概念只在来源有效 | 缩域，做独立源迁移与反向例；检查 ID 和单位泄漏 | 新名称数量当作发明率 |
| 精确查询多数 UNKNOWN | 保留不确定；缩小查询，前瞻实验检验有限候选 | 把求解器未找到解当作世界已排除 |
| 分歧更大但任务更差 | 改为任务相关及短期组合动作比较，保留直接操作路径 | 宣称信息增益本身就是任务收益 |
| 鲁棒策略从不行动 | 同时检查效用和覆盖，缩小有依据的集合 | 无限放大风险集来保证安全 |
| 新方法不如强代码档案 | 限定贡献、检查额外成本和控制组织 | 剥夺基线回滚、测量或修复权限 |
| 多代后越来越慢 | 候选归并、按scope检索、档案暂存、真实成本回馈 | 删除全部旧反例或只报告最后最好一代 |

5. Howard et al. **Time-uniform, nonparametric, nonasymptotic confidence sequences**. Annals of Statistics 49(2), 1055–1080, 2021. DOI `10.1214/20-AOS1991`。用于有适当数据假设的连续检验，而非任意自适应发现保证。`https://arxiv.org/abs/1810.08240`
6. Mohajerin Esfahani and Kuhn. **Data-driven distributionally robust optimization using the Wasserstein metric: performance guarantees and tractable reformulations**. Mathematical Programming 171, 115–166, 2018. DOI `10.1007/s10107-017-1172-1`。用于后续限定模型下的鲁棒求解与半径校准；不是分布漂移下的无条件安全结论。`https://link.springer.com/article/10.1007/s10107-017-1172-1`

## 19. 最终判据

下一阶段不以“完整黑格尔机完成百分比”验收，而依次回答：

1. 运行中的系统是否自主获得了一个此前未提供的有用表示／关系／实验构造？
2. 它是否在旧成功、新预测和错误类比中有可以复核的适用范围？
3. 后继是否实际使用该知识，而不是开发者手工装配？
4. 相同起点和预算下，它是否提高了后继学习，而不只是把更多任务答案放进记忆？

四个答案都在多个独立来源上得到支持时，才有理由将主张从“可修订的有限研究机制”推进为“可迁移的认知结构学习与有效元改进”。
