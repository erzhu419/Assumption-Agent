## 5. 如何复跑本审计的有限核验

使用 Python 标准库即可。先将用户原始 Hegel_v14_GPT6_Audit_Handoff_20261118.zip 解压到一个目录，以下以 /absolute/path/v14_input 为示例。它应同时含 receipts、bundled_sources 和 05_STANDALONE_VERIFY_V14.py。

在本审计包根目录运行：

    python3 probes/recompute_v14.py --bundle /absolute/path/v14_input --output recomputed_results_rerun.json

    python3 probes/probe_d3_object_removal.py --bundle /absolute/path/v14_input --output object_removal_rerun.json

    python3 probes/probe_scope_replay.py --bundle /absolute/path/v14_input --output scope_replay_rerun.json

    python3 probes/compare_replay_receipts.py --bundle /absolute/path/v14_input --output replay_comparison_rerun.json

作者原核验器可另运行：

    python3 /absolute/path/v14_input/05_STANDALONE_VERIFY_V14.py --output author_verify_rerun.json

这些命令不需要研究模型 API，不会修改用户仓库。新探针为审计代码，刻意隔离已识别问题。不要用它们取代下一版真实 KnowledgeLibrary、真实 EvidenceBatch 和完整研究入口的验收。

recompute_v14.py 的探索性簇符号翻转检验假定来源簇独立、符号可交换，未做多重比较校正。报告没有把不显著当成等价，也没有把小样本探索 p 值当成主研究结论。
