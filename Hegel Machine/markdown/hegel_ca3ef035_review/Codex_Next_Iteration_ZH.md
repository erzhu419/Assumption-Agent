## D2：目标、参数身份与来源审计

1. 参数槽绑定其实际基函数、类型、单位、历史／guard；保留明确的排列和缩放，不直接按hole编号跨科学角色对应。
2. 同输入不同after的冲突先于sample gate检测；结论仅作用于该视图。
3. 抽取实际来源的拟合数据／权重／求解状态引用。不要通过添加source_id使不可识别问题变为查表。
4. 明确三种用途：exact edit map、parameter proposal、structural revision。三者共享执行器但使用不同的支持语义。
5. 参数提案若允许后续world refit，应独立标明；不能把refit后的成功归给原精确映射。
6. 单位别名只依公开声明规范化；系数单位按输出／基函数推导，未知物理角色仍未知。
7. 若这11条记录仅体现同一拟合形状的漂移，冻结为诊断／回归材料，不再要求它证明一般新关系。

**完成标准：** 给每项拟学关系写出输入、目标、作用、可识别前提和失败分流；必须影响实际候选与后续动作。
