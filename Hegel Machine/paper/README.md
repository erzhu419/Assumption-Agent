# Hegel Machine review materials

Local release: **paper-2026-10-12-v3** (12 October 2026).
This revision adds the completed recurrent representation, method-transfer and
live-continuation studies; the earlier v2 archive remains unchanged.
This release identifier is separate from the research package version 0.181.0.
The paper uses the included JMLR preprint style. Author and affiliation details
follow the supplied RE-SAC manuscript; preparation status is recorded in
`paper/FINALIZATION.md`.

Open `paper/manuscript.pdf` for the complete paper, including Appendices A–I.
`paper/ARTIFACT_INDEX.md` maps studies to their protocols,
results, available source snapshots and replay commands. Extract this archive
as one directory so that relative Markdown links keep their project layout.

The editable source is `paper/manuscript.md`.
Its TeX and PDF files are generated by `scripts/build_manuscript.py`.
From the extracted project root, after editing Markdown, rebuild with:

```bash
python3 scripts/build_manuscript.py --source paper/manuscript.md
```

The builder uses Python packages `markdown-it-py` and `PyMuPDF`, XeLaTeX,
and the Latin Modern Roman / Math fonts named in its preamble.
The supplied PDF can be read without these build dependencies. PDF artifact
links point to an internal index of readable paths in this extracted bundle.

Reading saved results, numerical replay and new language-model authorship
are separate operations; consult `paper/ARTIFACT_INDEX.md` before replay.
Use Python 3.10 or later. Tables 4–8 can be regenerated from included results
without model calls or third-party Python dependencies:

```bash
python3 scripts/regenerate_manuscript_tables.py --output /tmp/hegel-tables.md
```

The final source-condition comparison includes its 24 saved outcomes, paid traces,
three source inputs and the saved runtime. Recompute the outcome attribution with:

```bash
python3 artifacts/response_condition_retention_20261011/audit_outcomes.py
```

This reads saved observations and rewrites only the extracted audit JSON; it
executes no environment or model. Its aggregate C4 result includes one gain and
one loss; the changed-gain cost increase remains in the attribution.

The main-document builder uses the same generator to refresh these tables before
rendering. A representative numerical replay uses the included frozen online
research source, with no model service or additional data (choose a new output):

```bash
env -u PYTHONPATH python3 artifacts/online_inquiry_20261005_main/source/scripts/run_online_inquiry_study.py --profile development --output /tmp/hegel-online-development-replay --workers 1
```

This selective review bundle excludes unlinked large records, raw provider
logs, credentials, environments, CSV datasets and checkpoints. Some replay
entry points require the complete research checkout. `paper/BUNDLE_CONTENTS.json`
lists selected files and identifies current source, which is not an immutable
historical runtime. The ZIP fixes the selected local documents and code at
packaging time, while historical-source completeness remains study-specific.
It is not a public archive or an immutable dependency environment. This local
review package grants no new software license or submission status.
