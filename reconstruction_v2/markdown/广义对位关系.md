# 一、你的核心判断是对的：很多通用假设是在提供“非相似型关系”

传统 embedding 检索主要是：

[
x\approx y.
]

也就是两个对象在语义或向量空间中接近。

但你列出的通用先验提供的是完全不同的关系：

[
x\approx T(y),
]

[
x\preceq y,
]

[
F(x_1,\ldots,x_n)=c,
]

[
f(g\circ h)=f(g)\circ f(h),
]

[
\langle f_i,f_j\rangle=0.
]

这些不是“相似性的不同版本”，而是不同种类的**结构对应规律**。

不过，HippoRAG 也不能严格说只使用词语相似性。它通过知识图谱和 Personalized PageRank 进行关联传播，已经利用了实体和关系网络；但这种图传播最终主要形成的是节点之间的关联性、可达性或 proximity score。你提出的方向更进一步：**关系本身有不同语义、方向、代数规律和可证伪条件，不能全部压缩成一个 proximity 值。** ([GitHub][1])

当前 QuAC RJMC 也已经不是纯 similarity evaluator。它使用：

[
\texttt{same_section},
\quad
\texttt{adjacent_window},
\quad
\texttt{entity_chain}
]

三种 typed edges，并通过关系注意力比较完整 evidence sets。它还强制：

[
f(L,R)=g(L,R)-g(R,L),
]

所以：

[
f(RAW,RAW)=0.
]

这已经是一个很小的“代数关系系统”：有带类型边，也有反对称性规律。但关系种类和组合规律都是人工冻结的，尚没有使用22条通用假设。

# 二、范畴论在这里的真正作用

范畴论最适合负责三件事：

[
\boxed{
\text{关系的类型}
+
\text{关系的组合}
+
\text{组合后必须成立的等式}
}
]

一个最简单的有限表示是：

[
\mathcal C
==========

\langle
\operatorname{Obj},
\operatorname{Mor},
\mathcal E
\rangle.
]

其中：

* (\operatorname{Obj})：对象，例如 evidence units、claims、dialogue turns、states；
* (\operatorname{Mor})：生成态射，例如 supports、contradicts、precedes、transforms-to；
* (\mathcal E)：路径等式或约束，例如两个推理路径必须产生相同结论。

范畴数据库理论本来就把 schema 表示为小范畴，把数据实例表示为到集合范畴的函子；schema 不只是图，还包含路径等式。([科学直通车][2]) 近年的 categorical deep learning 工作则明确把范畴论定位为连接“模型必须满足什么约束”与“如何实现这些模型”的语言。([Proceedings of Machine Learning Research][3])

所以在你的系统中：

[
\boxed{
\text{范畴论是语法和编译框架；22条假设是具体关系定律和先验。}
}
]

范畴论不会自动告诉模型“这里有守恒性”，但它可以精确表达：

> 如果假设守恒性成立，哪些对象和态射应当形成一个交换图；该图不交换时，假设被反驳。

# 三、22条假设不能全部变成边类型

这是设计上最重要的一点。

它们至少属于四个不同层级。

## 1. 对象间关系

这类可以直接表示成 typed edge：

[
R(x,y).
]

包括：

* 相似；
* 反对/矛盾；
* 支持；
* 因果先后；
* 层级/包含；
* 邻接/局部性；
* 对称变换对应。

例如：

[
\texttt{contradicts}(e_i,e_j),
]

[
\texttt{precedes}(e_i,e_j),
]

[
\texttt{subrelationOf}(r_i,r_j).
]

知识图谱 embedding 文献本身也在区分 symmetry、antisymmetry、inverse、composition 和 hierarchy 等不同 relation patterns，而不只是学习统一距离。([AAAI Journal][4])

---

## 2. 关系必须满足的代数规律

这类不是新边，而是对边施加约束。

### 对称性

[
R(x,y)\Rightarrow R(y,x).
]

或者一个变换 (T) 满足：

[
T\circ T=\operatorname{id}.
]

你说的“某部分相反但整体对应”，更准确地属于**反射/对合 symmetry**，而不是所有对称性。

### 单调性

连续情况下可以写成导数符号：

[
\frac{\partial f}{\partial x}\ge0.
]

但更一般的离散形式是：

[
x\preceq y
\Rightarrow
f(x)\preceq f(y).
]

也就是说，它是一个 order-preserving morphism。

### 传递/组合性

[
R_1(x,y)\land R_2(y,z)
\Rightarrow
R_3(x,z).
]

这正是范畴论最自然处理的部分：

[
x\xrightarrow{R_1}y\xrightarrow{R_2}z
\quad\mapsto\quad
x\xrightarrow{R_2\circ R_1}z.
]

---

## 3. 高阶关系和整体图约束

这类不能表示成普通二元 edge。

### 守恒性

[
\sum_{i\in \mathrm{in}}q_i
==========================

\sum_{j\in \mathrm{out}}q_j.
]

它作用于多个对象和多个变化过程，是 (n) 元关系或交换图。

### 加性

[
F(x\oplus y)=F(x)+F(y).
]

它涉及对象的组合规则，最自然的形式是 monoidal structure。

### 互补性

[
U({x,y})
--------

## U({x})

U({y})
+
U(\varnothing)
\neq0.
]

当前 QuAC RJMC 的有效科学假设，本质上就是这种关系：证据集合价值不能还原成单个 evidence relevance 之和。

### 拓扑、覆盖和局部—全局一致性

例如每个局部 evidence chain 都可解释，但组合后出现全局矛盾。这类问题更适合 hypergraph、sheaf 或 diagram consistency，而不是单条 edge。图模型处理不了的高阶 group membership 本来就是 hypergraph 方法的主要动机。([OpenReview][5])

---

## 4. 对整个关系系统的先验

这类甚至不是关系，而是关系图的复杂度假设：

* 稀疏性；
* 低秩；
* 低频；
* MDL/简洁性；
* 最大熵；
* 典型规律加少数异常；
* 可证伪性；
* 决策相关性。

例如稀疏性不是：

[
R_{\mathrm{sparse}}(x,y).
]

而是：

[
|{R:R\text{ active}}|\ll |\mathcal R|.
]

低秩是：

[
\operatorname{rank}(\mathbf R)\ll n.
]

低频是关系信号在图 Laplacian 的高频特征向量上能量较小。

所以22条不能简单编译成22种 edge labels。

# 四、更准确的数学框架：关系范畴 + 高阶图约束

普通 category 的箭头通常更接近函数或确定性变换。你这里需要的是一般关系，因此更贴近：

[
\boxed{
\operatorname{Rel}
\text{ / allegory / enriched relational category}
}
]

Allegory 是专门处理关系而不是单值函数的范畴式结构；2026年的一篇综述还系统整理了多种 “categories for relations” 及其 enriched versions。([逻辑计算机科学方法][6])

对于有强弱程度的关系，可以使用 enriched category：

[
\mathcal C(x,y)\in V,
]

其中 (V) 可以是：

* ([0,1])：关系置信度；
* (\mathbb R_{\ge0})：距离；
* 概率分布；
* 向量；
* 一个偏序集合。

Enriched category 已被用于将二元 similarity 扩展为 graded similarity 或 distance，而不是只有“有边/无边”。([科学直通车][7])

对于守恒、互补、覆盖等 (n) 元关系，则应补充：

* hypergraph；
* operad；
* symmetric monoidal category；
* constraint diagram。

因此完整系统更像：

[
\boxed{
\text{typed relational category}
+
\text{hyperrelations}
+
\text{diagram constraints}
+
\text{global priors}.
}
]

# 五、把“广义对位关系”形式化

可以定义每一种关系先验 (a) 为：

[
\mathcal R_a:
X_1\times\cdots\times X_{k_a}
\rightarrow V_a.
]

其中：

* (k_a)：arity；
* (V_a)：关系强度、概率、符号或向量空间。

再定义假设定律：

[
\mathcal L_a(\mathcal R_a,D)=0
]

或：

[
\mathcal L_a(\mathcal R_a,D)\le0.
]

例如：

### 对称

[
\mathcal L_{\mathrm{sym}}
=========================

|R(x,y)-R(y,x)|.
]

### 单调

[
\mathcal L_{\mathrm{mono}}
==========================

\max{0,f(x)-f(y)},
\qquad x\preceq y.
]

### 守恒

[
\mathcal L_{\mathrm{cons}}
==========================

\left|
\sum_i q_i^{\mathrm{in}}
------------------------

\sum_j q_j^{\mathrm{out}}
\right|.
]

### 互补

[
\mathcal L_{\mathrm{comp}}
==========================

*

\left[
U(x,y)-U(x)-U(y)+U(\varnothing)
\right].
]

### 正交

[
\mathcal L_{\mathrm{orth}}
==========================

|\langle r_i,r_j\rangle|.
]

这样“假设是否成立”变成了可以计算的 violation：

[
v_a(D)=\mathbb E_D[\mathcal L_a].
]

Posterior weight：

[
p(a\mid D)
\propto
p(D\mid a),
p(a),
e^{-\lambda v_a(D)}.
]

这才是22条 universal assumptions 在 Assumption Agent 中最合适的落地方式。

* semantic association；
* same entity；
* same section；

* complementarity；

* facet coverage；

* sparse active relation types；
* low-order interactions；

[

}
]

GRJMC 则让 agent 从22条假设库中选择少数 active relation laws。

# 七、Assumption Agent 的核心任务也要改变

目前 `HypothesisProgram` 已经把 hypothesis 编译成 trigger、action graph、expected effect 和 verifier contract；这是很好的执行与审计格式。

但如果采用你的新方向，Agent 不应直接从 residual 生成：

> “遇到这种任务时，执行步骤 A、B、C。”

而应先生成一个**关系模式假设**：

> “失败来自当前表示缺少 evidence complementarity relation。”

或者：

> “失败来自 evidence order relation 被忽略。”

再编译成 evaluator/action。

完整链条变成：

[
\boxed{
\text{residual}
\rightarrow
\text{relation-family hypothesis}
\rightarrow
\text{diagram/constraint}
\rightarrow
\text{discriminating test}
\rightarrow
\text{evaluator/action}
}
]

例如：

```text
Hypothesis:
  evidence utility contains a pairwise complementarity component

Objects:
  evidence units

Relation:
  complement(e_i, e_j)

Law:
  U({i,j}) - U({i}) - U({j}) + U(∅) > δ

Prediction:
  replacing both units together outperforms either single replacement

Falsifier:
  held-out pair interaction is not positive

Compiler:
  enable pair-interaction relation channel in RJMC
```

这比自由生成 action 更容易获得 material improvement，因为它首先修改了系统如何表示世界，而不是仅修改 prompt。

# 八、如何控制组合爆炸

这是该方案最大的风险。

如果有 (n) 个 evidence units、22种关系和任意 arity，候选数会爆炸。因此必须同时使用你之前为 SC-OLH-KG 总结的先验：

[
\boxed{
\text{稀疏}
+
\text{低阶}
+
\text{局部}
+
\text{MDL}
}
]

建议规则：

1. 每个 residual cluster 最多激活3个 relation families；
2. 主实验只允许 unary、binary 和少量 ternary relations；
3. 只有在二元模型留下系统 residual 时才打开高阶关系；
4. relation extractor 必须在 TRAIN 上达到最低 precision；
5. 每增加一种 relation type 必须支付 complexity cost；
6. 没有 held-out 增量证据就回到 RAW/current RJMC。

目标函数：

[
\operatorname{Score}(H)
=======================

## \Delta U_{\mathrm{hold}}

## \beta L(H)

\gamma\operatorname{Harm}(H).
]

这样22条是搜索库，不是同时启用的22个模型分支。

# 九、最合理的第一项实验

不要立即实现全部22条。先在 QuAC 上测试5类广义关系：

1. **similarity/association**：现有语义检索基线；
2. **complementarity/redundancy**：当前 RJMC 最可能的核心机制；
3. **order/locality**：turn、section、adjacent window；
4. **opposition/contradiction**：相互冲突或纠正的证据；
5. **coverage/conservation**：一个 evidence set 是否保存了回答所需全部 dialogue facets。

再加两个全局先验：

[
\text{sparsity},
\qquad
\text{permutation invariance}.
]

比较：

[
\text{similarity-only}
]

[
\text{current RJMC}
]

[
\text{flat multi-relation RJMC}
]

[
\text{category/diagram-constrained GRJMC}
]

[
\text{oracle relation-family selector}.
]

同时控制参数量，使提升不能被解释成“模型更大”。

关键指标：

* relation-family selection accuracy；
* held-out utility；
* gain/harm；
* RAW tie rate；
* relation violation；
* assumption description length；
* untouched search retained effect。

\textbf{识别候选关系定律}
\rightarrow
\textbf{验证定律是否成立}
\rightarrow
\textbf{寻找跨领域的结构保持映射}
}
]

当前系统已经有很好的后半段：`HypothesisProgram` 保存 trigger、anti-trigger、action DAG、expected effect、verifier、fallback 和 lineage；这应继续作为**可执行 treatment 层**，而不是被替换。 当前 RJMC 也已经支持 `same_section`、`adjacent_window`、`entity_chain` 三种 typed relation，并用反对称构造保证 (f(\mathrm{RAW},\mathrm{RAW})=0)；所以不是从零开始，而是缺少一个能发现和验证更多关系定律的前端。

下面这份可以直接交给 Codex。它不指定具体函数名，但冻结了数据对象、阶段契约、禁止事项、实验和验收标准。

# Generalized Structural Correspondence Layer

## Codex Implementation Specification v0.1

## 0. 项目目标

在现有 Assumption Agent 中新增一个 **Generalized Structural Correspondence Layer, GSCL**。

GSCL 不把对称、单调、守恒、互补等通用假设处理成自然语言主题或语义相似标签，而将它们表示为：

1. 带类型对象；
2. 带角色的关系或变换；
3. 可组合路径；
4. 路径等式、不等式或高阶约束；
5. 可观察预测；
6. 反例与证伪条件。

完整流程必须是：

```text
input / residual / evidence
→ typed structural diagram
→ candidate relation-law families
→ role binding
→ law-specific constraint evaluation
→ contrastive falsification
→ structural correspondence
→ HypothesisClaim
→ TreatmentProgram / EvaluatorProgram
→ existing paired validation and promotion
```

禁止从输入直接生成 treatment。

---

## 1. 核心研究主张

当前 retrieval 和图传播主要利用：

```text
semantic similarity
association
proximity
reachability
```

GSCL 要检验的主张是：

> 除了 similarity / association 之外，数据中还存在 symmetry、order、opposition、conservation、complementarity、locality、invariance 等结构关系。将这些关系表示为可检验的关系定律，可以产生仅靠语义接近无法发现的假设与 evaluator。

这不是“将相似度扩展为22种相似度”，而是：

```text
similarity is one relation family;
other assumptions define different relational laws.
```

---

## 2. 明确的非目标

第一阶段不得实现以下内容：

1. 不实现任意抽象范畴论证明器；
2. 不要求模型学习完整的数学范畴；
3. 不把22条假设全部变成 edge label；
4. 不把 embedding cosine similarity 当作结构关系成立的证据；
5. 不允许 LLM 仅输出“二者本质相似”作为 relation match；
6. 不允许未经结构验证的 analogy 进入 promotion；
7. 不修改现有 sealed split、late-label barrier、paired validation、evaluator epoch 和 fallback 规则；
8. 不用 validation/test outcome 生成或选择 relation family；
9. 不声称完整的通用关系发现已经实现。

第一阶段只实现**有限 typed diagrams、有限 law registry 和有限约束验证**。

## 4. 22条假设的注册方式

初始化 registry 时按以下结构注册。

### A. 压缩与表示先验

```text
simplicity / MDL
sparsity
low rank
minimal sufficient representation / quotient
```

这些是 `global_model_prior`，约束整个关系模型的复杂度，不生成普通 edge。

### B. 分解与机制先验

```text
additivity / low-order interaction
orthogonality / nonredundancy
modularity / independent mechanisms
locality / Markov blanket
compositionality / mechanism reuse
```

其中：

* additivity 可以是 n-ary 或 monoidal constraint；
* orthogonality 是解释向量或预测向量的非冗余约束；
* locality 是距离或图邻域约束；
* compositionality 是路径组合规律。

### C. 动态与频率先验

```text
low frequency / smoothness
piecewise smoothness / sparse change
scale separation / slow variables
stability / contraction
```

这些主要约束 episode 中 transition sequence 和 relation signal。

### D. 不变性与形状先验

```text
symmetry / invariance / equivariance
conservation / balance
topological persistence
monotonicity / order / diminishing returns
```

其中：

* symmetry 是 transformation law；
* monotonicity 是 order-preserving law；
* conservation 是 n-ary balance constraint；
* topology 是 diagram-level invariant。

### E. 不确定性先验

```text
typical mechanism + sparse exceptions
maximum entropy / minimum commitment
```

这些控制 residual 与 abstention，不生成普通相似关系。

### F. 认识论治理先验

```text
falsifiability / active discrimination
evidence triangulation
decision relevance / boundary sufficiency
```

这些控制下一步测试和 promotion，不作为世界中的 edge。

## 5. 范畴论的使用边界

第一阶段只使用以下有限范畴概念：

```text
object
typed morphism
identity
composition
path
commutative or approximately commutative diagram
structure-preserving mapping
```

一个 episode 表示为有限 typed diagram：

[
D=(O,M,H,E)
]

其中：

* (O)：typed objects；
* (M)：typed directed morphisms；
* (H)：n-ary hyperrelations；
* (E)：必须满足的路径等式、不等式或守恒约束。

两个 episode 之间的 structural correspondence 是一组映射：

[
F_O:O_1\rightarrow O_2,
\qquad
F_M:M_1\rightarrow M_2
]

并要求：

1. 角色类型保持；
2. source/target 保持；
3. 组合关系保持；
4. law residual 在映射后仍然小；
5. 关键不变量保持；
6. 反例结构不能被错误映射为正例。

不得仅通过文本 embedding 找 (F_O,F_M)。

Embedding 可用于生成候选 object mapping，但最终 correspondence 必须通过结构约束验证。

## 6. 识别关系的主算法

### Stage 1：结构抽取

把输入转换为 `StructuralEpisode`。

必须优先抽取以下中性角色：

```text
system
state
external perturbation
internal response
controlled quantity
direction of change
constraint or invariant
before/after
local/global scope
```

角色名称必须 domain-neutral。不能把“磁通”“化学平衡”直接当作关系类别。

抽取结果必须保留原始 evidence span，以便 verifier 回溯。

---

### Stage 2：根类门控

不能对22条 law 和所有对象排列做穷举。

先依据观察特征选择最多4个 root families：

```text
transformation/invariance
order/dynamics
aggregation/balance
interaction/complementarity
locality/composition
global complexity/uncertainty
```

门控只允许使用 TRAIN 信息和当前 episode。

若无法选择，应返回 abstain 或 request_evidence。

---

### Stage 3：候选定律实例化

每个 root family 最多实例化3个 leaf laws。

总候选 binding 数设硬上限。

初版限制：

```text
binary relations: allowed
ternary relations: allowed
arity > 3: only conservation/coverage templates with predefined aggregation
free-form arbitrary arity: forbidden
```

---

### Stage 4：结构约束评估

对每个 binding 计算：

[
S_{\mathrm{struct}}
===================

S_{\mathrm{law-fit}}
+
S_{\mathrm{invariance}}
+
S_{\mathrm{composition}}
+
S_{\mathrm{contrast}}
---------------------

## S_{\mathrm{violation}}

\beta L(H).
]

其中：

* `law-fit`：canonical constraint 是否成立；
* `invariance`：合法变换后是否仍成立；
* `composition`：路径组合是否保持；
* `contrast`：与竞争假设或反例的区分度；
* `violation`：已观测反例；
* (L(H))：假设复杂度。

语义相似度不得出现在 `S_struct` 中。它只能影响候选召回。

---

### Stage 5：主动反证

每个 candidate law 必须生成至少一个：

```text
supporting prediction
counter-prediction
hard negative
discriminating probe
```

不能只问：

```text
“二者是否相似？”
```

必须问：

```text
“若该定律成立，什么可观察结果必须出现？”
“什么看似相似的案例应被拒绝？”
“哪项干预可以区分两个竞争定律？”
```

当观测不足时，状态必须是：

```text
insufficient_evidence
```

不能自动改成 accepted。

---

### Stage 6：结构对应

只有两个 episode 分别存在已验证的 `LawBinding`，才能尝试跨领域对应。

对应成功要求：

```text
same law family
compatible role mapping
compatible sign/order pattern
compatible composition
compatible invariants
counterexample checks passed
```

结果必须说明：

```text
哪些对象相互对应
哪些 morphism 相互对应
保持了哪些等式/不等式
哪些部分没有对应
```

---

### Stage 7：生成 HypothesisClaim

结构对应不能直接修改 agent policy。

必须先生成 `HypothesisClaim`，并附：

```text
law binding
predictions
falsifier
competing hypotheses
evidence ledger
```

然后再由 compiler 生成 evaluator 或 treatment。

## 7. 勒夏特列原理—楞次定律的验收示例

系统不得通过以下理由判定对应：

```text
“二者都描述抵抗变化。”
```

必须把两个案例抽象成同一结构模板：

### NegativeFeedbackLaw

角色：

```text
S: system
Q: regulated or observed quantity
D: external disturbance
R: induced internal response
```

结构：

[
D:S\rightarrow S'
]

扰动引起：

[
\Delta_D Q
]

内部响应引起：

[
\Delta_R Q
]

必要约束：

[
\Delta_D Q\cdot\Delta_R Q<0
]

并且在可比较尺度下：

[
|\Delta_D Q+\Delta_R Q|
<
|\Delta_D Q|.
]

还必须满足：

```text
R is induced after or by D;
R acts on the same controlled quantity or its causal pathway;
R reduces the net deviation rather than merely having an opposite label.
```

映射：

```text
Le Chatelier:
  D = concentration / pressure / temperature disturbance
  R = equilibrium shift
  Q = disturbed equilibrium-related quantity

Lenz:
  D = magnetic flux change
  R = induced current and induced magnetic field
  Q = magnetic flux change through the circuit
```

硬负例必须包括：

```text
Newton's third-law force pair
friction opposing motion
two political groups disagreeing
two words with antonym relation
```

这些案例可能具有“相反”“抵抗”等语义，但未必满足 disturbance-induced negative-feedback diagram。

验收标准：

1. Le Chatelier–Lenz 在隐藏领域词后仍被识别；
2. 高语义重叠但结构错误的负例被拒绝；
3. 替换实体名称和调整句序后结果保持；
4. 反转 response direction 后 law violation 显著上升；
5. 输出明确角色绑定和约束残差。

## 8. 防止退化为相似情景库

以下测试必须作为硬门槛。

### 8.1 Low-semantic-overlap positive set

正例共享结构但词汇和领域差异很大。

要求：

```text
structural recall high
semantic similarity may be low
```

### 8.2 High-semantic-overlap negative set

负例词汇接近但违反定律。

要求：

```text
false analogy rate low
```

### 8.3 Role-swap test

交换 disturbance 和 response。

关系应被拒绝。

### 8.4 Sign-flip test

翻转单调方向、反馈方向或守恒符号。

关系应被拒绝。

### 8.5 Entity-renaming test

实体重命名后关系不变。

### 8.6 Paraphrase test

措辞变化后结构结果不变。

### 8.7 Semantic-only ablation

移除结构 verifier，只使用 embedding/LLM similarity。

该版本必须单独报告，不允许混入主方法。

## 为什么这份规格能避免第一次失败

第一次范畴论版本大概率缺的不是“更高级的 category theory”，而是下面四件事：

[
\boxed{
\text{角色抽象}
+
\text{路径定律}
+
\text{硬负例}
+
\text{证伪门槛}
}
]

如果只有：

```text
Le Chatelier → opposes change
Lenz → opposes change
```

那无论叫知识图谱、范畴、morphism 还是 analogy，最后都会变成语义相似。

真正的结构对应必须给出：

[
\begin{array}{c|c|c}
\text{结构角色} & \text{勒夏特列} & \text{楞次}\
\hline
\text{系统} & \text{化学平衡系统} & \text{电磁回路}\
\text{外部扰动} & \Delta c,\Delta p,\Delta T & \Delta\Phi\
\text{诱发响应} & \text{平衡移动} & \text{感应电流/磁场}\
\text{受控量} & \text{扰动影响的平衡量} & \text{磁通变化}\
\text{关系定律} & \Delta_DQ,\Delta_RQ<0 & \Delta_DQ,\Delta_RQ<0
\end{array}
]

然后还必须拒绝“摩擦力阻碍运动”等表面相似例子，因为摩擦不一定是由系统为减少某个受扰状态偏差而诱发的闭环响应。

当前论文方法已经证明**冻结的关系型 evaluator 可以产生 retained effect**，但通用 proposer 尚未稳定发现新的可执行机制；这也是为什么应当先建设关系定律识别层，而不是继续优化自由 action prompt。 README 中多轮负结果也表明，精确 trigger 和覆盖并不足以产生 treatment utility，缺失的是 material mechanism。

这份规格建议作为一个全新、独立于当前 QuAC claim 的研究分支实施，避免追溯性修改现有证据。

# Codex 规范性修订 v0.2（2026-07-30）

## 0. 修订结论与适用范围

本节保留 v0.1 的核心方向，但替换其数学与工程合同。后续实现不得把本节当成
当前 WikiSQL 已消费 cohort 的补丁，也不得据此重开、重采样或修改既有正式
study。GSCL v0.2 是一个新的、上游的假设形成层：

```text
raw evidence
→ evidence-grounded StructuralEpisode
→ executable law candidates
→ constrained role binding
→ law-specific residual and counterfactual tests
→ partial structural correspondence
→ existing HypothesisClaim
→ existing treatment/evaluator compiler
```

范畴论在 v0.2 中只承担类型、组合和路径约束的表示职责。候选生成可以使用本地
embedding/NLI/LLM，但接受或拒绝一个 binding 必须由可审计的证据绑定与确定性
约束计算决定。

## 1. 当前系统事实边界

“22 条/13 条完全没有使用”不是准确描述：

1. 13 条旧假设已经映射到 22 条 UAO，并不是第二套独立本体；
2. QuAC RJMC 没有使用这套本体，只使用三种人工冻结关系；
3. WikiSQL UAO 暴露了 T02、T05、T08、T18 四个手写 recipe，并由 TRAIN
   选择了 T05 与 T18；
4. 上述 recipe 是本体名称约束下的手写 feature extractor，不等于从原始证据
   自动发现、绑定和验证关系定律；
5. 旧 structural morphism 前端主要依赖关键词 marker，因此不能充当开放域
   结构发现已经成立的证据。

GSCL 的增量不是再注册一套本体，而是补齐：

```text
evidence → typed episode → executable law binding → falsification
```

## 3. 最小数学对象

第一阶段只实现一个有限、带属性的有向超图：

\[
D=(O,M,H,C)
\]

其中：

- \(O\)：带类型对象和状态变量；
- \(M\)：有 source/target 的带类型、有方向 morphism；
- \(H\)：二元边不能忠实表示的 n 元 hyperrelation/factor；
- \(C\)：可执行等式、不等式、路径或守恒约束。

不要在第一阶段叠加 sheaf、operad、任意 theorem prover 或通用 enriched
category。只有某一新增形式主义解决了现有 typed hypergraph 无法表达的已登记
需求时，才允许单独提出。

### 3.1 StructuralEpisode

每个 episode 必须保存：

```text
episode_id
typed objects
typed states
ordered transitions
quantities and units
declared system boundary
evidence spans
source commitments
observed / inferred / unknown status
missing observables
```

自然语言字符串不得直接充当对象类型。任何 inferred field 必须同时保存：

```text
extractor identity
input evidence hash
supporting span ids
confidence/calibration bucket
alternative bindings
```

### 3.2 ExecutableLawSchema

每条 law 必须包含：

```text
law_id
ontology_template_id
arity
typed role schema
required observables
applicability preconditions
canonical residual function id
legal transformations
hard-negative transformations
missing-evidence policy
complexity cost
```

`canonical residual function id` 必须指向本地、版本化、确定性的实现，不得指向
自然语言 prompt。

### 3.3 LawBinding

一个 binding 至少包含：

```text
episode_id
law_id
role-to-object mapping
role-to-transition mapping
evidence span ids
observed residual vector
support rows
counterevidence rows
missing required observables
contrastive residuals
status
```

状态只允许：

```text
accepted
rejected
insufficient_evidence
not_applicable
```

语义相似度只参与候选召回，不能单独改变 `status`。

### 3.4 StructuralCorrespondence

两个 episode 之间的对应记作：

\[
F=(F_O,F_M,F_H)
\]

它只需在被绑定的有限子图上保持：

1. 对象和角色类型；
2. source/target；
3. 已声明的组合路径；
4. law-specific residual 的符号和容差；
5. 关键不变量；
6. hard-negative transformation 的拒绝行为。

一般情况下它是 **partial typed structure-preserving correspondence**，不是严格
functor。只有 source/target、identity 和全部相关 composition 均被证明保持时，
才允许在证明或文档中称为 functor。

## 4. 定律适用条件与 residual

每个 residual 都必须先检查适用条件；缺少前提时返回
`insufficient_evidence` 或 `not_applicable`，不得用默认值补全。

### 4.1 Involution / symmetry / equivariance

必须声明变换 \(T\) 或群作用 \(g\)，以及输出作用 \(\rho(g)\)：

\[
v_{\mathrm{eq}} =
d\!\left(f(g\!\cdot\!x),\rho(g)\!\cdot\!f(x)\right).
\]

若主张 involution，还需检查 \(T(T(x))=x\)。普通文本中出现“相反”不能触发
该定律。

### 4.2 Order / monotonicity

必须声明偏序、输入方向和输出方向。对一组可比 pair：

\[
v_{\mathrm{mono}} =
\sum_{(x,y):x\preceq y}
\max\{0,f(x)-f(y)-\epsilon\}.
\]

不可比对象不计作满足，也不计作违反。

### 4.3 Conservation / balance

必须声明量纲、系统边界、时间窗口、源、汇和边界流：

\[
v_{\mathrm{bal}} =
\left|
\Delta q_{\mathrm{storage}}
+ \sum q_{\mathrm{out}}
- \sum q_{\mathrm{in}}
- \sum q_{\mathrm{source}}
+ \sum q_{\mathrm{sink}}
\right|.
\]

未观测边界流存在时不得接受守恒 binding。

### 4.4 Low-order interaction / complementarity

必须声明 utility 的方向和基线。二阶 interaction 定义为：

\[
I(x,y)=U(x,y)-U(x)-U(y)+U(\varnothing).
\]

“互补”必须绑定预注册的 \(I>\epsilon\)；“冗余”绑定
\(I<-\epsilon\)；近零只表示近似可加，不能由公式前的未定义正负号决定。

### 4.5 Composition / path consistency

对两个类型兼容路径 \(p,q:a\rightarrow b\)：

\[
v_{\mathrm{path}}=d(\operatorname{eval}(p),\operatorname{eval}(q)).
\]

必须记录两条路径的全部组成 morphism，不能只比较两个终点文本。

## 5. 计分与支持语言

v0.1 中

\[
p(a\mid D)\propto p(D\mid a)p(a)e^{-\lambda v_a(D)}
\]

可能把 violation 同时计入 likelihood 和额外惩罚。v0.2 禁止使用未定义的
“posterior”语言。初版统一采用可审计的支持分数：

\[
\operatorname{score}(b;D)=
-\beta\,V_L(b;D)
+\gamma\,C_L(b;D)
-\lambda\,\operatorname{DL}(b),
\]

其中：

- \(V_L\)：冻结 law residual 与已观测反例；
- \(C_L\)：冻结 hard-negative/竞争定律上的 contrastive margin；
- \(\operatorname{DL}\)：binding、额外对象和路径的确定性编码长度。

若以后引入概率解释，必须先显式定义：

\[
p(D\mid b,L)\propto \exp[-\beta V_L(b;D)]
\]

并证明没有重复惩罚。

## 6. 结构抽取的信任边界

结构抽取是本项目最困难且必须独立评价的部分，不能被一句“让 LLM 抽取角色”
代替。

### 6.1 提议器

提议器可使用：

```text
local parser
local embedding/NLI
frozen local LLM
domain metadata parser
```

它只能提出对象、角色和 span 候选。

### 6.2 绑定器

绑定器必须通过 bounded CSP/branch-and-bound 在有限候选上搜索，并执行：

```text
type compatibility
source/target compatibility
required-observable completeness
unit compatibility
order compatibility
law residual
hard-negative residual
```

### 6.3 验证器

验证器不得接收提议器的自然语言结论，只接收：

```text
typed candidate
evidence spans
numeric/symbolic observables
frozen law schema
```

抽取失败、歧义或观测不足必须保留为失败或 abstention，不能由下游 verifier
回填。

## 8. 勒夏特列—楞次示例的边界

该例只保留为直觉性远域类比，不作为 Phase 1 的唯一或首要硬验收。

- 楞次定律明确给出感应电动势相对磁通变化的负号；
- 勒夏特列原理是对平衡扰动后响应方向的定性原则；
- 二者都可以实例化“扰动—诱发响应—局部减弱偏离”的候选 motif；
- 但
  \(|\Delta_D Q+\Delta_R Q|<|\Delta_D Q|\)
  不是在所有表述、尺度和条件下均由两个定律共同保证的无条件等式。

因此系统只能在各自适用条件和可比观测均已绑定时接受局部结构对应。Phase 1
优先使用形式无歧义的 involution、order、balance、pair interaction 和
path equality 合成世界；勒夏特列—楞次放在后续 far-domain diagnostic。

#### 9.1.1 第一次长叙事执行回填（2026-07-30）

source-free 合成 qualification 虽然全绿，但第一次 ARN public intrinsic attempt
在 label-open/scorer 前证明 v1 extractor 不满足 9.1：

```text
items                                      871
required story decisions                 2,613
valid closed-choice decisions               41
story_span_catalog_lexical_count_invalid 2,539
items with complete three-story binding      0
all four arms ARM_RUNTIME_ERROR          871 / 871
```

原因不是 GSCL residual，也不是 MiniLM 语义 encoder，而是 raw-evidence grammar：
它把输入限制为最多 32 个 lexical tokens，并把任意叙事固定压成
`1 generator + 2 objects`。这既不能处理 ARN 的 17–175 词输入，也不能满足
多句文本的 sentence-level generator/object coverage。MiniLM 的正式终止信息另有一个
path-sensitive comparator 误报，但修正路径比较不会改变四臂共同全错的事实。

因此 9.1 增加以下 implementation contract；它们是 extractor 表达能力，不是效果 gate：

```text
deterministic hierarchical sentence/episode partition
bounded candidate count independent of total 1–4-gram count
multiple program-owned generators and objects
every sentence either covered by a typed episode or explicitly abstained
teacher-forced answer-position logits only
typed non-content error taxonomy
content-identity MiniLM binding with separate location proof
```

本次 ARN labels 未打开，scorer 未调用；结果定性为
`implementation-invalid / intrinsic efficacy unknown`。ARN 输入已用于
implementation postmortem，后续可用于不读 labels 的 compatibility diagnostic，
但不得再称为 untouched intrinsic effect cohort。

## 10. 论文 claim 边界

“结构类比不同于表面相似”“用图或关系表示类比”已有大量工作，因此以下内容
本身不构成充分创新：

```text

22 law names
typed edge labels
LLM-generated diagrams
analogy retrieval
```

可检验的论文增量必须同时包括：

1. universal-law schema 的可执行 residual；
2. 对原始 evidence span 的角色绑定；
3. law-specific hard negatives 与反事实拒绝；
4. partial correspondence 到 HypothesisClaim 的内容寻址编译；
5. 与 semantic-only、legacy keyword 和 no-verifier 的因果消融；
6. 在 untouched downstream measurement 上产生 material、retained utility。

在第 6 项成立前，只能声称结构绑定和对应机制成立；不得声称 GSCL 普遍优于
HippoRAG 或已经解决 Assumption Agent 的全部现实域缺口。
